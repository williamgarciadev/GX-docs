# GAM - Initialize Metadata option

This action executes the initialization process of the [GeneXus Access Manager](https://wiki.genexus.com/commwiki/wiki?24746) metadata. That is to say, it defines a GAM repository, GAM version, the administrator, and connection user.

To do so, select **Tools > GAM > Initialize Metadata** in the [GeneXus MenuBar](https://wiki.genexus.com/commwiki/wiki?7212).

**Note**: the GAM database metadata is initialized automatically in the build process (F5). This menu option could be necessary in cases when previous initializations fail.
