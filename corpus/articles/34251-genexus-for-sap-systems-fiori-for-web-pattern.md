# GeneXus for SAP Systems - Fiori for Web Pattern

Patterns empower applications by easily adding new features.

When a pattern is applied, GeneXus creates all the necessary objects to provide the desired behavior without the need of programming them.

GeneXus offers the Fiori for Web pattern that can be applied to a [Transaction object](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?1908,,) or a [Web Panel object](https://wiki.genexus.com/commwiki/wiki?6916). In this case, it is applied to a Transaction.

For example, consider that in a Transaction object called Country, you apply the Fiori for Web pattern (using the Horizon version), as explained in [HowTo: Apply the Fiori for Web pattern for the first time](https://wiki.genexus.com/commwiki/wiki?38862).

You can choose from the following List floorplans. In this case, use the List Report:

`[imagen omitida: wiki id 54741]`

Do not forget to click on “Apply this pattern on save” and save.

Now, if the Country Transaction is placed here:

`[imagen omitida: wiki id 53126]`

you can see several objects below the Transaction, which were created by GeneXus when the pattern was applied. These objects implement the web screens.

Before pressing [Build All](https://wiki.genexus.com/commwiki/wiki?5691), note that GeneXus has configured the FioriLaunchpad object as [Startup Object](https://wiki.genexus.com/commwiki/wiki?5393).

`[imagen omitida: wiki id 53127]`

Therefore, this object containing the references to all the Knowledge Base objects that the GeneXus Fiori for Web pattern is applied to will be compiled and run instead.

Before leaving the web application, note something important: the Launchpad only includes tiles for objects with the Fiori Horizon Pattern applied in the Knowledge Base. For example, in this case, you haven't applied the pattern to the Customer Transaction, so you can't invoke it from the Launchpad. There is an object in the Knowledge Base, generated automatically  —the [Procedure](https://wiki.genexus.com/commwiki/wiki?6293) called ListFioriPrograms— which obtains the collection of programs to be included in the Launchpad:

`[imagen omitida: wiki id 53183]`

When the pattern Fiori List Report for Web is applied to a new Transaction, this Procedure is modified to include a tile with the new pattern.

Since the launchpad will be the main object of the web application, it will surely require tiles to invoke other objects, in addition to those listed (for example, Web Panels created by the developer).  You may even want some of the Fiori List Reports not to be displayed on the launchpad.

You can easily achieve it by creating an object of Procedure type that receives a parameter the list of programs created by ListFioriPrograms, and handles it according to the launchpad's requirements. For example, it may delete some of the programs (tiles) or insert new ones.

Add a tile to invoke the Customer Transaction. To do so, create a Procedure called ListFioriProgramsUsr.

Define the rule that indicates the parameters received and/or returned by the object. In this case, define an input/output variable that will assume the predefined Structured Data Type ProgramNames (because the same name as the data type is given). This data type allows recording the collection of programs to be invoked:

`[imagen omitida: wiki id 53185]`

As you can see, it is a collection of a simple [Structured Data Type (SDT) object](https://wiki.genexus.com/commwiki/wiki?10021) corresponding to a tile's information.

An internal variable of the Procedure for this data type also needs to be defined:

`[imagen omitida: wiki id 34311]`

Load the necessary elements of the tile you want to add in the Procedure Source. Here, for the number of customers indicator, the same Count formula is to be used again. However, note that this time it is a local or inline formula; that is to say, it is not associated with an attribute, and it is only triggered in this Procedure when this statement is run).

Next, add this “tile” to the collection of ProgramNames:

`[imagen omitida: wiki id 34312]`

Lastly, include a call to that Procedure (ListFioriProgramsUsr) in the Procedure generated for the Pattern (ListFioriProgram), at the end of the source (outside the /\* Generated by GeneXus Fiori Pattern <Start> - Do not change \*/ - /\* Generated by GeneXus Fiori Pattern <End> - Do not change \*/ comments).
