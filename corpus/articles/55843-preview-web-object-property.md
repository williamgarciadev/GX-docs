# Preview Web Object property

Indicates the application that shows users the basic data to decide if they must take a Task.

### [Scope](#Scope)

**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Java](https://wiki.genexus.com/commwiki/wiki?12258)  
**Controls:** [Task](https://wiki.genexus.com/commwiki/wiki?17495)

### [Description](#Description)

This property is offered for [Tasks](https://wiki.genexus.com/commwiki/wiki?17495) in [Business Process Diagrams](https://wiki.genexus.com/commwiki/wiki?16486).

It indicates the Web Object that shows users the basic data to decide if they must take a Task.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
