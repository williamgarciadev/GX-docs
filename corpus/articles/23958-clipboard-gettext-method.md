# Clipboard.getText method

Use this method to get a copy of the string that the clipboard contains. It returns an empty string if no text is in the Clipboard.

### [Syntax](#Syntax)

```
Clipboard.getText()
```

**Type returned:**  
Character

### [Example](#Example)

```
Event 'getURLfromClipboard'
   &URL = Clipboard.getText()
Endevent
```
