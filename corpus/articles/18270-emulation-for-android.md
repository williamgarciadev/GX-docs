# Emulation for Android

Applications generated for Smart Devices from GeneXus can be emulated. Before starting with the following steps please check that the [Android Requirements](https://wiki.genexus.com/commwiki/wiki?14449) are correctly installed.

`[imagen omitida: wiki id 37594]`

In order to use the emulator (executed the application on the PC), follow these steps:

* Configure [Generate Android property](https://wiki.genexus.com/commwiki/wiki?18654) in the Smart Devices Generator in True (default value):  
  `[imagen omitida: wiki id 37595]`

* At the end of the [Run process](https://wiki.genexus.com/commwiki/wiki?5692) (F5), if a Smart Device object is set as [Startup Object](https://wiki.genexus.com/commwiki/wiki?5393) and [Main Platform property](https://wiki.genexus.com/commwiki/wiki?18657) is Android, the Emulator will be opened and you will be able to run the application on it.

### [Notes](#Notes)

* If the emulator is running when the build process is run, then it's not started again and only the application deployment/run is executed.
* If an Android device is connected to the computer where the build process is executed, then the application is deployed to this device instead of using an emulator.  
  See [Execution for Android Using the Device](https://wiki.genexus.com/commwiki/wiki?14910) for details.
