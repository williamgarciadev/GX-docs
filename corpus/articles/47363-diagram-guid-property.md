# Diagram Guid property

GUID identifier of a workflow element.

### [Scope](#Scope)

**Objects:** [Business Process Diagram](https://wiki.genexus.com/commwiki/wiki?16486)

### [Description](#Description)

This is the Workflow metadata GUID for the Business Process Diagram's element selected.

It is the value stored in the Workflow database.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at run-time.

### [Availability](#Availability)

This property is available since [GeneXus 17 upgrade 1](https://wiki.genexus.com/commwiki/wiki?46852,,).
