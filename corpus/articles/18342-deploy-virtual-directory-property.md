# Deploy Virtual Directory property

Allows to set a string value representing the name of the virtual directory to which the application will be deployed.

### [Description](#Description)

The value typically represents the name of your application. It's unique to that server.

**Note:** This property is available only when enabling the [Deploy to cloud property](https://wiki.genexus.com/commwiki/wiki?15041).

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply changes made by this property, do a Build with this Only of the object.

### [Scope](#Scope)

**Platforms:** Web(.Net, Java)
