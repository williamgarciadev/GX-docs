# Target JRE property

Defines the Java Runtime Environment version where the deployed application will run

### [Values](#Values)

|  |
| --- |
| **JRE 11** |
| **JRE 17** |
| **JRE 21 (or higher)** |
| **JRE 6** |
| **JRE 7/8** |
| **JRE 9 (or higher)** |

### [Scope](#Scope)

**Generators:** [Java](https://wiki.genexus.com/commwiki/wiki?12258)  
**Level:** Deploy Target Options

### [Description](#Description)

The Target JRE property is used in the deployment engine to determine which JARs to deploy when the libraries have different JARs depending on the JRE version that is used at runtime.
