# BPD Events

An event is something that happens during the execution of a process. They can catch or throw processes. For example, a process could be modeled to start when a certain condition is met or when a timer notifies that a certain time period has elapsed. An event is represented by a circle and the border style shows the type of event.

There are three types of events:

* [Start Events](https://wiki.genexus.com/commwiki/wiki?17269): Start a process flow.
* [Intermediate Events](https://wiki.genexus.com/commwiki/wiki?17270): Happen during the course of a process flow.
* [End Events](https://wiki.genexus.com/commwiki/wiki?17271): End a process flow.
