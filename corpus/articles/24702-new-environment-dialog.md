# New Environment dialog

Creates a new [Environment](https://wiki.genexus.com/commwiki/wiki?7115) in the [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836).

### [Description](#Description)

Through this dialog a new Environment can be created in your Knowledge Base by specifying the basic information needed for that purpose.

* Runtime Environment
  + Local
  + On the Cloud
* Back end
  + Language
  + Data Store
* Front end
  + Generator

`[imagen omitida: wiki id 46807]`

Through the Advanced tab, additional information can be configured.
