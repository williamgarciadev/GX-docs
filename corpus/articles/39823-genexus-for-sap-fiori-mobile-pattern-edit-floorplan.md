# GeneXus for SAP Fiori Mobile Pattern - Edit Floorplan

The Edit [Floorplan](https://wiki.genexus.com/commwiki/wiki?38629,,) is a set of templates that allow you to edit data.

This article explains how to apply it to a [Panel object](https://wiki.genexus.com/commwiki/wiki?24829).

## [How to apply it](#How+to+apply+it)

If you have never applied the FioriMobile Pattern on your KB before, read [GeneXus for SAP Systems - Fiori Mobile Pattern](https://wiki.genexus.com/commwiki/wiki?39800).

On the other hand, once you create a Panel, the following window showing a group of categories will be displayed, each one offering different templates.

If you select the Edit Category, three templates are shown. You can apply any of them the Panel:

`[imagen omitida: wiki id 39824]`

**1. Data Edit**

`[imagen omitida: wiki id 39825]`

**2. Edit with 2 sections**

`[imagen omitida: wiki id 39826]`

**3. Edit with 4 sections**

`[imagen omitida: wiki id 39827]`

Another way to apply a category template to a Panel is the following: Open an existing  Panel, then right-click and select **Apply FioriMobile template to control**:

`[imagen omitida: wiki id 39828]`

## How to incorporate it into your App

To incorporate this into your app, read [Genexus for SAP Fiori Mobile Pattern - Menu Floorplan](https://wiki.genexus.com/commwiki/wiki?39836)
