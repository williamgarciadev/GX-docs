# StartAsBeacon method

Advertises the current device as a beacon.

### [Parameters](#Parameters)

|  |  |  |
| --- | --- | --- |
| **Name** | **Type** | **Description** |
| beaconInfo | [BeaconInfo SDT](https://wiki.genexus.com/commwiki/wiki?27039) | The beacon information to advertice. |

### [Return Value](#Return+Value)

* Boolean
  + Type: [Boolean](https://wiki.genexus.com/commwiki/wiki?4374)
  + Returns a boolean which indicates if the device was succesfully started as a beacon.
