# Execution and process monitoring

You can run a BPD object (pressing the right mouse button over it and selecting the Run option) and the Workflow engine will follow the execution flow of the diagram, invocating the corresponding application when it reaches each activity associated to a GeneXus object.

You should separate the concept of the **Process Definition**, which is related to de business process design information, and the **Process Instance**, which is about the execution instance of a business process diagram. One [Business Process Diagram object](https://wiki.genexus.com/commwiki/wiki?16486) can be executed many times, and each one of those times is a different execution instance of the process.

The [GXflow Client General Structure](https://wiki.genexus.com/commwiki/wiki?17836) provides a user-friendly interface, with many functionalities to control de execution and monitoring of each of the instances process created by the [Workflow Engine](https://wiki.genexus.com/commwiki/wiki?17673).
