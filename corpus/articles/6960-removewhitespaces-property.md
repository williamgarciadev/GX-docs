# RemoveWhiteSpaces Property

Indicates whether the blank spaces, tabulations and end of lines at the beginning and end of the value of a TEXT or ELEMENT type node must be eliminated.

### [Syntax](#Syntax)

**&***DataType***.RemoveWhiteSpaces**

### [Description](#Description)

Indicates if the blank spaces, tabulations and end of lines at the beginning and end of the value of a TEXT or ELEMENT type node must be eliminated.  
  
**Note:**  
The default value is TRUE.

### [Scope](#Scope)

**Extended Data Types:** [XmlReader](https://wiki.genexus.com/commwiki/wiki?6928)  
**Languages:** .NET, Java, Ruby (up to GeneXus X Evolution 3), Visual FoxPro (up to GeneXus X Evolution 3)
