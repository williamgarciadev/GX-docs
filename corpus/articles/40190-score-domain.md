# Score domain

Represents a score value between 0.000 and 1.000 in the context of the [GeneXus Cognitive API](https://wiki.genexus.com/commwiki/wiki?40167). The semantics of a score value depends on the AI task used.

## [Semantics](#Semantics)

|  |  |
| --- | --- |
| [GeneXus Cognitive API - SentimentAnalysis procedure](https://wiki.genexus.com/commwiki/wiki?40184) | Sentiment from negative (0.000) to positive (1.000). |

## [Scope](#Scope)

|  |  |
| --- | --- |
| **AI Tasks:** | [GeneXus Cognitive API - SentimentAnalysis procedure](https://wiki.genexus.com/commwiki/wiki?40184), [GeneXus Cognitive API - Analyze procedure](https://wiki.genexus.com/commwiki/wiki?41041) |
| **Generators:** | [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Java](https://wiki.genexus.com/commwiki/wiki?12258), [Apple](https://wiki.genexus.com/commwiki/wiki?14917), [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Angular](https://wiki.genexus.com/commwiki/wiki?42550), [Angular](https://wiki.genexus.com/commwiki/wiki?42550) |

## [Availability](#Availability)

This domain is available as of [GeneXus 16](https://wiki.genexus.com/commwiki/wiki?35351,,).
