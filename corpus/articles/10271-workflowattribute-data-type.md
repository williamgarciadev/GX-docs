# WorkflowAttribute Data Type

This Data Type represents a generic attribute. It is used in other objects (currently, in the Activity and Process Definition objects) to describe extended attributes. It is provided by the [Workflow API](https://wiki.genexus.com/commwiki/wiki?51350).

### [Properties](#Properties)

|  |  |  |  |
| --- | --- | --- | --- |
| **Property** | **Type** | **Access** | **Description** |
| Name | [WorkflowName](https://wiki.genexus.com/commwiki/wiki?15734) | Read/Write | Attribute name |
| Value | [WorkflowValue](https://wiki.genexus.com/commwiki/wiki?15734) | Read/Write | Attribute value |
