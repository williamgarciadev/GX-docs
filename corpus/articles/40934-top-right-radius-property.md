# Top Right Radius property

Sets the radius of the top right border corner.

### [Scope](#Scope)

**Objects:** Theme for Smart Devices  
**Platforms:** Smart Devices(Android, IOS)

### [Description](#Description)

The purpose of this property is to be able to set the radius of the top right border corner.
