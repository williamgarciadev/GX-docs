# SetAll method

Sets a new style to the cell borders.

### [Syntax](#Syntax)

**&***VarBasedOnExcelDocument***.SetAll*****(**borderStyle***)**

**Where:**  
  
*borderStyle*  
     Is an ExcelBorderStyle data type. It defines the new color and type of the borders.

**Type Returned:**   
Boolean

### [Scope](#Scope)

**Extended Data Types:** [ExcelDocument data type](https://wiki.genexus.com/commwiki/wiki?2476)  
**Generators:** 
[Java](https://wiki.genexus.com/commwiki/wiki?12258)

### [Description](#Description)

It sets borderStyle as the new style of all the borders of the cell.
