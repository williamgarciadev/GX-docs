# Autonumber start property

Allows specifying a number to start automatic numbering.

### [Scope](#Scope)

**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [Java](https://wiki.genexus.com/commwiki/wiki?12258)  
**Level:** [Attribute](https://wiki.genexus.com/commwiki/wiki?7240)

### [Description](#Description)

This property is offered for a key numeric attribute if its Autonumber property is set to True. The values to be given to the property must correspond to a whole number (without decimals).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
