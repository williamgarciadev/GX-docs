# Module Interface Tab

This Tab displays the set of public objects that make up the Module *Interface*. Objects are public and included in the *Interface* when their [Object Visibility property](https://wiki.genexus.com/commwiki/wiki?22473) is set to *Public*.

To view this tab, open the module by selecting it in the [KB Explorer](https://wiki.genexus.com/commwiki/wiki?3210) and pressing F12. You can also right-click on the module and select Open.

The Interface is divided into three sections:

`[imagen omitida: wiki id 32466]`

1. **Services**: Defines the module's API. The objects included in this section are: [Procedures](https://wiki.genexus.com/commwiki/wiki?6293), [Data Providers](https://wiki.genexus.com/commwiki/wiki?5270), [API Objects](https://wiki.genexus.com/commwiki/wiki?46151), and [External Objects](https://wiki.genexus.com/commwiki/wiki?5669).
2. **Data**: The objects included in this section are: [Transactions](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?1908,,), [Business Components](https://wiki.genexus.com/commwiki/wiki?5846) and [Structured Data Types](https://wiki.genexus.com/commwiki/wiki?10021).
3. **User Interface**: The objects included in this section are: [Master Pages](https://wiki.genexus.com/commwiki/wiki?10348), [Web Components](https://wiki.genexus.com/commwiki/wiki?1864), [Web Panels](https://wiki.genexus.com/commwiki/wiki?6916), [Master Panels](https://wiki.genexus.com/commwiki/wiki?46247), [Panels](https://wiki.genexus.com/commwiki/wiki?24829), [Stencils](https://wiki.genexus.com/commwiki/wiki?38418), and [User Controls](https://wiki.genexus.com/commwiki/wiki?39356).
