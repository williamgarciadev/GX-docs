# Team Development node

The purpose of the Team Development Node is to centralize all the properties of the connection with [GeneXus Server](https://wiki.genexus.com/commwiki/wiki?9911).

`[imagen omitida: wiki id 32570]`

It's properties are:

|  |
| --- |
| [Server URL property](https://wiki.genexus.com/commwiki/wiki?21104) |
| [Server Linked Knowledge Base property](https://wiki.genexus.com/commwiki/wiki?21105) |
| [Server Linked Version property](https://wiki.genexus.com/commwiki/wiki?21106) |
| [Server Connection Type property](https://wiki.genexus.com/commwiki/wiki?21107) |
| [Server Username property](https://wiki.genexus.com/commwiki/wiki?21108) |
| [Server Password property](https://wiki.genexus.com/commwiki/wiki?21109) |
