# Configuring GeneXus for using the Chatbot Generator

To build a chatbot using the GeneXus [Chatbot generator](https://wiki.genexus.com/commwiki/wiki?37102), create a [Conversational Flows object](https://wiki.genexus.com/commwiki/wiki?37113) and configure at least, the following properties:

|  |
| --- |
| [NLP Provider property](https://wiki.genexus.com/commwiki/wiki?38931) |
| **Watson** |
| [Authentication Type property](https://wiki.genexus.com/commwiki/wiki?41262) |
| [API Key property](https://wiki.genexus.com/commwiki/wiki?41263) |
| [Region property in Conversational Flows Instance](https://wiki.genexus.com/commwiki/wiki?41264) |
| [User Name property](https://wiki.genexus.com/commwiki/wiki?38932) |
| [User Password property](https://wiki.genexus.com/commwiki/wiki?38933) |
| [Workspace Id property](https://wiki.genexus.com/commwiki/wiki?39768) |
| **DialogFlow** |
| [Dialogflow Agent property](https://wiki.genexus.com/commwiki/wiki?39758) |
| [Google Cloud Project property](https://wiki.genexus.com/commwiki/wiki?39759) |
| [Client Id property](https://wiki.genexus.com/commwiki/wiki?39761) |
| [Client Secret property](https://wiki.genexus.com/commwiki/wiki?39762) |
