# Domain definition

By selecting **View > Domains** in the GeneXus Toolbar, you can view and manage the defined [Domains](https://wiki.genexus.com/commwiki/wiki?7221) in the [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836).

GeneXus automatically creates some domains in each Knowledge Base and of course, you can define your own domains.

When you click on a given domain, the Properties Window is refreshed with that domain properties.

Generic properties that every domain has:

|  |
| --- |
| **Properties** |
| [Name property](https://wiki.genexus.com/commwiki/wiki?6985) |
| [Description property](https://wiki.genexus.com/commwiki/wiki?7446) |
| [Based on property](https://wiki.genexus.com/commwiki/wiki?7782) |
| [Data Type property](https://wiki.genexus.com/commwiki/wiki?7232) |
| [Enum Values property](https://wiki.genexus.com/commwiki/wiki?7379) |

Then, depending on the [data type](https://wiki.genexus.com/commwiki/wiki?7232) configured, different properties are offered.
