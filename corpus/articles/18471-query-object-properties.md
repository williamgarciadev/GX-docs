# Query Object Properties

The following properties define the query object's behavior.

|  |  |
| --- | --- |
| **General Properties** |  |
| [Name property](https://wiki.genexus.com/commwiki/wiki?6985) | In a Data View object, it is the name of the external physical file (or logical file in iSeries), or the name of the external index file |
| [Description property](https://wiki.genexus.com/commwiki/wiki?7446) | Describes the content or purpose of the element |
| [Module/Folder](https://wiki.genexus.com/commwiki/wiki?25540) | Sets the Module or Folder to which the GeneXus object will belong. |
| [Object Visibility property](https://wiki.genexus.com/commwiki/wiki?22473) | Defines whether objects in other Modules can access the object |

|  |  |
| --- | --- |
| **Data Properties** |  |
| Remove duplicates property | Remove duplicate records from the query |
| [Max Rows property](https://wiki.genexus.com/commwiki/wiki?18477) | Limits the number of records shown in a query |
| Text For Null Values property | Text that is displayed when values are null |

|  |  |
| --- | --- |
| **Output Properties** |  |
| Output Type | The default output type for the query: Card, Chart, Pivot, Table and Pivot Table |
| [Title property](https://wiki.genexus.com/commwiki/wiki?7234) | Title that will be displayed on top of the output |
| [Show Values property](https://wiki.genexus.com/commwiki/wiki?19684,,) | Enables you to define if the values that make up the graph will be shown or not |
