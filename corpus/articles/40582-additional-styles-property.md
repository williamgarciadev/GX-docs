# Additional Styles property

Additional UI Design Systems or Themes associated with this platform.

### [Scope](#Scope)

**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917)  
**Level:** Platforms node > Platform

### [Description](#Description)

In the [KB Explorer](https://wiki.genexus.com/commwiki/wiki?3210), under the Customization node, you can find the [Platforms](https://wiki.genexus.com/commwiki/wiki?24284) node.

Under the [Platforms](https://wiki.genexus.com/commwiki/wiki?24284) node, several subnodes are offered, each one corresponding to a specific platform.

For each platform, the **Additional** **Styles property** is offered to allow adding additional [Design System Object](https://wiki.genexus.com/commwiki/wiki?47375)s and [Theme object](https://wiki.genexus.com/commwiki/wiki?16595)s to the specified platform (Android and Apple).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, execute a [Build All](https://wiki.genexus.com/commwiki/wiki?5691).

### [Availability](#Availability)

This property is available since [GeneXus 17 Upgrade 5](https://wiki.genexus.com/commwiki/wiki?48247,,).
