# Knowledge Manager Menu

The Knowledge Manager is a GeneXus component that is in charge of interchanging objects among [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836)s.

`[imagen omitida: wiki id 52322]`

The process of extracting a set of objects is known as [Export](https://wiki.genexus.com/commwiki/wiki?3942), and the process of importing them in another Knowledge Base is known as [Import](https://wiki.genexus.com/commwiki/wiki?3179). When you export, an [XPZ](https://wiki.genexus.com/commwiki/wiki?1922) is created, which is later read when you import.

In addition to the process of importing and exporting objects, you can use the Manage Module References option to install a module provided by other developers. For more information, check: [Manage Module References article.](https://wiki.genexus.com/commwiki/wiki?40172)
