# ControlName property

A name assigned to the control, and used to assign its properties at runtime.

### [Scope](#Scope)

**Objects:** [Transaction](https://wiki.genexus.com/commwiki/wiki?1908), [Web Panel](https://wiki.genexus.com/commwiki/wiki?6916)  
**Controls:** [Button](https://wiki.genexus.com/commwiki/wiki?6011), [Embedded Page](https://wiki.genexus.com/commwiki/wiki?6070), [Error Viewer](https://wiki.genexus.com/commwiki/wiki?6073), [Free Style Grid](https://wiki.genexus.com/commwiki/wiki?6058), [Grid](https://wiki.genexus.com/commwiki/wiki?24817), [Image](https://wiki.genexus.com/commwiki/wiki?5939), [Text Block](https://wiki.genexus.com/commwiki/wiki?5948), [Web Component](https://wiki.genexus.com/commwiki/wiki?31172)

### [Description](#Description)

The name can be any alphanumeric string that begins with a letter, and can include the underscore (\_) character.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
