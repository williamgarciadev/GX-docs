# Minimum Time Between Sends property

Determines the time between calls to the synchronization Send services, which are in charge of sending the changes made in the device to the application server.

### [Scope](#Scope)

**Objects:** [Offline Database](https://wiki.genexus.com/commwiki/wiki?22509)  
**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917)

### [Description](#Description)

This property applies to Offline Native Mobile applications in which an [Offline Database object](https://wiki.genexus.com/commwiki/wiki?22509) has the [Send Changes property](https://wiki.genexus.com/commwiki/wiki?23392,,) set to "When connected."

You have to complete the value (in seconds) corresponding to the minimum time-lapse between calls to the Synchronization.Send programs by the app.
