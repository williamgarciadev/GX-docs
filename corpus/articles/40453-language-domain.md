## [Notes](#Notes)

* This domain is more general than [Locale domain](https://wiki.genexus.com/commwiki/wiki?40450).
* Not every language is available for every [Provider](https://wiki.genexus.com/commwiki/wiki?40195). In such case, GeneXusAI will raise an [GXAI5000 code](https://wiki.genexus.com/commwiki/wiki?40188) with the information needed.
* If some language is not available on the domain definition for your upgrade installation, you can add it at runtime by using [FromString method](https://wiki.genexus.com/commwiki/wiki?12694).  
  e.g.: &language.FromString(!"xx"), being *xx* a valid language code.
