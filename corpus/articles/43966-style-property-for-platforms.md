# Style property for Platforms

Assigns a specific Design System or Theme.

### [Scope](#Scope)

**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Angular](https://wiki.genexus.com/commwiki/wiki?42550), [Apple](https://wiki.genexus.com/commwiki/wiki?14917)  
**Level:** Platforms node > Platform

### [Description](#Description)

In the [KB Explorer](https://wiki.genexus.com/commwiki/wiki?3210), under the Customization node, you can find the [Platforms](https://wiki.genexus.com/commwiki/wiki?24284) node.

Under the [Platforms](https://wiki.genexus.com/commwiki/wiki?24284) node, several subnodes are offered, each one corresponding to a specific platform.

For each platform, the **Style property** is offered to set the desired [Design System Object](https://wiki.genexus.com/commwiki/wiki?47375) or [Theme object](https://wiki.genexus.com/commwiki/wiki?16595).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Availability](#Availability)

This property is available since [GeneXus 17 Upgrade 6](https://wiki.genexus.com/commwiki/wiki?48684,,).
