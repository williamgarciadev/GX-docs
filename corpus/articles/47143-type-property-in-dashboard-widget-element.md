# Type property in Dashboard widget element

Defines the Output type used.

### [Values](#Values)

|  |  |
| --- | --- |
| **Axis** | To slice and dice the data |
| **Datum** | It contain the relevant information provided by the query. |

### [Scope](#Scope)

**Objects:** [Dashboard](https://wiki.genexus.com/commwiki/wiki?36769)  
**Controls:** [Dashboard Widget](https://wiki.genexus.com/commwiki/wiki?36779)

### [Description](#Description)

Defines how a [query element](https://wiki.genexus.com/commwiki/wiki?19788) from a [Dashboard widget](https://wiki.genexus.com/commwiki/wiki?36779) will be displayed, it can be set as an Axis or directly as a Datum value.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
