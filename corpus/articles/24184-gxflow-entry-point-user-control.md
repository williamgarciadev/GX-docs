# GXflow Entry Point User Control

The GXflow Standard Client is an application that allows users to get access to [GXflow Inbox](https://wiki.genexus.com/commwiki/wiki?7465), [GXflow Outbox](https://wiki.genexus.com/commwiki/wiki?10052), [GXflow My Processes](https://wiki.genexus.com/commwiki/wiki?10133), My Performance, and other applications called 'components'. These components allow users to interact with the workflow engine in order to create/execute/send [BPD Tasks](https://wiki.genexus.com/commwiki/wiki?17495). However, sometimes it is necessary to get access to these components from another generated application.

### [Purpose](#Purpose)

This user control is used to embed any of the GXflow components within any other generated application.

### [Description](#Description)

You can find the zip file containing the GXflow Entry Point User Control in your [GeneXus](https://wiki.genexus.com/commwiki/wiki?1756) installation directory

```
<GeneXusX>\Packages\GXPM\Extra
```

where <GeneXusX> is the GeneXus installation folder.
