# Knowledge Manager Menu (GeneXus 18 latest upgrade or prior)

The Knowledge Manager menu provides different options for managing knowledge (objects, modules, etc.).

`[imagen omitida: wiki id 52322]`

The process of selecting a set of [GeneXus objects](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?1866,,) to distribute (share) is called [Export](https://wiki.genexus.com/commwiki/wiki?3942), and the process of importing them into another [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836) is called [Import](https://wiki.genexus.com/commwiki/wiki?3179).

When you export, an [XPZ](https://wiki.genexus.com/commwiki/wiki?1922) file is created. When you import, you must indicate an XPZ file.

In addition to importing and exporting objects, you can use the [Manage Module References](https://wiki.genexus.com/commwiki/wiki?40172) option to install modules provided by other developers.

If your Knowledge Base is administered by a [GeneXus Server](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?31337,,), the [Team Development](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?20864,,) option will also be available.

The [Explore Remote Knowledge Base](https://wiki.genexus.com/commwiki/wiki?42133) option allows you to explore and integrate knowledge from a remote Knowledge Base hosted in a GeneXus Server.

Another available option is [View Last Import Log](https://wiki.genexus.com/commwiki/wiki?9574).
