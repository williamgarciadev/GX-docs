# Block Insert Performance

Some of the charts here are the result of different performance tests.  
  
These values are based on specific tests using .NET and were taken from a particular environment. The result may vary because there are many variables that can affect these values, such as network speed, driver version, etc. The values are for illustrative purposes only and should not be taken as a universal measure.
