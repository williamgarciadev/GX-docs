# GeneXus 18 Compatibility Section (GeneXus 18)

This document states an overview of the compatibility issues or considerations you may need to take into account when adopting GeneXus 18 and, afterward, links to more details.

These considerations should be taken into account before [Steps to build with GeneXus 18 a KB of GeneXus 17 or prior](https://wiki.genexus.com/commwiki/wiki?52345).

## [Changes in Software Requirements](#Changes+in+Software+Requirements)

### [Requirement changes in GeneXus (IDE & Code generation)](#Requirement+changes+in+GeneXus+%28IDE+%26+Code+generation%29)

* By default, an internet connection is required for building your applications. This happens when the build systems require new or updated packages from Maven or Nuget repositories.
* Compilation of Java programs may require more memory. This is because Gradle is used to compile, and Gradle by default tries to parallelize compilation for performance optimization.  
  Furthermore, JDK 11 or higher is recommended to improve compilation performance.
* Native mobile apps compilation supports macOS Ventura
* .NET 6 is required when using the [GeneXus .NET Generator](https://wiki.genexus.com/commwiki/wiki?38604)

### [Requirement changes in the generated application](#Requirement+changes+in+the+generated+application)

* Changes in browser support:
  + Internet Explorer as a browser to be used in generated web applications has been discontinued. Special code to support Internet Explorer has been removed and associated potential security risks lowered.
  + Web applications require Browsers with [CSS Cascade Layers](https://developer.mozilla.org/en-US/docs/Web/CSS/@layer) support. Also, native mobile apps that load those web applications using [Component domain](https://wiki.genexus.com/commwiki/wiki?16186) (Webview), require devices with the corresponding browser version or an up-to-date base software.  
    The following is a detailed list of browsers that support this feature <https://caniuse.com/css-cascade-layers>. Note that on Apple devices, iOS 15.4 or higher is required and Android devices require an updated [Android System Webview](https://play.google.com/store/apps/details?id=com.google.android.webview&hl=en&gl=US) as stated on <https://caniuse.com/css-cascade-layers>.  
    Note: Although as of November 2022, 89% of the browsers support CSS Cascade Layers (*source: <https://caniuse.com/css-cascade-layers>*), [GeneXus 18 upgrade 1](https://wiki.genexus.com/commwiki/wiki?51081) will remove this requirement for applications that use [Theme object](https://wiki.genexus.com/commwiki/wiki?16595) to improve compatibility. It will remain as a requirement when using [Design System Object](https://wiki.genexus.com/commwiki/wiki?47375).
* Changes in the backend
  + .NET 6 is required on applications generated by the [GeneXus .NET Generator](https://wiki.genexus.com/commwiki/wiki?38604)

More information: [GeneXus 18 hardware and software requirements](https://wiki.genexus.com/commwiki/wiki?30900)

### [Third-Party Software Requirements: User Controls, Patterns, and Extensions](#Third-Party+Software+Requirements%3A+User+Controls%2C+Patterns%2C+and+Extensions)

* If you are using User Controls, Extensions, or Patterns provided by others, please contact their manufacturers, because they may need to provide a new version of them.

## [Backward compatibility of KBs](#Backward+compatibility+of+KBs)

Although you can open with previous versions of GeneXus the KBs created with GeneXus 18, you may not be able to open every component, since those versions do not have the required features to recognize them. Furthermore, you may not be able to build those KBs with previous versions. For example, the information of [KB Platforms](https://wiki.genexus.com/commwiki/wiki?24284) saved by GeneXus 18 in KBs created with GeneXus 18 cannot be read with previous versions.

## [Deprecated Features](#Deprecated+Features)

* [HTML Editor](https://wiki.genexus.com/commwiki/wiki?7673). You should use this Editor only on existing objects. New objects should be developed using the [Web Abstract Editor](https://wiki.genexus.com/commwiki/wiki?24795)
* The value 'Previous Version Compatible' of [Web User Experience property](https://wiki.genexus.com/commwiki/wiki?22449) has been deprecated. You should [convert to Smooth Web UX](https://wiki.genexus.com/commwiki/wiki?22561,,)
* [Developer Menu](https://wiki.genexus.com/commwiki/wiki?18484) has been deprecated; related features for faster prototyping will happen in [Launchpad Tool Window](https://wiki.genexus.com/commwiki/wiki?52315).

## [Removed Features](#Removed+Features)

* The Build > Deploy to GeneXus Cloud Services option has been removed and the associated services have been discontinued
* The standalone [Theme Editor](https://wiki.genexus.com/commwiki/wiki?2544,,) has been discontinued. For [DesignOps](https://wiki.genexus.com/commwiki/wiki?46870) use the [Design Import option](https://wiki.genexus.com/commwiki/wiki?46882)

## [Renamed Features](#Renamed+Features)

* 'Work with for Smart Devices' Pattern has been renamed to 'Work With'.

## [Other Changes](#Other+Changes)

### [Changes in new KBs](#Changes+in+new+KBs)

New KBs are created with [Unanimo](https://wiki.genexus.com/commwiki/wiki?48382). The most remarkable changes when you work on KBs created with GeneXus 18, besides the GeneXusUnanimo Module, are:

* the new KB uses a [Design System Object](https://wiki.genexus.com/commwiki/wiki?47375) as its default style instead of a [Theme object](https://wiki.genexus.com/commwiki/wiki?16595),
* some objects distributed by GeneXus are now part of a 'General' module and its submodules,
* the default value for [Generate OpenAPI interface property](https://wiki.genexus.com/commwiki/wiki?31859) changed to 'Yes',

### [Changes in GAM and GXflow UI:](#Changes+in+GAM+and+GXflow+UI%3A)

* The out-of-the-box GXflow and GAM back offices and the corresponding frontend objects are based on [Unanimo design system](https://wiki.genexus.com/commwiki/wiki?48382).

### [Changes in Work with for Web Pattern](#Changes+in+Work+with+for+Web+Pattern)

* New instance names include the string 'Web' to distinguish them from instances of the Work With Pattern.

### [API Changes](#API+Changes)

* GXflow API discontinues the use of WorkflowRestriction and WorkflowRestrictionDefinition data types. There is information regarding alternatives in [SAC 51781](https://www.genexus.com/developers/websac?es,,,51781)
* The endpoint of web sockets has changed. More information in [SAC 71701](https://www.genexus.com/developers/websac?es,,,51701)
