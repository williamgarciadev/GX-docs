# Assembly version number property

It determines the version number to be assigned to the ‘Strong Named assemblies’.

### [Description](#Description)

It only applies when the [Generate strong named assemblies property](https://wiki.genexus.com/commwiki/wiki?8950) is set to Yes.

Default value: 1.0.0.0

### [Scope](#Scope)

**Platforms:** Web(.Net)
