# BackColorOdd property

To allow modification of the back color of even lines in a grid or free style grid, with the value ‘Header’ or ‘Report’ in the BackColorStyle property.

### [Syntax](#Syntax)

**control.** BackColorOdd = expression   

Type returned: Numeric

**Where:**  
*control*   
Is the name of a control inserted in the form.  
  
*expression*  
Is a numeric representing an RGB color.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at run-time.

### [Scope](#Scope)

**Objects:** Transaction, Web Panel  
**Platforms:** Web(.Net, Java)  
**Controls:** FreeStyle Grid, Grid
