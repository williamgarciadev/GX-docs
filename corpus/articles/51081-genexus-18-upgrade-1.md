# GeneXus 18 Upgrade 1

This article is an overview of GeneXus 18 Upgrade 1 features (compared to [GeneXus 18](https://wiki.genexus.com/commwiki/wiki?51066)) and what needs to be taken into account to adopt it.

It has been released on December 21th, 2022.

## [Download](#Download)

<https://www.genexus.com/en/developers/downloadcenter?data=5972>

## [Overview](#Overview)

This upgrade provides overall stability improvements, especially related to the IDE and Design Systems.

#### [UX and Design Ops](#UX+and+Design+Ops)

* [Cascade Layers in CSS](https://wiki.genexus.com/commwiki/wiki?53234) on applications generated by Java and .NET that use [Design System Object](https://wiki.genexus.com/commwiki/wiki?47375).
* UI consistency improvements in Unanimo
* Improvements related to importing Designs from Figma or Sketch
* Support for Events in local notifications

#### [Performance](#Performance)

* Support for accessing [Read Replicas](https://www.genexus.com/developers/websac?en,,,52177)
* [Join optimization for tables with huge volumes of data](https://www.genexus.com/developers/websac?en,,,39325)
* [iOS startup performance improved](https://www.genexus.com/developers/websac?en,,,52205)

#### [Security](#Security)

* OWASP: [Documentation](https://wiki.genexus.com/commwiki/wiki?50180) and [Security Scanner](https://wiki.genexus.com/commwiki/wiki?46412) updated to latest guidelines

#### [Backend](#Backend)

* Package Sources of an Azure services backend deployment unit for uploading them to GitHub
* Service Bus API (for Azure Services Bus). See [Message Broker API](https://wiki.genexus.com/commwiki/wiki?51782) for more information.
* [Support for providing gRPC services in GeneXus (Beta)](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?53430,,)
* [Log settings with environment variables](https://wiki.genexus.com/commwiki/wiki?53361)
* [Log format](https://wiki.genexus.com/commwiki/wiki?53005) can be semi-structured

#### [GeneXus for SAP pack](#GeneXus+for+SAP+pack)

* Fiori Pattern now is based on [Design System Object](https://wiki.genexus.com/commwiki/wiki?47375)
* [GeneXus for SAP Systems](https://wiki.genexus.com/commwiki/wiki?33616) documentation overhauled

### [Compatibility & Installation](#Compatibility+%26+Installation)

* Updated [Android Requirements](https://wiki.genexus.com/commwiki/wiki?14449)
* The minimum supported iOS version is now 12, and the watchOS version is 5. (tvOS minimum version was already set to 12 in [GeneXus 17 Upgrade 11](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?49972,,))
* To maintain compatibility with [GeneXus 17 Upgrade 11](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?49972,,) or prior, applications that use [Web Theme object](https://wiki.genexus.com/commwiki/wiki?6420) do not use CSS layers.
