# Disambiguation property

Enables disambiguations for this instance.

### [Scope](#Scope)

**Objects:** [Conversational Flows Instance](https://wiki.genexus.com/commwiki/wiki?37113)

### [Description](#Description)

If its value is True, it activates all disambiguation functions. Otherwise, when False, the disambiguation function is not considered.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Availability](#Availability)

This property is available since [GeneXus 17 upgrade 3](https://wiki.genexus.com/commwiki/wiki?47659,,).
