# ClientStorage.Clear method

Clears all pairs of key-value stored in the device via [ClientStorage.Set method](https://wiki.genexus.com/commwiki/wiki?24133).

### [Syntax](#Syntax)

**ClientStorage.Clear()**

**Type returned:**  
None

### [Scope](#Scope)

**Objects:** [Objects for Native Mobile applications development](https://wiki.genexus.com/commwiki/wiki?20087), [Offline Procedures](https://wiki.genexus.com/commwiki/wiki?6293)  
**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917)

### [Availability](#Availability)

This feature is available since [GeneXus X Evolution 3](https://wiki.genexus.com/commwiki/wiki?20247,,)
