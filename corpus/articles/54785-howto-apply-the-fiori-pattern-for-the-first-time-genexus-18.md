# HowTo: apply the Fiori pattern for the first time (GeneXus 18 Upgrade 3 or prior)

This article explains how to apply the Fiori pattern for the first time when you are working with [GeneXus for SAP Systems](https://wiki.genexus.com/commwiki/wiki?33616).

Consider a Transaction, in this case it is called Customer. Look at the [Patterns](https://wiki.genexus.com/commwiki/wiki?2814) tab of the that Transaction. It offers the following tabs:

* [Fiori for Web](https://wiki.genexus.com/commwiki/wiki?34251)
* [Work With for Web](https://wiki.genexus.com/commwiki/wiki?25475)
* [Work With](https://wiki.genexus.com/commwiki/wiki?5636)

Focus on the Fiori for Web tab.

The first time you intend to apply the Fiori for Web Pattern in one KB, you will find the "Initialize Fiori" link in order to import everything which is necessary to work with that pattern.

`[imagen omitida: wiki id 54727]`

You must select that link and GeneXus will start to import the Fiori theme and all the [floorplans](https://wiki.genexus.com/commwiki/wiki?38629,,).

Once finished, you will be able to apply the Fiori pattern (by selecting the "Apply this pattern on save" checkbox) and select a Floorplan (by clicking a new link).

Once you click on the "Select floorplant..." link, you can choose from the following List floorplans:

`[imagen omitida: wiki id 54741]`

Check this link to learn more about the different versions of the Fiori Pattern: [GeneXus for SAP Systems - Initialize Fiori](https://wiki.genexus.com/commwiki/wiki?54721). This article also explains a different way to initialize the different Fiori Patterns.
