# Unsetting a Startup Object

To unset a [Startup Object](https://wiki.genexus.com/commwiki/wiki?5393) defined for an [Environment](https://wiki.genexus.com/commwiki/wiki?7115), go to the [Startup Object property](https://wiki.genexus.com/commwiki/wiki?13606), right-click on it, and select the "Use Default" value as shown in the image below.

`[imagen omitida: wiki id 5399]`

After that, when you press F5, the [Launchpad Tool Window](https://wiki.genexus.com/commwiki/wiki?52315) will open.
