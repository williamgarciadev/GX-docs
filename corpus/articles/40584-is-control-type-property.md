# Is Control Type property

Specifies if this control is wanted to be included -in addition to the standard controls- within the Control Type property of Attributes and Variables.

### [Values](#Values)

|  |
| --- |
| **False** |
| **True** |

### [Description](#Description)

This property is offered for [User Control objects](https://wiki.genexus.com/commwiki/wiki?39356) to indicate whether it is wanted to be included -in addition to the standard controls- within the Control Type property of Attributes and Variables.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Availability](#Availability)

This property is available since [GeneXus 16](https://wiki.genexus.com/commwiki/wiki?35351,,).

### [Scope](#Scope)

**Objects:** User Control
