# Roles property in Task control

Configures the roles that have execute permissions for the Task o to start the process.

### [Scope](#Scope)

**Controls:** [Task](https://wiki.genexus.com/commwiki/wiki?17495)

### [Description](#Description)

Determines the associated roles to execute the Task.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
