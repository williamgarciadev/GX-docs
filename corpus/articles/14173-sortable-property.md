# Sortable property

Enables or disables the possibility of ordering a Grid by a certain column.

### [Values](#Values)

|  |
| --- |
| **False** |
| **True** |

### [Scope](#Scope)

**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [Java](https://wiki.genexus.com/commwiki/wiki?12258)  
**Controls:** [Grid](https://wiki.genexus.com/commwiki/wiki?24817)

### [Description](#Description)

Default value: True.

Allows you to make a [Grid](https://wiki.genexus.com/commwiki/wiki?24817) defined in a [Transaction Web Layout](https://wiki.genexus.com/commwiki/wiki?8057) or [Web Panel Web Layout](https://wiki.genexus.com/commwiki/wiki?8132) sortable by any column.

True: the end-user will have the possibility to order Grids by a certain column by clicking the column’s header.

False: the end-user will not have the possibility to order Grids by a certain column by clicking the column’s header.
