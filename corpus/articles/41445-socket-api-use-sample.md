# Socket API use Sample

This article describes the use of the Socket API with a simple example that simulates a chat using the [Server.Socket external object](https://wiki.genexus.com/commwiki/wiki?22442) and [Client.Socket External Object](https://wiki.genexus.com/commwiki/wiki?41299) through a WebSocket.

This example shows a message that is sent to all devices or to a specific device, as well as a message sent from an Android client to the server, achieving the purpose of bidirectional communication.
