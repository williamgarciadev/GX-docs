# Custom assign application property

Allows customizing the selection dialog of the users responsible for executing the selected tasks.

### [Scope](#Scope)

**Objects:** [Business Process Diagram](https://wiki.genexus.com/commwiki/wiki?16486)  
**Controls:** [Task](https://wiki.genexus.com/commwiki/wiki?17495)

### [Description](#Description)

**Note:**this property is only available when the [Is ad-hoc property](https://wiki.genexus.com/commwiki/wiki?11875)=True
