# gx-grid-row-class property (GeneXus 18 Upgrade 2 or prior)

Styles all the grid rows.

### [Scope](#Scope)

**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917), [Java](https://wiki.genexus.com/commwiki/wiki?12258), [Angular](https://wiki.genexus.com/commwiki/wiki?42550)  
**Level:** [Design System Style Class](https://wiki.genexus.com/commwiki/wiki?49309)

### [Description](#Description)

You can configure this property in the [Styles](https://wiki.genexus.com/commwiki/wiki?47379) tab of a [Design System Object](https://wiki.genexus.com/commwiki/wiki?47375) for the Grid class.

Since [GeneXus 18 upgrade 1](https://wiki.genexus.com/commwiki/wiki?51081) you may configure it for the FreeStyle Grid class as well.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [Availability](#Availability)

This property is available since [GeneXus 17 Upgrade 6](https://wiki.genexus.com/commwiki/wiki?48684,,).
