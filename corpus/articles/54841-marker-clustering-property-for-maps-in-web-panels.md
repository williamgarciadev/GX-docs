# Marker Clustering property for Maps in Web Panels

Shows markers that are close to each other in a single cluster.

### [Syntax](#Syntax)

**control.** Marker Clustering   

Default value: False

### [Values](#Values)

|  |
| --- |
| **False** |
| **True** |

### [Scope](#Scope)

**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Java](https://wiki.genexus.com/commwiki/wiki?12258)  
**Controls:** [Map](https://wiki.genexus.com/commwiki/wiki?5029)

### [Description](#Description)

When the **Marker Clustering** property of a [Map User Control](https://wiki.genexus.com/commwiki/wiki?5029) is set to True, a large number of markers that are close to each other are grouped into one cluster (which is a marker).

If there are many near points, the markers do not overlap, and they are shown as follows:

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies both at runtime and at design time.

### [Samples](#Samples)

Drag a [Map User Control](https://wiki.genexus.com/commwiki/wiki?5029) to the Web Layout of a Web Panel. A [subroutine](https://wiki.genexus.com/commwiki/wiki?24767) will be created.

Next, you have to customize the subroutine code suggested. Also, check the variables' data types and edit the data according to your needs.

### [Availability](#Availability)

This property is available since [GeneXus 18 Upgrade 4](https://wiki.genexus.com/commwiki/wiki?54238).
