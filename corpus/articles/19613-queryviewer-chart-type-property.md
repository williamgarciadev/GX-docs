# QueryViewer Chart Type property

This property allows developers to select the type of chart to be used by the [QueryViewer control](https://wiki.genexus.com/commwiki/wiki?9075) when the [Type](https://wiki.genexus.com/commwiki/wiki?19612) property has the Chart value.
