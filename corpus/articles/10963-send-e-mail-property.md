# Send e-mail property

Allows sending an e-mail notifying those responsible for the subsequent Tasks that they will receive a Task.

### [Values](#Values)

|  |
| --- |
| **False** |
| **True** |

### [Scope](#Scope)

**Controls:** [Task](https://wiki.genexus.com/commwiki/wiki?17495)

### [Description](#Description)

The default value for this property is False.

This property helps you define the behavior of the Business Process.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
