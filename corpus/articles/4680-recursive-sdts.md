# Recursive SDTs

[SDTs](https://wiki.genexus.com/commwiki/wiki?10021) can be defined recursively. To achieve this, the Generator initializes the SDT at runtime just before it is used (not at the beginning of the program like it did in previous versions).  
  
[Recursive Data Providers](https://wiki.genexus.com/commwiki/wiki?4891) is a Recursive Data Provider using this feature.
