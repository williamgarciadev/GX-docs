# Setting an Object as Startup Object

There are two ways to set a [Main Object](https://wiki.genexus.com/commwiki/wiki?5770) as the [Startup Object](https://wiki.genexus.com/commwiki/wiki?5393). To do so, you can:

1) Right-click on the desired object to open the context menu and select the **Set As Startup Object** option:

`[imagen omitida: wiki id 5395]`

2) Go to the Preferences window and set the [Startup Object property](https://wiki.genexus.com/commwiki/wiki?13606) at the environment level.

`[imagen omitida: wiki id 5396]`

Select the object you want to start running when F5 is pressed.

**Note**: If you select an object that is not Main yet, GeneXus will automatically set its Main Object property to True.
