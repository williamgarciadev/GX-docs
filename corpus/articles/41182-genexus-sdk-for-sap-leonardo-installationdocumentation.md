# GeneXus SDK for SAP Leonardo: InstallationDocumentation

## [Install GeneXus for SAP Systems](#Install+GeneXus+for+SAP+Systems)

To install the Genexus SDK for SAP Leonardo you need to have previously installed GeneXus for SAP Systems

If you don't have GeneXus for SAP Systems installed, please visit the following links for further information

* [GeneXus for SAP Systems Requirements](https://wiki.genexus.com/commwiki/wiki?33981)
* [GeneXus for SAP System Installation](https://wiki.genexus.com/commwiki/wiki?33839)
* [GeneXus for SAP Systems License Activation](https://wiki.genexus.com/commwiki/wiki?33840)

## [Get GeneXus SDK for SAP Leonardo](#Get+GeneXus+SDK+for+SAP+Leonardo)

You have two option in order to obtain GeneXus SDK for SAP Leonardo:

* Create a KB from GeneXus Server ([KB V1 GX16 from GX Server](http://samples.genexusserver.com/v16/kbdashboard.aspx?GeneXusSDKSAPLeonardoV1))

or

* Import [this xpz (V1 for GX16)](https://wiki.genexus.com/commwiki/wiki?41861,,) to your KB

## [Create KB from GeneXus Server with GeneXus SDK for SAP Leonardo](#Create+KB+from+GeneXus+Server+with+GeneXus+SDK+for+SAP+Leonardo)

In GeneXus IDE, go to File/New/Knowledge base from GeneXus Server

`[imagen omitida: wiki id 42372]`

Use this URL: samples.genexusserver.com/v16/kbdashboard.aspx?GeneXusSDKSAPLeonardoV1

`[imagen omitida: wiki id 42373]`

You will obtain a new KB with the module GeneXusSAPLeonardo.

## [Import GeneXus SDK for SAP Leonardo](#Import+GeneXus+SDK+for+SAP+Leonardo)

Import SDK Module to your Knowledge Base using the Import feature in the Knowledge Manager menu option.

`[imagen omitida: wiki id 41795]`

After you set the Import path where the downloaded .xpz file is stored, the objects in the file will load and the Import is ready to start.

`[imagen omitida: wiki id 41796]`

After the Import process is finished your Knowledge Base should have the following GeneXus objects.

`[imagen omitida: wiki id 41797]`

After importing you are ready to use this module! Please, refer to [this article to see how to use it.](https://wiki.genexus.com/commwiki/wiki?41183)
