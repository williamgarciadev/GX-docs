# Hide value property

Hides value.

### [Scope](#Scope)

**Objects:** Dashboard

### [Description](#Description)

Hides the Date or Datetime [Dashboard Element](https://wiki.genexus.com/commwiki/wiki?36769) value if a [grouping](https://wiki.genexus.com/commwiki/wiki?24777) is set.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Samples](#Samples)

For example, if you enable the [Group by semester property](https://wiki.genexus.com/commwiki/wiki?40433) and the Hide property, the Date or Datetime attribute is not displayed:

`[imagen omitida: wiki id 40460]`

### [Availability](#Availability)

This property is available since [GeneXus 15 upgrade 12](https://wiki.genexus.com/commwiki/wiki?39737,,).
