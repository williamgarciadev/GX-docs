# User Name property

Specify the Watson Assistant user name.

### [Scope](#Scope)

**Objects:** Conversational Flows

### [Description](#Description)

In the [Conversational Flows object](https://wiki.genexus.com/commwiki/wiki?37113) the [NLP Provider property](https://wiki.genexus.com/commwiki/wiki?38931) can be set to "Watson" value. In that case, you have to indicate the User Name of the Watson account.

For more information about the configuration to be done in order to use Watson provider, see [Configuring GeneXus for using the Chatbot Generator](https://wiki.genexus.com/commwiki/wiki?37096).

### [Availability](#Availability)

This property is available since [GeneXus 15 upgrade 12](https://wiki.genexus.com/commwiki/wiki?39737,,).
