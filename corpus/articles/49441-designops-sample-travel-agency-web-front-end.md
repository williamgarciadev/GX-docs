# DesignOps - Sample - Travel Agency web front-end

This article refers to a design file for a Travel Agency web front end made with the [Sketch design tool](https://www.sketch.com/) and exported by [GxDesignOps plugin](https://wiki.genexus.com/commwiki/wiki?46875) in .gxsketch format.

## [Sample download](#Sample+download)

`[imagen omitida: wiki id 40856]` [Travel Agency Web Frontend.gxsketch](https://wiki.genexus.com/commwiki/wiki?49442,,)

## [Importing gxsketch file](#Importing+gxsketch+file)

Basically, you must follow the instructions described in the [Design Import option](https://wiki.genexus.com/commwiki/wiki?46882) article.

Once you select the .gxsketch file from your filesystem and after checking the "Import as Web Panels" option, by clicking on the "Load" button the Sketch to GeneXus dialog will be shown as follows:

`[imagen omitida: wiki id 49443]`

When you are sure you want to import the design file, just click on the "OK" button and the Output dialog (General tab) will show you the import progress. Once it has finished importing, check the generated web-panels and how they look. Also, check the style-classes, image objects, and file objects (fonts) imported.

## [Runtime execution](#Runtime+execution)

Finally, run the [Developer Menu](https://wiki.genexus.com/commwiki/wiki?18484) in order to see the generated web-panels.

**Warning**: Do not expect it to be perfect. It is highly probable that you or your designer must fix something in the design file or the generated objects (abstract layout or theme-class).
