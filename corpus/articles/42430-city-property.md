### [Scope](#Scope)

**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Java](https://wiki.genexus.com/commwiki/wiki?12258)  
**Controls:** [Map](https://wiki.genexus.com/commwiki/wiki?5029)

### [Description](#Description)

This property allows you to select a City and center the map on it with no need to configure the [Latitude property](https://wiki.genexus.com/commwiki/wiki?42431) nor the [Longitude property](https://wiki.genexus.com/commwiki/wiki?42432).

To set another location in addition to those offered, set this property to Specific Coordinate and enter the coordinates for the [Latitude property](https://wiki.genexus.com/commwiki/wiki?42431) and [Longitude property](https://wiki.genexus.com/commwiki/wiki?42432).

To add a city to the combo, edit the User Control/Map/Mapdefinition.xml file.
