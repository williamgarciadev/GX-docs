# Minimum Height property

Determines the number of rows in a Panel Grid with Multiple by Size in Items Layout Mode and Horizontal scroll direction. The Grid will fit as many rows as possible with at least this height; 0 means the entire height will be used.

### [Scope](#Scope)

**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Angular](https://wiki.genexus.com/commwiki/wiki?42550), [Apple](https://wiki.genexus.com/commwiki/wiki?14917)  
**Controls:** [Grid](https://wiki.genexus.com/commwiki/wiki?24817)

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
