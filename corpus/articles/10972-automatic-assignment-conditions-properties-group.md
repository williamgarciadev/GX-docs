# Automatic Assignment Conditions Properties Group

This is a group of properties which allows you to define conditions through which tasks can be automatically assigned.

They can be found in a task's properties (in a [Business process diagram](https://wiki.genexus.com/commwiki/wiki?16486)), under the node **Advanced properties>Automatic Assignment Conditions**:
