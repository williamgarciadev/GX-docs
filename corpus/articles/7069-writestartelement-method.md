# WriteStartElement method

Starts a compound element.

### [Syntax](#Syntax)

**&***VarBasedOnXmlWriter***.WriteStartElement(***ElementName***)**

**Where:**  
  
*ElementName*  
    Name of the element to be created.

### [Scope](#Scope)

**Extended Data Types:** [XmlWriter](https://wiki.genexus.com/commwiki/wiki?6938)  
**Generators:**

[.NET](https://wiki.genexus.com/commwiki/wiki?38604),
[.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Java](https://wiki.genexus.com/commwiki/wiki?12258),
Ruby (up to GeneXus X Evolution 3), Visual Basic (up to GeneXus X Evolution 3),
Visual FoxPro (up to GeneXus X Evolution 3)

### [Description](#Description)

This method starts a compound element. This element may have sub-elements, so it is valid to nest calls to WriteStartElement/WriteElement.
