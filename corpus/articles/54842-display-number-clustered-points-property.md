# Display Number Clustered Points property

Shows the number of markers of each cluster when set to True.

### [Values](#Values)

|  |
| --- |
| **False** |
| **True** |

### [Scope](#Scope)

**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Java](https://wiki.genexus.com/commwiki/wiki?12258)  
**Controls:** [Map](https://wiki.genexus.com/commwiki/wiki?5029)

### [Description](#Description)

This property is offered when the [Marker Clustering property for Maps in Web Panels](https://wiki.genexus.com/commwiki/wiki?54841) = True.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies both at runtime and at design time.

### [Samples](#Samples)

Drag a [Map User Control](https://wiki.genexus.com/commwiki/wiki?5029) to the Layout of a [Web Panel object](https://wiki.genexus.com/commwiki/wiki?6916).

After setting the [Marker Clustering property for Maps in Web Panels](https://wiki.genexus.com/commwiki/wiki?54841) of the Map to True, the **Display Number Clustered Points** property is offered. When its value is set to True, at runtime the Web Panel Layout will show the Map with the number of markers of each cluster:

`[imagen omitida: wiki id 54894]`

Note that the [Marker Clustering property for Maps in Web Panels](https://wiki.genexus.com/commwiki/wiki?54841) and the **Display Number Clustered Points** property make sense when there is a considerable set of points loaded on the map.

### [Availability](#Availability)

This property is available since [GeneXus 18 Upgrade 4](https://wiki.genexus.com/commwiki/wiki?54238).
