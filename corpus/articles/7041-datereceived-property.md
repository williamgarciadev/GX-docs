# DateReceived Property

This property indicates the date and time on which the message was received by the server.

### [Syntax](#Syntax)

**&***DataType***.DateReceived**  
  
**Type Returned:**   
DateTime

### [Description](#Description)

This property is read-only, therefore, it cannot be assigned.

### [Scope](#Scope)

**Extended Data Types:** [MailMessage](https://wiki.genexus.com/commwiki/wiki?6925)  
**Languages:** .NET, Java, Ruby (up to GeneXus X Evolution 3), Visual FoxPro (up to GeneXus X Evolution 3)
