# Control Properties - Font

**Deprecated**: Since [GeneXus 18](https://wiki.genexus.com/commwiki/wiki?51066). Replaced by [Web Abstract Editor](https://wiki.genexus.com/commwiki/wiki?24795).

**Warning**: These properties are offered only if you use the HTML Editor. You should use the HTML Editor only on existing objects. New objects should be developed using the Web Abstract Editor. [Here](https://wiki.genexus.com/commwiki/wiki?25250) you find a guide on how to use it. You may also want to convert existing applications so that they can be responsive. More information on that at [How to convert my application to make it responsive](https://wiki.genexus.com/commwiki/wiki?25214).

The following properties allow setting the font for a control in a Form.

|  |  |
| --- | --- |
| **Property** | **Description** |
| **Name** | Allows selecting the desired Font. |
| **Size** | Allows choosing the desired Font Size. |
| **Unit** | Unit of measure for the Font. |
| **Bold** | Specifies whether the Font is bold or not. |
| **Underline** | Check it to underline the text. |
| **GdiCharSet** | Obtains the number of bytes that specify the GDI character set used by this font. |
| **GdiVerticalFont** | Boolean value that indicates if this font is derived from a GDI vertical font. |
| **Italic** | Allows choosing the desired style. |
| **Strikeout** | Allows inserting a horizontal line over selected text. |
| **Underline** | Allow inserting a line under the selected text. |
