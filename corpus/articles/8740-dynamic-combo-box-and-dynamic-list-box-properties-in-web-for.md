# Dynamic Combo Box and Dynamic List Box Properties in Web Forms

When the control type of a variable or an attribute is a Dynamic Combo Box or a Dynamic List Box, besides the properties described in the Attribute/Variable Control Properties, in web forms you can assign a value to these properties:

|  |  |
| --- | --- |
| **Control** | **Appearance** |
| [Item Descriptions property](https://wiki.genexus.com/commwiki/wiki?8807) | [BackColor property](https://wiki.genexus.com/commwiki/wiki?8688) |
| [Sort Descriptions Property](https://wiki.genexus.com/commwiki/wiki?8839) | [Fill property](https://wiki.genexus.com/commwiki/wiki?8722) |
| [Item Values property](https://wiki.genexus.com/commwiki/wiki?8808) | [Font property](https://wiki.genexus.com/commwiki/wiki?8774) |
|  | [ForeColor property](https://wiki.genexus.com/commwiki/wiki?8693) |
|  | [ReadOnly](https://wiki.genexus.com/commwiki/wiki?8826) |

The autoresize property applies only to dynamic list boxes.
