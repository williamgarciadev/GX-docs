# None Intermediate Event in BPD

Is used to document that certain activities have been completed or that the process has reached a defined state, such as a milestone. The name of the Event can often provide enough information for these purposes.

### [Symbol](#Symbol)

`[imagen omitida: wiki id 12197]`

### [Description](#Description)

For this Event, no circumstance is defined. Therefore, this fires immediately.
