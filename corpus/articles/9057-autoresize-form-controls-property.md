# Autoresize form controls property

Sets autoresize for controls to be made after translation.

### [Values](#Values)

|  |  |
| --- | --- |
| **Based on current translation** | Sets autoresize based on the current translation. This is the default value. |
| **Based on longest available translation** | Sets autoresize based on the longest available translation. |
| **Based on message code** | Sets autoresize based on message code. |

### [Scope](#Scope)

**Level:** [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836)

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, execute a Rebuild All.
