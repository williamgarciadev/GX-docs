# Theme Editor class menu options

**Warning**: Since [GeneXus 18](https://wiki.genexus.com/commwiki/wiki?51066) the standalone Theme Editor is discontinued and its setup is not distributed anymore. For [DesignOps](https://wiki.genexus.com/commwiki/wiki?46870) use the [Design Import option](https://wiki.genexus.com/commwiki/wiki?46882). In addition, it is recommended to use [Design System Object](https://wiki.genexus.com/commwiki/wiki?47375)s instead of Themes.

Right-clicking on the tree view items of the [Theme](https://wiki.genexus.com/commwiki/wiki?4375) Editor opens the following menu:

`[imagen omitida: wiki id 46484]`

* **Copy class properties:** This option copies only the non-default class properties.
* **Copy all class properties:** Copies all the property values (default and non-default).
* **Paste class properties:** After having copied the class properties of another class, paste them at the selected class.
* **Add rule:** (Only Web). Add a CSS rule. For more information, see [Conditional Class Properties for Themes](https://wiki.genexus.com/commwiki/wiki?25116).
* **Add class:** This allows adding a new class to the selected class (or subclass). This child class inherits the properties of the parent class. See [Theme Class](https://wiki.genexus.com/commwiki/wiki?6246) for more information.
* **Go to CSS definition:** (Only Web). Show the CSS definition on the right-hand panel.  
  `[imagen omitida: wiki id 46485]`
* **Import CSS:**(Only Web). Opens an editor panel to enter a CSS definition to be imported into the selected class. See [Import CSS option for Theme classes](https://wiki.genexus.com/commwiki/wiki?28644).
* **Show/Hide SD/Web classes:**By default, a [Web Theme object](https://wiki.genexus.com/commwiki/wiki?6420) displays only the Web classes. With this option, you can show or hide Mobile classes. The same happens with the [Theme object](https://wiki.genexus.com/commwiki/wiki?16595) for Web classes. For more information, read [Theme menu option: Show / Hide Classes](https://wiki.genexus.com/commwiki/wiki?27858).
