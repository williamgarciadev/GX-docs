# GXFlow Business Process Deployment Advanced Settings

#### [**Override Task-Role Assignments: Yes | No**](#Override+Task-Role+Assignments%3A+Yes+No)

This preference indicates whether the Roles-Task assignment made in the GeneXus IDE will be considered in the next process impact.

`[imagen omitida: wiki id 52411]`

### [Values](#Values)

|  |  |
| --- | --- |
| **Yes** | On every business process impact, the Task-Role assignment defined in the GeneXus IDE will be copied in the new process definition. This is the default value. |
| **No** | The Task-Role assignments are not going to be considered in the process impact. The new process version will take the Task-Role assignments from the previous one. This option needs to be used when the assignment is made at runtime. |

### [**How to apply changes**](#How+to+apply+changes)

It applies the next time the [business processes](https://wiki.genexus.com/commwiki/wiki?7273,,) are deployed.
