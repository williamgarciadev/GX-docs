# Address property

Indicates the recipient’s email address.

### [Syntax](#Syntax)

**control.** Address

### [Description](#Description)

**OutlookSession****:** In Outlook, it is not possible to use this property when receiving an email for the To, CC, Bcc and From properties. In these cases the address property will have the same value as the name property.

**Extended Data Types:** [MailRecipient](https://wiki.genexus.com/commwiki/wiki?6926)

**Platforms:** Web(.Net, Java)
