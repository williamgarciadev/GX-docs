# Generate Views property

If it is true, GeneXus will generate the Views.

### [Scope](#Scope)

**Objects:** Conversational Flows Pattern

### [Description](#Description)

The Generate Views property is available for the Transaction node under the Conversational Configuration (Pattern Settings).

`[imagen omitida: wiki id 40383]`

### [Availability](#Availability)

This property is available since [GeneXus 15 upgrade 12](https://wiki.genexus.com/commwiki/wiki?39737,,).
