# Import Dialog Options

Import options are shown as properties inside the [Import Dialog](https://wiki.genexus.com/commwiki/wiki?3179).

`[imagen omitida: wiki id 54429]`

To display these properties, click on the Options link:

* [Import Type property](https://wiki.genexus.com/commwiki/wiki?5612)
* [Automatic Backup property](https://wiki.genexus.com/commwiki/wiki?5617)
* [LanguageTranslations property](https://wiki.genexus.com/commwiki/wiki?7616)
* [Redefine External Programs Property](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?7615,,)
* [Theme Import Behavior Property](https://wiki.genexus.com/commwiki/wiki?10127)
* [Class Conflicts Property](https://wiki.genexus.com/commwiki/wiki?10126)
