# DashboardViewer control

The DashboardViewer is a [user control](https://wiki.genexus.com/commwiki/wiki?5273) to be used on a web form in order to view a [Dashboard object](https://wiki.genexus.com/commwiki/wiki?36769).

### [How to work with this control?](#How+to+work+with+this+control%3F)

1) Drag the DashboardViewer control from the Toolbox to a Web form.

`[imagen omitida: wiki id 36776]`

2) Set the **Object** property pointing to a [Dashboard object](https://wiki.genexus.com/commwiki/wiki?36769).

`[imagen omitida: wiki id 36777]`

3) If necessary, set the additional properties Width, Height, and Class to set the desired look and feel. Use the Dashboard theme node to further customize the look and feel.

4) Run the associated [Web Panel object](https://wiki.genexus.com/commwiki/wiki?6916).

### [Scenarios](#Scenarios)

A dashboard is a visual interface that allows you to display on a single screen the most relevant elements of the system state (to get the "big picture") and execute actions. The most common scenario is to show key performance indicators on the home page or to be available as a specific layout.
