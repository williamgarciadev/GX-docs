# Modules - Known Limitations

As of [GeneXus 15](https://wiki.genexus.com/commwiki/wiki?27605,,):

#### [General](#General)

* [SDT](https://wiki.genexus.com/commwiki/wiki?2427) 'Messages' must belong to the [Root module](https://wiki.genexus.com/commwiki/wiki?22439).
* Generators not supporting Module objects: Cobol and RPG — see [Generators supporting modules](https://wiki.genexus.com/commwiki/wiki?22491).

#### [[GeneXus Access Manager (GAM)](https://wiki.genexus.com/commwiki/wiki?24746)](#wiki%3F24746%2CToc%253AGeneXus%2BAccess%2BManager%2B%2528GAM%2529+GeneXus+Access+Manager+%28GAM%29)

* [Permission Prefix property](https://wiki.genexus.com/commwiki/wiki?17571) for two [Objects](https://wiki.genexus.com/commwiki/wiki?1866) with the same [name](https://wiki.genexus.com/commwiki/wiki?6985) is defined with the same value since, by default, the value is the [name](https://wiki.genexus.com/commwiki/wiki?6985) of the object. In other words [Permission Prefix property](https://wiki.genexus.com/commwiki/wiki?17571) is not affected by the [Qualified Name property](https://wiki.genexus.com/commwiki/wiki?22477).
