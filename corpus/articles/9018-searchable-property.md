# Searchable property

The purpose is to allow the end user to find specific information from different sources.

### [Values](#Values)

|  |  |
| --- | --- |
| **False** | Business components are not made searchable. This is the default value. |
| **True** | All Business components of the Knowledge Base are made searchable. |
| **Use Environment property value** |

### [Description](#Description)

If the [Searchable property](https://wiki.genexus.com/commwiki/wiki?9018) is set to True, all [Business Component](https://wiki.genexus.com/commwiki/wiki?5846) of the [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836) are made searchable. You can change it locally for certain Business Components if you want.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply changes made by this property, do a Build with this Only of the object.

**Platforms:** Web(.Net, Java)
