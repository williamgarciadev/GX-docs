# QueryViewer control compatibility

This section details changes made to the [QueryViewer control](https://wiki.genexus.com/commwiki/wiki?9075).

### [Upgrading to GeneXus 17](#Upgrading+to+GeneXus+17)

The Refresh QueryViewer method is not supported; the query will be updated automatically when anyfilter change its value.

### [Upgrading to GeneXus 15 upgrade 12](#Upgrading+to+GeneXus+15+upgrade+12)

Several changes were done to the Theme object associated to the [QueryViewer control](https://wiki.genexus.com/commwiki/wiki?9075) to be coordinated with the [Dashboard object](https://wiki.genexus.com/commwiki/wiki?36769). The new "look and feel" (default) uses blue as the central color.

*`[imagen omitida: wiki id 40016]`*

Up to [GeneXus 15 Upgrade 11](https://wiki.genexus.com/commwiki/wiki?38845,,) the default color was gray:

*`[imagen omitida: wiki id 40017]`*

To keep the previous value since [GeneXus 15 upgrade 12](https://wiki.genexus.com/commwiki/wiki?39737,,) check [SAC #43674](https://www.genexus.com/developers/websac?en,,,43674).
