# Select Event dialog

This option helps you design your objects, that is, when you wish to assign events to your controls. It can be accessed via the Insert/Events main menu option when you are editing events for [Transactions](https://wiki.genexus.com/commwiki/wiki?1908) and [Web Panels](https://wiki.genexus.com/commwiki/wiki?6916).

### Shortcut

Ctrl+Shift+E

`[imagen omitida: wiki id 9854]`

### Dialog Options

#### Controls column

This column will display the list of controls that you have added to the form you are designing. Here, select the Control (via the highlight bar) to which you want to assign an event.

#### Events column

This column will display all the events that can be set for the Control you have selected and for the form that you are editing.
