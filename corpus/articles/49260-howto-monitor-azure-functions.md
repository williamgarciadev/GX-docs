# HowTo: Monitor Azure Functions

[Azure Monitor](https://docs.microsoft.com/en-us/azure/azure-monitor/overview) is the native monitoring solution for Microsoft Azure aimed at helping users maximize application availability and performance. Azure Monitor provides users with full observability into their cloud and on-premise environments, collecting and analyzing data from a variety of sources before storing the information to be processed later (similar to Amazon CloudWatch).

[Application Insights](https://docs.microsoft.com/en-us/azure/azure-monitor/app/app-insights-overview) is a feature of Azure Monitor used to monitor your live applications. It automatically detects performance anomalies and includes analytics tools to help you diagnose issues.

### [Using Application Insights](#Using+Application+Insights)

You can create an Application Insights instance when you [create your function app](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?47419,,). In this case, the instrumentation key required for the integration is already set as an application setting named APPLICATIONINSIGHTS\_CONNECTION\_STRING.  
  
If your function app doesn't have the instrumentation key set, you need to [enable Application Insights integration](https://docs.microsoft.com/en-us/azure/azure-functions/configure-monitoring?tabs=v2#enable-application-insights-integration).

For example, if you see an error in the monitor, you can use Application Insights to get the complete stack and details of the error.

### [Check the logs generated by the GeneXus application](#Check+the+logs+generated+by+the+GeneXus+application)

With Application Insights integration enabled, telemetry data is sent to your connected Application Insights instance. This data includes logs generated by GeneXus.

Go to Diagnostic Settings in the Azure portal, and add a Diagnostic setting.

`[imagen omitida: wiki id 49744]`

Next, below Categories select "FuntionAppLogs", and below Destination details select "Send to log analytics workspace" as shown in the following image.

`[imagen omitida: wiki id 49745]`

**Note**: A quick (and recommended) way to activate the log is through the [Log output property](https://wiki.genexus.com/commwiki/wiki?39568), which can be set as an environment variable. See [HowTo: Logging to Azure Application Insights](https://wiki.genexus.com/commwiki/wiki?58044).

Another option would be to do the following:

Configure the [Log output property](https://wiki.genexus.com/commwiki/wiki?39568) to "Console Appender" value, and check the logs going through the Log Analytics workspace you selected. Then go to the "Logs" option on the left side menu, and run the query over the FunctionAppLogs table.

`[imagen omitida: wiki id 49746]`

For detailed information on this topic, see [Monitoring Azure Functions with Azure monitor logs](https://docs.microsoft.com/en-us/azure/azure-functions/functions-monitor-log-analytics?tabs=csharp).
