# Security Client ID property

Identifies a Native Mobile application in GAM.

### [Scope](#Scope)

**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Angular](https://wiki.genexus.com/commwiki/wiki?42550), [Apple](https://wiki.genexus.com/commwiki/wiki?14917)

### [Description](#Description)

The Client ID is the Identifier of the application in GAM ([GAM Application](https://wiki.genexus.com/commwiki/wiki?15910)​), this is used in Panel objects that are main and used by Android, Apple and Angular to perform [OAuth 2.0 Authentication](https://wiki.genexus.com/commwiki/wiki?39484).

The values of this property are:

Any valid [GUID](https://wiki.genexus.com/commwiki/wiki?21842).  
  
Default value: It takes a default value given by GeneXus. The default value is assigned after the object is created, in the first Build process where the [Application's Registration process](https://wiki.genexus.com/commwiki/wiki?19964,,) takes place.

The value of this property of a main object is different depending on the [Environment](https://wiki.genexus.com/commwiki/wiki?7115).
