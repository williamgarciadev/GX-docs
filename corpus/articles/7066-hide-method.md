# Hide method

Hides the document. If no document is visible, it hides the application.

### [Syntax](#Syntax)

**&***VarBasedOnExtendedDataType***.Hide()**  
  
**Type Returned:**   
Numeric

### [Scope](#Scope)

**Extended Data Types:** [ExcelDocument](https://wiki.genexus.com/commwiki/wiki?2476), [WordDocument](https://wiki.genexus.com/commwiki/wiki?2478,,)  
**Generators:**

[.NET](https://wiki.genexus.com/commwiki/wiki?38604), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892),
[Java](https://wiki.genexus.com/commwiki/wiki?12258), Visual FoxPro (up to GeneXus X Evolution 3)

**Note**: This method returns an error code, so it is possible to call it as a function (I.E.: **&**Err **=** **&**DataType**.Hide()**).
