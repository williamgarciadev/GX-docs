# GAM Application logout object

The GAM Application logout object is configured using the [GAM - Web Backoffice](https://wiki.genexus.com/commwiki/wiki?15935) under the Application's configuration (or programmatically, using the [GAM API](https://wiki.genexus.com/commwiki/wiki?16535)).

Its purpose is to determine the URL of the object to be redirected after executing the [Logout in SSO applications](https://wiki.genexus.com/commwiki/wiki?32336).

`[imagen omitida: wiki id 32365]`

Since GeneXus 15 upgrade 5, the URL can be absolute or relative depending on the [UseAbsoluteUrlByEnvironment property](https://wiki.genexus.com/commwiki/wiki?35933,,) value.
