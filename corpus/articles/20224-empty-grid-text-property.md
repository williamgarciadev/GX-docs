# Empty Grid Text property

Shows a text when the Grid has no data.

### [Scope](#Scope)

**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917), [Java](https://wiki.genexus.com/commwiki/wiki?12258)  
**Controls:** [Grid](https://wiki.genexus.com/commwiki/wiki?24817), [Free Style Grid](https://wiki.genexus.com/commwiki/wiki?6058)

### [Samples](#Samples)

Consider an example where you want to show a list of clients, so you apply the [Work With pattern](https://wiki.genexus.com/commwiki/wiki?15974) to the Client [Transaction](https://wiki.genexus.com/commwiki/wiki?1908) and add an entry point in a [Menu object](https://wiki.genexus.com/commwiki/wiki?16321) pointing to the WorkWithDevicesClient.Client.List(). If there are clients in the database and you go to the WorkWithDevicesClients screen, the list will be shown; however, if you don't have any records the list will appear empty and sometimes the user may think there is a problem.

In sum, this property allows you to show a text instead of an empty space.
