# Extract Zip property

Specifies whether the contents of a zip file should be automatically unzipped when copied.

### [Values](#Values)

|  |
| --- |
| **True** |
| **False** |

### [Scope](#Scope)

**Objects:** [File](https://wiki.genexus.com/commwiki/wiki?5852)  
**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Java](https://wiki.genexus.com/commwiki/wiki?12258)

### [Description](#Description)

The Extract Zip property simplifies the management of zip files during copy operations.

When set to True, the contents of the zip file are automatically unzipped when copied. On the other hand, when it is set to False, the zip file is copied without unzipping.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, Build any object.
