# HowTo: Maps - Mapbox

Mapbox is a leading open-source mapping platform worldwide. It offers APIs to access its UI, services, and functionalities.  
  
This provider has been added to those already available for Mobile application generators in order to expand their offering and make it easier for customers who already work on this platform to adopt it.

### [Scope](#Scope)

**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453)

### [Implementation](#Implementation)

To use this provider, set in your [Main](https://wiki.genexus.com/commwiki/wiki?5770) [Panel object](https://wiki.genexus.com/commwiki/wiki?24829):

* [Android Maps API property](https://wiki.genexus.com/commwiki/wiki?22729) = Mapbox API

Two properties will be enabled that need to be configured:

* [Android Maps API Key property](https://wiki.genexus.com/commwiki/wiki?19115)
* [Mapbox API Private Key property](https://wiki.genexus.com/commwiki/wiki?47972)

Configure, respectively, a public and a secret token that can be obtained at [Mapbox Access Token](https://account.mapbox.com/access-tokens/)

The implemented functionalities are as follows:

* [Show my location](https://wiki.genexus.com/commwiki/wiki?42206)
* [Location Attribute property](https://wiki.genexus.com/commwiki/wiki?42209)
* [DrawGeography](https://wiki.genexus.com/commwiki/wiki?47024)
* [Editable geographies](https://wiki.genexus.com/commwiki/wiki?46337)
* [Directions Layer](https://wiki.genexus.com/commwiki/wiki?42225)     
        `[imagen omitida: wiki id 48365]`
* [Geography Layer](https://wiki.genexus.com/commwiki/wiki?48253)   Full functionality as with the other providers  
        `[imagen omitida: wiki id 48364]`
* [MapsOffline External Object](https://wiki.genexus.com/commwiki/wiki?48363)

### [Availability](#Availability)

Since [GeneXus 17 upgrade 4](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?47936,,).
