# Design System Class Properties List (GeneXus 18 Upgrade 4 or prior)

This article refers to those properties that are specific to GeneXus which start with the prefix "gx-".

Follow this link to access the complete list of properties: [Design System Class Properties List File](https://wiki.genexus.com/commwiki/wiki?49527,,).

For Web objects like [Web Panels](https://wiki.genexus.com/commwiki/wiki?6916), [Master Pages](https://wiki.genexus.com/commwiki/wiki?17088), [Transactions](https://wiki.genexus.com/commwiki/wiki?1908), etc., the [standard properties](https://wiki.genexus.com/commwiki/wiki?49323) match those of CSS, so they are not all listed here (for more details, read [CSS Reference](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference)).

Take into account that in the list the second column of the table indicates the platform to which the property applies:

* **Web**: Properties related to [Angular](https://wiki.genexus.com/commwiki/wiki?42550), [.NET](https://wiki.genexus.com/commwiki/wiki?38604) and [Java](https://wiki.genexus.com/commwiki/wiki?12258).
* **[Web Panels](https://wiki.genexus.com/commwiki/wiki?6916)**: Properties available in web objects: .NET and Java (not only for Web Panel objects).
* **[Panels](https://wiki.genexus.com/commwiki/wiki?24829)**: Properties available in Native Mobile and Angular objects: [Apple](https://wiki.genexus.com/commwiki/wiki?14917), [Android](https://wiki.genexus.com/commwiki/wiki?14453) and Angular (not only for Panel objects).
* **All**: Properties related to all of them (Apple, Android, Angular, .NET, Java).

The third and fourth columns are for mapping these properties to those used in the [Theme object](https://wiki.genexus.com/commwiki/wiki?16595):

* The third one indicates the root classes of the Theme's class tree in which the property is located.
* The fourth one indicates the name of the property in those classes or their heirs in the Theme.

The fifth column indicates the fixed preset values that can be specified for the property, if any.
