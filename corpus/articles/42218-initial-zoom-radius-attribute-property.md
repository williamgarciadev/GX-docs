# Initial Zoom Radius Attribute property

Attribute that contains the minimum distance (in meters) that should be visible around the designated center point of the map.

### [Description](#Description)

The [Attribute/Variable](https://wiki.genexus.com/commwiki/wiki?6911) indicated in this property contains the value for the minimum distance (in meters) that should be visible around the designated [center](https://wiki.genexus.com/commwiki/wiki?42220) point of the map. The map's zoom level will be adjusted so that at least this distance is visible in all directions.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply changes made by this property, do a Build with this Only of the object.

### [Scope](#Scope)

**Objects:** Panel for Smart Devices, Work With for Smart Devices  
**Platforms:** Smart Devices(Android, IOS)  
**Controls:** Grid
