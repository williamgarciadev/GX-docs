# External Package Name property

Specifies the name of the package where the class associated with the External Object is located.

### [Scope](#Scope)

**Objects:** [External Object](https://wiki.genexus.com/commwiki/wiki?5669)  
**Generators:** [Java](https://wiki.genexus.com/commwiki/wiki?12258)

### [Description](#Description)

The External Package Name property is only available for [External Objects with Type property 'Native Object'](https://wiki.genexus.com/commwiki/wiki?6148).

You can find the property under the Java Information node.

Due to the restrictions introduced by the [Modules](https://wiki.genexus.com/commwiki/wiki?22441,,) in GeneXus, you cannot have an External Object without a package.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at runtime.
