# Chatbot Flow: Set up an appointment for any administrative formality

Similarly to the [Make a demand Flow](https://wiki.genexus.com/commwiki/wiki?39071) and [Get Information Flow](https://wiki.genexus.com/commwiki/wiki?39072); in this case, you can define a flow where the user is asked to enter for which type of formality he is making an appointment. This is represented with a User Input that [matches with an entity](https://wiki.genexus.com/commwiki/wiki?39295) in the Provider.

`[imagen omitida: wiki id 43969]`

Then, a [Conversational Object](https://wiki.genexus.com/commwiki/wiki?38189) leads to the final selection where the user determines date and time of the appointment.
