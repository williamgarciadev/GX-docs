# Layout control

The layout control allows inserting an abstract layout into an HTML form. The abstract layout is edited using the [Web Abstract Editor](https://wiki.genexus.com/commwiki/wiki?24795) and its main purpose is to help in the design of a [Responsive Web Applications](https://wiki.genexus.com/commwiki/wiki?25159).

The layout control is available in the toolbox when the web form is HTML. When dragging the layout control to the form, the web form is composed of an HTML form and nested into it; the abstract layout can be edited using the Web Abstract Editor.

It gives the designer the possibility of using the [Web Abstract Editor](https://wiki.genexus.com/commwiki/wiki?24795) in a HTML form, in order to obtain the advantages of both.
