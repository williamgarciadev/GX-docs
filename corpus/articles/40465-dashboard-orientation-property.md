# Dashboard Orientation property

Specifies whether to arrange the attributes horizontally or vertically when more than one data attribute is present.

### [Values](#Values)

|  |  |
| --- | --- |
| **Horizontal** | Data is displayed side by side. This is the default value. |
| **Vertical** | Data is displayed in a vertical layout. |

### [Scope](#Scope)

**Objects:** Dashboard

### [Description](#Description)

Specifies how attributes are arranged. For further details, click [here](https://wiki.genexus.com/commwiki/wiki?33178).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Availability](#Availability)

This property is available since [GeneXus 15 upgrade 12](https://wiki.genexus.com/commwiki/wiki?39737,,).
