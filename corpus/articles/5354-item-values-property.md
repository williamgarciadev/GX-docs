# Item Values Property

This property applies to the [Dynamic Combo Box](https://wiki.genexus.com/commwiki/wiki?7598) and [Dynamic List Box](https://wiki.genexus.com/commwiki/wiki?7599) controls. It identifies an attribute whose values will be added to the list.

The default value is the attribute itself (the one you are setting this property to), unless it is a subtype, in which case, the default value is its supertype.
