# Zoom Outside Control property

Allows the image to expand outside the bounds of the control.

### [Values](#Values)

|  |
| --- |
| **True** |
| **False** |

### [Scope](#Scope)

**Generators:** [Apple](https://wiki.genexus.com/commwiki/wiki?14917), [Android](https://wiki.genexus.com/commwiki/wiki?14453)  
**Controls:** Attribute/Variable (Control Type: Image, [Advanced Image](https://wiki.genexus.com/commwiki/wiki?20497))

### [Description](#Description)

Allows you to zoom in on images to expand them beyond the size of their containers. This offers application users an enhanced experience when zooming in on an image.

When the Control Type =**Image,** the [Enable Zoom property](https://wiki.genexus.com/commwiki/wiki?46466) has to be set to True to make the Zoom Outside Control property available.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
