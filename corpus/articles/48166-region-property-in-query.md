# Region property in Query

Specifies whether to display a country, a continent, or the entire world map.

### [Values](#Values)

|  |
| --- |
| **Continent** |
| **Country** |
| **World** |

### [Scope](#Scope)

**Objects:** [Query](https://wiki.genexus.com/commwiki/wiki?9026)  
**Generators:** [Java](https://wiki.genexus.com/commwiki/wiki?12258), .NET, [.NET Core](https://wiki.genexus.com/commwiki/wiki?38604)

### [Description](#Description)

Use this property to select the region of the world you want to show.

It may be the entire **world** or a smaller area, such as a **continent** or a **country**.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
