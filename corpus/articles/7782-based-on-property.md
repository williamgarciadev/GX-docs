# Based on property

Bases a variable on a specified attribute or domain. Also, it bases an attribute on a specified domain and bases a domain on another domain.

### [Scope](#Scope)

**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Angular](https://wiki.genexus.com/commwiki/wiki?42550), [Apple](https://wiki.genexus.com/commwiki/wiki?14917), [Java](https://wiki.genexus.com/commwiki/wiki?12258), .NET, [.NET Core](https://wiki.genexus.com/commwiki/wiki?38604)  
**Level:** [Attribute](https://wiki.genexus.com/commwiki/wiki?7240), [Domain](https://wiki.genexus.com/commwiki/wiki?7221), [Variable](https://wiki.genexus.com/commwiki/wiki?7375)

### [Description](#Description)

When defining a variable, you can indicate that it is based on a [domain](https://wiki.genexus.com/commwiki/wiki?7239) or an attribute. Likewise, you can define an attribute based on a domain; also, a domain may be based on another domain.

A relationship is created between the variable, attribute or domain defined and the definition on which they are based. So, if later on the definition on which attributes, variables or domains are based is updated, the update is automatically inherited.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, execute a [Build with this Only](https://wiki.genexus.com/commwiki/wiki?5693) of the object.
