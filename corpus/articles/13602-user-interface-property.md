# User Interface property

Allows to specify the platform for which the application will be generated.

### [Description](#Description)

`[imagen omitida: wiki id 28607]`

#### [Values](#Values)

Web  
Windows

When you switch into both values, the change occurs only in the generator, also by default.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply changes made by this property, do a Re-Build All.

### [Scope](#Scope)

**Platforms:** Web(.Net, Java)
