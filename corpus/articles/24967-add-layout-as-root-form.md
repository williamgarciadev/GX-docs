# Add Layout as Root Form

This is an option of the contextual menu of the Web Form of the [HTML Editor](https://wiki.genexus.com/commwiki/wiki?7673).

### [Description](#Description)

If the user needs to change the [Root form](https://wiki.genexus.com/commwiki/wiki?24972) to use the [Web Abstract Editor](https://wiki.genexus.com/commwiki/wiki?24795), the way to do it is to create an abstract layout including an [HTML container](https://wiki.genexus.com/commwiki/wiki?24960) with the HTML web form.

By right clicking in the Web Form - when it is not empty - there is an option in the contextual menu, called Add Layout As Root Form, as the figure shows:

`[imagen omitida: wiki id 24978]`

As a result of executing this menu option, a Layout form is created including the HTML Container.

`[imagen omitida: wiki id 24979]`

By double clicking on the HTML Container, you can edit the Web Form as before and visualize the resulting tree structure:

`[imagen omitida: wiki id 24980]`

### [Note](#Note)

In order to convert an HTML form to an Abstract form see [Convert to Abstract Layout menu option](https://wiki.genexus.com/commwiki/wiki?29297).
