# Tick Interval property

Indicates the Tick event frequency in seconds.

### [Scope](#Scope)

**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917)  
**Controls:** Attribute/Variable (Control Type: [Chronometer](https://wiki.genexus.com/commwiki/wiki?25058))

### [Description](#Description)

Indicates the frequency in seconds in which the Tick event will be called.

Applies to Attribute/Variable controls included in a [Transaction Web Layout](https://wiki.genexus.com/commwiki/wiki?8057), [Panel object](https://wiki.genexus.com/commwiki/wiki?24829), [Web Panel Web Layout](https://wiki.genexus.com/commwiki/wiki?8132), and [WW](https://wiki.genexus.com/commwiki/wiki?15974) whose [Control Type](https://wiki.genexus.com/commwiki/wiki?9550)=[Chronometer](https://wiki.genexus.com/commwiki/wiki?25058).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, execute a [Build All](https://wiki.genexus.com/commwiki/wiki?5691).
