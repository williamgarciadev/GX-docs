# Manually configuring Tomcat

From Genexus 17 Upgrade 5 the [Tomcat path property](https://wiki.genexus.com/commwiki/wiki?48354) is implemented that replaces the [Servlet directory property](https://wiki.genexus.com/commwiki/wiki?9122) and the [Static content directory seen from client property](https://wiki.genexus.com/commwiki/wiki?9124).

When changing the [Tomcat path property](https://wiki.genexus.com/commwiki/wiki?48354) to a new tomcat server after a rebuild all the application is generated in the new path and no manual configuration is needed.

For information on how to configure older versions please see [Manually configuring Tomcat](https://wiki.genexus.com/commwiki/wiki?48668,,)
