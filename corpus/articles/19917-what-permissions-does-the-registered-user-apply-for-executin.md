# What permissions does the registered user apply for executing

If managing [GAM Permissions](https://wiki.genexus.com/commwiki/wiki?15912) is desired for users registered with the [Auto-register anonymous users](https://wiki.genexus.com/commwiki/wiki?19395) mechanism, [Roles](https://wiki.genexus.com/commwiki/wiki?17569) must be assigned to the "anonymous" user by applying the [GAM Backoffice](https://wiki.genexus.com/commwiki/wiki?15935).

With the gamexamplewwusers Web Panel it is possible to go through the "Roles" link for the “Anonymous" user and add the role(s) to be granted to that user, as shown in the figure below.

`[imagen omitida: wiki id 19824]`

If no role is assigned to the Anonymous user, the role-assigning criteria is the same for all users, and it will take the default Role from the repository.

Role permissions are configured at the GAM Web Backoffice (see [HowTo: Add a Permission to a Role using GAM](https://wiki.genexus.com/commwiki/wiki?17963)).

This allows for restricting what these anonymous users may execute in the smart device application.
