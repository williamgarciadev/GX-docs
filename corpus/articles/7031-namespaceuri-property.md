# NameSpaceURI Property

This property returns the URI used to identify the namespace of the current node.

### [Syntax](#Syntax)

**&***DataType***.NameSpaceURI**  
  
**Type Returned:**  
Character

### [Description](#Description)

It is used to return the URI used to identify the namespace of the current node.  
It is valid only for Element and EndTag type nodes.

### [Scope](#Scope)

**Extended Data Types:** [XmlReader](https://wiki.genexus.com/commwiki/wiki?6928)  
**Languages:** .NET, Java, Ruby (up to GeneXus X Evolution 3), Visual FoxPro (up to GeneXus X Evolution 3)
