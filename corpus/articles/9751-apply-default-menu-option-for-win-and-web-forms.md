# Apply Default menu option (for Win and Web Forms)

This option restores the default form according to the [Transaction object](https://wiki.genexus.com/commwiki/wiki?1908)'s [structure](https://wiki.genexus.com/commwiki/wiki?7661).

Any changes done to the form controls will be lost.

There are two ways to select this option:

1) If you have opened a certain Transaction Web form, you can choose: Edit > Apply Default (Web Layout)  
2) If you want to apply the default form to several Transactions, you can choose: Tools > Refactoring > Apply Defaults (Web forms)

### [Sample](#Sample)

The first Windows form shows a personalized form. The second Windows form shows the default form obtained after applying this option.
