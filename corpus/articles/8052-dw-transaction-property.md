# DW transaction property

Specifies whether the Transaction is used for Data Warehouse.

### [Values](#Values)

|  |
| --- |
| **False** |
| **True** |

### [Scope](#Scope)

**Objects:** [Transaction](https://wiki.genexus.com/commwiki/wiki?1908)  
**Generators:** Cobol, [Java](https://wiki.genexus.com/commwiki/wiki?12258), .NET, RPG

### [Description](#Description)

The default value is False.  
If this property is set to True, the [DW transaction type property](https://wiki.genexus.com/commwiki/wiki?8053) is displayed.

### [Compatibility](#Compatibility)

Ruby and Visual FoxPro generators offer this property up to GeneXus X Evolution 3.
