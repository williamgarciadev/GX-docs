# Control Type property in Action Groups for Web objects

Indicates if the Action Group will be rendered as a ToolBar or a Menu.

### [Values](#Values)

|  |  |
| --- | --- |
| **Menu** | The Action Group will be rendered as a Menu. |
| **ToolBar** | The Action Group will be rendered as a ToolBar. |

### [Scope](#Scope)

**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Java](https://wiki.genexus.com/commwiki/wiki?12258)  
**Controls:** [Action Group](https://wiki.genexus.com/commwiki/wiki?25631)

### [Description](#Description)

This [Action Group](https://wiki.genexus.com/commwiki/wiki?25631) property allows you to set if you want to render the group as a Toolbar or a Menu.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
