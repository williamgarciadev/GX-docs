# GeneXus 18

GeneXus 18 is the latest major stable release of [GeneXus](https://wiki.genexus.com/commwiki/wiki?1756). Read about the latest stable update at [GeneXus Release Channel](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?28878,,).

This is the entry point of GeneXus 18 technical release notes. They are an overview of GeneXus 18 features (compared to [GeneXus 17](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?46066,,)) and what needs to be taken into account to adopt it.

For a broader overview of GeneXus 18, please visit: <http://genexus.com/live>.

**Download**: <http://genexus.com/v18-download>

**Note:** To read more about GeneXus, go to [GeneXus - Table of contents](https://wiki.genexus.com/commwiki/wiki?22331), and to learn GeneXus, go to <http://training.genexus.com>.
