# Common Controls

GeneXus provides a set of standard controls that allow not only the creation of the user interface but also of the application itself. These controls, which are applicable to [Web Panel object](https://wiki.genexus.com/commwiki/wiki?6916)s and [Transaction object](https://wiki.genexus.com/commwiki/wiki?1908)s, are located in each object's Toolbox.

The following figure shows a web form and the Toolbox:

`[imagen omitida: wiki id 5936]`

To insert a control in the web form, just drag it from the Toolbox to the web form.

### [Standard Controls Catalog](#Standard+Controls+Catalog)

* Controls
  + **[Attribute/Variable](https://wiki.genexus.com/commwiki/wiki?5985).** Inserts both attributes and variables in the form from a selection dialog box.
  + **[Button](https://wiki.genexus.com/commwiki/wiki?6011).** Allows inserting a button in the form. The button may be associated with a previously defined event or you may wish to define a new event for the button.
  + **[Embedded Page](https://wiki.genexus.com/commwiki/wiki?6070).** Allows the inclusion of external information to display the contents of any URL in Web objects generated with GeneXus.
  + **[Error Viewer](https://wiki.genexus.com/commwiki/wiki?6073).** Where messages are displayed.
  + **[Horizontal Rule](https://wiki.genexus.com/commwiki/wiki?6016).** Inserts a cosmetic line in the web form.
  + **[HyperLink](https://wiki.genexus.com/commwiki/wiki?6007).** Links in the object’s Web form. Before adding a link you will be able to configure it.
  + **[Image](https://wiki.genexus.com/commwiki/wiki?5939).** Pictures in the object’s Web Form to show different images from the Knowledge Base Image repository.
  + **[Text Block](https://wiki.genexus.com/commwiki/wiki?5948).** Text blocks in the object’s Web form.
  + **[Web Component](https://wiki.genexus.com/commwiki/wiki?31172).** Web Panels that have a property indicating that they are components.
  + **[Table](https://wiki.genexus.com/commwiki/wiki?6001).** Tables in the form where other objects, such as images, text, etc., are added inside rows and columns.
* Containers
  + **[Flex](https://wiki.genexus.com/commwiki/wiki?35354)**
  + **[Free Style Grid](https://wiki.genexus.com/commwiki/wiki?6058).** Inserts a grid to put attributes, variables, images, etc.
  + **[Grid](https://wiki.genexus.com/commwiki/wiki?24817).** Inserts a grid that shows multiple records from attributes and variables.
  + **[Group](https://wiki.genexus.com/commwiki/wiki?6570).** Inserts a container to deploy other objects separately and titled.
  + Html
  + **[Responsive Table](https://wiki.genexus.com/commwiki/wiki?24961)**
  + **[Section](https://wiki.genexus.com/commwiki/wiki?6112).** The area where other objects are added such as images, text, etc.
  + **[Tab](https://wiki.genexus.com/commwiki/wiki?25623)**
  + **[Table control](https://wiki.genexus.com/commwiki/wiki?6001)**
* Action Groups
  + **[New Action Group](https://wiki.genexus.com/commwiki/wiki?25631)**
* Miscellaneous
  + **[AnimationView](https://wiki.genexus.com/commwiki/wiki?37185)**
  + BasicTab
  + Tab
