# Assign to the same user who executes a previous task property

Allows to automatically assign a task to the user who executed a specific previous task (User Tasks).

### [Scope](#Scope)

**Controls:** [Task](https://wiki.genexus.com/commwiki/wiki?17495)

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
