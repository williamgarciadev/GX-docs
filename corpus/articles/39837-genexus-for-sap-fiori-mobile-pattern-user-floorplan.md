# GeneXus for SAP Fiori Mobile Pattern - User Floorplan

The User [Floorplan](https://wiki.genexus.com/commwiki/wiki?38629,,) is a set of templates that allow you to manage the registration of a user.

This article explains how to apply it to a [Panel object](https://wiki.genexus.com/commwiki/wiki?24829).

## [How to apply it](#How+to+apply+it)

If you have never applied the FioriMobile Pattern on your KB before, read [GeneXus for SAP Systems - Fiori Mobile Pattern](https://wiki.genexus.com/commwiki/wiki?39800).

Once you create a Panel, the following window showing a group of categories will be displayed. Each one of them offers different templates.

If you select the User category, only one template is shown. Select it to be applied to the Panel:

`[imagen omitida: wiki id 39838]`

1. Simple register user

`[imagen omitida: wiki id 39839]`

Another way to apply it is by selecting an existing panel, right-clicking on it, and selecting **Apply Fiori Mobile template to control**.

`[imagen omitida: wiki id 39840]`
