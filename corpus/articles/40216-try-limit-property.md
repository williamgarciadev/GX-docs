# Try Limit property

Limit of attempts when an entry is invalid.

### [Scope](#Scope)

**Objects:** Conversational Flows Instance

### [Description](#Description)

When [Ask again property](https://wiki.genexus.com/commwiki/wiki?40215) is set to TRUE, you can establish the number of times the user is asked to re-try.

### [Availability](#Availability)

This property is available since [GeneXus 15 upgrade 12](https://wiki.genexus.com/commwiki/wiki?39737,,).
