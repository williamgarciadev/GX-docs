# CallOptions

CallOptions are used to specify at runtime the transitions, behavior, and position in a call to a particular [Panel object](https://wiki.genexus.com/commwiki/wiki?24829).

Basically, in the passage from one Panel to another there are several elements of user experience that you must consider:

* **[CallOptions Transitions](https://wiki.genexus.com/commwiki/wiki?25321)****:** Enter and Exit effect for the new [Panel object](https://wiki.genexus.com/commwiki/wiki?24829).
* **[CallOptions Type](https://wiki.genexus.com/commwiki/wiki?25322)****:** Behavior of the new Panel (Popup, Callout, etc.).
* **[CallOptions Target](https://wiki.genexus.com/commwiki/wiki?25323)****:** Where the Panel is going to be loaded.
