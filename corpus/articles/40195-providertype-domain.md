# ProviderType domain

Enumerated domain representing every provider type in the context of [GeneXus Cognitive API](https://wiki.genexus.com/commwiki/wiki?40167).

## [Values](#Values)

|  |  |
| --- | --- |
| **Alibaba** | Alibaba AI cloud-based provider. |
| **Amazon** | Amazon Web Services cloud-based provider. |
| **Baidu** | Baidu AI cloud-based provider. |
| **Google** | Google Cloud Platform cloud-based provider. |
| **IBM** | IBM Watson cloud-based provider. |
| **Microsoft** | Microsoft Azure Cognitive Services cloud-based provider. |
| **MLKit** | Firebase ML Kit on-device provider |
| **SAP** | SAP Leonardo cloud-based provider. |
| **Tencent** | Tencent AI cloud-based provider. |

## [Scope](#Scope)

|  |  |
| --- | --- |
| **Generators:** | [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Java](https://wiki.genexus.com/commwiki/wiki?12258), [Apple](https://wiki.genexus.com/commwiki/wiki?14917), [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Angular](https://wiki.genexus.com/commwiki/wiki?42550) |

## [Availability](#Availability)

This domain is available as of [GeneXus 16](https://wiki.genexus.com/commwiki/wiki?35351,,).

* As of [GeneXus 16 upgrade 1](https://wiki.genexus.com/commwiki/wiki?40782,,):  
  - Support for Google value.
* As of [GeneXus 16 upgrade 2](https://wiki.genexus.com/commwiki/wiki?41525,,):  
  - Support for Amazon and Tencent values.
* As of [GeneXus 16 upgrade 3](https://wiki.genexus.com/commwiki/wiki?42129,,):  
  - Support for Baidu provider.
* As of [GeneXus 16 upgrade 4](https://wiki.genexus.com/commwiki/wiki?42755,,):  
  - Alibaba AI is available.
* As of [GeneXus 16 Upgrade 11](https://wiki.genexus.com/commwiki/wiki?45901,,):  
  - Firebase ML Kit is available.
