# Responsive Web Applications

Responsive Web Applications (RWA) are applications that provide an optimal viewing experience (easy reading and navigation, good spacing, etc.) across a wide range of devices.

Because they provide an optimal experience on any device, Responsive Web Applications are what users really want. They are achieved by using a [Responsive Web Design (RWD)](https://wiki.genexus.com/commwiki/wiki?25161).
