# Page size property

Enables you to define the number of rows that will be shown when the Paging property is activated.

### [Description](#Description)

This property is active when the value of the [Paging property in QueryViewer Control](https://wiki.genexus.com/commwiki/wiki?19677) is True.

#### [Values](#Values)

Any numeric value greater than zero.

#### [Scope](#Scope)

Output type: Table, PivotTable
