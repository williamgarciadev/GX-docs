# Style property in Font Theme Class (GeneXus 18 Upgrade 6 or prior)

Defines how the font will be styled.

### [Values](#Values)

|  |  |
| --- | --- |
|  | The property is not set (because it's optional). This is the default value. |
| **italic** | The font style will be italic. |
| **oblique** | The font style will be oblique. |

### [Scope](#Scope)

**Level:** [Theme Class](https://wiki.genexus.com/commwiki/wiki?6246)

### [Description](#Description)

This property is available for the Fonts [Theme Class](https://wiki.genexus.com/commwiki/wiki?6246).

`[imagen omitida: wiki id 56523]`

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
