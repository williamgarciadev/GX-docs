# Server property

Enables generators to know which INFORMIX server they must connect to.

### [Values](#Values)

|  |  |
| --- | --- |
| **On Line** | Indicates whether the Informix server is Informix on Line. |
| **Standard Engine** | Indicates whether this Informix server is an Informix Standard Engine. |

### [Scope](#Scope)

Available at the Data Store.  
**Data Store:** INFORMIX  
**Generators:** [Java](https://wiki.genexus.com/commwiki/wiki?12258), .NET, [.NET Core](https://wiki.genexus.com/commwiki/wiki?38604)  
**Level:** [Data Store](https://wiki.genexus.com/commwiki/wiki?7117)

### [Description](#Description)

The Server property is available when the [Access technology to set property](https://wiki.genexus.com/commwiki/wiki?9030) is set to **JDBC.**

The **default value** of this property is = On Line.

The Ruby generator offers this property up to GeneXus X Evolution 3.
