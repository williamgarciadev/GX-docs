# Web Service Protocol property

Specifies the communication protocol to be used when exposing a web service.

### [Values](#Values)

|  |  |
| --- | --- |
| **REST Protocol** | Uses a standard OpenAPI definition. |
| **SOAP Protocol** | Default value. Uses a definition written in WSDL (Web Services Description Language). |

### [Scope](#Scope)

**Objects:** [Data Provider](https://wiki.genexus.com/commwiki/wiki?5270)

### [Description](#Description)

The Web Service Protocol property can only be configured when the [Expose as Web Service property](https://wiki.genexus.com/commwiki/wiki?36480) is set to True:
