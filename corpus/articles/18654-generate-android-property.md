# Generate Android property

Enables the Native Mobile generator to generate the code corresponding to the Android platform.

### [Values](#Values)

|  |
| --- |
| **False** |
| **True** |

### [Scope](#Scope)

**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453)  
**Level:** Front end

### [Description](#Description)

Default value: False

When you create in your [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836) the first object for mobile development, the property is automatically set to True.

In addition, the Android Specific group will be added allowing you to set the necessary properties to generate applications in this platform.
