# Mac Host property

Your Mac computer name (computer name property in the Remote Login settings) or its IP address.

### [Scope](#Scope)

**Platforms:** Smart Devices(IOS)

### [Description](#Description)

Your Mac computer name (computer name property in the Remote Login settings) or its IP address.

Optionally, you can specify a port number as follows: host:port. If a port is not specified, the default one (i.e., 22) will be used.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Compatibility](#Compatibility)

The option specifying the port number is available as of GeneXus 16 Upgrade 11.
