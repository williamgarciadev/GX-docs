# Chat Control

The Chat Control provides a conversational interface that allows end users to enter input in a text box and display a list of messages. Responses will be shown in real time as they are generated.

To use this control, install the [GeneXusUIControls module](https://wiki.genexus.com/commwiki/wiki?60714) and drag the Chat Control from the [Toolbox](https://wiki.genexus.com/commwiki/wiki?10000) into the Layout (for a Panel object generated with Angular) or the Web Layout (for a Web Panel object).

`[imagen omitida: wiki id 60823]`

### [Usage scenarios](#Usage+scenarios)

The control can be connected to an Artificial Intelligence provider, for example:

* Through an [Agent object](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?59249,,). You can implement a common use case by following the steps in [HowTo: Use the Chat Control associated with a Procedure that calls an Agent](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?60802,,).
* Through an API. See [HowTo: Use the Chat Control associated with a Procedure that calls a Globant Enterprise AI API](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?61100,,).

### [Appearance and customization](#Appearance+and+customization)

You can customize the appearance of the Chat Control to match your application's design. Markdown formatting is supported in messages. Learn more about [Chat control properties, methods, and events](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?60814,,).
