# Convert to module

In some situations you may need to convert a [Folder object](https://wiki.genexus.com/commwiki/wiki?9757) into a [Module object](https://wiki.genexus.com/commwiki/wiki?22414). This can be done using the *Convert to module* option from the Folder Object contextual menu.

`[imagen omitida: wiki id 25230]`

To use this option just right click the Folder and press the *Convert to module* option. Then a new Module object will be created, with the same name as the previously selected Folder, containing all the Folder' objects.
