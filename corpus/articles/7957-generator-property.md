# Generator property

Indicates the Generator with which GeneXus will build the main object and all the objects of its call tree.

### [Scope](#Scope)

**Objects:** [Procedure](https://wiki.genexus.com/commwiki/wiki?6293), [Transaction](https://wiki.genexus.com/commwiki/wiki?1908), [Web Panel](https://wiki.genexus.com/commwiki/wiki?6916) (Only [Main Objects](https://wiki.genexus.com/commwiki/wiki?5770))

### [Description](#Description)

#### [Values](#Values)

The [GeneXus Generators](https://wiki.genexus.com/commwiki/wiki?7116) defined for the [Environment](https://wiki.genexus.com/commwiki/wiki?7115) are available to select one.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
