# Redirect to Flow property

Select an existing flow to redirect the conversation when the current condition is true.

### [Description](#Description)

This property is available for the [Chatbot User Input Redirections](https://wiki.genexus.com/commwiki/wiki?39003) nodes of the [Flow of a Conversational instance](https://wiki.genexus.com/commwiki/wiki?38531).

When the [Condition Property](https://wiki.genexus.com/commwiki/wiki?43716) evaluates to True, the flow redirects to another flow, indicated under the Redirect to flow property.

`[imagen omitida: wiki id 43718]`

### [Availability](#Availability)

This property is available since [GeneXus 16 upgrade 5](https://wiki.genexus.com/commwiki/wiki?43446,,).

### [Scope](#Scope)

**Objects:** [Conversational Flows Instance](https://wiki.genexus.com/commwiki/wiki?37113)
