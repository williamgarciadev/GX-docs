# HowTo: Add a Permission to a Role using GAM

The purpose of this article is to explain the necessary steps to add a Permission to [GAM Roles](https://wiki.genexus.com/commwiki/wiki?17569)

All you need to do is edit the role using the [GAM Backend](https://wiki.genexus.com/commwiki/wiki?15935) (go through the *Roles* option and edit the *Permissions* of the selected Role).

### [Step 1](#Step+1)

Enter the Roles section in the Backend. You can see all the roles that have been created there. Click on the "Edit" button of a Role (in this case "Administrator") to configure the Permissions associated to that Role, as it is shown in the following picture:

`[imagen omitida: wiki id 52534]`

### [Step 2](#Step+2)

Once you are in edition mode of a Role, you have to click on the "More Options" button and select "Permissions" from the display Menu:

`[imagen omitida: wiki id 52533]`

### [Step 3](#Step+3)

Select the application where the Permission has been defined (remember that permissions exist within the scope of [Applications](https://wiki.genexus.com/commwiki/wiki?15910) and [Roles](https://wiki.genexus.com/commwiki/wiki?17569). See [GAM Repository structure](https://wiki.genexus.com/commwiki/wiki?17568) for details).

`[imagen omitida: wiki id 52536]`

### [Step 4](#Step+4)

Click on the "Add" button to agreggate a new Permission to the "Administrator" Role.

`[imagen omitida: wiki id 52530]`

### [Step 5](#Step+5)

Select the Permission you want, and press "Add selected" button.

Afterwards, you need to set the [Permission Access Type](https://wiki.genexus.com/commwiki/wiki?20603) on this Role (Allow, Deny, Restricted).

`[imagen omitida: wiki id 52535]`

### [Adding a Role to a user](#Adding+a+Role+to+a+user)

Just go through the "users" option at GAM Backend and edit Roles information for the corresponding user.

`[imagen omitida: wiki id 52537]`
