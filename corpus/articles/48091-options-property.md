# Options property

Specifies the Design System options for an image.

### [Scope](#Scope)

**Objects:** [Image](https://wiki.genexus.com/commwiki/wiki?23387)  
**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Angular](https://wiki.genexus.com/commwiki/wiki?42550), [Apple](https://wiki.genexus.com/commwiki/wiki?14917), [Java](https://wiki.genexus.com/commwiki/wiki?12258), .NET, [.NET Core](https://wiki.genexus.com/commwiki/wiki?38604)

### [Description](#Description)

It is possible to vary an image at runtime not only according to the Style, Language, Density, Layer, but also to the [Options of the Tokens set](https://wiki.genexus.com/commwiki/wiki?47378) (only when the Style property specifies a [Design System Object](https://wiki.genexus.com/commwiki/wiki?47375) that has parameters for that Tokens).  
  
The **Options property** allows you to specify a value for each option (parameter) of the Tokens Set, in order to use the current image when these options values are the current ones in runtime.

### [Samples](#Samples)

[How to change an image according to the Design System Object Option](https://wiki.genexus.com/commwiki/wiki?48694).

### [Availability](#Availability)

This property is available since [GeneXus 17 Upgrade 6](https://wiki.genexus.com/commwiki/wiki?48684,,).
