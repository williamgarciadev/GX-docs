# Expand Bounds Limit property

Indicates if the control is able to be expanded beyond the application and/or status bars.

## [Values](#Values)

|  |  |
| --- | --- |
| **Behind System Bars** | Default value. The container control will be expanded beyond both [Application and Status Bars](https://wiki.genexus.com/commwiki/wiki?17879) (in conjunction they are known as *System Bars*). |
| **Behind Application Bars** | The container control will be expanded only beyond [Application Bar](https://wiki.genexus.com/commwiki/wiki?19486) (space for Status Bar is still reserved). |

## [Description](#Description+)

This property is visible only when [Expand Bounds property](https://wiki.genexus.com/commwiki/wiki?37136) has not *None* value.

For example, when the [Application Bar](https://wiki.genexus.com/commwiki/wiki?19486) is not visible we have the following result.

|  |  |
| --- | --- |
| **Behind Application Bars** | **Behind System Bars** |
|  |  |

## [Run-time/Design-time](#Run-time%2FDesign-time)

This property applies only at design-time.

## [Scope](#Scope)

**Controls:** [Grid control](https://wiki.genexus.com/commwiki/wiki?24817), [Tab control](https://wiki.genexus.com/commwiki/wiki?29986), [Canvas control](https://wiki.genexus.com/commwiki/wiki?22452), [Table control](https://wiki.genexus.com/commwiki/wiki?6001)  
**Platforms:** Smart Devices(IOS)

## [Availability](#Availability)
