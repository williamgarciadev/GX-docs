# ErrDescription Property

It describes the error message for the last operation.

### [Syntax](#Syntax)

**&***DataType***.ErrDescription**  
  
**Type Returned:**   
Character  
  
**Where:**  
*DataType*  
Is the variable name of tge DBConnection, Directory, ExcelDocument, File, HttpClient, HttpRequest, HttpResponse, MAPISession, OutlookSession, POP3Session, SMTPSession, WordDocument, XMLWriter or XMLReader type.

### [Description](#Description)

This property is read only, it cannot be assigned.

### [Scope](#Scope)
