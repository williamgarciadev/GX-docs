# Filter empty item text property

Text associated with the empty item.

### [Description](#Description)

Set the desired text when the [Empty item](https://wiki.genexus.com/commwiki/wiki?40139) property is enabled.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
