# Web maximum single line edit length property

Sets the maximum length in characters for controls of Edit type. If it is exceeded, it is converted into a multi-line edit.

### [Scope](#Scope)

**Level:** [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836)

### [Description](#Description)

This property is used to define the default control for an attribute.

If the attribute length exceeds the value of the [Web Maximum Edit Length Property](https://wiki.genexus.com/commwiki/wiki?4565) but does not exceed this property value, it is defined as a single line edit with horizontal scrolling.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, execute a Rebuild All.
