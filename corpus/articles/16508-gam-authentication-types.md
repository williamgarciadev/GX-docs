# GAM - Authentication Types

There are different types of authentication you can choose for applications that use [GeneXus Access Manager (GAM)](https://wiki.genexus.com/commwiki/wiki?24746).

Authentication Types can be defined using [GAM Backoffice](https://wiki.genexus.com/commwiki/wiki?15935), or just using the [GAM API](https://wiki.genexus.com/commwiki/wiki?16535) in any object. See Figure 1 where the "Work With Authentication Types" [Web Panel](https://wiki.genexus.com/commwiki/wiki?6916) is shown.

Figure 1.

### [Available Authentication Types](#Available+Authentication+Types)

|  |  |
| --- | --- |
| [Local Authentication Type](https://wiki.genexus.com/commwiki/wiki?20703) | User credentials are stored in GAM database repository. |
| [Facebook Authentication Type](https://wiki.genexus.com/commwiki/wiki?29007) | Authentication is done using Facebook. |
| [External Authentication Type](https://wiki.genexus.com/commwiki/wiki?21755):  * [External Web Services Authentication Type](https://wiki.genexus.com/commwiki/wiki?16512) * [Custom Authentication Type](https://wiki.genexus.com/commwiki/wiki?21751) | In the case of an External Web service, authentication is done through any SOAP web service which applies to some standards and has to be declared in the Authentication Type configuration, specifying its location, and other useful information to connect to it.  In the case of Custom, the authentication is done using any external program, which has to apply to some standards in the input and output parameters. |
| [Twitter Authentication Type](https://wiki.genexus.com/commwiki/wiki?17208) | Authentication is done using Twitter. |
| [Google Authentication Type](https://wiki.genexus.com/commwiki/wiki?29013) | Authentication is done using Google. |
| [GAMRemote Authentication Type](https://wiki.genexus.com/commwiki/wiki?25355) | Authentication is done using another GAM application. Only GeneXus Evolution 3. |
| [OAuth 2.0 Authentication Type](https://wiki.genexus.com/commwiki/wiki?39484) | Authentication is done using any OAuth 2.0 provider. |
