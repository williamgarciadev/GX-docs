# Grid Theme class

The Grid [class](https://wiki.genexus.com/commwiki/wiki?6246) of the [Theme object](https://wiki.genexus.com/commwiki/wiki?16595) allows you to set some properties to style [Grid control](https://wiki.genexus.com/commwiki/wiki?24817)s.

`[imagen omitida: wiki id 37661]`

* [Name property](https://wiki.genexus.com/commwiki/wiki?6985)

* Border Color property
