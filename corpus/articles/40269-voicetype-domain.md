# VoiceType domain

Enumerated domain representing the voice type of a spoken audio in the context of the [GeneXus Cognitive API](https://wiki.genexus.com/commwiki/wiki?40167).

## [Values](#Values)

|  |  |
| --- | --- |
| **Female** | Female voice. |
| **Male** | Male voice. |

|  |  |
