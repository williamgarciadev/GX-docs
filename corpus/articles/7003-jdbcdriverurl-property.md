# JDBCDriverURL Property

Returns or associates a JDBC URL to a DBConnection variable.

### [Syntax](#Syntax)

**&***DataType***.JDBCDriverURL**  
  
**Type Returned:**   
Character

### [Example](#Example)

```
&myConn.JDBCDriverURL='jdbc:inetdae:barbanegra:1433?database=testemp2'
```
