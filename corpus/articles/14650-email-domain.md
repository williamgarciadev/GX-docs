# Email domain

This domain is used to load emails. In Edit mode, the information is entered as text using the platform’s input method. In View mode, the information is shown in a textual form.

`[imagen omitida: wiki id 14651]`

Through a tap gesture allows opening the platform´s email client.

The Email domain type is VarChar(100).
