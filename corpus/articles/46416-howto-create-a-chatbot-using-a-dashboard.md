# HowTo: Create a chatbot using a Dashboard

Using a [Dashboard object](https://wiki.genexus.com/commwiki/wiki?36769) is a quick option to create a chatbot based on a series of queries.

To do this, simply right-click on the Dashboard object you want to use to initialize the chatbot and select the option "Create Chatbot from Dashboard":

`[imagen omitida: wiki id 46452]`

This action will create a new chatbot initialized with all the queries on the Dashboard.

`[imagen omitida: wiki id 46453]`
