# Functions in Transactions

Below is a list of available functions that can be used within a [Transaction object](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?1908,,).

Note that some of them can be used in [Transaction Rules](https://wiki.genexus.com/commwiki/wiki?8213), [Transaction Events](https://wiki.genexus.com/commwiki/wiki?8042) and/or [Global Formulas](https://wiki.genexus.com/commwiki/wiki?6440).

By selecting **Insert** and then, **Function...** from the [GeneXus Main Menu](https://wiki.genexus.com/commwiki/wiki?7212), the dialog shows only the functions available for the [Transaction object](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?1908,,) section in which you are working.
