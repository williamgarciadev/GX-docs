# Table responsive sizes property

Sets the responsive sizes.

### [Scope](#Scope)

**Objects:** Dashboard

### [Description](#Description)

This property allows arranging [Dashboard widgets](https://wiki.genexus.com/commwiki/wiki?36779) in the [layout](https://wiki.genexus.com/commwiki/wiki?36769) of four different screen sizes.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Availability](#Availability)

This property is available since [GeneXus 15 upgrade 12](https://wiki.genexus.com/commwiki/wiki?39737,,).
