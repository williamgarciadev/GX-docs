# Selectable for ad-hoc property

Allows setting whether a Task appears in the successor Tasks selection dialog shown on completing an ad-hoc task.

### [Values](#Values)

|  |
| --- |
| **False** |
| **True** |

### [Scope](#Scope)

**Controls:** [Task](https://wiki.genexus.com/commwiki/wiki?17495), [Subprocess](https://wiki.genexus.com/commwiki/wiki?17268)

### [Description](#Description)

When this property is set to True, the Task appears in the successor Tasks selection. This is the default value.  
When this property is set to False, the Task does not appear in the successor Tasks selection.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
