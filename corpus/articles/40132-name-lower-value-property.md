# Name (lower value) property

Filter name for the lower value.

### [Scope](#Scope)

**Objects:** Dashboard

### [Description](#Description)

Name associated with the lower value in a Range filter. The link between the lower value and other Dashboard elements is accomplished through this name.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
