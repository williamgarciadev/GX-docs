# OneSignal - App ID property

Property OneSignal App ID as specified in the App Settings page on OneSignal

### [Description](#Description)

This property is available at [Java](https://wiki.genexus.com/commwiki/wiki?7244) and [.NET](https://wiki.genexus.com/commwiki/wiki?7243) generator level when [Notifications Provider property](https://wiki.genexus.com/commwiki/wiki?33670) has OneSignal value.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply changes made by this property, do a Build All.

### [Availability](#Availability)

This property is available since [GeneXus 15 Upgrade 4](https://wiki.genexus.com/commwiki/wiki?33798,,).

### [Scope](#Scope)

**Platforms:** Smart Devices(Android, IOS)
