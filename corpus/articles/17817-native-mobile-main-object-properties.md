# Native Mobile Main object properties

## [Notes](#Notes)

(1) Name changed from "Google Play URL" to "Update URL" as of [GeneXus 15 Upgrade 4](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?33798,,).  
(2) Available at Main object level since [GeneXus 15 Upgrade 5](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?34646,,).  
(3) Available as of [GeneXus 15 Upgrade 6](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?35908,,).  
(4) Grouped as of [GeneXus 15 Upgrade 7](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?36355,,) whose properties were available in previous versions at Main Object properties level.  
(5) Available as of [GeneXus 15 Upgrade 8](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?36778,,).  
(6) Deprecated as of [Genexus 15 Upgrade 10](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?38023,,). Use [Ads View control](https://wiki.genexus.com/commwiki/wiki?32653).
