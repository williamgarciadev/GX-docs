# ClearProximityAlerts method

This method eliminates the active [alerts](https://wiki.genexus.com/commwiki/wiki?25185) in the device.

Consider that it cannot be used on the server side. If used, the [spc0200](https://wiki.genexus.com/commwiki/wiki?6774) message will be displayed.
