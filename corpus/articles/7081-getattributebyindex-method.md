# GetAttributeByIndex method

Returns the value of an attribute of the current node indicated by its index.

### [Syntax](#Syntax)

**&***VarBasedOnXmlReader***.GetAttributeByIndex(***Index***)**  
  
**Where:**  
*Index*  
    Index of the attribute to be read.  
  
**Type Returned:**  
Character

### [Scope](#Scope)

**Extended Data Types:** [XmlReader](https://wiki.genexus.com/commwiki/wiki?6928)  
**Generators:**

[.NET](https://wiki.genexus.com/commwiki/wiki?38604),
[.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Java](https://wiki.genexus.com/commwiki/wiki?12258), Ruby (up to GeneXus X Evolution 3), Visual FoxPro (up to GeneXus X Evolution 3)

### [Description](#Description)

Returns the value of an attribute of the current node indicated by its index, obtained through the [Read method](https://wiki.genexus.com/commwiki/wiki?7049) or the [ReadType method](https://wiki.genexus.com/commwiki/wiki?7048).  
It is valid only for nodes of the [GXflow Elements](https://wiki.genexus.com/commwiki/wiki?25812) type.             
Positions are numbered starting at 1.
