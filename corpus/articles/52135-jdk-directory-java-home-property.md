# JDK Directory (JAVA HOME) property

Specifies the path to the Java JDK root.

### [Scope](#Scope)

**Generators:** [Java](https://wiki.genexus.com/commwiki/wiki?12258)  
**Level:** Generator

### [Description](#Description)

To be able to compile a GeneXus Java application, you have to complete the JDK Directory property with the path to the Java JDK.

### [Samples](#Samples)

Suppose you have Java 18 (Oracle JDK 18) installed. In this case, you should type something very similar to the following:

C:\Program Files\Java\jdk-18

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

No action is required to apply the corresponding changes when the property value is configured.
