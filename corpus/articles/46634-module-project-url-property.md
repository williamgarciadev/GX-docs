# Module Project URL property

Sets the URL where the module is documented.

### [Scope](#Scope)

**Objects:** [Module](https://wiki.genexus.com/commwiki/wiki?22411)

### [Description](#Description)

The linked site should contain a complete description of the module, with all the details the user of the module should know to be able to use it successfully.
