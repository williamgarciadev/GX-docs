# DashboardViewer ValuesHighlightedData property

Name of the variable containing information about the DashboardViewer ValuesHighlighted event when it's raised.

### [Description](#Description)

Upon clicking on a value on any object with the On Item Click property equals to HighlightValues in the DashboardViewer control we may want to trigger a particular action. This property contains the name of the variable based on the DashboardViewerValuesHighlightedData SDT that can be used in the ValuesHighlighted event.
