# Next Event

To bring up the next record in the table, according to the current index.

### [Description](#Description)

The GeneXus developer cannot associate any code with this event.

This event occurs when the user clicks on the associated button  `[imagen omitida: wiki id 8206]`

### [Scope](#Scope)

**Objects:** [Transactions](https://wiki.genexus.com/commwiki/wiki?1908)  
**Languages:** .NET, Java, Ruby (up to GeneXus X Evolution 3)  
**Interfaces:** Web
