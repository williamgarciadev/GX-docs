# Knowledge Base properties (GeneXus 18 latest upgrade or prior)

Some properties allow you to configure specific aspects of the [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836).

To access these properties, open the [Preferences](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?7109,,) window and select the main node (Knowledge Base node). The [Properties window](https://wiki.genexus.com/commwiki/wiki?3160) will then refresh to display all configurable properties for the Knowledge Base.
