# Reload method

Reloads all the possible values of a [Dynamic Combo Box](https://wiki.genexus.com/commwiki/wiki?7598) from its corresponding table.

### [Syntax](#Syntax)

*Control***.Reload( )**

### [Scope](#Scope)

**Controls:** [Dynamic Combo Box](https://wiki.genexus.com/commwiki/wiki?7598), [Dynamic List Box](https://wiki.genexus.com/commwiki/wiki?7599)  
**Generators:**

[.NET](https://wiki.genexus.com/commwiki/wiki?38604),
[Java](https://wiki.genexus.com/commwiki/wiki?12258), Ruby (up to GeneXus X Evolution 3), Visual FoxPro (up to Genexus X Evolution 3)

### [Description](#Description)

Reads the corresponding table and loads all the values into the combo box.  
This property applies only at execution time.

**Note**: This method is not supported in Web environments: [SAC#40258](https://www.genexus.com/developers/websac?es,,,40258)
