# Knowledge Base Preferences

You can find the Preferences window in the tab next to the [KB Explorer](https://wiki.genexus.com/commwiki/wiki?3210). This is where you can set the [Knowledge Base properties](https://wiki.genexus.com/commwiki/wiki?33001), the [Version properties](https://wiki.genexus.com/commwiki/wiki?7860) and manage the [Environments](https://wiki.genexus.com/commwiki/wiki?7115).

`[imagen omitida: wiki id 54586]`

To open the preferences window, go to **View > Other Tool Windows > Preferences**:

`[imagen omitida: wiki id 54587]`
