# Column Tooltip property in Tabular Grid Control Column

Indicates the text to be displayed when the cursor is placed over the column header.

### [Scope](#Scope)

**Generators:** [Angular](https://wiki.genexus.com/commwiki/wiki?42550)  
**Controls:** [Tabular Grid](https://wiki.genexus.com/commwiki/wiki?54449)

### [Description](#Description)

The text typed in this property is displayed as a tooltip when hovering the mouse over the column header.

By default, the text displayed as a tooltip is the title of the column.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [Availability](#Availability)

This property is available since [GeneXus 18 Upgrade 6](https://wiki.genexus.com/commwiki/wiki?54240).
