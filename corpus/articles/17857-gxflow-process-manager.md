# GXflow Process Manager

The Process Manager consists of applications aimed at process manager users.  
  
These applications allow managing different processes, tasks, and users participating in the processes, among other things.    
  
The following figure shows this application interface:  
`[imagen omitida: wiki id 52239]`

The process manager consists of the following applications:

* [GXflow Processes](https://wiki.genexus.com/commwiki/wiki?32180)
* [Tasks](https://wiki.genexus.com/commwiki/wiki?10145)
* [Business Events](https://wiki.genexus.com/commwiki/wiki?11934)
* [Process Definition](https://wiki.genexus.com/commwiki/wiki?10153)
* [Calendars](https://wiki.genexus.com/commwiki/wiki?10157)
* [Participants](https://wiki.genexus.com/commwiki/wiki?10161)
* [Notification templates](https://wiki.genexus.com/commwiki/wiki?17860)

For an overview of GXflow client refer to the [GXflow Client General Structure](https://wiki.genexus.com/commwiki/wiki?17836) section.
