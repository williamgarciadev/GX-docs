# HeightUnit property

HeightUnit is a run-time property specifying the unit of measure that the value of Height Property is in.

### [Description](#Description)

#### [Values](#Values)

|  |  |
| --- | --- |
| **"px"** | Pixels.  This is the default value. |
| **"%"** | Percentage |

### [Samples](#Samples)

```
BLData.HeightUnit= "%"
BLData.height = 200
```

### [Scope](#Scope)

**Controls:** Embedded Page
