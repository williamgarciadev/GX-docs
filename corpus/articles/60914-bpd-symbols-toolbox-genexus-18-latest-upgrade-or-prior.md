# BPD Symbols (Toolbox) (GeneXus 18 latest upgrade or prior)

This bar includes all the components that will allow drawing a [Business Process Diagram](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?16486,,). Once you have selected a button, you must drag in the drawing area to insert the selected symbol.
