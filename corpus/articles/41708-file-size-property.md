# File Size property

Returns the image's file size in bytes. Read-only property.

### [Syntax](#Syntax)

**control.** File Size

### [Samples](#Samples)

```
&fileSize = &image.FileSize
```

### [Availability](#Availability)

This property is available since [GeneXus 16 upgrade 2](https://wiki.genexus.com/commwiki/wiki?41525,,).

### [Scope](#Scope)

**Platforms:** Smart Devices(IOS)
