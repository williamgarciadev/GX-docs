# Input Not Understood Redirection property

Select an existing flow to redirect when the chatbot does not understand the user input.

### [Description](#Description)

When the the user input isn't recognized by the [AI](https://en.wikipedia.org/wiki/Artificial_intelligence), a possible action to take is to redirect to a [Flow of a Conversational instance](https://wiki.genexus.com/commwiki/wiki?38531) of the model.

There, the chatbot can ask the user to enter some [User Input](https://wiki.genexus.com/commwiki/wiki?38959) to guide him in the conversation.

### [Availability](#Availability)

This property is available since [GeneXus 15 upgrade 12](https://wiki.genexus.com/commwiki/wiki?39737,,).

### [Scope](#Scope)

**Objects:** Conversational Flows
