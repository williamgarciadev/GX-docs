# Variable definition

You may define variables in most [GeneXus objects](https://wiki.genexus.com/commwiki/wiki?1866).

GeneXus objects that allow defining variables, contains a selector named Variables in order to define and manage them.

`[imagen omitida: wiki id 42587]`

If you select it, the [Variables Editor](https://wiki.genexus.com/commwiki/wiki?3173) will be opened.

Variables are local, which means that they are accessible only inside the object. If you need to send some variable values to another object, you can [call](https://wiki.genexus.com/commwiki/wiki?16224) the desired object, sending the variables as parameters to it.

After defining a variable, you will be able to use it (inside an allowed section like the Source, Rules, Events, etc.) referencing its name preceded by the & symbol.

For example, if you define a variable named &Quantity, then being in a section of the same object where it is allowed to use variables, you can type & and you will be able to select the &Quantity variable or other defined variable.

Each variable has some properties in order to set them. The main properties are the following:

|  |
| --- |
| **Properties** |
| [Name](https://wiki.genexus.com/commwiki/wiki?6985) |
| [Description](https://wiki.genexus.com/commwiki/wiki?7446) |
| [Based on](https://wiki.genexus.com/commwiki/wiki?7782) |

Depending on the [Data Type property](https://wiki.genexus.com/commwiki/wiki?7232) you choose, different related properties are offered to set them.
