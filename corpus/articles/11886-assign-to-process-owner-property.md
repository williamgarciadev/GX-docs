# Assign to process owner property

Assigns the Task automatically to the user who created the process.

### [Values](#Values)

|  |
| --- |
| **False** |
| **True** |

### [Scope](#Scope)

**Controls:** [Task](https://wiki.genexus.com/commwiki/wiki?17495)

### [Description](#Description)

The property does not apply when an instance of the diagram is created as a [Subprocess](https://wiki.genexus.com/commwiki/wiki?17268).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
