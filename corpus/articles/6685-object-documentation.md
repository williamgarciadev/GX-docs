# Object Documentation

Most GeneXus objects have a section to write documentation. All the [documentation sources inside the Knowledge Base](https://wiki.genexus.com/commwiki/wiki?5275) make up a [wiki-like](http://en.wikipedia.org/wiki/Wiki) documentation system.

The Documentation Editor is a [WYSIWYG](http://en.wikipedia.org/wiki/WYSIWYG) editor that can be accessed at the Object level, through the 'Documentation' object's selector, as shown in the following Transaction:
