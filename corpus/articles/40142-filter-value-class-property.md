# Filter value class property

Filter value theme class.

### [Description](#Description)

Define the [Theme](https://wiki.genexus.com/commwiki/wiki?4375) class used to describe the filter value look & feel.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Availability](#Availability)
