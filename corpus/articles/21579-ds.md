# DS

Acronym of Data Selector.

A [Data Selector object](https://wiki.genexus.com/commwiki/wiki?5271) is a GeneXus object for storing a set of Parameters, Conditions, Orders, and a Defined By clause, in order to invoke it from different queries, calculations, etc. and reuse the same navigation several times.
