# HowTo: Convert a Folder into a Module

This article shows you the steps to convert a Folder into a Module.

In order to convert a [Folder object](https://wiki.genexus.com/commwiki/wiki?9757) into a [Module object](https://wiki.genexus.com/commwiki/wiki?22414), you can use the [Convert to module](https://wiki.genexus.com/commwiki/wiki?25229) option.

**Note**: It's not possible to turn a Folder into a Module if the folder contains Win type objects.

### [Steps](#Steps)

1. Right-click the [Folder object](https://wiki.genexus.com/commwiki/wiki?9757) you want to convert into a Module.
2. Select the [Convert to module](https://wiki.genexus.com/commwiki/wiki?25229) from the contextual menu.

When the conversion process is over, a new Module with the same [Name property](https://wiki.genexus.com/commwiki/wiki?6985) as the selected Folder and that contains all the Folder's Objects will be created, and the Folder will be deleted.
