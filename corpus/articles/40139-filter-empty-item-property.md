# Filter empty item property

Adds an item for 'none/all' selection.

### [Description](#Description)

Defines whether a new item is added when using a Radio button or Combo box [Dashboard Filter](https://wiki.genexus.com/commwiki/wiki?36769).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
