# Item Expand Data property

Upon expanding the value of a [Query Element](https://wiki.genexus.com/commwiki/wiki?19788), we may want to trigger a particular action (such as recalculating a value, changing the color of a text, interacting with another control, etc.). This property contains the name of the variable based on the QueryViewerItemExpandData SDT that can be used in the [ItemExpand Event](https://wiki.genexus.com/commwiki/wiki?19563,,).

### Values

|  |  |
| --- | --- |
| &ItemExpandData | Name of the variable that will implement the event’s inherent properties. This is the default value. |
