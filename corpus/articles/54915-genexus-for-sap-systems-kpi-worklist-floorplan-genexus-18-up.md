# GeneXus For SAP Systems KPI Worklist Floorplan (GeneXus 18 Upgrade 3 or prior)

The [KPI](https://wiki.genexus.com/commwiki/wiki?35542,,) Worklist [Floorplan](https://wiki.genexus.com/commwiki/wiki?38629,,) is a set of layouts that allows you to query and view data and it also calculates a KPI that you define.

This article describes how to apply it to a [Transaction](https://wiki.genexus.com/commwiki/wiki?1908) or [Web Panel](https://wiki.genexus.com/commwiki/wiki?6916) to obtain a page like the following:

`[imagen omitida: wiki id 53275]`

In the shown image, the KPI calculated corresponds to the average population of the country.

**Note**: The design guideline of this floorplan is at [SAP's documentation](https://experience.sap.com/fiori-design-web/work-list/#worklist-with-kpi).

## [How to apply the KPI Worklist Floorplan](#How+to+apply+the+KPI+Worklist+Floorplan)

Look at the Patterns tab of the Country Transaction. If you have never applied the Fiori for Web pattern in your Knowledge Base before, [read here](https://wiki.genexus.com/commwiki/wiki?21477,,). Otherwise, by positioning on the Fiori for Web Pattern tab, check the Apply this pattern on save checkbox and select the offered link to choose a floorplan:

`[imagen omitida: wiki id 54852]`

Then, select the KPI Worklist option from the list given by GeneXus:

`[imagen omitida: wiki id 53271]`

This floorplan can be applied to a [Transaction object](https://wiki.genexus.com/commwiki/wiki?1908) or a [Web Panel object](https://wiki.genexus.com/commwiki/wiki?6916).

[Learn how to apply it to a Web Panel](https://wiki.genexus.com/commwiki/wiki?42011).

## [How to set the KPI](#How+to+set+the+KPI)

By default, the KPI is an unset variable. In order to set it, you have to open the Object KPI Worklist Web Panel.

`[imagen omitida: wiki id 53273]`

**Note:** Temporarily the Web Panel's name is not WebPanelNameKPIWorklist but it is WebPanelNameListReport.

Once there, go to the Events section.

You can program the KPI behavior on the Refresh Event.

If you want to have a dynamic KPI (the calculation changes when a filter is applied) you can solve it by using the [Data Selector object](https://wiki.genexus.com/commwiki/wiki?5271) generated by GeneXus:

`[imagen omitida: wiki id 53274]`

**Note:** Temporarily the Data Selector's name is not YourObjectNameSimpleWorklistDS but it is YourObjectNameListReportDS.

Remember to do it outside the code generated by GeneXus (to avoid being overwritten by GeneXus).

`[imagen omitida: wiki id 38781]`

## [How to customize it](#How+to+customize+it)

The following section explains how to customize your KPI Worklist.

### [Add/Modify/Delete actions](#Add%2FModify%2FDelete+actions)

You can add, modify or delete actions by positioning on the KPI Worklist tab. However, if you want to do this, you may prefer the [GeneXus For SAP Systems - List Report Floorplan](https://wiki.genexus.com/commwiki/wiki?38572).

To add actions, right-click on the GridActions node and then, select Add > UserAction from the contextual menu. The action will be added outside the grid (in the section where is located the button to insert).

`[imagen omitida: wiki id 54916]`

To modify these actions, right-click on the action node and select the 'Go to Event' option. Then, you can modify the event code, but remember to do it outside the code generated by GeneXus (to avoid being overwritten by GeneXus).

If you want to add an action inside the grid for every line, right-click on the Grid node and select Add > UserAction in the contextual menu:

`[imagen omitida: wiki id 54917]`

In order to modify these actions, you have to follow the next steps:

1. Right-click on the KPI Worklist tab and select Open YourObjectNameKPIWorklist.

`[imagen omitida: wiki id 54918]`

2. Once in the KPI Worklist Web Panel, go to the Events Section.

`[imagen omitida: wiki id 38783]`

3. While there, you only have to create the [Click event](https://wiki.genexus.com/commwiki/wiki?8177) for your customized actions.

`[imagen omitida: wiki id 38784]`

### [Manage filters](#Manage+filters)

You can manage the [filters](https://wiki.genexus.com/commwiki/wiki?38588) by positioning on the KPI Worklist tab.

To add filters you have to right-click on the GridActions node, select Add in the contextual menu and then choose the kind of filter you want.

`[imagen omitida: wiki id 54919]`

For more information, see [GeneXus For SAP Filters](https://wiki.genexus.com/commwiki/wiki?38588).

### [Manage Orders](#Manage+Orders)

You can manage the Orders by positioning on the KPI Worklist tab. Once there, you have to right-click on the GridActions node and then select Add > Orders.

`[imagen omitida: wiki id 54920]`

After having created the Orders node, right-click on Orders and then choose Add > Order to add a new one.

`[imagen omitida: wiki id 54922]`

For each order you create, you have to complete its Name property:

`[imagen omitida: wiki id 54923]`

and you have to add the attribute(s) by which the list will be sorted:

`[imagen omitida: wiki id 54924]`

For each attribute, you can change the Ascending property to choose whether you want the list to be sorted in ascending or descending order considering that attribute(s) value(s).

`[imagen omitida: wiki id 54925]`

### [Customize the information to be shown on the list.](#Customize+the+information+to+be+shown+on+the+list.)

You can manage the attributes to show by positioning on the KPI Worklist tab.

To prevent attributes from being shown on the KPI worklist you have to right-click on the attribute and select Delete. Don't worry, it will be deleted from the Web Panel, not from the Transaction.

`[imagen omitida: wiki id 54926]`

To add attributes to be shown in the list, you have to right-click on the Grid node, then select Add > GridAttribute:

`[imagen omitida: wiki id 54927]`

Then, GeneXus will display a list of attributes for you to choose which ones you want to add.

`[imagen omitida: wiki id 38774]`
