# Features that are exclusive to Angular development (GeneXus 18 Upgrade 2 or prior)

The following is a list of features that is exclusive to [Angular Application Development](https://wiki.genexus.com/commwiki/wiki?42539), that is, may not be able when developing [Native mobile apps](https://wiki.genexus.com/commwiki/wiki?24799) or Web using the traditional approach.

## [User Controls](#User+Controls)

A [User Control object](https://wiki.genexus.com/commwiki/wiki?39356) is supported as a UI control in [Panel object](https://wiki.genexus.com/commwiki/wiki?24829) and [Work With object](https://wiki.genexus.com/commwiki/wiki?15974) but, it is only supported in Angular (Not in Apple or Android generators).  
You should create a layout that is specific to Angular if you want to use this feature.

More information at [Multiple Layouts in Panels](https://wiki.genexus.com/commwiki/wiki?23489) and [KB Platforms](https://wiki.genexus.com/commwiki/wiki?24284).

## [Master Panels](#Master+Panels)

As the [Web Master Panel object](https://wiki.genexus.com/commwiki/wiki?10348) to the [Web Panel object](https://wiki.genexus.com/commwiki/wiki?6916), so the [Master Panel object](https://wiki.genexus.com/commwiki/wiki?46247) to the [Panel object](https://wiki.genexus.com/commwiki/wiki?24829).  
This object is only supported in Angular (Not in Apple or Android generators).

## [Web Platforms](#Web+Platforms)

Web Platforms have been added to the [KB Platforms](https://wiki.genexus.com/commwiki/wiki?24284), so you can design layouts that are specific for Angular apps running in browsers, or specific to Desktop screens

## [Call Options (Target: Top)](#Call+Options+%28Target%3A+Top%29)

Angular supports the target Top as a [CallOptions Target](https://wiki.genexus.com/commwiki/wiki?25323).
