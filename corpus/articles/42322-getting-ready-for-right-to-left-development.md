# Getting ready for Right-to-Left Development

About [75% of the internet](http://www.internetworldstats.com/stats7.htm) speaks a language other than English. Some of these other languages read Right-to-Left ([RTL](https://wiki.genexus.com/commwiki/wiki?42318)), which can completely ruin the layout of your designs.

Cultural and linguistic peculiarities can be a hassle when you’re developing for different regions and markets. Specifically, when it comes to the RTL market developers must use their knowledge to adhere to a completely different set of rules, making the whole process more challenging and potentially frustrating.

In order to be effective in developing RTL applications, there are a number of specific details that need to be taken into account, which are detailed in this TOC.
