# GxRemove variable

Indicates which records will be deleted.

In [Transaction object](https://wiki.genexus.com/commwiki/wiki?1908)s, GeneXus uses an automatic numeric variable in the first column of the second level grid in order to implement an easy record deletion mechanism.

**Data Type:**  
Numeric(1.0)
