# Is Main property for the Selection Node of a Work With for Web Pattern instance

Sets whether the Main Program property must be set to True or False for the Selection Web Panel to be generated.

### [Scope](#Scope)

**Level:** [Work With for Web Pattern Instance](https://wiki.genexus.com/commwiki/wiki?25475)

### [Description](#Description)

The default value is False.

The True value forces the generated object to be generated as a [Main Object](https://wiki.genexus.com/commwiki/wiki?5770).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
