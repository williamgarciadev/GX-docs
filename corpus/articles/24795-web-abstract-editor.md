# Web Abstract Editor

To achieve a Responsive Web Application, and an optimal viewing experience, you must use the Web Abstract Editor.

The main purpose of the Web Abstract editor is to assist in the design of [Responsive Web Applications](https://wiki.genexus.com/commwiki/wiki?25159). It is based on an [Abstract Layout](https://wiki.genexus.com/commwiki/wiki?25209) where the designer can drag and drop any control over a [Responsive Table](https://wiki.genexus.com/commwiki/wiki?24961).

The controls supported are the same controls supported by the [HTML Editor](https://wiki.genexus.com/commwiki/wiki?7673):  [Common Controls](https://wiki.genexus.com/commwiki/wiki?5928) and [User Controls](https://wiki.genexus.com/commwiki/wiki?5273).

In addition, other controls can be used. They are as follows:

* [Tab control for Web Panels](https://wiki.genexus.com/commwiki/wiki?25623)
* [Action Group Control for the Web](https://wiki.genexus.com/commwiki/wiki?25631)
