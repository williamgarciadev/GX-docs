# Identifier Property

Allows assigning a name to a table, row or cell that can then be used in JavaScripts to modify its properties in runtime.

### [Description](#Description)

This property applies only at design time.

### [Scope](#Scope)

**Objects:** [Transactions](https://wiki.genexus.com/commwiki/wiki?1908), [Web Panels](https://wiki.genexus.com/commwiki/wiki?6916)  
**Controls:** [Embedded Pages](https://wiki.genexus.com/commwiki/wiki?6070), [Forms](https://wiki.genexus.com/commwiki/wiki?8132), [Tables](https://wiki.genexus.com/commwiki/wiki?6001), [Tables’s](https://wiki.genexus.com/commwiki/wiki?6001) Cells, [Tables’s](https://wiki.genexus.com/commwiki/wiki?6001) Rows  
**Languages:** .NET, Java, Ruby (up to GeneXus X Evolution 3)  
**Interfaces:** Web
