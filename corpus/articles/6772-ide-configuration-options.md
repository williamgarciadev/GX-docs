# IDE Configuration Options

Certain parts of the IDE can be configured to provide you with a more comfortable experience using it. This can be achieved by specifying your preferences. For instance, you can determine the location of the [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836)s.

The IDE can be configured from the Options window dialog (by selecting in the main GeneXus Menu: **Tools > Options**). Configurable options include Editor configuration and Search engine management, among others.

The following options are available for configuration:

* [Wiki](https://wiki.genexus.com/commwiki/wiki?6834)
* [Themes](https://wiki.genexus.com/commwiki/wiki?43699)
* [Build](https://wiki.genexus.com/commwiki/wiki?24030)
* [Custom Build](https://wiki.genexus.com/commwiki/wiki?43849)
* [Patterns](https://wiki.genexus.com/commwiki/wiki?6841)
* [Comparer](https://wiki.genexus.com/commwiki/wiki?12887)
* [Search](https://wiki.genexus.com/commwiki/wiki?6762)
* [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?6775)
* [Editors](https://wiki.genexus.com/commwiki/wiki?6780)
* [KB Explorer](https://wiki.genexus.com/commwiki/wiki?12913)

These functionalities are frequently enhanced, so be sure to check back regularly for updates.   
The list varies by GeneXus version, so not all of the above listed may be available to your installation.
