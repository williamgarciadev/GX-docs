# Huawei Services File property

Huawei platform configuration file downloaded from the Huawei console. It must be a File in the Knowledge Base.

### [Scope](#Scope)

**Objects:** [Menu](https://wiki.genexus.com/commwiki/wiki?16321), [Panel](https://wiki.genexus.com/commwiki/wiki?24829), [Work With](https://wiki.genexus.com/commwiki/wiki?15974) (Only [Main Objects](https://wiki.genexus.com/commwiki/wiki?5770))  
**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453)

### [Description](#Description)

[Huawei Platform](https://wiki.genexus.com/commwiki/wiki?47546,,) configuration file.

In order to use the [Huawei Platform](https://wiki.genexus.com/commwiki/wiki?47546,,) libraries, you must add a configuration file downloaded from the platform console. Next, add it to the KB as a File under the name "agconnect-services.json" and make sure that the file is referenced from this property. GeneXus will do the rest automatically.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
