# GeneXus for SAP Systems 18 Release Notes

[GeneXus for SAP](http://genexus.com/sap) is the low-code tool for SAP systems, which allows you to develop applications fully integrated with the ERP in a simple and fast way, following a Fiori look&feel, also allowing you to use [HANA in-memory DB](https://wiki.genexus.com/commwiki/wiki?31713) and  [deploy them to SAP BTP.](https://wiki.genexus.com/commwiki/wiki?49572)  
  
Continuing with this purpose, in [GeneXus 18](https://wiki.genexus.com/commwiki/wiki?51066) we added:

[SAP ERP Connection through Destination](https://wiki.genexus.com/commwiki/wiki?52786)

[SAP BTP as IdP](https://wiki.genexus.com/commwiki/wiki?52787)
