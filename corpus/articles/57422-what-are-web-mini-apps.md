# What are Web Mini Apps?

In addition to the [Native Mobile Mini Apps](https://wiki.genexus.com/commwiki/wiki?58298), it is possible to create Web Mini Apps.

A Web Mini App is a web application designed to operate efficiently on mobile devices within the context of a Super App. Unlike traditional Web applications, Web Mini Apps typically have a smaller size and provide services in a faster and more direct way.

 Web Mini Apps features:

* **Standard web technology:** Web Mini Apps are developed using standard web technologies such as HTML, CSS and JavaScript. This facilitates their compatibility with several devices and browsers.
* **Automatic updates:** Because they are hosted on web servers, the updates to Web Mini Apps can be implemented automatically and without user intervention.
* **Web Mini Apps are loaded within the Super App:** A Web Mini App is loaded into a Super App via a Web View that allows mobile applications to display web content.

While the option to use Web Mini Apps is powerful, Native Mobile Mini Apps are even more robust. It is strongly recommended to lean towards the latter as the preferred solution.  
The choice between a Native Mobile Mini app and a Web Mini App will depend on the project's specific requirements and the user's preferences.
