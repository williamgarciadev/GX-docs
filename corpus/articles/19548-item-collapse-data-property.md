# Item Collapse Data property

Upon collapsing the value of a [Query Element](https://wiki.genexus.com/commwiki/wiki?19788), we may want to trigger a particular action (such as recalculating a value, changing the color of a text, interacting with another control, etc.). This property contains the name of the variable based on the QueryViewerItemCollapseData SDT that can be used in the [ItemCollapse Event](https://wiki.genexus.com/commwiki/wiki?19552).

### Values

|  |  |
| --- | --- |
| **&ItemCollapse** | Name of the variable that will implement the event’s inherent properties. This is the default value. |
