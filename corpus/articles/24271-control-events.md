# Control Events

Controls present in a form often have associated events, which have to do with the different actions user can perform in runtime on the control. An example might be the [Click event](https://wiki.genexus.com/commwiki/wiki?8177) in a web environment.

Depending on the control (and its type and mode: readOnly or not) and on the environment (win, web or smart devices) the events offered.

A subset of these events consists of those who directly have to do with a mouse action ([click](https://wiki.genexus.com/commwiki/wiki?8177), [double click](https://wiki.genexus.com/commwiki/wiki?6769), right button: in win or web environment) or finger (tap, long tap, double tap, etc.: in smart devices: known as [touch events](https://wiki.genexus.com/commwiki/wiki?20044)).

Examples of  control events (other than previous) are those that recognize when a non read-only variable or attribute has changed its value ([ControlValueChanged event](https://wiki.genexus.com/commwiki/wiki?22676) in SD, [IsValid event](https://wiki.genexus.com/commwiki/wiki?8049) in web), or a page of a paged grid has changed ([PageChanged event](https://wiki.genexus.com/commwiki/wiki?22735)), etc.
