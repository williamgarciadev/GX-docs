# Rows per page property for the Selection Node of a Work With for Web Pattern instance

Defines the number of rows per page to be displayed in the grid of the Web Panel to be generated.

### [Scope](#Scope)

**Level:** [Work With Pattern Instance](https://wiki.genexus.com/commwiki/wiki?15974)

### [Description](#Description)

The value can be:

* A fixed number (e.g. 10 rows)
* An [Enumerated Domain](https://wiki.genexus.com/commwiki/wiki?2207) (like Page.Rows)
* <unlimited>
* <default>

When setting <default>, the value is taken from the [Work With for Web Pattern Settings](https://wiki.genexus.com/commwiki/wiki?5642) (Grid section).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
