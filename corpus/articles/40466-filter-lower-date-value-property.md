# Filter lower (Date) value property

Filter's default lower value for a range type filter.

### [Description](#Description)

Set a default lower value for a range type filter.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Availability](#Availability)
