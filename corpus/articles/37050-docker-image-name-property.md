# Docker image name property

Name (tag) of the generated Docker image.

### [Scope](#Scope)

**Level:** Deploy Target Options

### [Description](#Description)

This is the name of the docker image that is created when [Deploying to Docker](https://wiki.genexus.com/commwiki/wiki?36951).

By default, the created docker image is tagged with 'latest'. To Tag the image, use this syntax:

```
<docker image name>[:<tag>]
```

e.g.: myfirstappondocker:1.0.0

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Availability](#Availability)

This property is available since [GeneXus 15 Upgrade 8](https://wiki.genexus.com/commwiki/wiki?36778,,).
