# SAP ERP purchase order approval

Web and SD application with Fiori UI that allows to approve or reject purchase orders directly from a SAP ERP installation.

* Allows registering a list of SAP ERP servers
* Log into one SAP ERP from this list
* Retrieve pending purchase orders from SAP ERP
* Approve or Reject purchase order

It's Omni-channel: Web Responsive, Native Android application; all with Fiori look & feel.

You can download this sample from GeneXus for SAP by going to the Start Page->Samples and selecting it.
