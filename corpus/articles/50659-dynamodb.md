# DynamoDB

This is a guide to learn how to consume data saved in DynamoDB with GeneXus.

DynamoDB is a non-relational Database (NoSQL) service. It allows you to scale data reading and writing almost indefinitely, without worrying about maintenance of the associated hardware.
