# Extended Data Type Size Property

This property is used to specify the size of the font used to display the value of the cells.

### [Syntax](#Syntax)

**&***ExcelDocument***.Cells(…).***Size*  
  
**Type Returned:**   
Numeric

### [Description](#Description)

If there are cells using different font *sizes* in the *ExcelCells* object, the *Size* property will return 0.

### [Scope](#Scope)

**Extended Data Types:** [ExcelCells](https://wiki.genexus.com/commwiki/wiki?6958)  
**Languages:** .NET, Java, Ruby, Visual Basic, Visual FoxPro
