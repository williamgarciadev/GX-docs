# Minimum Seconds property

Sets a number of seconds such that when the counter becomes equal to or lower than that value, the text set in the Minimum Text property is displayed.

### [Scope](#Scope)

**Generators:** [Apple](https://wiki.genexus.com/commwiki/wiki?14917)  
**Controls:** Attribute/Variable (Control Type: [Relative Timer](https://wiki.genexus.com/commwiki/wiki?42490))

### [Description](#Description)

This property is only visible for [Panel](https://wiki.genexus.com/commwiki/wiki?24829) Attributes or Variables whose data type is [DateTime](https://wiki.genexus.com/commwiki/wiki?7370).

Once the counter equals or falls below the set duration, specified in seconds, the content designated in the [Minimum Text property](https://wiki.genexus.com/commwiki/wiki?42259) becomes visible.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies both at runtime and at design time.

### [Samples](#Samples)

Suppose that the Minimum Seconds property = 30. When the counter becomes lower than or equal to 30 seconds, the value entered in the Minimum Text property will be displayed.
