# Android specific properties

### [Android SDK Directory](#Android+SDK+Directory)

Specifies the path where the [Android SDK](https://developer.android.com/studio/index.html) is located in the local file system.

### [JDK Directory](#JDK+Directory)

Specifies the path where the [JDK](http://www.oracle.com/technetwork/java/javase/downloads/index.html) is located in the local file system.

### [Copy APK To Cloud](#Copy+APK+To+Cloud)

Specifies whether or not we want the generated app's APK to be uploaded to the Cloud when using [Deploy to Cloud](https://wiki.genexus.com/commwiki/wiki?15041).  
The default value for this property is **True**.

### [MultiDex Build in Android](#MultiDex+Build+in+Android)

Refer to [Multidex Build property](https://wiki.genexus.com/commwiki/wiki?35886) for more information.

### [Gradle Options](#Gradle+Options)

Specifies additional flags that can be passed to [Gradle](http://gradle.org/) (the build system used to compile Android).  
This property is for advanced developers only and it is their responsibility its right usage.

By default has the following command

> --deamon --parallel -Dorg.gradle.jvmargs=-Xmx$(ALLOC\_SIZE)m

Where *$(ALLOC\_SIZE)* is 2048. To disable this behavior simply remove '--daemon' flag.

|  |  |  |
| --- | --- | --- |
|  | **Flag** | **Description** |
|  | **--deamon** | Indicates the usage of [gradle's daemon](https://docs.gradle.org/current/userguide/gradle_daemon.html). This speeds up following builds significantly. |
|  | **--parallel** | Indicates to execute build task in parallel (i.e. compile mains projects in parallel). |
|  | **-Dorg.gradle.jvmargs** | Indicates the JVM arguments to be used by the daemon process.  Possible arguments can be found [here](http://docs.oracle.com/javase/7/docs/technotes/tools/solaris/java.html).  In particular, '-Xmx2048m' sets the maximum amount of memory that is able to allocate for Gradle Daemon. Android's Gradle plugin will use a special option [DexInProcess](https://medium.com/google-developers/faster-android-studio-builds-with-dex-in-process-5988ed8aa37e#.d8gs5kol6) when Gradle's daemon VM has enough memory allocated to speed up its build time significantly.  **Note**: When the [Multidex Build property](https://wiki.genexus.com/commwiki/wiki?35886) is enabled, the amount of memory required to enable dexInProcess increases by 1GB (since this property modifies the javaMaxHeapSize default value).            As a consequence, when [Multidex Build property](https://wiki.genexus.com/commwiki/wiki?35886) is set to True, the *$(ALLOC\_SIZE)* is set to **3GB.**Otherwise, the value used is 2GB. |

### [Android generator](#Android+generator)

Only for advanced users.

#### [Name](#Name)

Custom name for the generator. By default is "Android"

#### [General](#General)

* **Java package name**  
  The identifier of the application package. It is included in [Android Package Name property](https://wiki.genexus.com/commwiki/wiki?17814). By default is "com.<name\_KB\_name>". [Learn more](https://wiki.genexus.com/commwiki/wiki?24941).
* **Use decimal arithmetic**  
  Refer to [Use decimal arithmetic property](https://wiki.genexus.com/commwiki/wiki?10324).

#### [Data Access Information](#Data+Access+Information)

* **Transaction integrity**  
  Refer to [Transactional integrity property](https://wiki.genexus.com/commwiki/wiki?8957)
* **Initialize not referenced attributes**  
  Refer to [Initialize not referenced attributes property](https://wiki.genexus.com/commwiki/wiki?7946)

#### [Build Process](#Build+Process)

* **Classpath**  
  Environment variable to include \*.jar and directories dependencies. [Learn more](https://wiki.genexus.com/commwiki/wiki?9248,,)
* **Base Classpath**  
  Environment variable to include \*.jar and directories dependencies generated from a Module. [Learn more](https://wiki.genexus.com/commwiki/wiki?38567,,).
* **Compiler Path**  
  Path to java compiler binary (javac.exe).
* **Interpreter Path**  
   Path to java interpreter binary (java.exe).
