# Document object

Creates an object with the only purpose of writing documentation.

It is saved below the Orphan Documents node, which is below the Documentation node in the [KB Explorer](https://wiki.genexus.com/commwiki/wiki?3210).

### [Description](#Description+)

When a Document object is created, it contains four selectors:

`[imagen omitida: wiki id 58579]`

1. Browse / Preview (the selector title changes depending on whether you are editing or not)
2. Edit
3. History
4. Back Links

The Edit selector allows you to type the content you want to document.

In the Edit selector, you can edit in an (almost) [WYSIWYG](http://en.wikipedia.org/wiki/WYSIWYG) (What You See Is What You Get) way.

You can include links to other Document objects (or other [GeneXus objects](https://wiki.genexus.com/commwiki/wiki?1866)), attributes, etc. in your Knowledge Base. Files can also be stored in the Knowledge Base as part of your documentation.

Remember you can use the [[ObjectType.ObjectName|Description]] syntax to relate documents within the KB Documentation.

`[imagen omitida: wiki id 58580]`
