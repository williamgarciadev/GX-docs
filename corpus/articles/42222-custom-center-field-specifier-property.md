# Custom Center Field Specifier property

Field of the SDT associated with the Grid for indicating the location (coordinates) used to center the map.

### [Scope](#Scope)

**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917)  
**Controls:** [Grid](https://wiki.genexus.com/commwiki/wiki?24817) (Control Type: [Maps](https://wiki.genexus.com/commwiki/wiki?15309))

### [Description](#Description)

Allows indicating a field of the [Structured Data Type object](https://wiki.genexus.com/commwiki/wiki?10021) associated with the [Grid control](https://wiki.genexus.com/commwiki/wiki?24817) which stores the value of the location used to center the map. This field has to be of [Geolocation domain](https://wiki.genexus.com/commwiki/wiki?14644) or [Geography data type](https://wiki.genexus.com/commwiki/wiki?32408).

The property is available when [Center property](https://wiki.genexus.com/commwiki/wiki?42220) = Custom.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#com.gxwiki.wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, execute a [Build with this Only](https://wiki.genexus.com/commwiki/wiki?5693) of the object.
