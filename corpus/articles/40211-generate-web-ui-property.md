# Generate Web UI property

Enables web user interface generation for this instance.

### [Scope](#Scope)

**Objects:** [Conversational Flows Instance](https://wiki.genexus.com/commwiki/wiki?37113)

### [Description](#Description)

If set to FALSE, the Web objects related to the [Conversational Flows object](https://wiki.genexus.com/commwiki/wiki?37113) are not generated.

For example, the main object <InstanceName>WebUI (main [Web Panel object](https://wiki.genexus.com/commwiki/wiki?6916) which calls the "PanelChatWeb" [resource](https://wiki.genexus.com/commwiki/wiki?37102) object) is not generated. The objects specified in the [Generated Web Component property](https://wiki.genexus.com/commwiki/wiki?39884) of the [Flows](https://wiki.genexus.com/commwiki/wiki?38531) are not generated neither.
