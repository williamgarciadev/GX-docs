# PivotTable Main color

Sets the Main color for the control layout and dialogs.

### [Scope](#Scope)

**Level:** [Design System Style Class](https://wiki.genexus.com/commwiki/wiki?49309)

### [Description](#Description)

Defines the Main color for the control layout and associated PivotTable dialogs.

You can find this definition in the Design System QueryViewer (which is located in [GeneXusReporting module](https://wiki.genexus.com/commwiki/wiki?51178)) with the token name gxqv-color-main. The default is the primary color of the [Unanimo Design System](https://wiki.genexus.com/commwiki/wiki?52175).
