# GeneXusObservability module

Currently, the *GeneXusObservability*module provides an API to manage custom Spans within your application's traces.

The module has a folder named *Tracing*, with the following External Objects:

* [Span](https://wiki.genexus.com/commwiki/wiki?57597)
* [SpanContext](https://wiki.genexus.com/commwiki/wiki?57603)
* [TraceContext](https://wiki.genexus.com/commwiki/wiki?57604)
* [Tracer](https://wiki.genexus.com/commwiki/wiki?57593)

To import this module, in the GeneXus menu select: **Knowledge Manager > Manage Module References**.

Next, to instrument your application using this module set the [Observability Provider property](https://wiki.genexus.com/commwiki/wiki?53408) and configure all the necessary settings for Opentelemetry to work in your environment.
