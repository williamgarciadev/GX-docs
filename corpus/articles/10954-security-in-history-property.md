# Security in history property

Constrains the historical information on the Task that can be accessed by users when displaying the process history.

### [Values](#Values)

|  |  |
| --- | --- |
| **All roles** | Any user accessing the process history can see the Task. This is the default value. |
| **None** | No user can see the Task in the process history. |
| **Selected roles** | It allows specifying a list of roles enabled to see the Task in the history. |
| **Task roles** | Only users with the role to execute the Task can see it in the history. |

### [Scope](#Scope)

**Controls:** [Task](https://wiki.genexus.com/commwiki/wiki?17495), [Subprocess](https://wiki.genexus.com/commwiki/wiki?17268)

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
