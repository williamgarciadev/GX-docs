# OfflineEventReplicator procedure

This procedure implements the [Synchronization.Send method](https://wiki.genexus.com/commwiki/wiki?23604) process in the server side.

It is part of the GeneXus.SD.Synchronization [core module](https://wiki.genexus.com/commwiki/wiki?31268).

To learn how to handle server-side errors in the synchronization process, please refer to: [Error handling in Synchronization.Send() operations](https://wiki.genexus.com/commwiki/wiki?25454)
