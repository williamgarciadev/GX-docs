# ScriptName Property

Returns the name of the object that is being executed, with the corresponding extension, as it appears in the URL.

### [Syntax](#Syntax)

**&***DataType***.ScriptName**  
  
**Type Returned:**   
String

### [Scope](#Scope)

**Extended Data Types:** [HttpRequest](https://wiki.genexus.com/commwiki/wiki?6933)  
**Languages:** .NET, Java, Ruby (up to GeneXus X Evolution 3)
