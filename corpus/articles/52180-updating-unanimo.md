# Updating Unanimo

Unanimo is distributed as a packaged module that is independent of the GeneXus version.

To get the latest version of Unanimo, follow the steps below:

1. Go to [Knowledge Manager](https://wiki.genexus.com/commwiki/wiki?5679) \ [Manage Module References](https://wiki.genexus.com/commwiki/wiki?40172).
2. Select Global Matrix.
3. Select GeneXusUnanimo module.
4. Click on Install.

See [Modules Distribution in GeneXus](https://wiki.genexus.com/commwiki/wiki?31376) to learn more about how to update modules.
