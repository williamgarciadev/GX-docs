# Show Response As property

Selects how the component will be visualized.

### [Values](#Values)

|  |  |
| --- | --- |
| **Call Panel** | The component will not be integrated into the chat. |
| **Component** | The component will be integrated into the chat. |

### [Scope](#Scope)

**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917)

### [Description](#Description)

The **Show Response As** property is available when the [Action property](https://wiki.genexus.com/commwiki/wiki?39492) is set to Component view.

It is available for the [Chatbot Message](https://wiki.genexus.com/commwiki/wiki?39875) at the [Response](https://wiki.genexus.com/commwiki/wiki?39781) node of a [Flow of a Conversational instance](https://wiki.genexus.com/commwiki/wiki?38531).
