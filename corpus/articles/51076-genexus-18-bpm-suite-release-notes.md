# GeneXus 18 BPM Suite Release Notes

[GeneXus 18 BPM Suite](https://wiki.genexus.com/commwiki/wiki?43435) is the most complete and robust version of GXflow. A new and more flexible UI based on Unanimo design system that allows you to customize it and also new resources to build your own Inbox.

There follows a list of the most important improvements.

### [New GXflow Client from scratch](#New+GXflow+Client+from+scratch)

A completely new GXflow Client, created from scratch with full ajax support, responsive, 100% made with genexus controls and based on Unanimo design system. More information: [GXflow Client](https://wiki.genexus.com/commwiki/wiki?17835)

### [Customizable GXflow Client UI](#Customizable+GXflow+Client+UI)

From now on you can apply a different Design System to customize de GXflow UI. More information: [GXflow Backend Style Override property](https://wiki.genexus.com/commwiki/wiki?51755)

### [New Custom Client based on Unanimo](#New+Custom+Client+based+on+Unanimo)

You can create your own Inbox using the new and freely available GXflow Custom Client as a reference. This Custom Client has also been created from scratch with full ajax support, responsive and based on Unanimo.

More information: [GXflow Web Custom Client based on Unanimo design system](https://wiki.genexus.com/commwiki/wiki?48897)

### [New native mobile Client based on Unanimo](#New+native+mobile+Client+based+on+Unanimo)

You can create your own Inbox as a native mobile application using a sample KB as a reference. More information: [GXflow Native Mobile Custom Client based on Unanimo design system](https://wiki.genexus.com/commwiki/wiki?50518,,)

### [Licenses Upgrade](#Licenses+Upgrade)

This version requires an upgrade of GXflow Licenses to version 18.

Follow these steps to upgrade them:

1. Use [GXflow license manager](https://wiki.genexus.com/commwiki/wiki?37207)
2. If you own nominated licenses, [export nominated users](https://wiki.genexus.com/commwiki/wiki?37207), so you don't need to type them in again later
3. [Uninstall licenses](https://wiki.genexus.com/commwiki/wiki?37207)
4. [Request a new license](https://wiki.genexus.com/commwiki/wiki?37207)
5. If you own nominated licenses, [HowTo: Work with GXflow license manager](https://wiki.genexus.com/commwiki/wiki?37207)

More Information: [GXflow license scheme](https://wiki.genexus.com/commwiki/wiki?37204), [HowTo: Work with GXflow license manager](https://wiki.genexus.com/commwiki/wiki?37207)
