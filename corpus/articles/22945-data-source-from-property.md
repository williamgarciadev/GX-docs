# Data Source From property

Indicates where the data used to fill the control is loaded from.

### [Values](#Values)

|  |  |
| --- | --- |
| **Attributes** | Indicates that the control will be filled with attributes (ItemValues and ItemDescriptions properties must be completed). |
| **Data Provider** | Indicates that a Data Provider will be used to fill the control. |
| **Values** | Selects a set of values that will be used to fill the control. It is only visible for Wheel Control for Native Mobile apps. |

### [Scope](#Scope)

**Controls:** Attribute/Variable (Control Type: [Dynamic Combo Box](https://wiki.genexus.com/commwiki/wiki?7598), [Dynamic List Box](https://wiki.genexus.com/commwiki/wiki?7599), Edit, [Wheel](https://wiki.genexus.com/commwiki/wiki?16239))

### [Description](#Description)

When the [Control Type property](https://wiki.genexus.com/commwiki/wiki?9550) = [Wheel Control for Native Mobile apps](https://wiki.genexus.com/commwiki/wiki?20180), the "Range" value is also offered. This value selects a range of numbers (Only for Numeric variables / attributes).

When you set the [Control Type property](https://wiki.genexus.com/commwiki/wiki?9550) = Edit, the Data Source From property can be set. The same applies if the [InputType property](https://wiki.genexus.com/commwiki/wiki?8799) or the [Suggest property](https://wiki.genexus.com/commwiki/wiki?8800) are not set to their default value ("Values" and "No", respectively). Details can be found in [Edit with Suggest](https://wiki.genexus.com/commwiki/wiki?55531).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
