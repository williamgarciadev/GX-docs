# Zoom Factor property

This property is available for [Table](https://wiki.genexus.com/commwiki/wiki?6001) and [Canvas](https://wiki.genexus.com/commwiki/wiki?22452) controls included in [SD Panels](https://wiki.genexus.com/commwiki/wiki?24829) and [WWSD](https://wiki.genexus.com/commwiki/wiki?15974).

It is a numeric value that increases the width and height of a [table](https://wiki.genexus.com/commwiki/wiki?6001) or [canvas](https://wiki.genexus.com/commwiki/wiki?22452) to simulate a zoom effect when scrolling on the control (or set of controls) indicated by [Scroll Attachment property](https://wiki.genexus.com/commwiki/wiki?29875).

The default value for this property is 0, meaning that no zoom effect has been applied to the control. In other cases, a smooth zoom effect is displayed when the end user scrolls on any of the controls where is attached. It will be a zoom-in effect if its value is positive, else will be a zoom-out effect.

### [Note](#Note)

It is commonly used with the [Scroll Factor property](https://wiki.genexus.com/commwiki/wiki?29874) to simulate a [Parallax Effect](https://en.wikipedia.org/wiki/Parallax_scrolling).
