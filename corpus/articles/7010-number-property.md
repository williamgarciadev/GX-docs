# Number Property

Indicates the value of the cells in numeric format.

### [Syntax](#Syntax)

**&***ExcelDocument***.Cells(…).***Number*  
  
**Type Returned:**   
Numeric

### [Description](#Description)

If there are cells with different values in the *ExcelCells* object, the *Number* property will return 0.

### [Scope](#Scope)

**Extended Data Types:** [ExcelCells](https://wiki.genexus.com/commwiki/wiki?6958)  
**Languages:** .NET, Java, Ruby (up to GeneXus X Evolution 3), Visual FoxPro (up to GeneXus X Evolution 3)
