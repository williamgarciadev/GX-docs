# GXtest UI Commands - Appear Text

Checks if certain text is shown on the page.

**Parameters:**

Text: text to search for

**Returns**:

A boolean value indicating if Text parameter was shown on the page.

**Example of use:**

```
&logoutShown = &driver.AppearText("Logout")
```

### [Availability](#Availability)

This set of commands is available since [GeneXus 16 upgrade 10](https://wiki.genexus.com/commwiki/wiki?45624,,).
