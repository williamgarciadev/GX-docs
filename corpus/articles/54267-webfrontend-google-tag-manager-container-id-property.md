# WebFrontend Google Tag Manager Container Id property

Specifies the Google Tag Manager container.

### [Scope](#Scope)

**Objects:** [Menu](https://wiki.genexus.com/commwiki/wiki?16321), [Panel](https://wiki.genexus.com/commwiki/wiki?24829), [Work With](https://wiki.genexus.com/commwiki/wiki?15974) (Only [Main Objects](https://wiki.genexus.com/commwiki/wiki?5770))  
**Generators:** [Angular](https://wiki.genexus.com/commwiki/wiki?42550)

### [Description](#Description)

Specifies the Google Tag Manager container.  
"Container Id" is a unique identifier for a specific container provided by GTM.

A container is a set of tags, triggers, and variables that are managed as a single entity in Google Tag Manager.

Each container created in Google Tag Manager has a unique Container Id, which is a string of letters and numbers that uniquely identifies the container. This Id is used to add the container to a website or mobile app so that the tags, triggers, and variables in the container can be used to track user behavior and other data.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [Availability](#Availability)

This property is available since [GeneXus 18 Upgrade 3](https://wiki.genexus.com/commwiki/wiki?53853).
