# Label Width property

Establishes the width, in percentages, of the control label for each screen size in a Responsive Web Application. The remaining percentage will be given to the control itself.

### [Scope](#Scope)

**Generators:** [Java](https://wiki.genexus.com/commwiki/wiki?12258), .NET, [.NET Core](https://wiki.genexus.com/commwiki/wiki?38604)

### [Description](#Description)

The Label Width property is available in the Responsive Sizes dialog box, for all the controls whose [Label Position property](https://wiki.genexus.com/commwiki/wiki?34141) = Left.

Its default value is 25%.
