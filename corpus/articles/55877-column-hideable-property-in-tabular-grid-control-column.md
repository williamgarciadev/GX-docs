# Column Hideable property in Tabular Grid Control Column

Indicates if the column can be hidden by the end user at runtime.

### [Scope](#Scope)

**Generators:** [Angular](https://wiki.genexus.com/commwiki/wiki?42550)  
**Controls:** [Tabular Grid](https://wiki.genexus.com/commwiki/wiki?54449)

### [Description](#Description)

This property is available when you are positioned in a column of a [Tabular Grid control](https://wiki.genexus.com/commwiki/wiki?54449) included in a [Panel object](https://wiki.genexus.com/commwiki/wiki?24829).

The available values for this property are:

* **True:** The end user can hide the column using the "Settings" button provided by the [Tabular Grid control](https://wiki.genexus.com/commwiki/wiki?54449). This is the default value.
* **False:** The end user can't hide the column.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [Availability](#Availability)

This property is available since [GeneXus 18 Upgrade 6](https://wiki.genexus.com/commwiki/wiki?54240).
