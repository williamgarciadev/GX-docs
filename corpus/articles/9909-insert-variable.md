# Insert - Variable

This dialog allows you to select and insert variables where you are positioned.

To insert a Variable into your object:

1. Position yourself in the section of the object where you want to insert the variable (form, rules, events, layout, etc.).  
2. In the [GeneXus Main Menu](https://wiki.genexus.com/commwiki/wiki?7212), select **Insert** and then **Variable...** (alternatively, you can press the **Ctrl + Shift + V** shortcut to open the insert variable dialog):

`[imagen omitida: wiki id 9910]`

As shown in the image above, this dialog offers the following buttons: New Variable... or Edit...  to create and edit a Variable in the object you are working on.

### [Shortcut](#Shortcut)

The keyboard shortcut **Ctrl+Shift+V** opens the Insert Variable dialog.
