# Time Attribute property

Attribute used as a reference to represent the time dimension in the graph. The attribute value will be used as the start value.

### [Description](#Description)

This property is only available for TimeLine charts. If it is left blank GX will set the first attribute with a Date domain as the "Time Attribute".

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply changes made by this property, Build a main object.

### [Scope](#Scope)

**Platforms:** Smart Devices(Android, IOS)
