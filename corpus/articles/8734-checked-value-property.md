# Checked Value property

Assigns a value to the control when the Check Box is selected.

### [Scope](#Scope)

**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [Java](https://wiki.genexus.com/commwiki/wiki?12258)  
**Controls:** Attribute/Variable (Control Type: Check Box, [Switch](https://wiki.genexus.com/commwiki/wiki?29973))

### [Description](#Description)

This property applies to Attribute/Variable controls included in a [Panel](https://wiki.genexus.com/commwiki/wiki?24829), [Web Panel Web Layout](https://wiki.genexus.com/commwiki/wiki?8132) or [Transaction Web Layout](https://wiki.genexus.com/commwiki/wiki?8057) whose [Control Type](https://wiki.genexus.com/commwiki/wiki?9550) = Check Box or Switch.

It allows you to specify the value that should be associated with the Check Box when it is checked.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
