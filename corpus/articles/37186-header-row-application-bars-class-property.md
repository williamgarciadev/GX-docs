# Header Row Application Bars Class property

[Application Bar theme-class](https://wiki.genexus.com/commwiki/wiki?17879) applied for smoothing transition with the theme class set on [Class property](https://wiki.genexus.com/commwiki/wiki?8741).

## [Notes](#Notes)

* Only displayed when [Enable Header Row Pattern property](https://wiki.genexus.com/commwiki/wiki?29843) is enabled.

## [Scope](#Scope)

**Controls:** [Main Table control](https://wiki.genexus.com/commwiki/wiki?6001)  
**Platforms:** Smart Devices(Android,IOS)

## [Availability](#Availability)

This property is available as of [GeneXus 15](https://wiki.genexus.com/commwiki/wiki?28265,,)
