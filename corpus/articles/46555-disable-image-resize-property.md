# Disable Image Resize property

Enables/disables automatic image resizing. It is enabled by default.

### [Values](#Values)

|  |
| --- |
| **False** |
| **True** |

### [Scope](#Scope)

**Generators:** [Java](https://wiki.genexus.com/commwiki/wiki?12258), .NET, [.NET Core](https://wiki.genexus.com/commwiki/wiki?38604)  
**Controls:** [FileUpload](https://wiki.genexus.com/commwiki/wiki?30574)

### [Description](#Description)

This property allows you to enable or disable the automatic image resize made by the FileUpload control.  
If False (default value), the image will be resized.  
If True, the image will keep its original size.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies both at run-time and at design-time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, execute a Build with this Only of the object.
