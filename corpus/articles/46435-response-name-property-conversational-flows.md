# Response Name property (Conversational Flows)

Defines a Response Name to identify it easily.

### [Scope](#Scope)

**Objects:** [Conversational Flows Instance](https://wiki.genexus.com/commwiki/wiki?37113)

### [Description](#Description)

This property defines a name for the [Chatbot Response](https://wiki.genexus.com/commwiki/wiki?39781) of the [Flow of a Conversational instance](https://wiki.genexus.com/commwiki/wiki?38531).

`[imagen omitida: wiki id 46603]`

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Availability](#Availability)

This property is available since [GeneXus 17](https://wiki.genexus.com/commwiki/wiki?46066,,).
