# Triggers property

Used to specify when a Grid refresh occurs.

### [Values](#Values)

|  |  |
| --- | --- |
| **Always** | Always refresh the Grid. This is the default value. |
| **Only when the object has the focus** | Refresh the Grid when the object receives the focus. |

### [Description](#Description)

#### [Note](#Note)

If Grid property is specified, this is considered.

### [Scope](#Scope)

**Objects:** Web Panel
