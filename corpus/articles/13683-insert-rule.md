# Insert - Rule...

By selecting **Insert** and then **Rule...** from the [GeneXus Main Menu](https://wiki.genexus.com/commwiki/wiki?7212), the following dialog opens, showing the available Rules to use in the [GeneXus object](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?1866,,) section where you are working.

`[imagen omitida: wiki id 58638]`

Then, you can select the appropriate rule from the list. Depending on where you are working:

* [Rules in Procedures](https://wiki.genexus.com/commwiki/wiki?8262)
* [Events in Transactions](https://wiki.genexus.com/commwiki/wiki?8042)
* [Rules in Transactions](https://wiki.genexus.com/commwiki/wiki?8213)
* [Rules in Web Panels](https://wiki.genexus.com/commwiki/wiki?8288), Panels, or Data Providers, etc.

different functions will be displayed.

### [Shortcuts](#Shortcuts)

The keyboard shortcut Ctrl+Shift+R opens the Insert Rule dialog.
