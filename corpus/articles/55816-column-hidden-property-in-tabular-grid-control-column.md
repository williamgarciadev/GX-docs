# Column Hidden property in Tabular Grid Control Column

Indicates whether the column is hidden or not. This can also be changed at runtime by the end user.

### [Scope](#Scope)

**Generators:** [Angular](https://wiki.genexus.com/commwiki/wiki?42550)  
**Controls:** [Tabular Grid](https://wiki.genexus.com/commwiki/wiki?54449)

### [Description](#Description)

This property is available when you are positioned in a column of a [Tabular Grid control](https://wiki.genexus.com/commwiki/wiki?54449) included in a [Panel object](https://wiki.genexus.com/commwiki/wiki?24829).

The possible values for this property are:

* **True**: The column is hidden for the end user in the Tabular Grid, but the end user can choose to show it from the Tabular Grid configuration using the "Settings" button at runtime.
* **False**: The column is visible to the end user in the Tabular Grid. This is the default value.

The difference between this property and the [Column Visible property](https://wiki.genexus.com/commwiki/wiki?55858) is that with the **Column Hidden property**, the end user can choose to display the column at runtime.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [Availability](#Availability)

This property is available since [GeneXus 18 Upgrade 6](https://wiki.genexus.com/commwiki/wiki?54240).
