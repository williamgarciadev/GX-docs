# Copy APK to Tomcat property

Specifies whether or not we want the generated app's APK to be copied to Tomcat.

### [Values](#Values)

|  |
| --- |
| **False** |
| **True** |

### [Scope](#Scope)

**Platforms:** Smart Devices(Android, IOS)
