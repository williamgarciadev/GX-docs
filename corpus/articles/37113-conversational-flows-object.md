# Conversational Flows object

It's used to define the dialog of a conversational bot, to be generated by the [Chatbot generator](https://wiki.genexus.com/commwiki/wiki?37102).

In the [New object](https://wiki.genexus.com/commwiki/wiki?9931) dialog, it's under the Chatbots category:

`[imagen omitida: wiki id 52925]`

Note that it contains two Tabs: Design and Tree inside the Instance Data.

`[imagen omitida: wiki id 52928]`

The default ConversationalFlow instance looks as follows (Designer tab):

`[imagen omitida: wiki id 52923]`

The main element of the Conversational Flows instance structure is the [Flow.](https://wiki.genexus.com/commwiki/wiki?38531)

You can also select the Tree tab that looks as follows:
