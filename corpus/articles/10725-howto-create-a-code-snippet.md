# HowTo: Create a Code Snippet

If you have to type the same code frequently, you can take advantage of the [Code Snippets](https://wiki.genexus.com/commwiki/wiki?10662) in any [GeneXus object](https://wiki.genexus.com/commwiki/wiki?1866) in order to reuse them as templates that can be activated easily via drag and drop or using a shortcut from the Snippets toolbox.

For example let's assume you are using the [Work With pattern](https://wiki.genexus.com/commwiki/wiki?5636) extensively and want to reuse the following code, which is automatically generated by the pattern to check the security, in an easy way:

```
PGetContext.Call(&Context)
IsAuthorized.Call(&PgmName, &IsAuthorized)
If (not &IsAuthorized)
    NotAuthorized.Call(&PgmName)
Endif
```

Suppose that instead of copying a pasting this code between objects and defining its variables, you want to have an easy way to insert the code in a [Procedure](https://wiki.genexus.com/commwiki/wiki?6293). You can do this by using a [code snippet](https://wiki.genexus.com/commwiki/wiki?10662), to encapsulate this code and use it as a command, like available [ones](https://wiki.genexus.com/commwiki/wiki?10662) such as [Call](https://wiki.genexus.com/commwiki/wiki?8260), [For Each command](https://wiki.genexus.com/commwiki/wiki?20195,,), [For In](https://wiki.genexus.com/commwiki/wiki?8585), etc.

Follow these steps to create a [Code Snippet](https://wiki.genexus.com/commwiki/wiki?10662):

### [Step 1. Create a snippet file wrapping your desired code](#Step+1.+Create+a+snippet+file+wrapping+your+desired+code)

Within the [GeneXus X Evolution I](https://wiki.genexus.com/commwiki/wiki?9256,,) installation directory, you will notice the default [code snippets](https://wiki.genexus.com/commwiki/wiki?10662) folder in the *<GeneXusInstallationFolder>\Snippets* folder.

The easiest way to create your own snippet is to reuse an existing one, and then do the desired modifications. This approach will be used.

Copy any command snippet and rename it, in this case its name will be *Check Security command.snippet*.

`[imagen omitida: wiki id 10726]`

Edit it and replace its content with the following code:

```
<?xml version="1.0" encoding="utf-8"?>
<CodeSnippets xmlns="http://schemas.microsoft.com/VisualStudio/2005/CodeSnippet">
    <CodeSnippet Format="1.0.0">
        <Header>
            <Title>Check Security Sample</Title>
            <Shortcut>css</Shortcut>
            <Description>Reuses the security checking generated by the Work With Pattern</Description>
            <Author>Artech</Author>
            <SnippetTypes>
                <SnippetType>Expansion</SnippetType>
                <SnippetType>SurroundsWith</SnippetType>
            </SnippetTypes>
        </Header>
        <Snippet>
            <Declarations>
                <Literal Editable="true">
                    <ID>ContextVariable</ID>
                    <ToolTip>Context SDT Variable</ToolTip>
                    <Default>&amp;Context</Default>
                    <Function>
                    </Function>
                </Literal>
                <Literal Editable="true">
                    <ID>IsAuthorizedVariable</ID>
                    <ToolTip>IsAuthorized Boolean Variable</ToolTip>
                    <Default>&amp;IsAuthorized</Default>
                    <Function>
                    </Function>
                </Literal>
            </Declarations>
            <Code Language="">
                <![CDATA[LoadContext.Call($ContextVariable$)
IsAuthorized.Call(&PgmName, $IsAuthorizedVariable$)
If (not $IsAuthorizedVariable$)
    NotAuthorized.Call(&PgmName)
Endif
]]>
            </Code>
        </Snippet>
    </CodeSnippet>
</CodeSnippets>
```

Some comments about the meaning of this code:

* The *Title*, *Shortcut* and *Description* tags are important because they detail how you will see and use the [code snippets](https://wiki.genexus.com/commwiki/wiki?10662) in the [IDE](https://wiki.genexus.com/commwiki/wiki?5272). In this case:
  + The *Check Security Sample* value will be shown as an available snippet.
  + When using the mouse over, you will get a tooltip with the *css* shortcut and the associated *description*.

                           `[imagen omitida: wiki id 10728]`

* Check the *Code* tag, which contains the desired block of code to be inserted. In this case the code has some minor changes comparing with the initial one because there are some variables to be replaced, that's why you will notice that the *$ContextVariable$* and *$IsAuthorizedVariable$* parameters are used. These are *Literals* which will have to be replaced.
* Check the *Declarations* tag, containing the default values for these variables.

### [Step2. Register your snippet for the desired GeneXus Object](#Step2.+Register+your+snippet+for+the+desired+GeneXus+Object)

Your snippet file is ready, so you will have to register it in the desired [GeneXus object](https://wiki.genexus.com/commwiki/wiki?1866) you want to use.

To register your snippet in a [GeneXus object](https://wiki.genexus.com/commwiki/wiki?1866) you will have to add an entry in a XML File. Notice that for each [GeneXus object](https://wiki.genexus.com/commwiki/wiki?1866) there's a *config.xml* file detailing the available ones for each part.

`[imagen omitida: wiki id 10727]`

In this case,  just register it in the [Source Procedure](https://wiki.genexus.com/commwiki/wiki?6293) section; notice that you need to add a new *Snippet* tag with the name of the snippet file within the <GeneXusInstallationFolder>\Snippets\Procedure\Procedure\config.xml configuration file:

```
<Snippets>
  <Category name="Snippets">
        <Snippet name="Check Security command"/>
        <Snippet name="Call command"/>
......
```

Ready; you have finished the registration process.

### [Step 3. Restart GeneXus](#Step+3.+Restart+GeneXus)

Make sure you have restarted your [IDE](https://wiki.genexus.com/commwiki/wiki?5272).

### [Step 4. Check your new Snippet](#Step+4.+Check+your+new+Snippet)

To make sure your custom snippet for the [Source Procedure](https://wiki.genexus.com/commwiki/wiki?6293) section is available, open or create a new [Procedure](https://wiki.genexus.com/commwiki/wiki?6293), and go to the snippet toolbox. Check the tooptip for more information.

`[imagen omitida: wiki id 10728]`

### [Step 5. Use it !!](#Step+5.+Use+it+%21%21)

To use it just drag & drop it or type the shortcut (*css* for "*Check Security snippet*" in this example) and tab; you will get the desired replacement.

`[imagen omitida: wiki id 10729]`

Once inserted, you just have to create the *&Context* and &*IsAuthorized* variables to complete the operation; notice the related green section.

Congratulations! You have created and used a [custom GeneXus Code Snippet](https://wiki.genexus.com/commwiki/wiki?10662)!

**Note**: Backup your [Code Snippets](https://wiki.genexus.com/commwiki/wiki?10662) every time you install a new GeneXus Upgrade.
