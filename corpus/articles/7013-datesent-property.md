# DateSent Property

This property sets the date and time when the message was sent.

### [Syntax](#Syntax)

**&***DataType***.DateSent**  
  
**Type Returned:**   
DateTime

### [Description](#Description)

This property is read only, so it cannot be assigned.

### [Scope](#Scope)

**Extended Data Types:** [MailMessage](https://wiki.genexus.com/commwiki/wiki?6925)  
**Languages:** .NET, Visual FoxPro (up to GeneXus X Evolution 3)
