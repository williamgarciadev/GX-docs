# Description property for the Selection Node of a Work With for Web Pattern instance

Indicates the description to be included in the Work With Web Panel to be generated.

### [Scope](#Scope)

**Level:** [Work With for Web Pattern Instance](https://wiki.genexus.com/commwiki/wiki?25475)

### [Description](#Description)

You can complete this property for the [Selection Node](https://wiki.genexus.com/commwiki/wiki?5640) of a [Work With for Web pattern](https://wiki.genexus.com/commwiki/wiki?25475) Pattern instance.

It is initialized using the [Transaction](https://wiki.genexus.com/commwiki/wiki?1908) Description property combined with the [Work With for Web Pattern Settings](https://wiki.genexus.com/commwiki/wiki?5642) (Labels section).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
