# Sharing Licenses with other GeneXus versions

GeneXus licenses, though granted for a specific GeneXus version, can be used in prior GeneXus versions.

When authorizing a GeneXus version, you are able to use previous versions without the need to authorize or transfer the licenses between them.

So, when you get a GeneXus 18 license, you can use that with GeneXus 17, or even prior versions, such as GeneXus 6.1.

However, in certain versions, you need to install some compatible upgrades, as follows:

* [GeneXus](https://wiki.genexus.com/commwiki/wiki?1756) 9.0: Install Development Environment 9.0 Upgrade 4 or higher.
* [GeneXus](https://wiki.genexus.com/commwiki/wiki?1756) 8.0: Install [Development Environment 8.0 Upgrade 8](https://www.genexus.com/en/developers/downloadcenter?data=1971;;) or higher.
* [GeneXus](https://wiki.genexus.com/commwiki/wiki?1756) 7.5: Install [Development Environment 7.5 Upgrade 5](https://www.genexus.com/en/developers/downloadcenter?data=1109;;) or higher.
* [GeneXus](https://wiki.genexus.com/commwiki/wiki?1756) 7.0 and 6.1: Download [this file](https://www.genexus.com/en/developers/downloadcenter?data=1114) and extract the protrun.dll file to [GeneXus](https://wiki.genexus.com/commwiki/wiki?1756) installation directory.

Note: If you use centralized licenses (installed in a server), you will have to install a [GeneXus Protection Server](https://wiki.genexus.com/commwiki/wiki?18887,,) that can hold license keys for the latest version of GeneXus. Supported GeneXus versions are listed here: [GeneXus Protection Server](https://wiki.genexus.com/commwiki/wiki?18887,,)
