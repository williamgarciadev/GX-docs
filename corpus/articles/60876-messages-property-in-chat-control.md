# Messages property in Chat control

Specifies the collection of messages in the chat,      which can be used to load past conversations or read existing messages.

### [Scope](#Scope)

Controls: [Chat Control](https://wiki.genexus.com/commwiki/wiki?59254)  
Generators: [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [Java](https://wiki.genexus.com/commwiki/wiki?12258), [Angular](https://wiki.genexus.com/commwiki/wiki?42550)

### [Description](#Description)

It is not recommended to add messages directly to the list in a user event. Instead, use the [AddNewMessage](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?60814,,) or [UpdateLastMessage](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?60814,,) methods.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [Availability](#Availability)

Since [GeneXus 18 Upgrade 14](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?59631,,) and [GeneXus Next](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?57864,,).
