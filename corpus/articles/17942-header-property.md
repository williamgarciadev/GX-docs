# Header property

Header text (caption) displayed above the Table or Grid.

### [Scope](#Scope)

**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [Java](https://wiki.genexus.com/commwiki/wiki?12258)  
**Controls:** [Grid](https://wiki.genexus.com/commwiki/wiki?24817), [Table](https://wiki.genexus.com/commwiki/wiki?6001), [Responsive Table](https://wiki.genexus.com/commwiki/wiki?24961), [Smart Table](https://wiki.genexus.com/commwiki/wiki?45577)

### [Description](#Description)

The string set in this property generates the HTML caption tag of the [Grid](https://wiki.genexus.com/commwiki/wiki?24817), [Table](https://wiki.genexus.com/commwiki/wiki?6001), [Responsive Table](https://wiki.genexus.com/commwiki/wiki?24961), and [Smart Table](https://wiki.genexus.com/commwiki/wiki?45577).

It is recommended to set this property to improve the accessibility of the applications.

More information at [Accessibility for Web Applications](https://wiki.genexus.com/commwiki/wiki?30632).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, execute a [Build with this Only](https://wiki.genexus.com/commwiki/wiki?5693) of the object.

### [Availability](#Availability)

This property is available since [Genexus 15 Upgrade 10](https://wiki.genexus.com/commwiki/wiki?38023,,).
