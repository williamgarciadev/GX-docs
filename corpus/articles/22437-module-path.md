# Module path

Modules are organized in a tree structure. The term Module path referes to the full set of Module names comprising any given branch - using the '.' as separator. The [Root module](https://wiki.genexus.com/commwiki/wiki?22439) is always ommited in the *Module path*.  
ModuleA.ModuleC, ModuleA.ModuleD and ModuleA.ModuleC.ModuleF are *Module paths* examples taken from the image below.
