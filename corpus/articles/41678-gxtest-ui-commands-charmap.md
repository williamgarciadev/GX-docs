# GXtest UI Commands - Charmap

The following table represents the mapping of special characters to be used in KeyStroke commands. Note that the value must be always exactly as shown on the Values column; uppercase and delimited by braces.

| Key | Description | Values |
| --- | --- | --- |
| Null |  | {NULL} |
| Cancel |  | {CANCEL} |
| Backspace |  | {BACKSPACE}  {BS}  {BKSP}  {BACK\_SPACE} |
| Tab |  | {TAB} |
| Enter |  | {ENTER} |
| Shift |  | {SHIFT} |
| Ctrl, Control |  | {CONTROL} |
| Alt |  | {ALT} |
| Escape |  | {ESC}  {ESCAPE} |
| Spacebar |  | {SPACE} |
| Page up |  | {PGUP}  {PAGE\_UP} |
| Page down |  | {PGDN}  {PAGE\_DOWN} |
| Navigation keys |  | {LEFT}  {UP}  {RIGHT}  {DOWN} |
| Equal |  | {EQUAL}  {EQUALS} |
| Delete |  | {DELETE}  {DEL} |
| Help |  | {HELP} |
| Operators |  | {MULTIPLY}  {ADD}  {SUBTRACT}  {DIVIDE} |
| Insert |  | {INSERT}  {INS} |
| Semicolon |  | {SEMICOLON} |
| Numpad keys |  | {NUMPAD0}  {NUMPAD1}  {NUMPAD2}  {NUMPAD3}  {NUMPAD4}  {NUMPAD5}  {NUMPAD6}  {NUMPAD7}  {NUMPAD8}  {NUMPAD9} |
| Pause |  | {PAUSE} |
| Clear |  | {CLEAR} |
| Return |  | {RETURN} |
| End |  | {END} |
| Home |  | {HOME} |
| Function keys |  | {F1}  {F2}  {F3}  {F4}  {F5}  {F6}  {F7}  {F8}  {F9}  {F10}  {F11}  {F12} |
| Meta |  | {META} |
| Command |  | {COMMAND} |
| Thousands | Represents the number pad thousands separator key | {SEPARATOR} |
| Decimal | Represents the number pad decimal separator key | {DECIMAL} |
