# Errors class property

Class used to style the dashboard's errors.

### [Description](#Description)

Defines the Theme class to be used when an error occur. Select a valid option from the *ErrorViewer* node section.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
