# Application property

The IBM Cloud application to deploy.

### [Scope](#Scope)

**Level:** Deploy Target Options

### [Description](#Description)

To deploy to IBM cloud, using the [Application Deployment tool](https://wiki.genexus.com/commwiki/wiki?32092), you have to configure the Application property at the deployment target, among other properties such as [User](https://wiki.genexus.com/commwiki/wiki?45930), [Password](https://wiki.genexus.com/commwiki/wiki?45931), [Space](https://wiki.genexus.com/commwiki/wiki?45921), and [Organization](https://wiki.genexus.com/commwiki/wiki?45920).
