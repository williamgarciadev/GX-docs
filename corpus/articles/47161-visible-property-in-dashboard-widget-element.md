# Visible property in Dashboard widget element

Indicates whether the attribute will be visible or hidden in a Dashboard widget, at runtime, in the DashboardViewer control.

### [Values](#Values)

|  |  |
| --- | --- |
| **Never** | The element is not visible and cannot be changed, but is still accessible. |
| **No** | The element appears hidden from the start, but the user can unhide with an action. |
| **Yes** | The element is visible from the start, but it can be hidden from the UI. It appears in the selected output (Card, Chart, Pivot Table or Table). This is the default value. |

### [Scope](#Scope)

**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Java](https://wiki.genexus.com/commwiki/wiki?12258)  
**Controls:** [Dashboard Widget](https://wiki.genexus.com/commwiki/wiki?36779)

### [Description](#Description)

Defines if a [Query Element](https://wiki.genexus.com/commwiki/wiki?19788) from a [Dashboard widget](https://wiki.genexus.com/commwiki/wiki?36779) will be displayed or not.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, execute a [Build with this Only](https://wiki.genexus.com/commwiki/wiki?5693) of the object.
