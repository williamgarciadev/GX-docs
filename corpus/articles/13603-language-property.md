# Language property

Defines the associated target language to be used when generating source files.

### [Description](#Description)

#### [Values](#Values)

Depends on the current [Environment](https://wiki.genexus.com/commwiki/wiki?7115). For Web environments, available values are C# (.Net) and Java.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply changes made by this property, do a Re-Build All.
