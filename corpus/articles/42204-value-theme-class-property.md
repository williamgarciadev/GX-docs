# Value Theme Class property

Theme class for the current value's bubble

### [Description](#Description)

Allow using a TextBlock type Theme class to modify the aspect of the value's bubble

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
