# AdMob Application ID property

AdMob Application Identifier. Can be found at https://apps.admob.com by registering your application.

### [Scope](#Scope)

**Objects:** [Menu](https://wiki.genexus.com/commwiki/wiki?16321), [Panel](https://wiki.genexus.com/commwiki/wiki?24829), [Work With](https://wiki.genexus.com/commwiki/wiki?15974) (Only [Main Objects](https://wiki.genexus.com/commwiki/wiki?5770))

### [Description](#Description)

This property appears to be configured if you set the [Ads Provider property](https://wiki.genexus.com/commwiki/wiki?46274) = GoogleMobileAds.

It is required as of [GeneXus 16 upgrade 5](https://wiki.genexus.com/commwiki/wiki?43446,,).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
