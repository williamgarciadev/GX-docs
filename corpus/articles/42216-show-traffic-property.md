# Show Traffic property

Indicates if traffic information is displayed on the map.

### [Values](#Values)

|  |
| --- |
| **False** |
| **True** |

### [Scope](#Scope)

**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917)  
**Controls:** [Grid](https://wiki.genexus.com/commwiki/wiki?24817) (Control Type: [Maps](https://wiki.genexus.com/commwiki/wiki?15309))

### [Description](#Description)

This property is only visible for [Panel](https://wiki.genexus.com/commwiki/wiki?24829) or [WW](https://wiki.genexus.com/commwiki/wiki?15974) Grids whose [Control Type property = Maps](https://wiki.genexus.com/commwiki/wiki?15309).

When set to True, this property shows traffic information, it is only shown if the maps provider provides this information for the specific region being displayed.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, execute a [Build with this Only](https://wiki.genexus.com/commwiki/wiki?5693) of the object.
