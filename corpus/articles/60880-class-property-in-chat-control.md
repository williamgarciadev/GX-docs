# Class property in Chat control

Assigns a CSS class to apply to the Chat Control, allowing customization of its appearance.

### [Scope](#Scope)

Controls: [Chat Control](https://wiki.genexus.com/commwiki/wiki?59254)  
Generators: [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [Java](https://wiki.genexus.com/commwiki/wiki?12258), [Angular](https://wiki.genexus.com/commwiki/wiki?42550)

### [Description](#Description)

The Chat Control includes a default class named **chat**, which imports styles from the Unanimo Design System. This class applies standard styling for messages, icons, buttons, and other chat elements.

Instead of using the default **chat** class, you can create and assign your own CSS class to customize the Chat Control’s appearance according to your design requirements.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [Availability](#Availability)

Since [GeneXus 18 Upgrade 14](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?59631,,) and [GeneXus Next](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?57864,,).
