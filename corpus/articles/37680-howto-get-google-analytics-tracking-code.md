# HowTo: Get Google Analytics Tracking Code

This article contains the basic steps to get a [Google Analytics](https://wiki.genexus.com/commwiki/wiki?21718,,) Tracking code to set in the [Code property](https://wiki.genexus.com/commwiki/wiki?55327) of [Google Analytics Control](https://wiki.genexus.com/commwiki/wiki?11847) or in the [Tracker Id property](https://wiki.genexus.com/commwiki/wiki?42119) to use [Google Analytics in Native Mobile and Angular front end Applications](https://wiki.genexus.com/commwiki/wiki?21716).

**Note**: A Gmail account is required to follow the steps listed below.

1. First, go to [Google Analytics](http://analytics.google.com) and log in. If you do not have an account, follow the steps described in the section [Create an Analytics account](https://support.google.com/analytics/answer/9304153?sjid=923999807161942513-SA&visit_id=638182086618542714-503093669&rd=2&hl=en).
2. If you already have an account and have set up a Google Analytics property, go to step 3. Otherwise, go to the section [Create a new Google Analytics property](https://support.google.com/analytics/answer/9304153?sjid=923999807161942513-SA&visit_id=638182086618542714-503093669&rd=2&hl=en).
3. Next, add a Web data stream. For information on how to do this, go to the section [Add a data stream](https://support.google.com/analytics/answer/9304153?hl=en&utm_id=ad&sjid=923999807161942513-SA#stream&zippy=%2Cweb%2Caplicaci%C3%B3n-ios-o-android).   
     

   **Note**: The data stream must not be of iOS or Android app type, even if it requires a mobile app Tracking ID.
4. After creating a Property, you get a MEASUREMENT ID ([Tracker Id](https://wiki.genexus.com/commwiki/wiki?42119) or [Code](https://wiki.genexus.com/commwiki/wiki?55327) that you need to set up in GeneXus), as shown in the image below. Otherwise, go to step 5.  
   `[imagen omitida: wiki id 54555]`
5. Go to the bottom left of the page, hover over the gear icon, and click on Admin to open the page:  
   `[imagen omitida: wiki id 54556]`  
   Then click on Data Streams in the Property section. Finally, clicking on the Web Data Stream will display a tab similar to the one in step 4.
