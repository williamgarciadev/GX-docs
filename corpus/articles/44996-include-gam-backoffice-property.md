# Include GAM Backoffice property

If true, GeneXus Access Manager Backoffice programs will be deployed with your application.

### [Values](#Values)

|  |
| --- |
| **False** |
| **True** |

### [Scope](#Scope)

**Level:** Deploy Target Options

### [Description](#Description)

This property is at the deployment unit Target options of the [Application Deployment tool](https://wiki.genexus.com/commwiki/wiki?32092).

When GeneXus Access Manager is activated, then the Include GAM Backoffice property will be shown. Since the Backoffice objects are distributed as binaries ([GAM - Web Backoffice](https://wiki.genexus.com/commwiki/wiki?15935)), this property works to include it or exclude it in the deployment unit. If true, GeneXus Access Manager Backoffice programs will be deployed with your application.
