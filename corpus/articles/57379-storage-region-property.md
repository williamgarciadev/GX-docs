# Storage Region property

Specifies the region where the bucket is located, which reduces data latency in your applications.

### [Values](#Values)

|  |  |
| --- | --- |
| **US Standard/US East (N. Virginia)** | Sets US Standard/US East (N. Virginia) region. |
| **US Standard/US East (Ohio)** | Sets US Standard/US East (Ohio) region. |
| **US West (N. California)** | Sets US West (N. California) region. |
| **US West (Oregon)** | Sets US West (Oregon) region. |
| **EU (Ireland)** | Sets EU (Ireland) region. |
| **EU (London)** | Sets EU (London) region. |
| **EU (Paris)** | Sets EU (Paris) region. |
| **EU (Frankfurt)** | Sets EU (Frankfurt) region. |
| **Asia Pacific (Tokyo)** | Sets Asia Pacific (Tokyo) region. |
| **Asia Pacific (Seoul)** | Sets Asia Pacific (Seoul) region. |
| **Asia Pacific (Osaka)** | Sets Asia Pacific (Osaka) region. |
| **Asia Pacific (Singapore)** | Sets Asia Pacific (Singapore) region. |
| **Asia Pacific (Sydney)** | Sets Asia Pacific (Sydney) region. |
| **South America (São Paulo)** | Sets South America (São Paulo) region. |
| **Canada (Central)** | Sets Canada (Central) region. |
| **Asia Pacific (Hong Kong)** | Sets Asia Pacific (Hong Kong) region. |
| **Asia Pacific (Mumbai)** | Sets Asia Pacific (Mumbai) region. |
| **Africa (Cape Town)** | Sets Africa (Cape Town) region. |
| **Middle East (Bahrain)** | Sets Middle East (Bahrain) region. |
