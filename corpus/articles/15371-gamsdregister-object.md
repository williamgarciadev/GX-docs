# GAMSDRegister object

GAMSDRegister object is an entry panel for smart devices applications which is incorporated automatically to the KB when [Enable Integrated Security Property](https://wiki.genexus.com/commwiki/wiki?14706) is set to Yes.

The idea is to enable new users to register to the application, as a consequence, this new user will be added to the [GAM](https://wiki.genexus.com/commwiki/wiki?14960) repository.

The "Register" button, in the smart device screen, has an associated Action. This Action calls a procedure that registers the user in the GAM repository using the [GAM API](https://wiki.genexus.com/commwiki/wiki?16535).

`[imagen omitida: wiki id 15374]`

**Note:** GAMSDRegister object is a sample object for the purpose described above, it can be changed or substituted by another one.
