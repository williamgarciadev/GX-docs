# Dashboard Widget Paging property

True to specify if the table or pivot table uses paging; False otherwise.

### [Description](#Description)

Enable or disable paging when using a Table or PivotTable [widget](https://wiki.genexus.com/commwiki/wiki?40467).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Availability](#Availability)

This property is available since [GeneXus 15 upgrade 12](https://wiki.genexus.com/commwiki/wiki?39737,,).

### [Scope](#Scope)

**Objects:** Dashboard
