# HTML container

The HTML container allows to drag an HTML form to an [Abstract Layout](https://wiki.genexus.com/commwiki/wiki?25209). The HTML form is edited using the [HTML Editor](https://wiki.genexus.com/commwiki/wiki?7673).

## [HTML container properties](#HTML+container+properties)

The HTML container can be dragged to an abstract layout, as shown in the following figure:

##### HTML Container inside abstract layout​

After dragging the control to the form, a tree structure is shown below, where each node can be selected and edited independently using the corresponding web editor.
