# REST API Key property

Specifies the API Key used by the OneSignal provider to access the OneSignal REST API.

### [Scope](#Scope)

**Generators:** [Java](https://wiki.genexus.com/commwiki/wiki?12258), [.NET](https://wiki.genexus.com/commwiki/wiki?38604)

### [Description](#Description)

This property is offered when the [Notifications Provider property](https://wiki.genexus.com/commwiki/wiki?33670) = OneSignal.

It defines the API Key that GeneXus uses internally to communicate with the OneSignal REST API when sending Push Notifications.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#com.gxwiki.wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, execute a [Build All](https://wiki.genexus.com/commwiki/wiki?5691).

### [Availability](#Availability)

This property is available since [GeneXus 15 Upgrade 4](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?33798,,).
