# Allow Drag property

Enables user-selected content in a grid row to be dragged to and dropped in another web control.

### [Values](#Values)

|  |
| --- |
| **False** |
| **True** |

### [Scope](#Scope)

**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Java](https://wiki.genexus.com/commwiki/wiki?12258)  
**Controls:** FreeStyle Grid, Grid

### [Description](#Description)

Default value: False.

Setting this property to True allows the user to drag every grid row and drop them in another web control (grid with the [Allow Drop property](https://wiki.genexus.com/commwiki/wiki?9765) enabled as well as another control with the [Drop event in Web](https://wiki.genexus.com/commwiki/wiki?9643) coded). The drag & drop function could be implemented between controls in different Web Components.

The dragged data can include all the contents of attribute/variable rows (hidden ones as well).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
