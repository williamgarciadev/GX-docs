# Border Style property for Rectangle controls

Sets the style of the four edges of the rectangle control.

### [Description](#Description)

The Border Style property is available for Rectangle controls (inserted within a [Printblock control](https://wiki.genexus.com/commwiki/wiki?1958) in a [Procedure Layout](https://wiki.genexus.com/commwiki/wiki?5468)).

It allows setting the style of the four edges of the rectangle, as shown in the figure below:

`[imagen omitida: wiki id 29324]`

### [Availability](#Availability)

This property is available since [GeneXus X Evolution 3 Upgrade 5](https://wiki.genexus.com/commwiki/wiki?29164,,).
