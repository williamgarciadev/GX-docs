# Location Field Specifier property

Field of the SDT containing the location information that is used to load the points on the map.

### [Scope](#Scope)

**Objects:** Panel for Smart Devices, Work With for Smart Devices  
**Platforms:** Smart Devices(Android, IOS)  
**Controls:** Grid

### [Description](#Description)

The [Maps Control Type](https://wiki.genexus.com/commwiki/wiki?15309) will load a set of location values. These location values are taken from the field of the [Structured Data Type (SDT) object](https://wiki.genexus.com/commwiki/wiki?10021) associated with the [Grid control](https://wiki.genexus.com/commwiki/wiki?24817) indicated in this property.  
This field has to be defined as [Geolocation domain](https://wiki.genexus.com/commwiki/wiki?14644) or [Geography data type](https://wiki.genexus.com/commwiki/wiki?32408).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#com.gxwiki.wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, execute a [Build with this Only](https://wiki.genexus.com/commwiki/wiki?5693) of the object.
