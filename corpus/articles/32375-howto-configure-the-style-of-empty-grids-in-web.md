# HowTo: Configure the style of empty grids in Web

This document shows the required steps for giving a style to standard grids when they have no data to show.

### [Step 1](#Step+1)

Assign a class for the grid, such as the Grid class.

`[imagen omitida: wiki id 33772]`

### [Step 2](#Step+2)

In the Theme, edit the Grid class and assign a value for the *Empty Grid Class property* of the Grid Class. Call it GridNoDataBeige.

`[imagen omitida: wiki id 32376]`

### [Step 3](#Step+3)

Configure the GridNoDataBeige class according to the style you want for the grid when it displays no data.

`[imagen omitida: wiki id 32377]`
