# FromBase64 function

Converts a base64 encoded string into a string.

### [Syntax](#Syntax)

**Str**( s1 )

**Where:**  
*s1*  
    Is a string encoded in base64

**Type returned:**  
Character

### [Scope](#Scope)

**Objects:**[Procedure](https://wiki.genexus.com/commwiki/wiki?6293), [Transaction](https://wiki.genexus.com/commwiki/wiki?1908), [Web Panel](https://wiki.genexus.com/commwiki/wiki?6916), [Objects for Native Mobile applications development](https://wiki.genexus.com/commwiki/wiki?20087)

### [Samples](#Samples)

```
&MyString = FromBase64(&MyBase64EncodedString)
```

### [Availability](#Availability)

It is available since [GeneXus 15 Upgrade 4](https://wiki.genexus.com/commwiki/wiki?33798,,)
