# Sort Descriptions Property

Sort the descriptions for the [Dynamic Combo Box](https://wiki.genexus.com/commwiki/wiki?7598) and [Dynamic List Box](https://wiki.genexus.com/commwiki/wiki?7599).

### [Values](#Values)

|  |  |
| --- | --- |
| **True** | List values are sorted. This is the default value. |
| **False** | List values are not sorted. |

*Note:  When Sort Description is disabled, GX will navigate the Table without any ORDER clause specified. The SQL specification doesn't state the specific order that records are to be returned, so it's going to be implementation dependent.*
