# Animated property

It's used to include an animation between state transitions. This transitions will be triggered by the end user when interacts with some controls in the application.

### [Values](#Values)

|  |
| --- |
| **False** |
| **True** |

### [Description](#Description)

When this property is set to True, it also enables the [Animation Duration property (for Animation Theme class)](https://wiki.genexus.com/commwiki/wiki?34112).

This property is available in [Theme object](https://wiki.genexus.com/commwiki/wiki?16595) classes.

When some control has enabled this property, the animation could be associated with:

* A [transformation](https://wiki.genexus.com/commwiki/wiki?23694) of the control.
* A smooth transition when a cell is [collapsed or expanend](https://wiki.genexus.com/commwiki/wiki?22743) (available as of [GeneXus 15 Upgrade 4](https://wiki.genexus.com/commwiki/wiki?33798,,)).
