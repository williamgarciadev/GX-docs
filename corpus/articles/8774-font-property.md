# Font property

Sets the font, size, and style to be used for the text inside the control.

### [Scope](#Scope)

**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [Java](https://wiki.genexus.com/commwiki/wiki?12258)  
**Controls:** Attribute/Variable

### [Description](#Description)

The letter size is specified in pixels and is fixed. The possibility of enlarging or shortening the font that the Browsers have is not applied to the controls.

Applies to: Check Boxes, Combo Boxes, Dynamic Combo Boxes, Dynamic List Boxes, Edits, Error Viewer, Grid Columns, List Boxes, and Radio Buttons.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
