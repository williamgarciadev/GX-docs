# How To: Convert Theme to Design System

By right-clicking on a [Web Theme object](https://wiki.genexus.com/commwiki/wiki?6420) or a [Theme object](https://wiki.genexus.com/commwiki/wiki?16595) a popup menu is opened offering the **Save As Design System...** option:

`[imagen omitida: wiki id 49211]`

Then, the following dialog is opened:

`[imagen omitida: wiki id 49213]`  
  
Once you save your new [Design System Object](https://wiki.genexus.com/commwiki/wiki?47375), GeneXus will automatically scan all the Theme classes and properties and will transform all into a Design System object.

### [Availability](#Availability)

This option is available since [GeneXus 17 Upgrade 6](https://wiki.genexus.com/commwiki/wiki?48684,,).
