# Filter control type property

Filter's control type.

### [Description](#Description)

Defines the filter's control type. The available values for the property varies depending on the [filter's type](https://wiki.genexus.com/commwiki/wiki?40131) and the [filter's data type](https://wiki.genexus.com/commwiki/wiki?40439) properties:

* **Edit**, valid for any filter
* **Radio button**, valid only for value type filters
* **Combo box**, valid only for value type filters
* **Check box**, valid only for boolean value type filters or any collection filter
* **Slider**, valid only for numeric, date or date-time non-collection filters
* **Drop-down list**, valid only for collection filters
* **Switch**, valid only for boolean value type filters

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Availability](#Availability)

This property is available since [GeneXus 15 upgrade 12](https://wiki.genexus.com/commwiki/wiki?39737,,).

### [Scope](#Scope)

**Objects:** Dashboard
