# Generate Apple property

Enables the generation of code for Apple's iOS platform.

### [Values](#Values)

|  |
| --- |
| **False** |
| **True** |

### [Scope](#Scope)

**Generators:** [Apple](https://wiki.genexus.com/commwiki/wiki?14917)  
**Level:** Generator

### [Description](#Description)

The True value will add the Apple Specific group to the list of properties and you will be able to set the necessary properties for prototyping in this platform.
