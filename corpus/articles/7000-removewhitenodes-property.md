# RemoveWhiteNodes Property

This property is used to indicate whether or not WhiteSpace type nodes are to be ignored when processing a document.

### [Syntax](#Syntax)

**&***DataType***.RemoveWhiteNodes**  
  
**Note:**  
The default value is TRUE.

### [Scope](#Scope)

**Extended Data Types:** [XmlReader](https://wiki.genexus.com/commwiki/wiki?6928)  
**Languages:** .NET, Java, Ruby (up to GeneXus X Evolution 3), Visual FoxPro (up to GeneXus X Evolution 3)
