# Method Property

This property returns the HTTP method for the request.

### [Syntax](#Syntax)

**&***DataType***.Method**  
  
**Type Returned:**   
String

### [Values](#Values)

**‘GET’**  
**‘POST’**  
(and any HTTP method)

### [Scope](#Scope)

**Extended Data Types:** [HttpRequest](https://wiki.genexus.com/commwiki/wiki?6933)  
**Languages:** .NET, Java, Ruby (up to GeneXus X Evolution 3)
