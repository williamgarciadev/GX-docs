# Paging Property for grids

The Paging property applies for [Grid control](https://wiki.genexus.com/commwiki/wiki?24817) and [Free Style Grid control](https://wiki.genexus.com/commwiki/wiki?6058), and allows to determine if the grid will have [Paging](https://wiki.genexus.com/commwiki/wiki?6064) or [Infinite scrolling](https://wiki.genexus.com/commwiki/wiki?31231) when [Rows property](https://wiki.genexus.com/commwiki/wiki?2452) is set to a value different than 0.

### [Values](#Values)

|  |  |
| --- | --- |
| **Infinite scrolling** | The grid will load using the [Infinite scrolling](https://wiki.genexus.com/commwiki/wiki?31231) pattern. |
| **One page at a time** | The grid will enable [Paging](https://wiki.genexus.com/commwiki/wiki?6064). |

When Paging property is set to Infinite Scrolling, the [Scroll bar property](https://wiki.genexus.com/commwiki/wiki?31236) is enabled.
