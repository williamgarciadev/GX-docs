# Time to Time TTL(mins) property

Sets the elapsed time, in minutes, that the statement cache keeps information for statements. The property applies to all the tables that have the Change Frequency property set to "Time to Time".

### [Scope](#Scope)

**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Java](https://wiki.genexus.com/commwiki/wiki?12258)  
**Level:** Generator

### [Description](#Description)

This property is enabled when the [Database access caching property](https://wiki.genexus.com/commwiki/wiki?8968) is set to Yes.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
