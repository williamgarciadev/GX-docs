# GeneXus for SAP Systems

GeneXusTM for SAP® Systems provides an agile, low-code, future-proof development platform that empowers companies to create customized, native software experiences leveraging SAP Technologies. Without deep technical knowledge or the need for low-level programming.

GeneXusTM for SAP® Systems is a set of features you can add to a GeneXus installation for developing future-proof applications that run over the SAP Business Technology Platform. You can generate responsive web and native mobile applications (Android and iOS). You can also leverage one-click cloud integration with SAP Business Technology Platform to deploy applications.

Main features:

* Omni-Channel application development as per Fiori UX guidelines
  + HTML 5 Web Responsive applications.
    - More information: [Responsive Web Design in GeneXus](https://wiki.genexus.com/commwiki/wiki?29134)
  + Native Android and iOS applications.
    - More information: [Native Mobile Applications Development](https://wiki.genexus.com/commwiki/wiki?24799)
* Support for SAP Hana in-memory database.
  + More Information: [SAP HANA Database](https://wiki.genexus.com/commwiki/wiki?31713), [How to use SAP HANA Database on SAP Business Technology Platform](https://wiki.genexus.com/commwiki/wiki?47848)
* Certified integration with SAP ERP through standard and custom Business APIs (BAPIs)
  + More information: [GeneXus ERP Connector](https://wiki.genexus.com/commwiki/wiki?26013)
* Automatic deployment to the SAP Business Technology Platform
  + More information: [HowTo: Deploy an application to SAP Cloud Platform](https://wiki.genexus.com/commwiki/wiki?32059)

### [Why GeneXusTM for SAP® Systems?](#Why+GeneXusTM+for+SAP%C2%AE+Systems%3F)

GeneXus simplifies application development for the SAP Business Technology Platform. GeneXus automatically generates & maintains all the relevant technologies required to work with the SAP Business Technology Platform:

* JAVA Applications
* Native Mobile Apps for iOS and Android
* Responsive Web Applications (HTML5 & CSS3)
* SAP HANA DB
* Fiori Apps
