# YAxis Title property

Defines the Y axis title when specified.

### [Scope](#Scope)

**Objects:** Query

### [Description](#Description)

Defines the Y axis title when using a [chart](https://wiki.genexus.com/commwiki/wiki?19612) [QueryViewer control](https://wiki.genexus.com/commwiki/wiki?9075).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies both at runtime and at design time.
