# iOS Applications Wireless Prototyping

Wireless prototyping is one way to prototype applications for iOS with GeneXus ([Deployment and Prototyping in the Apple Platform](https://wiki.genexus.com/commwiki/wiki?16234)).

This type of prototyping is based on [Push Notifications in Native Mobile Applications](https://wiki.genexus.com/commwiki/wiki?19945) to catalog the KB in the [GeneXus Project Navigator](https://wiki.genexus.com/commwiki/wiki?14974) (KBN). Another option is to do it manually, or by capturing the [QR Code](https://wiki.genexus.com/commwiki/wiki?18095) generated by GeneXus.

Regardless of whether it was cataloged through wireless prototyping or manually typing the KB's URL, once it has been cataloged, every time that the application is executed from the device (iPhone and/or iPad), it is automatically updated with the changes performed each time that GeneXus is executed.

### [Requirements](#Requirements)

* An iOS device (iPhone and/or iPad) connected to the same wireless network as the computer used to develop with GeneXus.
* The device must have the [KBN](https://wiki.genexus.com/commwiki/wiki?18653) installed.
* The device must have notifications enabled.

### [Configuring the KB to use the device](#Configuring+the+KB+to+use+the+device)

Ensure that the device is connected to the same network as the deployment machine (where GeneXus is installed).

Open the KBN on the device (for instance, an iPhone). If the KBN isn’t installed, download it from the Apple AppStore --- it only takes a few minutes, and it's free.

|  |
| --- |
|  |
| [GeneXus 15 KB Navigator](http://itunes.apple.com/app/?id=1144118177) |

Click on the Login button and enter your [GeneXus Developer Account](https://www.genexus.com/en/developers/) credentials (username/password).  
If you don’t have an account, create one and return to this step.  
`[imagen omitida: wiki id 37589]`

As soon as your account has been authenticated on the device, it should be registered in [your profile](https://www.genexus.com/en/developers/my-profile).  
In order to check if the device has been successfully added to your device list, login into your account at [GeneXus Developer](http://www.genexus.com/developers/) and click the on tab labeled as “My Devices”; the device(s) should be listed.  
`[imagen omitida: wiki id 37590]`

Open the Smart Devices generator properties. In the iOS Specific group (visible only when [Generate Apple property](https://wiki.genexus.com/commwiki/wiki?18656) is set to True), set the [Execution Type property](https://wiki.genexus.com/commwiki/wiki?18658) to **Knowledge Base Navigator (Device)**.  
`[imagen omitida: wiki id 37591]`

In the Execution Device property:

* Click the three dots button of the property.
* Type in your GeneXus Account username and password.
* Click on the Refresh button.

`[imagen omitida: wiki id 37592]`

### [Prototyping cycle](#Prototyping+cycle)

Press F5 to prototype the application directly on the device. Every time that a KB from the KBN is selected, it will be automatically refreshed with the changes performed in GeneXus.

### [What can go wrong](#What+can+go+wrong)

* The KBN version is old or it isn’t installed. Note that for effective prototyping the KBN version needs to be the corresponding to your GeneXus Version. You may need to maintain various KBN Versions installed, please check [HowTo: Back up and Restore an iOS Application using iTunes](https://wiki.genexus.com/commwiki/wiki?19811)
* The device isn't displayed in the list of devices of the generator’s Execution Device property.  
  Remember you must login to the KBN with the same [GeneXus Developer Account](https://www.genexus.com/en/developers/) user than in GeneXus IDE (option *Tools > GeneXus Account...*)
