# Work with documents property

Specifies whether or not the Task works with documents.

### [Values](#Values)

|  |
| --- |
| **False** |
| **True** |

### [Scope](#Scope)

**Controls:** [Task](https://wiki.genexus.com/commwiki/wiki?17495)

### [Description](#Description)

The default value for this property is False.

When the Work with documents property = True, the [Documents Property](https://wiki.genexus.com/commwiki/wiki?10938,,) is available to configure the document's definitions associated with the Task.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
