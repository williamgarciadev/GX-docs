# Server external object

Server external object allows the developer to manage some server features programmatically.

|  |  |
| --- | --- |
|  |  |

## [Properties](#Properties)

It does not have any.

## [Methods](#Methods)

### [InvalidateCache method](#InvalidateCache+method)

Invalidates the cache when [Smart Devices Cache Management property](https://wiki.genexus.com/commwiki/wiki?18370) has 'OFF' value.

|  |  |
| --- | --- |
| **Return value** | None |
| **Parameters** | None |
