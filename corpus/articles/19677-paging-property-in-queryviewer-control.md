# Paging property in QueryViewer Control

Determines whether there will be paging buttons.

### [Values](#Values)

|  |
| --- |
| **False** |
| **True** |

### [Scope](#Scope)

**Controls:** [QueryViewer](https://wiki.genexus.com/commwiki/wiki?9075)

### [Description](#Description)

The **Paging** property is offered for a [QueryViewer control](https://wiki.genexus.com/commwiki/wiki?9075) when its **Type** property =  "Default", "Pivot Table" or "Table".

The default value for the **Paging** property is True.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
