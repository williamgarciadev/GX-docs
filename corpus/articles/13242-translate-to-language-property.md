# Translate to language property

Sets the language you want to translate the Knowledge Base texts into (for example, label texts or texts inside quotes in rules, sources, etc.).

### [Scope](#Scope)

**Level:** [Environment](https://wiki.genexus.com/commwiki/wiki?7115)

### [Description](#Description)

This property is offered if the [Translation type property](https://wiki.genexus.com/commwiki/wiki?9126) = Static.

`[imagen omitida: wiki id 32860]`

One of the selected language(s) in the [GeneXus Application Localization](https://wiki.genexus.com/commwiki/wiki?6330) node (under Customization) of the KB Explorer:

`[imagen omitida: wiki id 32864]`

The offered languages to be selected are predefined; also, the developer can create a new [Language object](https://wiki.genexus.com/commwiki/wiki?7258).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, execute a [Rebuild All](https://wiki.genexus.com/commwiki/wiki?5691).
