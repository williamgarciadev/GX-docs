# PayPal Test Users

Paypal provides test users to use in sandbox mode for testing. By default, Paypal creates two users (one buyer and one seller):

youremail-buyer@yourdomain.com

youremail-facilitator@yourdomain.com

You can manage your test accounts from your dashboard page.  
Go to Sandbox > Accounts
