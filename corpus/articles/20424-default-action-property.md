# Default Action property

Default event to execute when selecting a Grid row. The default value calls the Detail.

### [Syntax](#Syntax)

**control.** default Action

### [Scope](#Scope)

**Objects:** [Panel](https://wiki.genexus.com/commwiki/wiki?24829), [Work With](https://wiki.genexus.com/commwiki/wiki?15974)  
**Controls:** [Grid](https://wiki.genexus.com/commwiki/wiki?24817)

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Samples](#Samples)

Suppose you have a [Panel object](https://wiki.genexus.com/commwiki/wiki?24829) including a Grid in its Layout and three [events](https://wiki.genexus.com/commwiki/wiki?17042): Insert, Delete, and About.

The following possible values will be offered for the Grid **Default Action** property:

`[imagen omitida: wiki id 20428]`

Select the event you want to be executed when selecting a Grid row.
