# Dashboard Card Include sparkline property

Specifies whether to include a sparkline chart for the values or not.

### [Description](#Description)

This property is only available when the [Type property](https://wiki.genexus.com/commwiki/wiki?40424) has the [Card](https://wiki.genexus.com/commwiki/wiki?31810) value assigned and allows displaying (under the Card indicator) a Sparkline chart showing the indicator's evolution.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Availability](#Availability)

This property is available since [GeneXus 15 upgrade 12](https://wiki.genexus.com/commwiki/wiki?39737,,).

### [Scope](#Scope)

**Objects:** Dashboard
