# Convert to Abstract Layout menu option

"Convert to Abstract Layout" is an option in the HTML Editor context menu.

This option allows converting a form that has been designed using the [HTML Editor](https://wiki.genexus.com/commwiki/wiki?7673) to an [Abstract Layout](https://wiki.genexus.com/commwiki/wiki?25209). Its objective is to make the conversion to [Responsive Web Design (RWD)](https://wiki.genexus.com/commwiki/wiki?25161) applications more agile.

Form controls are inserted in a [Responsive Table](https://wiki.genexus.com/commwiki/wiki?24961), keeping the position and relation of the controls in the original form.

When the conversion cannot be performed, a warning is displayed.

After the conversion, you need to work on the distribution of the controls for the different screen sizes, using the [Responsive Sizes property](https://wiki.genexus.com/commwiki/wiki?29125).

The distribution given to the controls is the default for each screen size. For extra small screens, the information is stacked in a single column. For small, medium, and large screen sizes, horizontally displayed information is given an equal width.

### [Availability](#Availability)

Since GeneXus X Evolution 3 upgrade 5.
