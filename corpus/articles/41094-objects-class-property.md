# Objects class property

Class used to style the dashboard's objects.

### [Description](#Description)

Set the [Theme class](https://wiki.genexus.com/commwiki/wiki?4375) used to style the [Dashboard object](https://wiki.genexus.com/commwiki/wiki?36769).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Scope](#Scope)

**Objects:** Dashboard
