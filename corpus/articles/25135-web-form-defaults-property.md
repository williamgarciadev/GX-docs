# Web Form Defaults property

Determines the default Web form to be generated (Web Abstract Editor or HTML editor).

### [Values](#Values)

|  |  |
| --- | --- |
| **Responsive Web Design** | The object's form will be generated using the Web Abstract Editor. As a result, the design will be responsive. |
| **Previous versions compatible** | The object's form will be generated using the HTML Editor. This is the default value. |

### [Scope](#Scope)

**Objects:** [Transaction](https://wiki.genexus.com/commwiki/wiki?1908)  
**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Java](https://wiki.genexus.com/commwiki/wiki?12258)  
**Level:** [Work With for Web Pattern Instance](https://wiki.genexus.com/commwiki/wiki?25475)

### [Description](#Description)

When there are Transaction forms and objects automatically generated by the Work With for Web pattern, you can decide whether the web form is going to be initialized using the HTML Editor or the [Web Abstract Editor](https://wiki.genexus.com/commwiki/wiki?24795). If the initialization is done using the last, the resulting design will be responsive.

The property at the Transaction level and at Work With Pattern instance level inherit their values from the value set at the version level. This value can be changed for each Transaction and Pattern instance.

##### Web Form Defaults property for Transactions

Notes:

* This property also applies when the menu option [Apply Default menu option (for Win and Web Forms)](https://wiki.genexus.com/commwiki/wiki?9751) is executed for a web form.
* When the **Web Form Defaults** property is set to Responsive Web Design, the following happens in the KB:
  + The Flat (Theme), RwdMasterpage, and RwdRecentLinks objects are imported in the KB.
  + The [Default Master Page property](https://wiki.genexus.com/commwiki/wiki?11597) is set to RwdMasterpage and the [Default Style property](https://wiki.genexus.com/commwiki/wiki?8145) is set to Flat.
* When using a Master Page, keep the Web Panel and associated MasterPage using the same **Web Form Defaults property** value; do not mix them as unexpected behavior may occur.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

No action is required to apply the corresponding changes when the property value is configured.
