# Identifying the Active Development Version

GeneXus provides several ways to easily identify what the active development version is at any given time.

* Its name is shown in the [Version](https://wiki.genexus.com/commwiki/wiki?7860) node of the [Preferences](https://wiki.genexus.com/commwiki/wiki?7109) windows
* It is displayed in bold in the [Knowledge Base Versions tool window](https://wiki.genexus.com/commwiki/wiki?5687), with a bubble next to it that reads: "You are working here"
