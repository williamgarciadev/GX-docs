# GeneXus for SAP Fiori Mobile Pattern - Other Floorplan

The Other [Floorplan](https://wiki.genexus.com/commwiki/wiki?38629,,) is a set of templates that add "an extra" to your app.

This article explains what this "extra" is and how to apply it to a [Panel object](https://wiki.genexus.com/commwiki/wiki?24829).

## [How to apply it](#How+to+apply+it)

If you have never applied the FioriMobile Pattern on your KB before, read [GeneXus for SAP Systems - Fiori Mobile Pattern](https://wiki.genexus.com/commwiki/wiki?39800).

Once you create a Panel, the following window showing a group of categories will be displayed. Each one of them offers different templates.

If you select the Other category, only one template is shown and you can select it to be applied to the Panel:

`[imagen omitida: wiki id 39947]`

### [Web Browser](#Web+Browser)

The Web Browser template allows you to show a web page on your app:

`[imagen omitida: wiki id 39945]`

To achieve this, go to the Event tab of the SD Panel to which the template has been applied and assign to the variable &UrlComponent the URL you want to show:

`[imagen omitida: wiki id 39946]`
