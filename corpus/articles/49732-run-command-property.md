# Run Command property

Sets the command used to start the web application; by default the app is served on localhost using a free port.

### [Scope](#Scope)

**Generators:** [Angular](https://wiki.genexus.com/commwiki/wiki?42550)  
**Level:** Generator

### [Description](#Description)

The default value for this property is "npm start." It executes the necessary commands (for example, ng serve) for the Angular application to run properly on localhost, on the first available port.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Availability](#Availability)

This property is available since [GeneXus 17 Upgrade 5](https://wiki.genexus.com/commwiki/wiki?48247,,).
