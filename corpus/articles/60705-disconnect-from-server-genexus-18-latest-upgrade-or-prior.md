# Disconnect From Server (GeneXus 18 latest upgrade or prior)

The Disconnect From Server option allows dissociating a local Knowledge Base from a [GeneXus Server](https://wiki.genexus.com/commwiki/wiki?9911) one.

### [Step by step](#Step+by+step)

1) Refer to the [Preferences](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?7109,,) menu and right-click upon the [Team Development node](https://wiki.genexus.com/commwiki/wiki?20902):

`[imagen omitida: wiki id 32243]`

2) The confirmation dialog will appear:

`[imagen omitida: wiki id 32244]`

3) Done! The local Knowledge Base now disconnected from the GeneXus Server one.

**Note:** After confirmation, the [Share Knowledge Base on GeneXus Server](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?60736,,) option will be available under the *File* menu.
