# Order property

Establishes the desired order in which the associated query will be returned. It is equivalent to writing the Order clause in the For Each command.

### [Scope](#Scope)

**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Java](https://wiki.genexus.com/commwiki/wiki?12258)  
**Controls:** [Grid](https://wiki.genexus.com/commwiki/wiki?24817), [Free Style Grid](https://wiki.genexus.com/commwiki/wiki?6058)

### [Description](#Description)

This property is offered for [Grid control](https://wiki.genexus.com/commwiki/wiki?24817)s and [Free Style Grid control](https://wiki.genexus.com/commwiki/wiki?6058)s in [Web Panel object](https://wiki.genexus.com/commwiki/wiki?6916)s.

It allows indicating the order in which the query must be returned. It is equivalent to writing the [Order clause](https://wiki.genexus.com/commwiki/wiki?6075) in the [For Each command](https://wiki.genexus.com/commwiki/wiki?24744).

You can indicate a simple or composed order.

To indicate that you want a descending order for a certain attribute of the list of attributes indicated, the name of that attribute must be written between brackets.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
