# WidthUnit property

WidthUnit is a run-time property specifying the unit of measure that the value of Width Property is in.

### [Description](#Description)

#### [Values](#Values)

|  |  |
| --- | --- |
| "**px**" | Pixels.  This is the default value. |
| "**%**" | Percentage |

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at run-time.

### [Samples](#Samples)

```
BLData.Width = 100
BLData.WidthUnit = "%"
```

### [Scope](#Scope)

**Controls:** Embedded Page
