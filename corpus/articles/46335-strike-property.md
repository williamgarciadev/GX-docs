# Strike property

Indicates if the font in the cell will be Strikethrough

### [Syntax](#Syntax)

&ExcelFont.**Strike**

### [Type returned](#Type+returned)

Boolean

### [Scope](#Scope)

[ExcelFont Data Type](https://wiki.genexus.com/commwiki/wiki?46318)

### [Availability](#Availability)

This property is available since [GeneXus 16 Upgrade 11](https://wiki.genexus.com/commwiki/wiki?45901,,)
