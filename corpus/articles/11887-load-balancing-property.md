# Load balancing property

Assigns automatically a Task to the user with less workload from the group of users authorized to execute the Task.

### [Values](#Values)

|  |
| --- |
| **False** |
| **True** |

### [Scope](#Scope)

**Controls:** [Task](https://wiki.genexus.com/commwiki/wiki?17495)

### [Description](#Description)

In this case, workload is the number of assigned Tasks the user has in his inbox.

The default value of this property is False.

This is a [User Task property](https://wiki.genexus.com/commwiki/wiki?17499), that helps you define the behavior of the Business Process.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
