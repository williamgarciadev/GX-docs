# XPZ

Usually refers to the files used by the [Knowledge Manager](https://wiki.genexus.com/commwiki/wiki?5679) to exchange objects between [Knowledge Bases](https://wiki.genexus.com/commwiki/wiki?1836).

The name comes from these files' extension (\*.xpz).
