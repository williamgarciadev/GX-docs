# RemoteAddress Property

This property returns the client address on ipv4 or ipv6 format depending on which is being used

### [Syntax](#Syntax)

**&***DataType***.RemoteAddress**  
  
**Type Returned:**   
String

### [Scope](#Scope)

**Extended Data Types:** [HttpRequest](https://wiki.genexus.com/commwiki/wiki?6933)  
**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Java](https://wiki.genexus.com/commwiki/wiki?12258)

### [Description](#Description)

Its behavior is the same as [RemoteAddr function](https://wiki.genexus.com/commwiki/wiki?8484). Please refer to that documentation for additional notes.
