# Label domain

Represents a string label in the context of the [GeneXus Cognitive API](https://wiki.genexus.com/commwiki/wiki?40167). The semantics depend on the AI task used.

A label is a category (discrete value) that is distinguishable from others. In other words, acts as an identifier. For example a place, an object, a language, etc.

## [Semantics](#Semantics)

|  |  |
| --- | --- |
| [GeneXus Cognitive API - ExtractEntities procedure](https://wiki.genexus.com/commwiki/wiki?40182) | A named entity (e.g. 'Bay of Montevideo' as a place). |
| [GeneXus Cognitive API - DetectFaces procedure](https://wiki.genexus.com/commwiki/wiki?40177) | A person's name or identifier (e.g. 'Tom Hanks'). |
| [GeneXus Cognitive API - DetectLanguage procedure](https://wiki.genexus.com/commwiki/wiki?40181) | A language identifier (e.g. 'en' for English). |
| [GeneXus Cognitive API - DetectObjects procedure](https://wiki.genexus.com/commwiki/wiki?40178) | An object name (e.g. 'car', 'table', etc). |
| [GeneXus Cognitive API - DetectScene procedure](https://wiki.genexus.com/commwiki/wiki?40179) | An image feature (e.g. 'landscape' or 'crowd'). |
| [GeneXus Cognitive API - KeyPhrases procedure](https://wiki.genexus.com/commwiki/wiki?40183) | A relevant word or phrase (e.g. 'customer' in an organizational context). |
