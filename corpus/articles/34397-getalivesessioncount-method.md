# GetAliveSessionCount method

Returns the number of sessions in all the repositories which are active.

### [Syntax](#Syntax)

**GAMRepository.GetAliveSessionCount(**out: GAMError Collection**)**: int

### [Description](#Description)

The GetAliveSessionCount method is available for GAMRepository as well as for GAM external objects. This method returns the number of sessions in all the repositories which are active (Status = Active). The only way to execute this method is by connecting to [GAM Manager Repository](https://wiki.genexus.com/commwiki/wiki?18617).

**Note**: This method was called GetActiveSessionCount until [GeneXus 16 upgrade 7](https://wiki.genexus.com/commwiki/wiki?44454,,).
