# Platform Overrides property

Sets a specific Style (Design System object or Theme), Navigation Style, and Orientation values different than the default ones to an application.

### [Scope](#Scope)

**Objects:** [Menu](https://wiki.genexus.com/commwiki/wiki?16321), [Panel](https://wiki.genexus.com/commwiki/wiki?24829), [Work With](https://wiki.genexus.com/commwiki/wiki?15974) (Only [Main Objects](https://wiki.genexus.com/commwiki/wiki?5770))  
**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917)

### [Description](#Description)

This property allows setting for a main object a Style (Design System object or Theme), [Navigation Style](https://wiki.genexus.com/commwiki/wiki?16229), and [Default Layout Orientation](https://wiki.genexus.com/commwiki/wiki?23398) that are different than the ones configured at [KB Platforms](https://wiki.genexus.com/commwiki/wiki?24284).

When you edit the Platform Overrides property, the following dialog is opened offering to configure the three properties shown below:

`[imagen omitida: wiki id 51298]`

**Note:** If Images that vary depending on the Theme are going to be used, it is necessary to add those Themes in the [Additional Styles property](https://wiki.genexus.com/commwiki/wiki?40582) of the platforms.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, Build the [Main Object](https://wiki.genexus.com/commwiki/wiki?5770).
