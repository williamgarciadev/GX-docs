# Root form

**Warning**: The HTML Editor is deprecated since [GeneXus 18](https://wiki.genexus.com/commwiki/wiki?51066). You should use it only on existing objects. New objects should be developed using the [Web Abstract Editor](https://wiki.genexus.com/commwiki/wiki?24795). [Here](https://wiki.genexus.com/commwiki/wiki?25250) you find a guide on how to use it. You may also want to convert existing applications so that they can be responsive. More information on that at [How to convert my application to make it responsive](https://wiki.genexus.com/commwiki/wiki?25214).

You can choose between the [Web Abstract Editor](https://wiki.genexus.com/commwiki/wiki?24795) and the [HTML Editor](https://wiki.genexus.com/commwiki/wiki?7673) for the different parts of the web form you are designing by nesting form layouts.

The Root form is the root node of the tree structure composed of HTML and Abstract form nodes.

The Root form can be HTML or an [Abstract Layout](https://wiki.genexus.com/commwiki/wiki?25209).
