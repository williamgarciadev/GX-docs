# Objects for Native Mobile applications development

The methodology used by GeneXus to create mobile applications involves the following objects:

* [Menu object](https://wiki.genexus.com/commwiki/wiki?16321)
* [Panel object](https://wiki.genexus.com/commwiki/wiki?24829)
* [Work With pattern and Work With object](https://wiki.genexus.com/commwiki/wiki?15974)
* [Design System object](https://wiki.genexus.com/commwiki/wiki?47375)
* [Theme object](https://wiki.genexus.com/commwiki/wiki?16595)
* [UI Test object](https://wiki.genexus.com/commwiki/wiki?46009)
* [Offline Database object](https://wiki.genexus.com/commwiki/wiki?22509)
* [Data Provider object](https://wiki.genexus.com/commwiki/wiki?5270)
* [Procedure object](https://wiki.genexus.com/commwiki/wiki?6293)

### [Notes](#Notes)

* The above objects **are not exclusively** for Native Mobile applications.
* There are also other concepts used when developing Native Mobile applications like [Business Component](https://wiki.genexus.com/commwiki/wiki?5846)s and more.
