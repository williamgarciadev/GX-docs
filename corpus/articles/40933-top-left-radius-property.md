# Top Left Radius property

Sets the radius of the top left border corner.

### [Scope](#Scope)

**Objects:** Theme for Smart Devices  
**Platforms:** Smart Devices(Android, IOS)

### [Description](#Description)

The purpose of this property is to be able to set the top left radius of the control.
