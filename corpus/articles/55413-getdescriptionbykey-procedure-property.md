# GetDescriptionByKey Procedure property

Sets the Procedure that returns the description to be displayed in the User Interface.

### [Scope](#Scope)

**Controls:** Attribute/Variable (Control Type: [Dynamic Combo Box](https://wiki.genexus.com/commwiki/wiki?7598), [Dynamic List Box](https://wiki.genexus.com/commwiki/wiki?7599), Edit, [Wheel](https://wiki.genexus.com/commwiki/wiki?16239))

### [Description](#Description)

The GetDescriptionByKey Procedure property is used to [Edit with Suggest](https://wiki.genexus.com/commwiki/wiki?55531) when the [Item Values property](https://wiki.genexus.com/commwiki/wiki?8808) and the [Item Descriptions property](https://wiki.genexus.com/commwiki/wiki?8807) are not the same (that is, they show different values and descriptions). In this case, you must create a Procedure that takes the values of the Item Values Property and returns the descriptions to display in the user interface (values of the Item Description property).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [Availability](#Availability)

This property is available since [GeneXus 18 Upgrade 5](https://wiki.genexus.com/commwiki/wiki?54239).
