# On assignment change property

Executes a Procedure when the assignment of a Task instance changes.

### [Scope](#Scope)

**Controls:** [Task](https://wiki.genexus.com/commwiki/wiki?17495), [Subprocess](https://wiki.genexus.com/commwiki/wiki?17268)   
**Level:** [Version](https://wiki.genexus.com/commwiki/wiki?7860)

### [Description](#Description)

The possible changes in the assignment could be:

#### [Take Task](#Take+Task)

Takes a set of tasks that have not been assigned to a user.

`[imagen omitida: wiki id 55692]`

#### [Reassign Task](#Reassign+Task)

This Task reassigns a workitem

`[imagen omitida: wiki id 55695]`

#### [Delegate Task](#Delegate+Task)

Delegates a Task to another system user or role.

`[imagen omitida: wiki id 55696]`

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
