# AdMob Application ID (iOS) property

Sets the AdMob Application Identifier for iOS.

### [Scope](#Scope)

**Objects:** [Menu](https://wiki.genexus.com/commwiki/wiki?16321), [Panel](https://wiki.genexus.com/commwiki/wiki?24829) (Only [Main Objects](https://wiki.genexus.com/commwiki/wiki?5770))  
**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917)

### [Description](#Description)

AdMob Application Identifier can be found at https://apps.admob.com by registering your application.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
