# Parameters property

Specifies the list of parameters with which a specific object will be invoked.

### [Description](#Description)

In several scenarios, when a property is used to indicate the name of an object to be called, another property called Parameters is available to indicate the list of parameters to be sent to the object.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
