# GeneXus for SAP Systems - Application Integration

[GeneXus for SAP Systems](https://wiki.genexus.com/commwiki/wiki?33616) offers several ways for application integration.

If you need to integrate with SAP ERP through BAPIs, the [GeneXus ERP Connector](https://wiki.genexus.com/commwiki/wiki?26013) is the tool that comes built-in.
