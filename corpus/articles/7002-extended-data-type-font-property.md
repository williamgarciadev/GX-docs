# Extended Data Type Font Property

This property is used to specify the font used to display the value of the cells.

### [Syntax](#Syntax)

**&**ExcelDocument**.Cells(…).**Font  
  
**Type Returned:**   
Character

### [Description](#Description)

If there are cells using different fonts in the *ExcelCells* object, the *Font* property will return an empty string.

### [Scope](#Scope)

**Extended Data Types:** [ExcelCells](https://wiki.genexus.com/commwiki/wiki?6958)  
**Languages:** .NET, Java, Ruby, Visual Basic, Visual FoxPro
