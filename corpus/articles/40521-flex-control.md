# Flex control

The Flex control is of container type. Its objective is to offer new ways to arrange controls in the user interface, even if the sizes of the controls contained are unknown. For this reason, it provides more efficient ways to achieve receptive user interfaces than the [Table](https://wiki.genexus.com/commwiki/wiki?6001) and [Responsive Table](https://wiki.genexus.com/commwiki/wiki?24961) controls.

To add a Flex control to the selected location, drag the Flex control `[imagen omitida: wiki id 40524]` from the toolbox:

`[imagen omitida: wiki id 40621]`

Also, a [Table](https://wiki.genexus.com/commwiki/wiki?6001) or [Responsive Table](https://wiki.genexus.com/commwiki/wiki?24961) control can be converted by right-clicking on them and selecting the "Convert to Flex" option from the context menu (this option is also available in the main table of the form).

`[imagen omitida: wiki id 40622]`

Unlike the [Table](https://wiki.genexus.com/commwiki/wiki?6001) and [Responsive Table](https://wiki.genexus.com/commwiki/wiki?24961) controls, the Flex Control container has a group of properties called "Layout Behavior," where the following properties can be configured:

|  |  |  |
| --- | --- | --- |
| Layout Behavior (Default)  |  | | --- | |  |   Layout Behavior (only if Flex Wrap is set to Wrap or Wrap Reverse) | [Flex Direction property](https://wiki.genexus.com/commwiki/wiki?36107)  [Flex Wrap property](https://wiki.genexus.com/commwiki/wiki?36109)  [Justify Content property](https://wiki.genexus.com/commwiki/wiki?36108)  [Align Items property](https://wiki.genexus.com/commwiki/wiki?36111)  [Align Content property](https://wiki.genexus.com/commwiki/wiki?36110) (if [Flex Wrap property](https://wiki.genexus.com/commwiki/wiki?36109) is set to Wrap or Wrap Reverse)  Adjust Container Size property (it is displayed if [Flex Wrap property](https://wiki.genexus.com/commwiki/wiki?36109) is set to No wrap) |

The [Flex](https://wiki.genexus.com/commwiki/wiki?40521) control has the [Class property](https://wiki.genexus.com/commwiki/wiki?8741): Flex configured by default.  This class can be customized from the theme. In addition, from the theme class the following properties can be configured: [Flex Direction property](https://wiki.genexus.com/commwiki/wiki?36107), [Flex Wrap property](https://wiki.genexus.com/commwiki/wiki?36109), [Justify Content property](https://wiki.genexus.com/commwiki/wiki?36108), [Align Items property](https://wiki.genexus.com/commwiki/wiki?36111), [Align Content property](https://wiki.genexus.com/commwiki/wiki?36110).

## [Availability](#Availability)

The control is available from [GeneXus 15 upgrade 12](https://wiki.genexus.com/commwiki/wiki?39737,,)

## [Scope](#Scope)

**Platforms**: SmartDevices (Android, iOS), Web(.Net, Java)  
**Objects**: Panel for Smart Devices, Work With for Smart Devices, Web Panels
