# HoveringColor property

Background color to be applied to the line on which the cursor is located, if the AllowHovering property is set to True.

### [Syntax](#Syntax)

**control.** HoveringColor = expression   

**Where:**  
*control*  
    Is the name of a grid control inserted in the form.

*expression*  
    Is a numeric representing an RGB color.

**Default Value =** ‘Cyan’

### [Scope](#Scope)

**Objects:** Transaction, Web Panel  
**Platforms:** Web(.Net, Java)  
**Controls:** Grid

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies both at run-time and at design-time.
