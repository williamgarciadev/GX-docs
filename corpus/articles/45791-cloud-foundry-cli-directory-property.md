# Cloud Foundry CLI Directory property

Sets the directory of Cloud Foundry CLI.

### [Scope](#Scope)

**Level:** Deploy Target Options

### [Description](#Description)

You must specify the path for Cloud Foundry command-line client (i.e.: C:\Program Files\Cloud Foundry). This tool is used to deploy your application automatically in the SAP Cloud Foundry environment.

### [Availability](#Availability)

This property is available since [GeneXus 16 upgrade 10](https://wiki.genexus.com/commwiki/wiki?45624,,).
