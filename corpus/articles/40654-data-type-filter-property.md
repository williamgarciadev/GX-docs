# Data Type Filter property

Indicates the data types list for which the user control is appropriate. A comma-separated list (,) is expected with the following values: Numeric, Character, VarChar, LongVarChar, DateTime, Date, Image, Video, Audio. and any other valid SDT type.

### [Description](#Description)

This property is offered for [User Control objects](https://wiki.genexus.com/commwiki/wiki?39356) that have their [Is Control Type property](https://wiki.genexus.com/commwiki/wiki?40584) set to True.

The value of this property must be a comma-separated list (,) with the following values: [Numeric](https://wiki.genexus.com/commwiki/wiki?6793), [Character](https://wiki.genexus.com/commwiki/wiki?6777), [VarChar](https://wiki.genexus.com/commwiki/wiki?6778), [LongVarChar](https://wiki.genexus.com/commwiki/wiki?7371), [DateTime](https://wiki.genexus.com/commwiki/wiki?7370), [Date](https://wiki.genexus.com/commwiki/wiki?7373), [Image](https://wiki.genexus.com/commwiki/wiki?15204), [Video](https://wiki.genexus.com/commwiki/wiki?16608), [Audio](https://wiki.genexus.com/commwiki/wiki?16529). For example, a valid value for the property can be: VarChar, Character, LongVarChar.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Availability](#Availability)

This property is available since [GeneXus 16](https://wiki.genexus.com/commwiki/wiki?35351,,).
