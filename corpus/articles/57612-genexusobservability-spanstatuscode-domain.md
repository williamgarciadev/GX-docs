# GeneXusObservability.SpanStatusCode domain

SpanStatusCode is a domain of the [GeneXusObservability module](https://wiki.genexus.com/commwiki/wiki?58681) that is used to set the Status Code of Spans.

* Unset: 0
* Ok: 1
* Error: 2

See [HowTo: Set an exception event in a Span](https://wiki.genexus.com/commwiki/wiki?57609) for an example of use.
