# KB alias

It is the name with which [GeneXus Server X Evolution 2](https://wiki.genexus.com/commwiki/wiki?17806,,) will identify the KB. It may or may not match the name of the local KB. In the event of doing a [Send Knowledge Base to GeneXus Server](https://wiki.genexus.com/commwiki/wiki?10215) we recommend that the actual name of the local KB be used as an AKA.

The AKA must be unique in the instance of Genexus Server. When a KB is sent to the KB with an AKA that already exists in GeneXus Server, the following error occurs:

"GeneXus Server: KB '<alias>' already hosted"
