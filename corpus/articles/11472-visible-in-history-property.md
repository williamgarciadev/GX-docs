# Visible in history property

Indicates if the task, gateway or subprocess should be shown or not in the history.

### [Values](#Values)

|  |
| --- |
| **False** |
| **True** |

### [Scope](#Scope)

**Controls:** [Task](https://wiki.genexus.com/commwiki/wiki?17495)

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
