# GeneXusMiniApps Module

The GeneXusMiniApps module is designed for the development of a [Mini App](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?50900,,). It facilitates the interaction needed to transition back from a Mini App to the [Super App](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?50900,,).

### [Module components](#Module+components)

The **GeneXusMiniApps** module includes an External Object called **Mini App.**For more details on this external object, refer to: [MiniApp external object in GeneXusMiniApps module](https://wiki.genexus.com/commwiki/wiki?58514).

### [How to install the module](#How+to+install+the+module)

Install the GeneXusMiniAppsmoduleusing the [Manage Module References](https://wiki.genexus.com/commwiki/wiki?40172) dialog from the Knowledge Manager option (located in the [GeneXus MenuBar](https://wiki.genexus.com/commwiki/wiki?7212)).
