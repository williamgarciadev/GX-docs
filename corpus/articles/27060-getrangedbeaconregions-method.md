# GetRangedBeaconRegions method

Retrieve a collection for the beacon regions that are currently providing ranging.

### [Return Value](#Return+Value)

* beaconRegions
  + Type: [BeaconRegion SDT Collection](https://wiki.genexus.com/commwiki/wiki?27041,,)
  + Returns a collection of the beacon regions that are currently providing ranging.
