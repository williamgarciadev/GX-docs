# GAM Web Backoffice - Sessions section

This article describes the Sessions section of the [GAM Web Backoffice](https://wiki.genexus.com/commwiki/wiki?15935), which allows you to monitor and manage active user sessions.

A session represents an active connection between a user and an application.

`[imagen omitida: wiki id 61015]`

The sessions section:

* Provides a list of currently active sessions in the system.
* Shows which users are logged in and from which applications.

Each session includes the following information:

**Date:** Shows when the session was created.  
**Token:** A unique identifier for each session.  
**User:** The email address of the user associated with the session.  
**Application Id:** Identifies the application where the session is active.  
**Status:** Indicates if the session is currently active.

### [Links in the Sessions option](#Links+in+the+Sessions+option)

* **CHILDREN:** Shows related sessions.
* **KILL:** Terminates the session if needed.
