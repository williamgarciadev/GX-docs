# TimeZone Support

The objective of TimeZone Support is to solve [The TimeZone problem](https://wiki.genexus.com/commwiki/wiki?22135). It can be enabled or disabled for an application generated with GeneXus.

* It is enabled when the property [DateTime storage timezone property](https://wiki.genexus.com/commwiki/wiki?17218) doesn’t have the "Undefined" value.
* It is disabled when the property [DateTime storage timezone property](https://wiki.genexus.com/commwiki/wiki?17218) is set to "Undefined".
