# Chatbots Channels API

GeneXusChannels is a [module](https://wiki.genexus.com/commwiki/wiki?22414) which has the necessary services to be able to send messages through different messaging platforms (i.e: Facebook Messenger, Whatsapp).

End users can send and receive messages through a channel, in turn they can have more than one channel of a different type, for example Facebook Messenger or Whatsapp.

Sending and receiving messages can be related to a Chatbot generated with the [Chatbot generator](https://wiki.genexus.com/commwiki/wiki?37102), or to sending a message that is not directly related to a Chatbot. For example, the end users who have contacted you through Messenger, may receive a message like: "Don't forget! Tomorrow the GeneXus meeting begins, are you going to miss it?".

So, the Channels API helps you send messages (text, images, video, etc.) to different channels.
