# Knowledge Base

To create a new software system with [GeneXus](https://wiki.genexus.com/commwiki/wiki?1756) you must [create a Knowledge Base (KB)](https://wiki.genexus.com/commwiki/wiki?9596).

A Knowledge Base stores the [Users' Views](https://wiki.genexus.com/commwiki/wiki?31312) about the business reality to be modeled. Those User's Views are described in the Knowledge Base using [Objects](https://wiki.genexus.com/commwiki/wiki?1866) of many kinds.

The stored knowledge is structured information that is so pure and platform-independent, that GeneXus can make inferences to obtain more knowledge and also automatically generate the system (database and the application programs) in as many platforms you decide.

That is the reason behind a Knowledge Base is not just called ‘Project’ as used in common Software development jargon.
