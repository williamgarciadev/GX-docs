# None

# Frame allow collapsing property ()

If True, it allows collapsing the frame.

### [Scope](#Scope)

**Objects:** Dashboard

### [Description](#Description)

Allows collapsing or expanding the frame containing the widget.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
