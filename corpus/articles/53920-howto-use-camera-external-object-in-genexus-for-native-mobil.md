# HowTo: Use Camera external object in GeneXus for Native Mobile apps (GeneXus 18 Upgrade 1 or prior)

An external object called Camera enables Native Mobile apps to interact with the device's photo camera. The main purpose of this external object is to invoke the Camera native application of the device, take a picture, and be able to use that image in the application.

This article offers a step-by-step tutorial to use this feature in a Native Mobile application generated by the GeneXus [Native Mobile Generator](https://wiki.genexus.com/commwiki/wiki?14451).

### [Step 1: External Object Camera](#Step+1%3A+External+Object+Camera)

To interact with the camera, the external object named Camera has to be used.

`[imagen omitida: wiki id 53885]`

TakePhoto: This method invokes the device's camera native application, so the user can take a picture and select it to use it in the application.
