# Migrate to Unanimo

If you have a [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836) that uses the Carmine Theme as the [Default Style](https://wiki.genexus.com/commwiki/wiki?8145), you can migrate it following the steps described in [Migration of KB with Carmine Theme to Unanimo Design System](https://wiki.genexus.com/commwiki/wiki?51821).

To install GeneXusUnanimo and start using it incrementally, go to Knowledge Manager > Manage Module References, select Global Matrix, and then select GeneXusUnanimo module. Lastly, click on Install.

See [Modules Distribution in GeneXus](https://wiki.genexus.com/commwiki/wiki?31376) to learn more about how to update modules.

In addition, you can use [Unanimo Showcase](https://wiki.genexus.com/commwiki/wiki?51986) to access different samples that show which class to use for every control that you can use in your [Panels](https://wiki.genexus.com/commwiki/wiki?24829).
