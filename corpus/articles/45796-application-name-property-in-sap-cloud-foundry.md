# Application Name property in SAP Cloud Foundry

Sets the application name in SAP Cloud Platform Cloud Foundry Environment.

### [Scope](#Scope)

**Level:** Deploy Target Options

### [Description](#Description)

You must specify the Application name that will be assigned in the SAP Cloud Foundry Environment.

### [Availability](#Availability)

This property is available since [GeneXus 16 upgrade 10](https://wiki.genexus.com/commwiki/wiki?45624,,).
