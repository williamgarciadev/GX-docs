# Polygon Class property

Theme class to use when drawing polygon elements on a grid control of Maps type.

### [Scope](#Scope)

**Controls:** [Grid](https://wiki.genexus.com/commwiki/wiki?24817) (Control Type: [Maps](https://wiki.genexus.com/commwiki/wiki?15309))

### [Description](#Description)

You have two options to apply the changes after setting the property:

1) Build a [Main Object](https://wiki.genexus.com/commwiki/wiki?5770) that involves the property.  
2) Execute a Build All.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
