# Timer expression type property

Selects whether the timer expression is a rule or a procedure.

### [Values](#Values)

|  |
| --- |
| **Procedure** |
| **Rule** |

### [Scope](#Scope)

**Objects:** [Business Process Diagram](https://wiki.genexus.com/commwiki/wiki?16486)

### [Description](#Description)

Possible values:

* Rule: Allows setting start information at design time(1).
* Procedure: Allows setting a procedure to set the Timer Date at runtime.

(1) - The [Timer Control](https://wiki.genexus.com/commwiki/wiki?43454) scheduler must be running to trigger the associated event.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, execute a [Build All](https://wiki.genexus.com/commwiki/wiki?5691).

### [Availability](#Availability)

This property is available since [GeneXus 16 upgrade 4](https://wiki.genexus.com/commwiki/wiki?42755,,).
