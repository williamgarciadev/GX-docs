# Attribute property (for Attribute/Variable control)

Indicates the control's name. A default name is always assigned.

### [Scope](#Scope)

**Objects:** Transaction, Web Panel  
**Generators:** [Java](https://wiki.genexus.com/commwiki/wiki?12258), .NET, [.NET Core](https://wiki.genexus.com/commwiki/wiki?38604)  
**Controls:** Attribute/Variable

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
