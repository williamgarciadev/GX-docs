# Developer Menu

**Deprecated**: Since [GeneXus 18](https://wiki.genexus.com/commwiki/wiki?51066). Replaced by  [Launchpad Tool Window](https://wiki.genexus.com/commwiki/wiki?52315).

In GeneXus a "Developer menu" is a program that is automatically generated to ease the prototyping process. If executed, the program displays the list of objects in the [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836) that can be directly called. That is:

* Do not have a [Parm rule](https://wiki.genexus.com/commwiki/wiki?6862).
* Are suitable for the environment (i.e. does not include a Work Panel in a Web environment).

The Developer Menu is available for Win, Web and Native Mobile environments.
