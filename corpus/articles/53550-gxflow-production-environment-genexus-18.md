# GXflow Production Environment (GeneXus 18)

Download the setup from the following link:

[GXflow Production Environment](http://www.genexus.com/gxflow-download)

This setup contains the [Business Process Deployer](https://wiki.genexus.com/commwiki/wiki?11607).

## [Guideline](#Guideline)

1) Execute *Setup.exe* file at production server.

2) Choose the target path for the application and click "Install"  to initialize the process.

`[imagen omitida: wiki id 52866]`

3) Once the application is installed, close the dialog.   
It is recommendable to restart your computer once installation process has finished.

`[imagen omitida: wiki id 52867]`

## [Notes](#Notes)

The installation starts will see the installation of the Microsoft Visual C++ Redistributable Package because it is necessary for the licenses to work properly.
