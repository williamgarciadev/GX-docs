# Data Provider property in Attributes/Variables

Indicates the name of the Data Provider object used to load data for the control.

### [Scope](#Scope)

**Level:** [Attribute](https://wiki.genexus.com/commwiki/wiki?7240), [Variable](https://wiki.genexus.com/commwiki/wiki?7375)

### [Description](#Description)

When the [Data Source From property](https://wiki.genexus.com/commwiki/wiki?22945) is set to Data Provider for a certain attribute/variable, the **Data Provider property** is offered (for the same attribute/variable) to indicate the name of the [Data Provider object](https://wiki.genexus.com/commwiki/wiki?5270) that will provide the data to be loaded.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
