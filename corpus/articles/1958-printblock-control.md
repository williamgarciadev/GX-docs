# Printblock control

A Printblock is a kind of control that may contain several types of controls (attributes, variables, images, lines, etc.). It is available specifically in the [Layout section](https://wiki.genexus.com/commwiki/wiki?5468) of each [Procedure object](https://wiki.genexus.com/commwiki/wiki?6293):

`[imagen omitida: wiki id 31584]`

By default, the Layout section of each Procedure contains an empty first printblock (named: printBlock1) ready to be used.
