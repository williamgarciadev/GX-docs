# Predefined GeneXus languages

When you create a new [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836) or open an existing one, a set of predefined [String constant](https://wiki.genexus.com/commwiki/wiki?54433,,)s and Languages are created in it (or updated if they already existed). They are used in the generated code for messages, button captions, labels, etc.

You can view the predefined languages in the [KB Explorer](https://wiki.genexus.com/commwiki/wiki?3210), in the localization node (under customization):

`[imagen omitida: wiki id 54439]`

### [Cross reference](#Cross+reference)

GeneXus provides a cross reference to where [String constant](https://wiki.genexus.com/commwiki/wiki?54433,,)s are used.

### [Language consolidation and distribution](#Language+consolidation+and+distribution)

Several options for language management are included.

#### [Export options](#Export+options)

* Include GeneXus Messages --> Include the GeneXus messages in the XPZ.
* Include Untranslated Messages --> Include the untranslated messages in the XPZ.

#### [Import options](#Import+options)

* An option called [Language Translations](https://wiki.genexus.com/commwiki/wiki?7616) is included for managing Language object imports.
