# HowTo: Define a Menu using GAM

When using [GeneXus Access Manager (GAM)](https://wiki.genexus.com/commwiki/wiki?24746), your Web application menu can be defined (dynamically) at runtime, based on the [Permissions](https://wiki.genexus.com/commwiki/wiki?15912) and [Roles](https://wiki.genexus.com/commwiki/wiki?17569) of the user logged in.

The purpose is to filter the menu options according to the end user's permission. Here, GAM returns the menu structure depending on the permissions of the user so that this structure may be loaded at runtime with any User Control.

The menu has to be defined for a particular [GAM Application](https://wiki.genexus.com/commwiki/wiki?15910) (multiple menus can be defined within a GAM Application).  
A menu option will have a permission and a resource associated with it.

### [Steps](#Steps)

The menu may be set using the [GAM Backoffice](https://wiki.genexus.com/commwiki/wiki?15935) or the [GAM API](https://wiki.genexus.com/commwiki/wiki?16535). For this purpose, see [GAM API for Menus](https://wiki.genexus.com/commwiki/wiki?29742).

**1.** Select the GAM application where you will define the Menu, and click on the "More options" button > "Menus" at the right-hand side:

`[imagen omitida: wiki id 52195]`

**2.** Click the "ADD" button to add a Menu:

`[imagen omitida: wiki id 52196]`

**3.** Define the Menu name and its description

`[imagen omitida: wiki id 52197]`

**4.** Add the Menu options with the "OPTIONS" button in each Menu:

`[imagen omitida: wiki id 52198]`

**5.**Click in the "ADD" button to add the options:

`[imagen omitida: wiki id 52199]`

**6.** When you add a Menu option, you will get a dialog like this:

`[imagen omitida: wiki id 52200]`

A menu option is associated with a [GAM Permission](https://wiki.genexus.com/commwiki/wiki?15912) and a resource.

The permission can be selected from a combo box that includes all the GAM permissions defined for that GAM Application, including the [Automatic Permissions generated by GeneXus](https://wiki.genexus.com/commwiki/wiki?17916) and the [Permissions Created by the User](https://wiki.genexus.com/commwiki/wiki?29723).

Note that if it's a Permission created by the user, the permission is used only to decide whether to show the menu option to the user or not. The permission isn't checked at the execution of the resource itself.

A Resource is any GeneXus object that may be executed from the URL or a URL itself. Since GeneXus 16 upgrade 10, you can use a relative URL, e.g: /genexus.security.backend.gam\_wwusers.  
If the GeneXus object is inside a module, include the module in the Resource field, for example.: **module1.webpanel1**.

By default, the resource of a menu option which is associated with an Automatic Permissions generated by GeneXus is any Object that has that permission as [Permission Prefix property](https://wiki.genexus.com/commwiki/wiki?17571).

The option type can be

* Simple
* Menu (a submenu may be defined here)

#### [Environment settings of the Application](#Environment+settings+of+the+Application)

The Environment settings of the Application influence in the behavior of this feature.

`[imagen omitida: wiki id 52201]`

Since GeneXus 15 upgrade 5, the URL can be absolute or relative, depending on the [UseAbsoluteUrlByEnvironment property](https://wiki.genexus.com/commwiki/wiki?35933,,) value.

The menu is defined automatically afterwards, based on the permissions of the resources and the user's Roles. The end user will view only the Menu options linked to resources associated with the permissions that the user may access.

The menu may be displayed using any User Control. See [HowTo: Display a GAM Menu using Jscookmenu UC](https://wiki.genexus.com/commwiki/wiki?29743).

**Note**: The Menu of the GAM Web Backoffice is automatically defined in the [GAM Backend Application](https://wiki.genexus.com/commwiki/wiki?29699). It is created when [GAM repository creation for the first time from GeneXus](https://wiki.genexus.com/commwiki/wiki?29701).

**Deployment:** When the application is deployed to production using the [Application Deployment tool](https://wiki.genexus.com/commwiki/wiki?32092), you have to add all the objects of your application related to the menu options manually.
