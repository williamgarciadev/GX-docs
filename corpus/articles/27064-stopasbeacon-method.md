# StopAsBeacon method

Stops advertising the current device as a beacon.

### [Return Value](#Return+Value)

* Boolean
  + Type: [Boolean](https://wiki.genexus.com/commwiki/wiki?4374)
  + Returns a boolean which indicates if the device was succesfully stoped as a beacon.
