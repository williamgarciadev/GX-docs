# Super App API External Object property

Specifies a mock External Object used for Super Apps not made in GeneXus (including Kotlin, Swift, React-Native, Flutter).

### [Scope](#Scope)

**Objects:** [Mini App](https://wiki.genexus.com/commwiki/wiki?58037)  
**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917)

### [Description](#Description)

This property allows you to reference an External Object that defines the API exposed by the Super App.

By configuring this property in the Mini App settings, you can integrate the Mini App with the [Super App's API](https://wiki.genexus.com/commwiki/wiki?58207) without requiring direct access to the implementation details of the Super App's External Object.

Once configured, the Super App API External Object property grants the Mini App access to the functionalities defined by the specified External Object.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [Availability](#Availability)

This property is available since [GeneXus 18 Upgrade 10](https://wiki.genexus.com/commwiki/wiki?54244).
