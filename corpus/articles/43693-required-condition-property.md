# Required Condition property

Condition to evaluate. If true, the User Input will be required.

### [Description](#Description)

This property is available in the [Chatbot User Input](https://wiki.genexus.com/commwiki/wiki?38959) and allows indicating the condition under which the user input will be required. It's supported only for Watson.  
  
The property is activated when the [Required property](https://wiki.genexus.com/commwiki/wiki?43692) is set to "Condition" and it should be an expression based on a [context](https://wiki.genexus.com/commwiki/wiki?39351) variable.

### [Availability](#Availability)

This property is available since [GeneXus 16 upgrade 5](https://wiki.genexus.com/commwiki/wiki?43446,,).

### [Scope](#Scope)

**Objects:** [Conversational Flows Instance](https://wiki.genexus.com/commwiki/wiki?37113)
