# Base CSS Library property

A CSS library to include as a base style for the theme or the user control object.

### [Values](#Values)

|  |
| --- |
| **Bootstrap v3** |
| **None** |

### [Scope](#Scope)

**Objects:** [Web Theme](https://wiki.genexus.com/commwiki/wiki?6420), [User Control](https://wiki.genexus.com/commwiki/wiki?39356)  
**Generators:** [Java](https://wiki.genexus.com/commwiki/wiki?12258), .NET, [.NET Core](https://wiki.genexus.com/commwiki/wiki?38604)

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, Build any object.
