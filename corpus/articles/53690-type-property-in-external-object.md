# Type property in External Object

Specifies the External Object type.

### [Values](#Values)

|  |  |
| --- | --- |
| **Native Object** | Stores information about how to access a class defined in a Java class, .Net assembly, or JavaScript source. |
| **Stored Procedure** | Stores information on how to access a set of stored procedures located in a DBMS. |
| **WSDL** | Stores information for using the Web Service described in a WSDL. |
| **Java Session Bean** | Stores information to call Java Session Beans hosted on a JEE server. |
| **SAP Connector Interface** | Internal value, so you do not see it in the combo box to choose it. |

### [Scope](#Scope)

**Objects:** [External Object](https://wiki.genexus.com/commwiki/wiki?5669)

### [Description](#Description)

The SAP External Object type is only used when the External Object is for SAP.

The only way to create an object of SAP Connector Interface type is through the SAP Connector, by importing functions from SAP.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, execute a [Build with this Only](https://wiki.genexus.com/commwiki/wiki?5693) of the object.
