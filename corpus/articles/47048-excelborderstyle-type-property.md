# ExcelBorderStyle Type Property

Indicates the type of border in a [ExcelBorderStyle data type](https://wiki.genexus.com/commwiki/wiki?46308)

### [Syntax](#Syntax)

&ExcelBorderStyle.Type

### [Type returned](#Type+returned)

CellBorderType domain (enumerated character data type)

### [Scope](#Scope)

[ExcelBorderStyle data type](https://wiki.genexus.com/commwiki/wiki?46308)

### [Availability](#Availability)

This property is available since [GeneXus 16 Upgrade 11](https://wiki.genexus.com/commwiki/wiki?45901,,)
