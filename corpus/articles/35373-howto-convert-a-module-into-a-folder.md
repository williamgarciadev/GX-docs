# HowTo: Convert a Module into a Folder

To convert a [Module object](https://wiki.genexus.com/commwiki/wiki?22414) into a [Folder object](https://wiki.genexus.com/commwiki/wiki?9757), you can use the [Convert to folder](https://wiki.genexus.com/commwiki/wiki?35371) option.

**Note**: Modules that contain Win type objects may not be converted.

### [Steps](#Steps)

**1.** Right-click on the [Module object](https://wiki.genexus.com/commwiki/wiki?22414) you want to convert into a Folder.

**2.** Select the [Convert to folder](https://wiki.genexus.com/commwiki/wiki?35371) from the context menu.

When the conversion process is completed, a new Folder with the same [Name property](https://wiki.genexus.com/commwiki/wiki?6985) as the selected Module containing all the Module's Objects will be created, and the Module will be deleted.
