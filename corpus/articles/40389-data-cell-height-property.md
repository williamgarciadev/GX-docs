# Data Cell Height property

Sets the height of the Matrix Grid data cells.

### [Scope](#Scope)

**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917)  
**Controls:** [Grid](https://wiki.genexus.com/commwiki/wiki?24817) (Control Type: [Matrix Grid](https://wiki.genexus.com/commwiki/wiki?25139))

### [Description](#Description)

This property can be set for grids whose [Control Type property](https://wiki.genexus.com/commwiki/wiki?9550) = Matrix Grid.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
