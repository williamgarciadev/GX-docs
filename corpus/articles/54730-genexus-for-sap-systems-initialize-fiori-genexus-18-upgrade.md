# GeneXus for SAP Systems Initialize Fiori (GeneXus 18 Upgrade 3 or prior)

Once the [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836) has been created as shown in [GeneXus for SAP Systems - First Application](https://wiki.genexus.com/commwiki/wiki?34041) you must initialize the resources for Fiori, in order to generate the UI using the Fiori Design system.

To Initialize resources for Fiori you should go to the GeneXus Toolbar and select **Tools > Fiori.**You can choose some of the following versions according to your needs or preferences:
