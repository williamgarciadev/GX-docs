# Huawei Services API Key property

Huawei Services API Key used in Huawei Services (i.e. Map Kit).

### [Scope](#Scope)

**Objects:** [Menu](https://wiki.genexus.com/commwiki/wiki?16321), [Panel](https://wiki.genexus.com/commwiki/wiki?24829), [Work With](https://wiki.genexus.com/commwiki/wiki?15974) (Only [Main Objects](https://wiki.genexus.com/commwiki/wiki?5770))  
**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453)

### [Description](#Description)

Sets the associated Huawei Map Kit API Key.

`[imagen omitida: wiki id 48094]`

Sign in to [AppGallery Connect](https://developer.huawei.com/consumer/en/service/josp/agc/index.html), select the app project, and click on the desired app name. Below *General information* in the *App information* area, copy the *API Key* entry.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
