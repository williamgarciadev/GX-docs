# Web Application property

Indicates the kind of web application to be generated.

### [Values](#Values)

|  |  |
| --- | --- |
| **Default** | Generates a regular web application. This is the default value. |
| **Progressive** | Generates a Progressive Web Application. |

### [Scope](#Scope)

**Objects:** [Web Panel](https://wiki.genexus.com/commwiki/wiki?6916) (Only [Main Objects](https://wiki.genexus.com/commwiki/wiki?5770))  
**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Java](https://wiki.genexus.com/commwiki/wiki?12258)

### [Description](#Description)

There can be only one main [Web Panel object](https://wiki.genexus.com/commwiki/wiki?6916) with the Web Application property set to "Progressive" per Knowledge Base.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, execute a [Build with this Only](https://wiki.genexus.com/commwiki/wiki?5693) of the object.

### [Availability](#Availability)

This property is available since [GeneXus 16 upgrade 5](https://wiki.genexus.com/commwiki/wiki?43446,,).
