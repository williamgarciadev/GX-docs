# Permissions by Method in the API object

In the API object, it is possible to assign different security profiles for each defined method. This makes it possible to discriminate the authorization by method, generating individual permissions for each one, and to add a general permission to control all the methods of the object. 

To achieve authorization by method in API object, the permission generation process is performed as follows.

The first thing to do is to set [Enable Integrated Security property](https://wiki.genexus.com/commwiki/wiki?14706) to True, and [Integrated Security Level property](https://wiki.genexus.com/commwiki/wiki?15214) is set to "Authorization" value. Then you can choose between:

* Generating permissions by method
* Generating Full Control permissions.

These permissions are automatically generated by GeneXus when pressing F5. They can also be checked at runtime and managed programmatically using the [SecurityPermission annotation](https://wiki.genexus.com/commwiki/wiki?55422). For more information, see [GAM - Permissions](https://wiki.genexus.com/commwiki/wiki?15912).

In addition, you can use the [SecurityLevel annotation](https://wiki.genexus.com/commwiki/wiki?55437) to change the security level required for a method.

### [Generating permissions by Method](#Generating+permissions+by+Method)

Individual permissions are generated for each method by combining the [Permission Prefix property](https://wiki.genexus.com/commwiki/wiki?17571) with the method name.

#### [Sample](#Sample)

For the CustomerInfo method defined in APICustomer, of the example detailed in [HowTo: Define an API object with a security scheme](https://wiki.genexus.com/commwiki/wiki?52840), the APICustomer\_Service\_CustomerInfo permission is generated.

### [Generating Full Control permission](#Generating+Full+Control+permission)

In addition to the per-method permissions, there is an additional permission that allows all methods of the object to be executed. This general permission is created using the [Permission Prefix property](https://wiki.genexus.com/commwiki/wiki?17571), followed by \_Service\_FullControl.

#### [Sample](#Sample)

For the CustomerInfo method defined in APICustomer, of the example detailed in [HowTo: Define an API object with a security scheme](https://wiki.genexus.com/commwiki/wiki?52840), the permission APICustomer\_Service\_FullControl, which grants access to all operations of the object, will be generated.

### [Availability](#Availability)

This feature is available since [GeneXus 18 Upgrade 6](https://wiki.genexus.com/commwiki/wiki?54240).
