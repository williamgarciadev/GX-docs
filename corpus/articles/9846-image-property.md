# Image property

It allows you to assign an image to an Image control.

### [Description](#Description)

To assign an image, press the ellipsis button in the property to open the Select Image window.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Scope](#Scope)

**Objects:** Procedure, Transaction, Web Panel  
**Platforms:** Web(.Net, Java)  
**Controls:** Image
