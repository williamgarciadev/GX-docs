# Insert - Command

Inserts a command into the Source or Event section of a [GeneXus object](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?1866,,).

`[imagen omitida: wiki id 13686]`

When selecting **Insert** and then **Command...** from the [GeneXus Main Menu](https://wiki.genexus.com/commwiki/wiki?7212), a window is displayed showing the possible commands to be inserted. Select the command you need.

### [Shortcut](#Shortcut)

The keyboard shortcut Ctrl+Shift+K opens the Insert Command dialog.
