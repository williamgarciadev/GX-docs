# Custom Start Event Code property

Defines the custom code to be included in the Start event of the generated object.

### [Scope](#Scope)

**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Java](https://wiki.genexus.com/commwiki/wiki?12258)  
**Level:** [Work With for Web Pattern Instance](https://wiki.genexus.com/commwiki/wiki?25475)

### [Description](#Description)

This property allows you to customize the [Start event](https://wiki.genexus.com/commwiki/wiki?8043) of the Web Panels generated by the [Work With for Web pattern](https://wiki.genexus.com/commwiki/wiki?25475).

What you enter for this property will be included as the first sentences in the Start Event generated by the Pattern.

You can find this property in the following nodes of the Work With for Web pattern instance:

* General
* [Selection](https://wiki.genexus.com/commwiki/wiki?5640)
* [View](https://wiki.genexus.com/commwiki/wiki?5646)

**Note:** Customization in one of the nodes does not automatically customize it in the other ones because they are independent (different Start events for different Web Panels to be generated).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at runtime.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

No action is required to apply the corresponding changes when the property value is configured.

### [Availability](#Availability)

This property is available since [GeneXus 17 Upgrade 11](https://wiki.genexus.com/commwiki/wiki?49972,,).
