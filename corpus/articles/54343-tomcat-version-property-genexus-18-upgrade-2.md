# Tomcat version property (GeneXus 18 Upgrade 2)

Sets the Tomcat version where the code will run.

### [Values](#Values)

|  |
| --- |
| **10 or higher** |
| **7** |
| **8 or 9** |

### [Scope](#Scope)

**Generators:** [Java](https://wiki.genexus.com/commwiki/wiki?12258)  
**Level:** Generator

### [Description](#Description)

When this property is changed [Tomcat path property](https://wiki.genexus.com/commwiki/wiki?48354) will change to the latest tomcat installed that has the same version.

The default value is the value of the latest tomcat version detected.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

No action is required to apply the corresponding changes when the property value is configured.

### [Availability](#Availability)

This property is available since [GeneXus 17 Upgrade 5](https://wiki.genexus.com/commwiki/wiki?48247,,).
