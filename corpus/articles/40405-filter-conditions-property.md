# Filter conditions property

Filter conditions.

### [Scope](#Scope)

**Objects:** [Dashboard](https://wiki.genexus.com/commwiki/wiki?36769)

### [Description](#Description)

Define the conditions (filters to the database) to apply for the [Dashboard](https://wiki.genexus.com/commwiki/wiki?36769) filter.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Availability](#Availability)

This property is available since [GeneXus 15 upgrade 12](https://wiki.genexus.com/commwiki/wiki?39737,,).
