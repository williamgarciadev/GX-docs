# Default Template Layout property

Specifies a Template used to generate default Transactions and WorkWith web layouts.

### [Scope](#Scope)

**Objects:** [Design System](https://wiki.genexus.com/commwiki/wiki?47375)  
**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Angular](https://wiki.genexus.com/commwiki/wiki?42550), [Apple](https://wiki.genexus.com/commwiki/wiki?14917), [Java](https://wiki.genexus.com/commwiki/wiki?12258), .NET, [.NET Core](https://wiki.genexus.com/commwiki/wiki?38604)

### [Description](#Description)

This property is used to indicate the set of Templates of the [Work With Patterns](https://wiki.genexus.com/commwiki/wiki?5636) that are used with the [Design System Object](https://wiki.genexus.com/commwiki/wiki?47375).

The designs, in addition to their set of classes that give them style, have a particular structure in the form, that is why the screens are generated differently depending on the value you select for this property.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Availability](#Availability)

This property is available since [GeneXus 17 Upgrade 6](https://wiki.genexus.com/commwiki/wiki?48684,,).
