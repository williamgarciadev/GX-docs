# GeneXus 18 Installation Manual

This manual contains all the necessary information to start with [GeneXus 18](https://wiki.genexus.com/commwiki/wiki?51066).

## [Download and Install](#Download+and+Install)

Start downloading the setup from <http://www.genexus.com/v18-download> and then follow the [GeneXus Installation Steps](https://wiki.genexus.com/commwiki/wiki?25842). There you will find a detailed description of the installation process. Before starting the installation, check the requirements of each component in the [GeneXus 18 hardware and software requirements](https://wiki.genexus.com/commwiki/wiki?30900). Please, make sure your computer matches them and then run the setup program that will guide you through the rest of the installation.

## [Activate Licenses](#Activate+Licenses)

**If it's the first time** you install GeneXus and you have no licenses of previous versions, in [Authorizing a GeneXus License for the First Time](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?19789,,) you will find the required steps to activate it.

**If you already have licenses** of previous GeneXus versions you can upgrade them to GeneXus 18 and share them with that previous version. See [Upgrade licenses to a new GeneXus version](https://wiki.genexus.com/commwiki/wiki?5736) for more details.

## [Knowledge Bases Conversion](#Knowledge+Bases+Conversion)

If you are planning to migrate your Knowledge Base from a previous GeneXus version to GeneXus 18, read [Converting Knowledge Bases to GeneXus 16, 17 or higher](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?10903,,).

## [Useful Resources for everyone](#Useful+Resources+for+everyone)

Finally, in [GeneXus SA and Community Resources for GeneXus Users](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?12699,,) you will find more information about the product as well as interesting links to resources on documentation, support, forums, etc.

## [Additional Information](#Additional+Information)

[GeneXus 18 Setup](http://www.genexus.com/v18-download) has the following components:

### [Development Environment](#Development+Environment)

It is an [Integrated Development Environment](https://wiki.genexus.com/commwiki/wiki?5272) (IDE) for designing and prototyping your applications, regardless of the production platform.

### [Generators](#Generators)

GeneXus generates native code for the leading platforms. The generators available are the following:  
  
[GeneXus Native Mobile Generator](https://wiki.genexus.com/commwiki/wiki?24799): Android, Apple (iOS, watchOS, tvOS)  
[GeneXus Java Generator](https://wiki.genexus.com/commwiki/wiki?12258)  
[GeneXus .NET Generator](https://wiki.genexus.com/commwiki/wiki?38604)  
[GeneXus .NET Framework Generator](https://wiki.genexus.com/commwiki/wiki?2892)  
[GeneXus iSeries RPG and Cobol Generators](https://wiki.genexus.com/commwiki/wiki?9296)  
[GeneXus Angular Generator](https://wiki.genexus.com/commwiki/wiki?42550)
