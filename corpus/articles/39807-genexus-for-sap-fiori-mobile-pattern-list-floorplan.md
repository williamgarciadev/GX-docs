# GeneXus for SAP Fiori Mobile Pattern - List Floorplan

The List [Floorplan](https://wiki.genexus.com/commwiki/wiki?38629,,) is a set of templates designed to query, insert, update and delete data on Smart Devices (SD).

This article describes how to apply it to a [Transaction](https://wiki.genexus.com/commwiki/wiki?1908) or a [Panel for Smart Devices](https://wiki.genexus.com/commwiki/wiki?24829) (SD).

## [How to apply it](#How+to+apply+it)

Look at the patterns tab of the Country transaction. If you have never applied the Fiori Mobile Pattern on your KB before, read [GeneXus for SAP Systems - Fiori Mobile Pattern](https://wiki.genexus.com/commwiki/wiki?39800). Otherwise, select the Work With by positioning on the patterns tab of the transaction.

`[imagen omitida: wiki id 39937]`

Then, to select a template under the List category, the following window will open:

`[imagen omitida: wiki id 39938]`

There are eight kinds of List templates:

1. List with amount
2. Card with image
3. Cards with text
4. List with image
5. List with image and amount
6. Title and subtitle
7. Titles
8. Card background image
9. Timeline

**1. List with amount**

This template lists data with a Title and a Subtitle on the left side and an Amount on the right side (which must be a numeric attribute):

`[imagen omitida: wiki id 39814]`

**2. Cards with image**

This template lists data inside cards. Each one includes an image on top and a title and subtitle under it:

`[imagen omitida: wiki id 39815]`

**3. Cards with text**

This template lists data inside cards. Each one includes a title, a category, and a subtitle:

`[imagen omitida: wiki id 39816]`

**4. List with image**

This template lists data showing for each line an image on the left and a title and a subtitle on the right side:

`[imagen omitida: wiki id 39817]`

**5. List with image and amount**

This template lists data showing for each line an image on the left side, a title and subtitle on the middle, and an amount on the right side:

`[imagen omitida: wiki id 39818]`

**6. Title and subtitle**

This template lists data showing for each line a title and a subtitle under it:

`[imagen omitida: wiki id 39819]`

**7. Titles**

This template lists data showing only a title for each line:

`[imagen omitida: wiki id 39820]`

**8. Card background image**

This template lists data inside cards, each one includes an image on its background and a title and subtitle on the image, at the bottom of the card:

`[imagen omitida: wiki id 39848]`

**9. Timeline**

This template lists data in a timeline format.

`[imagen omitida: wiki id 41259]`
