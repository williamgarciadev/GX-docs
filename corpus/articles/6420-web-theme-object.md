# Web Theme object

Defines graphic and functional design of controls for Web applications (equivalent to [Theme object](https://wiki.genexus.com/commwiki/wiki?16595) but only for Web).

### [Description](#Description)

The Web [Theme](https://wiki.genexus.com/commwiki/wiki?4375) object helps you to define the look and feel of your Web application.

Every [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836) contains a Web Theme object named 'Carmine' automatically created and it is used by default when generating Web applications.

The 'Carmine' Theme is referenced in the [Default Theme property](https://wiki.genexus.com/commwiki/wiki?8145) at [version level](https://wiki.genexus.com/commwiki/wiki?7860).

Besides, every [Web Panel object](https://wiki.genexus.com/commwiki/wiki?6916) and [Transaction object](https://wiki.genexus.com/commwiki/wiki?1908) contains the [Theme property](https://wiki.genexus.com/commwiki/wiki?8145) (which by default inherits the Theme configured in the [Default Theme property](https://wiki.genexus.com/commwiki/wiki?8145)).

Of course, you are able to change the values of all these properties by other Web Themes defined in your KB.
