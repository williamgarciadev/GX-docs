# Super App Identifier property

String that uniquely identifies your Super App in the Mini App Center.

### [Scope](#Scope)

**Objects:** [Super App](https://wiki.genexus.com/commwiki/wiki?53457,,)  
**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917)

### [Description](#Description)

This property must use the reverse DNS format, i.e com.example.mysuperapp.

If you have already registered the Super App in the Mini App Center, this value must be obtained from there.

**Note**: This property is still in [Beta](https://wiki.genexus.com/commwiki/wiki?38509,,).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
