# BottomMargin property

The browsers add a space by default between the window and the page's contents. The space separating the window from the end of the page can be modified with the Bottom Margin property. The space defined is completed with the background color or image of the form.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Scope](#Scope)

**Objects:** Transaction, Web Panel  
**Platforms:** Web(.Net, Java)
