# Associated Table property (for Transaction's Levels)

It shows which is the table associated with the level of the Transaction.

### [Scope](#Scope)

**Level:** [Transaction Level](https://wiki.genexus.com/commwiki/wiki?42569)

### [Description](#Description)

This is a read-only property.

It displays which is the table associated with a certain [Transaction Level](https://wiki.genexus.com/commwiki/wiki?42569).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

No action is required to apply the corresponding changes when the property value is configured.
