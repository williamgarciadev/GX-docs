# KB

Acronym of Knowledge Base or [GeneXus](https://wiki.genexus.com/commwiki/wiki?1756) [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836).

Instead of storing the source information in text files like a traditional programming language, GX store it in an kind of database named 'Knowledge Base'.
