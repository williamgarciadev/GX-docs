# Server Linked Knowledge Base property

This property is defined when the [Send Knowledge Base to GeneXus Server](https://wiki.genexus.com/commwiki/wiki?10215) or the [Knowledge Base from GXserver](https://wiki.genexus.com/commwiki/wiki?10625,,) actions are performed. It defines the name of the [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836) to which the local [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836) is connected to in the [GeneXus Server](https://wiki.genexus.com/commwiki/wiki?9911).

### [Values](#Values)

A valid [KB alias](https://wiki.genexus.com/commwiki/wiki?21220) from the [GeneXus Server](https://wiki.genexus.com/commwiki/wiki?9911) instance.

### [Example](#Example)

TravelAgency
