# Enable Multiple Selection property

Allows you to enable multiple selections over a Grid control.

### [Scope](#Scope)

**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917), [Angular](https://wiki.genexus.com/commwiki/wiki?42550)  
**Controls:** [Grid](https://wiki.genexus.com/commwiki/wiki?24817), [Tabular Grid](https://wiki.genexus.com/commwiki/wiki?54449)

### [Description](#Description)

|  |  |
| --- | --- |
| **False** | Default value. Multiple selections are not allowed. |
| **True** | Multiple selections are allowed.     It displays a set of properties for setting its behavior:  • [Show Selector property](https://wiki.genexus.com/commwiki/wiki?36199)  • [Selection Flag property](https://wiki.genexus.com/commwiki/wiki?36202)  • [Selection Flag Field Specifier property](https://wiki.genexus.com/commwiki/wiki?36203) |

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
