# Consult Web Object property

Indicates the application that will be displayed when the task is queried in the history.

### [Scope](#Scope)

**Objects:** [Business Process Diagram](https://wiki.genexus.com/commwiki/wiki?16486)  
**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Angular](https://wiki.genexus.com/commwiki/wiki?42550), [Java](https://wiki.genexus.com/commwiki/wiki?12258)  
**Controls:** [Task](https://wiki.genexus.com/commwiki/wiki?17495)

### [Description](#Description)

It applies only when using the GXflow Client for Web Applications and when the task has already been executed.

The application associated with the Query Application Property will be opened when the task is opened from the history.

**Note**: In versions prior to GeneXus 17 Upgrade 7 the name of this property was Consult application.
