# Standard classes update policy property

Determines the update policy of the standard classes referenced by the generated application.

### [Values](#Values)

|  |  |
| --- | --- |
| **Defined by Generator** | This is the default value. The generated application uses the standard classes version released with the installed generator. |
| **Custom** | Enables you to set a specific standard classes version in the 'Standard classes specific version' property. |

### [Scope](#Scope)

**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [Java](https://wiki.genexus.com/commwiki/wiki?12258)

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, execute a [Rebuild All](https://wiki.genexus.com/commwiki/wiki?5691).
