# Fill property

Sets:
the controls transparency (if the background color is specified or not). In controls with Read Only set to true, the background color is generally white.
In [ExcelFont Data Type](https://wiki.genexus.com/commwiki/wiki?46318) the object that controls the background of a cell.

### [Values](#Values)

|  |
| --- |
| **False** |
| **True** |

### [Scope](#Scope)

**Objects:** Procedure, Transaction, Web Panel  
**Platforms:** Web(.Net, Java)

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
