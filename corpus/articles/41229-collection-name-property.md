# Collection Name property

Names the collection returned by the Data Provider (this property is offered if you have set the Collection property of the Data Provider to True; therefore, a name for the collection to be returned is required).

### [Scope](#Scope)

**Objects:** [Data Provider](https://wiki.genexus.com/commwiki/wiki?5270)  
**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917), [Java](https://wiki.genexus.com/commwiki/wiki?12258)

### [Description](#Description)

If you define a [Data Provider object](https://wiki.genexus.com/commwiki/wiki?5270) and you set its [Collection property](https://wiki.genexus.com/commwiki/wiki?41179) to True, the **Collection Name** property is automatically added in order to give a name to the collection to be returned by the Data Provider.

A default name is set for the property and you can edit it.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
