# Create Offline Database

This action generates the [Offline Database reorganization](https://wiki.genexus.com/commwiki/wiki?27121) files. You can find this action in the Build menu or in the Context Menu of the Offline Database object by right-clicking on it.

`[imagen omitida: wiki id 27124]`

### [Considerations](#Considerations)

This action is only visible when there is at least one [Offline Database object](https://wiki.genexus.com/commwiki/wiki?22509) in the Knowledge Base.

### [Availability](#Availability)

This feature is available since [GeneXus X Evolution 3](https://wiki.genexus.com/commwiki/wiki?20247,,).
