# Synchronization.SetSendCheckpoint method

### [Syntax](#Syntax)

Synchronization**.SetSendCheckpoint**()

### [Description](#Description)

This method allows setting a checkpoint in the pending events list, in order to perform a [batch synchronization](https://wiki.genexus.com/commwiki/wiki?42733) in several requests instead of using only one big-sized request.
