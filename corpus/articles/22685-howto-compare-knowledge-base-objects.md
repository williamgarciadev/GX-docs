# HowTo: Compare Knowledge Base objects

The purpose of this document is to show how to compare the last revision of two objects of the same [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836).

There are two ways of comparing objects, both can be used from the [KB Explorer](https://wiki.genexus.com/commwiki/wiki?3210) and from the Work With Objects dialog.

* Using the *Select Left Side To Compare* and *Compare With* options
* Usingthe *Compare selected objects*

**Note**: These options will be available at the contextual menu, when selecting an object and right clicking on it.

### [Option 1](#Option+1)

#### [Select Left Side To Compare](#Select+Left+Side+To+Compare)

This option is used to select the object for the left side of the comparer:

`[imagen omitida: wiki id 22775]`

After this option is used the *Compare With* option will be available at the contextual menu for objects of the same type.

#### [Compare With](#Compare+With)

This option is enabled after using the *Select Left Side To Compare* if the object has the same type of the one previously selected:

`[imagen omitida: wiki id 22776]`

When this option is selected the comparer will be opened.

### [Option 2](#Option+2)

#### [Compare selected objects](#Compare+selected+objects)

This option is used to compare differences between two objects.

It is used by selecting an object from the Folder View (or from the Work With Attributes dialog), then pressing the *CTRL* key and selecting another object of the same type. This will make the *Compare Selected Objects* option available on the menu:

`[imagen omitida: wiki id 22686]`

When the comparer is opened, the two objects are compared:

`[imagen omitida: wiki id 22687]`
