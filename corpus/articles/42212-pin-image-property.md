# Pin Image property

Image used to display the points on the map.

### [Scope](#Scope)

**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917), [Angular](https://wiki.genexus.com/commwiki/wiki?42550)  
**Controls:** [Grid](https://wiki.genexus.com/commwiki/wiki?24817) (Control Type: [Maps](https://wiki.genexus.com/commwiki/wiki?15309))

### [Description](#Description)

Allows indicating an [Image object](https://wiki.genexus.com/commwiki/wiki?23387) to be used to display the point on an [Grid with its Control Type property=Maps](https://wiki.genexus.com/commwiki/wiki?15309) present in a [Panel object](https://wiki.genexus.com/commwiki/wiki?24829).  
All the points on the map will be displayed using this image unless something different is indicated in the [Load event](https://wiki.genexus.com/commwiki/wiki?8188) with the [Pin Image Attribute property](https://wiki.genexus.com/commwiki/wiki?42213) or [Pin Image Field Specifier property](https://wiki.genexus.com/commwiki/wiki?42214).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, execute a [Build with this Only](https://wiki.genexus.com/commwiki/wiki?5693) of the object.
