# gRPC Package property

Adds a package specifier to the gRPC service to prevent name clashes between protocol message types.

### [Scope](#Scope)

**Objects:** [API](https://wiki.genexus.com/commwiki/wiki?46151)  
**Generators:** [Java](https://wiki.genexus.com/commwiki/wiki?12258), [.NET Core](https://wiki.genexus.com/commwiki/wiki?38604)

### [Description](#Description)

This property is available if [gRPC Protocol property](https://wiki.genexus.com/commwiki/wiki?46381) is set to True.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
