# GeneXus SDK for SAP Leonardo

(SAP Leonardo was decommissioned by SAP on 30 June 2020)

GeneXus SDK for SAP includes all the required GeneXus objects to use SAP Leonardo Machine Learning Functional Services.

The following document provides detailed information on the functionality of the SDK, the Installation requirements for the SDK and a walkthrough example on how the end user develops using SAP Leonardo ML Functional Services.
