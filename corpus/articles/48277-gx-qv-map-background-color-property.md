# gx-qv-map-background-color property

**Note**:

This property of the Design Systems object corresponds to the Color property of the [Theme](https://wiki.genexus.com/commwiki/wiki?4375).

Specifies the map's background color.

### [Scope](#Scope)

**Objects:** [Design System](https://wiki.genexus.com/commwiki/wiki?47375), [Theme](https://wiki.genexus.com/commwiki/wiki?17876,,)  
**Generators:** [Java](https://wiki.genexus.com/commwiki/wiki?12258), .NET, [.NET Core](https://wiki.genexus.com/commwiki/wiki?38604)

### [Description](#Description)

Use this property to select a color for the map's background. The background may also be specified as transparent (or partially transparent used in combination with the Opacity property).

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, Run the main object.
