# HowTo: Draw animations between locations on a Map

This article explains how to draw animations between points on a map (in other words, how to use the Animations Layer). This allows you to show, for example, the fleet of vehicles in a typical mobility application such as Uber, Cabify, etc.

## [Scope](#Scope)

**Controls:**[Grid](https://wiki.genexus.com/commwiki/wiki?24817) (Control Type: [Maps](https://wiki.genexus.com/commwiki/wiki?15309))  
**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917)

## [Description](#Description)

When you include in a [Panel object](https://wiki.genexus.com/commwiki/wiki?24829) a [Grid control](https://wiki.genexus.com/commwiki/wiki?24817) with its Control Type property set to Maps, you can set the [Animations Layer property](https://wiki.genexus.com/commwiki/wiki?43487) to True. This will make it possible to view the animation of the records specified in the Grid given by an attribute or variable that indicates their location (based on the [GeoPoint data type](https://wiki.genexus.com/commwiki/wiki?58058) or [Geolocation domain](https://wiki.genexus.com/commwiki/wiki?14644)) at runtime.
