# GAM Web Backoffice - Dashboard section

The Dashboard is the first screen displayed when you access the [GAM Web Backoffice](https://wiki.genexus.com/commwiki/wiki?15935). It provides an overview of the system's summary data and user statistics.

`[imagen omitida: wiki id 60979]`

At the top of the Dashboard screen, the Date Range selector allows you to filter the displayed statistics by a specific time period.

The dashboard is divided into the following sections:

### [New Users](#New+Users)

Displays the number of new users registered within the selected date range.

### [Total Sessions](#Total+Sessions)

Shows the total number of sessions started during the specified period.

### [Total Sessions by Applications](#Total+Sessions+by+Applications)

A bar chart shows the number of sessions per application.

### [Total Sessions by Day](#Total+Sessions+by+Day)

Shows a timeline graphic that tracks daily session activity.  
Includes options to zoom in and group data by day.  
A dropdown menu allows a comparison with the previous period.

### [Total Registered Users](#Total+Registered+Users)

Displays the total number of users registered in the system.

### [Current Active Sessions](#Current+Active+Sessions)

Shows the number of users currently logged into the system.
