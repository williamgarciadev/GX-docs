# Web Panel Web Layout

Defines the screen that specifies how end users will access data (the controls and their distribution) for a certain Web page. The generated screen will be an HTML page.

The controls that can be used in web objects are classified into three groups:

1. Controls that may be used in all GeneXus objects:

* [Attributes](https://wiki.genexus.com/commwiki/wiki?8133)
* [Variables](https://wiki.genexus.com/commwiki/wiki?8133)
* [Buttons](https://wiki.genexus.com/commwiki/wiki?6011)
* [Error viewers](https://wiki.genexus.com/commwiki/wiki?6073)

2. Web object controls, or those with different behavior than in the rest of the objects:

* [Images](https://wiki.genexus.com/commwiki/wiki?5939)
* [Text Blocks](https://wiki.genexus.com/commwiki/wiki?5948)
* [Hyperlinks](https://wiki.genexus.com/commwiki/wiki?6007)
* [Tables](https://wiki.genexus.com/commwiki/wiki?6001)
* [Horizontal Rules](https://wiki.genexus.com/commwiki/wiki?6016)
* [Grids](https://wiki.genexus.com/commwiki/wiki?24817)
* [Free Style Grids](https://wiki.genexus.com/commwiki/wiki?6058)
* [Error Viewers](https://wiki.genexus.com/commwiki/wiki?6073)
* [Web Components](https://wiki.genexus.com/commwiki/wiki?6056,,)
* [Embedded Pages](https://wiki.genexus.com/commwiki/wiki?6070)
* [Groups](https://wiki.genexus.com/commwiki/wiki?6570)
* [Sections](https://wiki.genexus.com/commwiki/wiki?6112)

3. Extended controls created in the GeneXus community or by third parties, such as:

* [FBHoverPanel](https://wiki.genexus.com/commwiki/wiki?11801)
* [Google Analytics](https://wiki.genexus.com/commwiki/wiki?11847)
* [Google Annotated Time Line](https://wiki.genexus.com/commwiki/wiki?10617)
* And more...
