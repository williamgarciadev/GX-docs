# Type property (in Web Panels and Transactions)

Sets whether the object type is a Component, Web Page, or Web Master Panel.

### [Values](#Values)

|  |  |
| --- | --- |
| **Component** | The object type is a Web Component. |
| **Master Page** | The object type is a Web Master Panel. |
| **Web Page** | The object type is a Web Page. |

### [Scope](#Scope)

**Objects:** Web Panel, Transaction  
**Generators:** [Java](https://wiki.genexus.com/commwiki/wiki?12258), .NET, [.NET Core](https://wiki.genexus.com/commwiki/wiki?38604)

### [Description](#Description)

Every [Web Panel object](https://wiki.genexus.com/commwiki/wiki?6916) and every [Transaction object](https://wiki.genexus.com/commwiki/wiki?1908) by default is set and generated as a Web page.

However, a Web Panel can be used also to define a [Web Master Panel object](https://wiki.genexus.com/commwiki/wiki?10348) or a [Web Component object](https://wiki.genexus.com/commwiki/wiki?1864) while a Transaction can be defined as a [Web Component object](https://wiki.genexus.com/commwiki/wiki?1864).

This property allows you to set which is your objective (the type) for the object.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
