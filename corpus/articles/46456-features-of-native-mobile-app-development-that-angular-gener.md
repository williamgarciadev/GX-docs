# Features of Native Mobile App development that Angular generator still misses

This is a list of features that are supported when creating [Native mobile apps](https://wiki.genexus.com/commwiki/wiki?24799) but are not supported when generating with Angular.

## [Functionalities of the [GeneXus Core module](https://wiki.genexus.com/commwiki/wiki?31268) that are not supported](#Functionalities+of+the+wiki%3F31268%2CGeneXus%2BCore%2Bmodule+GeneXus+Core+module+that+are+not+supported)

* GeneXus.Common.Configuration.ConfigurationManager
* GeneXus.Common.Configuration.ExternalStorage
* GeneXus.Common.UI.Appearance
* Navigation Split
* GeneXus.Common.DirectionServices
* GeneXus.Common.Analytics
* GeneXus.Common.AnalyticsPurchase
* GeneXus.Common.Clipboard
* GeneXus.Common.Maps
* GeneXus.Common.Messages
* GeneXus.SD.Media.Audio
* GeneXus.SD.Media.AudioPlayerCustomAction
* GeneXus.SD.Media.AudioPlayerSettings
* GeneXus.SD.Media.AudioRecorder
* GeneXus.SD.Media.Files
* GeneXus.SD.Media.ImagesCollection
* GeneXus.SD.Media.MediaItem
* GeneXus.SD.Media.MediaItemFinishedInfo
* GeneXus.SD.Media.MediaQueue
* GeneXus.SD.Media.MediaQueueState
* GeneXus.SD.Notifications\*
* GeneXus.SD.Offline
* GeneXus.SD.Store
* GeneXus.SD.Synchronization
* GeneXus.SD.AppLifeCycle
* GeneXus.SD.ARPreview
* GeneXus.SD.Beacon\*
* GeneXus.SD.CardInformation
* GeneXus.SD.CardScanner
* GeneXus.SD.Contact\*
* GeneXus.SD.DeepLink
* GeneXus.SD.DeviceAuthentication
* GeneXus.SD.Printer
* GeneXus.SD.ScannedBarcodes
* GeneXus.SD.Scanner
* GeneXus.SD.Search
* GeneXus.SD.SearchScope
* GeneXus.SD.WebBrowser

Note that some of them make no sense on Angular (eg.: GeneXus.SD.Offline).

## [UI Controls that have not been implemented yet](#UI+Controls+that+have+not+been+implemented+yet)

* Ads View
* Scanner
* Facebook Button
* Advanced Image
* File
* Relative Timer
* Matrix Grid
* Charts
* Sparkline
* Slider

Note: Controls that already are deprecated in Apple and Android won't be supported in Angular either. More information at [GeneXus 17 Compatibility Section](https://wiki.genexus.com/commwiki/wiki?46344,,)

## [Theme properties](#Theme+properties)

* Under the node **Group** - Property: **Group Separator**

## [Beta - Not fully implemented yet](#Beta+-+Not+fully+implemented+yet)

* Query Viewer

## [Commands that are not implemented yet](#Commands+that+are+not+implemented+yet)

* refresh keep

## [Other Features that have not been implemented yet](#Other+Features+that+have+not+been+implemented+yet)

* Built-in Search and Filter on grids
* Live Editing
* Themes (Note: Use [Design System Object](https://wiki.genexus.com/commwiki/wiki?47375) instead)
  + Transitions
  + Animations
