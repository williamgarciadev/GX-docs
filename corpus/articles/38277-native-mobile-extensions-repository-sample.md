# Native Mobile Extensions Repository Sample

The repository called [SDExtensionsSample](https://github.com/genexuslabs/SDExtensionsSample) contains extensions samples for [Native Mobile Generator](https://wiki.genexus.com/commwiki/wiki?14451). You get working code on how to implement a User Control and External object for Apple and Android.
