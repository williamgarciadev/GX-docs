# Not Authorized Object for SD property

Indicates the object to execute when there is a permission error in Native Mobile applications (the user who is trying to execute an object has no rights/permissions to execute it).

### [Scope](#Scope)

**Level:** [Version](https://wiki.genexus.com/commwiki/wiki?7860)

### [Description](#Description)

This property is available when the [Enable Integrated Security property](https://wiki.genexus.com/commwiki/wiki?14706) = True and at least one object of the Knowledge Base has its [Integrated Security Level property](https://wiki.genexus.com/commwiki/wiki?15214) set to "Authorization".

You can configure this property with any object for Native Mobile applications, which informs the user that he/she has no rights to perform the desired action.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
