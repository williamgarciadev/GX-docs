# GetDescriptionByKey Procedure Parameters property

Sets additional parameters to be added before the description and value parameters.

### [Scope](#Scope)

**Controls:** Attribute/Variable (Control Type: [Dynamic Combo Box](https://wiki.genexus.com/commwiki/wiki?7598), [Dynamic List Box](https://wiki.genexus.com/commwiki/wiki?7599), Edit, [Wheel](https://wiki.genexus.com/commwiki/wiki?16239))

### [Description](#Description)

This property is offered when the [Item Values property](https://wiki.genexus.com/commwiki/wiki?8808) and the [Item Descriptions property](https://wiki.genexus.com/commwiki/wiki?8807) do not match (that is, they show different values and descriptions). In this case, you must set a [Procedure object](https://wiki.genexus.com/commwiki/wiki?6293) to the [GetDescriptionByKey Procedure property](https://wiki.genexus.com/commwiki/wiki?55413) and specify its parameters in GetDescriptionByKey Procedure Parameters.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [Availability](#Availability)

This property is available since [GeneXus 18 Upgrade 5](https://wiki.genexus.com/commwiki/wiki?54239).
