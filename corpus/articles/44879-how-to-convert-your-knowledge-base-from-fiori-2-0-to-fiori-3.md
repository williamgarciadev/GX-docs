# How to convert your Knowledge Base from Fiori 2.0 to Fiori 3.0

To change the [Fiori pattern](https://wiki.genexus.com/commwiki/wiki?34251) version of your Knowledge Base from 2.0 to 3.0, select in the GeneXus main menu: **Tools > Fiori > Reinitialize Fiori 3.0**

`[imagen omitida: wiki id 44881]`

The following popup window will appear:

`[imagen omitida: wiki id 44882]`

Click on the OK button. Then, GeneXus will start importing the new pattern version. This action will overwrite all the previous pattern objects with the new pattern ones.

When this process finishes, go to **Preferences > Patterns > Fiori for Web**.Then,in the opened interface:

1) Click on the "Transaction floorplan (Main)" tab  
2) Click on the gear icon  
3) Select: Update Instances (Transaction floorplan: Main)

`[imagen omitida: wiki id 44896]`

After that, in the same opened interface:

1) Click on the "Web Panel  floorplans" tab  
2) For each Web Panel template, click on the gear icon  
3) Select: Update Instances (Web Panel template: EmptyWithTitle)

`[imagen omitida: wiki id 44935]`

**Note:** The process to return from the 3.0 version to the 2.0 version, is completely analogous to the process to move from the 2.0 to the 3.0 version. That is, you have to select in the GeneXus main menu: **Tools > Fiori > Reinitialize Fiori 2.0**and proceed in the analogous way that was explained.

### [Availability](#Availability)

This feature is available since [GeneXus 16 upgrade 7](https://wiki.genexus.com/commwiki/wiki?44454,,).
