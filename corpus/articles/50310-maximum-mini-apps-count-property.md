# Maximum Mini apps count property

Specifies the maximum number of Mini Apps that will be persisted in the cache of the Super App.

### [Scope](#Scope)

**Objects:** [Super App](https://wiki.genexus.com/commwiki/wiki?53457,,)  
**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917)

### [Description](#Description)

When the maximum number of Mini Apps is reached and a new one is installed, the Mini App with the longest time since it was last used is removed. A value of 0 means that there is no limit.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, Build the [Main Object](https://wiki.genexus.com/commwiki/wiki?5770).
