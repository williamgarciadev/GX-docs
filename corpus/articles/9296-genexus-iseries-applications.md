# GeneXus iSeries Applications

iSeries (green screen) applications in GeneXus are supported.

Support is provided to allow iSeries application developers to work on a powerful and easy-to-use development environment that provides the easiest migration path to the Web platform.

iSeries support status is as follows:

* RPG and COBOL generators are available.
* Text form editor and Text report editor are available.
* Run, Transfer, and Compile options are available.
