# Image theme-class

Allows the developer to set some properties to an image.

### [Properties](#Properties)

* Border Style
* Border Color
* Border Width
* [Border Radius](https://wiki.genexus.com/commwiki/wiki?27143)

- Margin
- BackgroundColor
- Highlighted Background Color
- Heigh
- Width
- [Content Mode](https://wiki.genexus.com/commwiki/wiki?23857)
- Label Class
- Label Width
- Label Horizontal Alignment
- Label Vertical Alignment
- Placeholder Image
- Image Loading Indicator

### [Notes](#Notes)

* Images can be [Image object](https://wiki.genexus.com/commwiki/wiki?23387), Image-based properties and attributes/variables based on [Image data type](https://wiki.genexus.com/commwiki/wiki?15204).

### [Scope](#Scope)

**Objects**: [Theme object](https://wiki.genexus.com/commwiki/wiki?16595)    
**Generator:** Android, Apple
