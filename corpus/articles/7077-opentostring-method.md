# OpenToString method

Creates an XML document through an internal buffer instead of a file.

### [Syntax](#Syntax)

**&***VariableBasedOnXMLWritterDataType***.OpenToString()**

### [Scope](#Scope)

**Extended Data Types:** [XmlWriter](https://wiki.genexus.com/commwiki/wiki?6938)  
**Generators:**

[.NET](https://wiki.genexus.com/commwiki/wiki?38604),
[Java](https://wiki.genexus.com/commwiki/wiki?12258), Ruby (up to GeneXus X Evolution 3),
Visual Basic (up to GeneXus X Evolution 3), Visual FoxPro (up to GeneXus X Evolution 3)

### [Description](#Description)

Allows the creation of an XML document through an internal buffer instead of a file.   
The buffer contents can be inquired using the [ResultingString Property](https://wiki.genexus.com/commwiki/wiki?6959).
