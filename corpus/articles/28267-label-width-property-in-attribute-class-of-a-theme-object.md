# Label Width property in Attribute class of a Theme object

Establishes the width for an Attribute class of a Theme object.

### [Scope](#Scope)

**Objects:** [Theme](https://wiki.genexus.com/commwiki/wiki?17876,,)  
**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917)

### [Description](#Description)

Setting this property allows you to align all labels of the same length.   
When a numeric value is set, it is automatically switched to DIP format.

## [Considerations](#Considerations)

When the label width has a very small value and overlaps the control, you may need to adjust the [RowSpan property](https://wiki.genexus.com/commwiki/wiki?8828) from the control.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
