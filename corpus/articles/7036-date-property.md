# Date Property

It gives the value of the cells in date and time format.

### [Syntax](#Syntax)

**&***ExcelDocument***.Cells(…).Date**  
  
**Type Returned:**   
DateTime

### [Description](#Description)

If there are cells with different values in the *ExcelCells* object, the *Date* property will return a null date.

**Extended Data Types:** [ExcelCells](https://wiki.genexus.com/commwiki/wiki?6958)
