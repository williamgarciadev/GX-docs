# IBM User property

IBM Cloud account.

### [Scope](#Scope)

**Level:** Deploy Target Options

### [Description](#Description)

To deploy to IBM cloud, using the [Application Deployment tool](https://wiki.genexus.com/commwiki/wiki?32092), you have to configure the User property at the deployment target, among other properties such as [Space](https://wiki.genexus.com/commwiki/wiki?45921), [Password](https://wiki.genexus.com/commwiki/wiki?45931), [Organization](https://wiki.genexus.com/commwiki/wiki?45920), and [Application](https://wiki.genexus.com/commwiki/wiki?45922).
