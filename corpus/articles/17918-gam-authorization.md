# GAM - Authorization

Authorization is the function of specifying access rights to resources.

[GeneXus Access Manager (GAM)](https://wiki.genexus.com/commwiki/wiki?24746) provides APIs to manage all the security issues concerning an application, in particular Authorization issues.

In order to get started with GAM Authorization start reading [Authorization Scenarios](https://wiki.genexus.com/commwiki/wiki?17583) where the scenarios are shown and their solution explained.
