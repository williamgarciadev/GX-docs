# Include Max and Min Property

Include Max and Min property it's a [QueryViewer control](https://wiki.genexus.com/commwiki/wiki?9075) and a [Query object](https://wiki.genexus.com/commwiki/wiki?9026) property. It's only available when the [Type property in QueryViewer control](https://wiki.genexus.com/commwiki/wiki?19612) has the [Card](https://wiki.genexus.com/commwiki/wiki?31810) value assigned and allows displaying (under the Card indicator) the highest and lowest value taken by the indicator.

### [Values](#Values)

|  |  |
| --- | --- |
| **False** | Maximum and minimum values are not shown. This is the default value. |
| **True** | Maximum and minimum values are displayed under the Card's indicator. |

### [Description](#Description)

If the Query object includes a Date or DateTime attribute, the highest and lowest values that the indicator took can be calculated and shown by setting the Include Max and Min property in True:
