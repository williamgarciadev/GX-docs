# Cache storage size property

Configures the amount of memory on the server running the application within the process being executed that is dedicated to storing the data cache.

### [Scope](#Scope)

**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Java](https://wiki.genexus.com/commwiki/wiki?12258)  
**Level:** Generator

### [Description](#Description)

This property is enabled when the [Database access caching property](https://wiki.genexus.com/commwiki/wiki?8968) is set to True.

The value of the property is expressed in **KBytes**, where zero represents infinite.

Zero (0) is the default value.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
