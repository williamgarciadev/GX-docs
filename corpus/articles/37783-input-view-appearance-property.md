# Input View Appearance property

Sets the appearance style of the input view (i.e. virtual keyboard).

### [Values](#Values)

|  |  |
| --- | --- |
| **Dark** | Force dark input view. |
| **Default** | Default value. Use Light or Dark depending on platform default. |
| **Light** | Force light input view. |

### [Description](#Description)

This property is available in [Form theme-class for Smart Devices](https://wiki.genexus.com/commwiki/wiki?37648) object and allows the developer to change virtual keyboard displayed when the end-user inputs text on an editable field. It's desirable that a Panel which allows input data on an editable filed (such as text, numbers, etc) displays the keyboard preserving the look and feel.

The following example, based on [My first application](https://wiki.genexus.com/commwiki/wiki?14738), shows both appearances of the keyboard when we try to insert a new customer.

|  |  |
| --- | --- |
| **Light** | **Dark** |
|  |  |

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply changes made by this property, do a Build All.

### [Availability](#Availability)
