# Events in Web Panels

The [Web Panel object](https://wiki.genexus.com/commwiki/wiki?6916) allows Event Driven Programming, a programming style in which the code remains idle until it is called by the user or the system.

The events available in Web Panels are:

|  |
| --- |
| [Enter event](https://wiki.genexus.com/commwiki/wiki?8167) |
| [Load event](https://wiki.genexus.com/commwiki/wiki?8188) |
| [OnMessage event](https://wiki.genexus.com/commwiki/wiki?58714) |
| [Refresh event](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?8195,,) |
| [Start event](https://wiki.genexus.com/commwiki/wiki?8043) |
| [TrackContext event](https://wiki.genexus.com/commwiki/wiki?8051) |
| [User defined event](https://wiki.genexus.com/commwiki/wiki?8044) |
