# Server Password property

This property is defined when the [Send Knowledge Base to GeneXus Server](https://wiki.genexus.com/commwiki/wiki?10215) or the [Knowledge Base from GXserver](https://wiki.genexus.com/commwiki/wiki?10625,,) actions are performed. It defines the password to be used when connecting to the [GeneXus Server](https://wiki.genexus.com/commwiki/wiki?9911).
