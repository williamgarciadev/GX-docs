# GeneXus Cognitive API

GeneXus provides capabilities to easily integrate cognitive services into your system. You do not have to be an expert on such a discipline or know how it works. You just set a few parameters, give your data as input and take the result.

Among the main task offered by GeneXus are image classification, facial recognition, audio transcription, text analysis, etc. Also, you can combine all these simple tasks for building sophisticated systems with a great look.
