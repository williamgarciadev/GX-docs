# Tracker Id property

Sets the Tracking ID delivered by Google Analytics or Firebase Analytics.

### [Scope](#Scope)

**Objects:** [Menu](https://wiki.genexus.com/commwiki/wiki?16321), [Panel](https://wiki.genexus.com/commwiki/wiki?24829), [Work With](https://wiki.genexus.com/commwiki/wiki?15974) (Only [Main Objects](https://wiki.genexus.com/commwiki/wiki?5770))  
**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917)

### [Description](#Description)

The Google Analytics Tracking ID is a unique identifier that Google Analytics assigns to a property. If you are using Universal Analytics (UA), it looks as follows:

**UA-XXX**

But if you have already switched to Google Analytics 4 (GA4), the next generation of Google Analytics, the Tracking ID is called “Measurement ID” and looks different:

**G-XXX**

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, Build the [Main Object](https://wiki.genexus.com/commwiki/wiki?5770).
