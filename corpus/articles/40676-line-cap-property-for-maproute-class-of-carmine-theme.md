# Line Cap property (for MapRoute class of Carmine Theme)

The line cap style to apply to the open ends of the path.

### [Values](#Values)

|  |
| --- |
| **Butt** |
| **Round** |
| **Square** |

### [Scope](#Scope)

**Objects:** [Theme](https://wiki.genexus.com/commwiki/wiki?17876,,)  
**Generators:** [Apple](https://wiki.genexus.com/commwiki/wiki?14917)

### [Description](#Description)

Indicates how the open ends of the path in the map are displayed.
