# Folder object

A Folder helps to organize [GeneXus objects](https://wiki.genexus.com/commwiki/wiki?1866) under a parent folder or [Module object](https://wiki.genexus.com/commwiki/wiki?22411).

As you create folders or objects under a folder or a module, you are organizing your KB, and the [KB Explorer](https://wiki.genexus.com/commwiki/wiki?3210) will show the objects in a tree where folders and modules are nodes of that tree.
