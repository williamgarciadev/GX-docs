# Program Description variable - Pgmdesc

Stores the description of the active program.

### [Syntax](#Syntax)

&Pgmdesc

**Data Type:**  
Character (31)

### [Scope](#Scope)

**Objects:** [Procedure](https://wiki.genexus.com/commwiki/wiki?6293), [Transaction](https://wiki.genexus.com/commwiki/wiki?1908), [Web Panel](https://wiki.genexus.com/commwiki/wiki?6916)  
**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), Ruby (up to GeneXus X Evolution 3), [Java](https://wiki.genexus.com/commwiki/wiki?12258), RPG, Visual Basic, Visual FoxPro (up to GeneXus X Evolution 3), Cobol

### [Description](#Description)

This GeneXus variable stores the active program's description when it is evaluated. The description is the one specified in the object's properties option.

**Note**: Although the [Objects Description](https://wiki.genexus.com/commwiki/wiki?7446) is currently supporting up to 256 characters, the variable continues with a 30 length to keep compatibility, so that no change is caused in the screens where it is used.
