# Subtotals property

Determines whether the element can have subtotals or not.

### [Values](#Values)

|  |  |
| --- | --- |
| **Hidden** | The subtotal is available but not visible. |
| **No** | The subtotal is not available. |
| **Yes** | Displays a subtotal for the element (default value). |

### [Availability](#Availability)

This property is available since [GeneXus 15 upgrade 12](https://wiki.genexus.com/commwiki/wiki?39737,,).
