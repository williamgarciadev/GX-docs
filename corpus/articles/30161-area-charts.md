# Area Charts

Area charts work in the same way as [Line Charts](https://wiki.genexus.com/commwiki/wiki?30167), but they fill the area between the line and the X axis.

**Area**

The area chart connects the data points with a straight line, similar to a [Line Chart](https://wiki.genexus.com/commwiki/wiki?30167).

|  |
| --- |
|  |

**Stacked area**

A stacked area chart works similarly to a stacked [Line Chart](https://wiki.genexus.com/commwiki/wiki?30167), stacking the series on top of each other.

|  |
| --- |
|  |

**100% stacked area**

A 100% stacked area chart stacks the data series and shows relative percentages like a 100% stacked [Line Chart](https://wiki.genexus.com/commwiki/wiki?30167) does.

|  |
| --- |
|  |

**Smooth area**

The smooth area chart connects the data points with a spline (curved line) instead with a straight line.

|  |
| --- |
|  |

**Step area**

The step area chart connects the data points of the series using horizontal and vertical lines.
