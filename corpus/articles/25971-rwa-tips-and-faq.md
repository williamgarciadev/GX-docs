# RWA - Tips and FAQ

Here are some tips and FAQ (frequently asked questions) for RWA (Responsive Web Apps).

#### [**1. Though Web Form Defaults property is set to Responsive Web Design, the web prompts are not responsive.**](#1.+Though+Web+Form+Defaults+property+is+set+to+Responsive+Web+Design%2C+the+web+prompts+are+not+responsive.)

The web prompts are not converted automatically, although they are automatic prompts generated by GeneXus and [Web Form Defaults property](https://wiki.genexus.com/commwiki/wiki?25135) is set to Responsive. This is because of compatibility reasons. The way to convert the prompts to responsive is to delete them and make them generate again. This is up to GeneXus Evolution 3 release version.

#### [**2. What to check if the responsive settings have no effect in devices (phones and tablets).**](#2.+What+to+check+if+the+responsive+settings+have+no+effect+in+devices+%28phones+and+tablets%29.)

Verify that the following meta tags are added to the master page code:

* Form.Meta.AddItem(!"viewport", 'width=device-width; initial-scale=1.0; maximum-scale=1.0; user-scalable=0;')
* Form.Meta.AddItem(!"apple-mobile-web-app-capable", 'yes')

#### 

#### [**3. What to check if the style controls do not have a responsive look and feel.**](#3.+What+to+check+if+the+style+controls+do+not+have+a+responsive+look+and+feel.+)

Check that the object uses the Theme Flat.

#### [**4. Problem: the web forms of WW pattern objects do not have a responsive form, although [Web Form Defaults property](https://wiki.genexus.com/commwiki/wiki?25135) is set to Responsive Web Design.**](#4.+Problem%3A+the+web+forms+of+WW+pattern+objects+do+not+have+a+responsive+form%2C+although+wiki%3F25135%2CWeb%2BForm%2BDefaults%2Bproperty+Web+Form+Defaults+property+is+set+to+Responsive+Web+Design.)

If the pattern has lost the dynamism, the default web form is not applied. You can apply the pattern again to all the parts ([Apply default web form (all parts)](https://wiki.genexus.com/commwiki/wiki?9751)) but the customization which has been done will be lost.
