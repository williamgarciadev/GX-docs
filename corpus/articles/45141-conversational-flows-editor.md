# Conversational Flows Editor

With the Conversational Flows editor, you can model [Conversational Flows](https://wiki.genexus.com/commwiki/wiki?37113) to create a [Chatbot](https://wiki.genexus.com/commwiki/wiki?38520).

In the Editor pane, two modes of operation are available: Designer and Tree, which can be selected using the tabs at the bottom of the Editor.  
The Designer mode allows you to add and edit [Flows](https://wiki.genexus.com/commwiki/wiki?38531) in a very intuitive way, as well as edit [User Inputs](https://wiki.genexus.com/commwiki/wiki?38959), [Chatbot Messages](https://wiki.genexus.com/commwiki/wiki?39875), and all the parts needed to create a Conversational Flows object.

`[imagen omitida: wiki id 45142]`

This Editor is available since [GeneXus 17](https://wiki.genexus.com/commwiki/wiki?46066,,).

For more information, see [Conversational Flows Designer](https://wiki.genexus.com/commwiki/wiki?45145).

The Tree Editor is an advanced editor where you can edit the properties of each node using the Properties editor.

`[imagen omitida: wiki id 45144]`

The way to add or remove different nodes (Messages, User Inputs, [Redirections](https://wiki.genexus.com/commwiki/wiki?39003), etc.) is through the contextual menu of each node or its parent.
