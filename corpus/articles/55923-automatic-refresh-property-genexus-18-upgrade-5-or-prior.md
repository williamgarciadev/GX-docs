# Automatic refresh property (GeneXus 18 Upgrade 5 or prior)

Refreshes the Grid automatically without the user having to click a "Refresh" button.

### [Values](#Values)

|  |  |
| --- | --- |
| **No** | The web panel does not refresh automatically. |
| **Yes** | A refresh is performed automatically after every change in any variable in the web form which is used in the Refresh, Load event or conditions. This is the default value. |

### [Scope](#Scope)

**Objects:** [Web Panel](https://wiki.genexus.com/commwiki/wiki?6916)  
**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [Java](https://wiki.genexus.com/commwiki/wiki?12258)

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
