# Empty method

Sets the cell or cells as empty.

### [Syntax](#Syntax)

**&***ExcelCellRange***.Empty*****(*****)**  
  
**Type Returned:**   
Boolean

### [Scope](#Scope)

**Extended Data Types:** [ExcelSpreadSheet](https://wiki.genexus.com/commwiki/wiki?46040)  
**Generators:** 
[Java](https://wiki.genexus.com/commwiki/wiki?12258)

### [Description](#Description)

This method sets the cell or group of cells defined in the [ExcelCellRange data type](https://wiki.genexus.com/commwiki/wiki?46081) as empty.

### [Availability](#Availability)

This data type is available since [GeneXus 16 Upgrade 11](https://wiki.genexus.com/commwiki/wiki?45901,,).
