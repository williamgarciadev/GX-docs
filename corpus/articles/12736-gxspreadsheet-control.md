# GXSpreadsheet control

**Discontinued** since: [GeneXus 18 Upgrade 10](https://wiki.genexus.com/commwiki/wiki?54244).

Adds a spreadsheet to your web applications.

### [Scope](#Scope)

**Controls**: Attribute/Variable

### [Usage](#Usage)

When you use Domains, Attributes and Variables of type Varchar or Long Varchar, the [Control Type property](https://wiki.genexus.com/commwiki/wiki?9550) can be set to the value 'GXSpreadsheet'.

GXspreadsheet is based on [JQuery Sheet](https://jspreadsheets.com/jquery-sheet/).

`[imagen omitida: wiki id 12737]`

Keep in mind that only one control per Web page is allowed, otherwise an error will occur.

### [Properties](#Properties)

* Width
* Height
* Autoresize
* Rows (quantity of rows by default)
* Columns (quantity of columns by default)
* CellWidth
* CellHeight
* Title
* Additional Info

### [Availability](#Availability)

This control is available as of [GeneXus X Evolution 1 Upgrade #1](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?12811,,).
