# Cache Password property

Sets the password to connect to the Cache system in a distributed caching environment.

### [Scope](#Scope)

**Level:** Generator

### [Description](#Description)

In a [distributed caching](https://wiki.genexus.com/commwiki/wiki?28136) environment, after configuring the [Cache Provider property](https://wiki.genexus.com/commwiki/wiki?31147), depending on your selection it may be required to specify the password to connect to the Cache system.

For example, it's required if the server supports SASL (e.g., Memcached SASL Authentication protocol).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
