# Min Value Image property

Sets an image representing the control's minimum value.

### [Scope](#Scope)

**Generators:** [Apple](https://wiki.genexus.com/commwiki/wiki?14917)  
**Controls:** Attribute/Variable (Control Type: [Slider](https://wiki.genexus.com/commwiki/wiki?20334))

### [Description](#Description)

Applies to Attribute/Variable controls defined in a [Panel object](https://wiki.genexus.com/commwiki/wiki?24829) or [WW](https://wiki.genexus.com/commwiki/wiki?15974) whose [Control Type](https://wiki.genexus.com/commwiki/wiki?9550) = [Slider](https://wiki.genexus.com/commwiki/wiki?20334).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies both at runtime and at design time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, execute a [Build with this Only](https://wiki.genexus.com/commwiki/wiki?5693) of the object.
