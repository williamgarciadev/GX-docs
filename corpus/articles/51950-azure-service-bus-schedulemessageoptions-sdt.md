# Azure Service Bus: ScheduleMessageOptions SDT

When the [Message Broker API](https://wiki.genexus.com/commwiki/wiki?51782) is used, the *ScheduleMessageOptions*[Structured Data Type](https://wiki.genexus.com/commwiki/wiki?10021) is defined under the *AzureServiceBus* module and represents the options that may be passed to the [ScheduleMessage](https://wiki.genexus.com/commwiki/wiki?51786) method.

`[imagen omitida: wiki id 52139]`

|  |  |
| --- | --- |
| **ScheduledEnqueueTime** | When using the *ScheduleMessage* method, the UTC time at which the message should be available for processing. |

### [Availability](#Availability)

This feature is available since [GeneXus 18 upgrade 1](https://wiki.genexus.com/commwiki/wiki?51081).
