# Which objects can be defined in a module?

Almost all [GeneXus objects](https://wiki.genexus.com/commwiki/wiki?1866) can be defined in a [Module object](https://wiki.genexus.com/commwiki/wiki?22411).

### [Exceptions](#Exceptions)

Below are the objects or concepts that do not belong to modules.

* [Language object](https://wiki.genexus.com/commwiki/wiki?7258)
* [Theme object](https://wiki.genexus.com/commwiki/wiki?16595)
* [Web Theme object](https://wiki.genexus.com/commwiki/wiki?6420)
* [Color Palette object](https://wiki.genexus.com/commwiki/wiki?31262)
* [Attribute](https://wiki.genexus.com/commwiki/wiki?6802)
* [Deployment Unit object](https://wiki.genexus.com/commwiki/wiki?38886)

**Notes:**

* The module of a [Table](https://wiki.genexus.com/commwiki/wiki?7120) is defined by the [Transaction object](https://wiki.genexus.com/commwiki/wiki?1908) that creates that table.
* Use the [Design System Object](https://wiki.genexus.com/commwiki/wiki?47375) instead of Theme, Web Theme, or Color Palette.
