# X-Axis Height property

The height of the X-axis column.

### [Description](#Description)

This property can be set for grids whose [Control Type property](https://wiki.genexus.com/commwiki/wiki?9550) = SD Matrix Grid.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Scope](#Scope)

**Controls:** Grid for Smart Devices
