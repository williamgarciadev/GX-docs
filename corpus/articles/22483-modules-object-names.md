# Modules - Object names

One important feature of [Module object](https://wiki.genexus.com/commwiki/wiki?22411)s is that they act as "qualifiers" of the value of the [Name property](https://wiki.genexus.com/commwiki/wiki?6985) of the objects in them. That is, the value of the [Name property](https://wiki.genexus.com/commwiki/wiki?6985) of an object must be unique among objects within the Module, but it can be reapeted in another module as shown in the image below. Therefore the [Qualified Name property](https://wiki.genexus.com/commwiki/wiki?22477) must be unique for every object on the [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836).
