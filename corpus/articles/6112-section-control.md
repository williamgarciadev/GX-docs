# Section Control

This control is aimed at establishing areas ([HTML div tags](http://www.w3schools.com/tags/tag_div.asp)) in Web Forms, which may contain other GeneXus controls.

The <div> tag defines a division or a section in an HTML document. The purpose of the <div> tag is to group block-elements to format them with CSS.

`[imagen omitida: wiki id 6125]` To add a Section control to the selected location, drag into the Web Form the corresponding icon from the toolbox.

Note:

For the  [Web Abstract Editor](https://wiki.genexus.com/commwiki/wiki?24795) the control is available as from [GeneXus X Evolution 3 Upgrade 6](https://wiki.genexus.com/commwiki/wiki?29463,,).

For previous versions, you should use a [Responsive Table](https://wiki.genexus.com/commwiki/wiki?24961) in its place.
