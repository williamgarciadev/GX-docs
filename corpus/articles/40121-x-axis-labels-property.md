# X axis labels property

Specifies if the labels in the X axis of a chart are shown horizontally or vertically.

### [Values](#Values)

|  |  |
| --- | --- |
| **Horizontally** | Labels are shown horizontally |
| **Rotated 30º** | Labels are shown 30º rotated |
| **Rotated 45º** | Labels are shown 45º rotated |
| **Rotated 60º** | Labels are shown 60º rotated |
| **Vertically** | Labels are shown vertically |

### [Description](#Description)

Define how the X axis labels are shown when using a [Chart widget](https://wiki.genexus.com/commwiki/wiki?40467).

The default value is Horizontally.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
