# GXtest 4 Installation

GXtest 4 is **included inside GeneXus IDE**,you cancheck it by going to the "Test"option on the menu bar**:**

**`[imagen omitida: wiki id 46560]`**

If you don't have it installed already, there are several GXtest versions for the different versions of GeneXus, so it is necessary to [install a compatible version](https://wiki.genexus.com/commwiki/wiki?42858).

### [Installing GXtest Recorder (for Google Chrome)](#Installing+GXtest+Recorder+%28for+Google+Chrome%29)

GXtest Recorder is a Chrome extension that allows you to record and playback user actions on any GeneXus web application. You can find it in the [Chrome Store](https://chrome.google.com/webstore/detail/gxtest-recorder/edbiefalppkhegcephbbcojpibobbdbd).

### [GXtest License](#GXtest+License)

GXtest has both free and licensed features. See the [details about the license model](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?41571,,).
