# Decrypt64 function

Decrypts any text that has been encrypted with a key.

### [Syntax](#Syntax)

 Decrypt64 (&text, &key)  
  
**Where:**  
  
***&****text*  
    Is the parameter to be decrypted.  
  
***&****key*  
    Is the key to be used for the decryption, generated by the [GetEncryptionKey](https://wiki.genexus.com/commwiki/wiki?8385) function.

**Type Returned:**  
Character  
    Is the result of the de-encryption.

### [Scope](#Scope)

**Objects:**  [Procedure](https://wiki.genexus.com/commwiki/wiki?6293), [Transaction](https://wiki.genexus.com/commwiki/wiki?1908), [Web Panel](https://wiki.genexus.com/commwiki/wiki?6916), [Panel](https://wiki.genexus.com/commwiki/wiki?24829), [Data Provider](https://wiki.genexus.com/commwiki/wiki?5270)  
**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604),
[.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Java](https://wiki.genexus.com/commwiki/wiki?12258), Ruby (up to GeneXus X Evolution 3), Visual FoxPro (up to GeneXus X Evolution 3), [Apple](https://wiki.genexus.com/commwiki/wiki?14917), [Android](https://wiki.genexus.com/commwiki/wiki?14453),
[Angular](https://wiki.genexus.com/commwiki/wiki?42550)

### [Description](#Description)

It decrypts the value received in the first parameter, using the indicated key.

Encryption is based on the [Twofish algorithm](http://en.wikipedia.org/wiki/Twofish) using a default key of 32 characters.
