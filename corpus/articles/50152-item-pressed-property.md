# Item Pressed property

A variable based on ActionGroupItem SDT with the item pressed.

### [Scope](#Scope)

**Objects:** [Web Panel](https://wiki.genexus.com/commwiki/wiki?6916), [Web Master Panel](https://wiki.genexus.com/commwiki/wiki?10348)

### [Description](#Description)

The ActionGroup item that triggered the event is instantiated in the variable configured in this property.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at runtime.

### [Availability](#Availability)

This property is available since [GeneXus 17 Upgrade 9](https://wiki.genexus.com/commwiki/wiki?49956,,).
