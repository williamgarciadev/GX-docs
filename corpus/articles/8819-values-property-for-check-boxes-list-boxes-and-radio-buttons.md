# Values property (for Check Boxes, List Boxes and Radio Buttons)

Displays the possible values for the control.

### [Scope](#Scope)

**Generators:** [Java](https://wiki.genexus.com/commwiki/wiki?12258), .NET, [.NET Core](https://wiki.genexus.com/commwiki/wiki?38604)

### [Description](#Description)

Applies to Check Boxes, List Boxes and Radio Buttons.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
