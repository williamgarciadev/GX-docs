# Dashboard Element Order property

It allows you to set the order in which the values of the element are displayed.

### [Values](#Values)

|  |  |
| --- | --- |
| **Ascending** | Element order is ascending. |
| **Custom** | Element order is defined by the developer. |
| **Descending** | Element order is descending. |
| **None** | No order is set (Default value). |

### [Description](#Description)

Set the desired order for a [Dashboard Element](https://wiki.genexus.com/commwiki/wiki?36769).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
