# Unanimo module components

The GeneXusUnanimo module contains different [Design Systems](https://wiki.genexus.com/commwiki/wiki?40108), [Stencils](https://wiki.genexus.com/commwiki/wiki?38418) with different layouts, images, files, and domains that give you all the resources necessary to create your applications based on Unanimo design concepts.

To learn more about the design foundations of Unanimo, visit [this page about the Unanimo project](https://projects.invisionapp.com/dsm/genexus/unanimo-ds).

`[imagen omitida: wiki id 60833]`

All the [Tokens](https://wiki.genexus.com/commwiki/wiki?47378) common to all Design Systems regardless of the platform are defined in Unanimo Design System.

These Tokens define not only the Color Scheme (dark & light) but also all the values used in the classes defined in the Styles section for each Design System. Then, when you want to change the base colors, changing these Tokens will apply to all the platforms. Read this document to learn how to [Customize Unanimo](https://wiki.genexus.com/commwiki/wiki?52178).

`[imagen omitida: wiki id 60843]`

All Design Systems include in their Styles definition the imported GeneXusUnanimo.Unanimo Design System. In this way, all the Styles and Tokens defined in the Unanimo Design System that are common to all of them are imported.

* **UnanimoControls** contains all the styles applied in the User Controls distributed with Unanimo.
* **UnanimoWeb** contains all the styles to be used in web applications generated by [.NET](https://wiki.genexus.com/commwiki/wiki?38604) or [Java](https://wiki.genexus.com/commwiki/wiki?12258).
* **UnanimoMobile** contains all the styles to be used in native mobile applications generated for iOS or Android.
* **UnanimoAngular** contains all the styles to be used in web applications generated by the [Angular generator](https://wiki.genexus.com/commwiki/wiki?42550).
* **Unanimo\_LegacyTokens** contains only the token definitions corresponding to versions prior to GeneXus 18 Upgrade 14 to maintain compatibility. Since [GeneXus 18 Upgrade 14](https://wiki.genexus.com/commwiki/wiki?59631) introduces major structural changes to the [Unanimo](https://wiki.genexus.com/commwiki/wiki?48382) Design System Object, the goal is to allow you to continue using Design Systems defined with previous versions and decide when to migrate to the new structure.

#### [**Consideration**](#+Consideration+)

If styles are lost after updating the Unanimo version, you should add this [Import style rule](https://wiki.genexus.com/commwiki/wiki?49346):

@import GeneXusUnanimo.Unanimo\_LegacyTokens.tokens;
