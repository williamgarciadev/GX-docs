# Work With Detail Node

The objective of the Detail node is to show detailed information about a record previously selected from the related [Work With List](https://wiki.genexus.com/commwiki/wiki?15984).

Below you can see the Detail node of the Work With pattern instance corresponding to the Property [Transaction object](https://wiki.genexus.com/commwiki/wiki?1908):

`[imagen omitida: wiki id 52225]`

Each Detail node may contain several [Sections](https://wiki.genexus.com/commwiki/wiki?20624).

At runtime (Android), the Detail with its Sections is shown as follows:  
  
`[imagen omitida: wiki id 52228]`

**Note**: You can use the [Display property](https://wiki.genexus.com/commwiki/wiki?15847) to specify how all the sections contained in the <All Sections Content> control of the Detail Node will look like.
