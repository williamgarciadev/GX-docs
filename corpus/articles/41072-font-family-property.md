# Font family property

Sets the QueryViewer control font family.

### [Description](#Description)

Defines the font family to be used by the [QueryViewer control](https://wiki.genexus.com/commwiki/wiki?9075).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Scope](#Scope)

**Objects:** Query
