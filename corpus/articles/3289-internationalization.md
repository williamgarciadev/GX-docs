# Internationalization

Internationalization (also known as i18n); refers to the practice of translating a program into multiple languages, effectively by translating all of the program's strings.

GeneXus allows building multi-language applications using the [Language objects.](https://wiki.genexus.com/commwiki/wiki?7258). You build the application in one language and then using this object, including the translations needed to have the application in a new language.

Translation can be **static**, which means that the application will be in only one language (the translation is done at generation time), or **dynamic**, which means that the application will have the possibility of changing its language at runtime.

More detail can be found [here](https://wiki.genexus.com/commwiki/wiki?6330).
