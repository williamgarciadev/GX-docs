# Menu for Web Applications

A menu in a web application is represented by an [Action Group](https://wiki.genexus.com/commwiki/wiki?25631) control.

An action group, as is, can also be used as a toolbar. The Control Type property of the action group determines how it will be displayed.

When the action group is used as a menu, it is called a [Web Navigation Bar](https://wiki.genexus.com/commwiki/wiki?31918), and it is based on [Bootstrap Navbars](https://getbootstrap.com/docs/3.3/components/#navbar).

As a menu (and as a toolbar also), the action group can be loaded dynamically, which means that it can be loaded from an SDT structure. See [How to create a dynamic menu for WEB applications](https://wiki.genexus.com/commwiki/wiki?33589).
