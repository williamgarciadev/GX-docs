# GeneXus Start Page

When you run GeneXus, the **Start Page** is opened by default. It shows recently used projects that can be opened and offers the chance to create a new project.

It may dynamically display technical information about [GeneXus](https://wiki.genexus.com/commwiki/wiki?1756) and the GeneXus community (news and solutions posted by other developers).

Furthermore, some extra sections provide more functionalities:

* **Samples:** Allows you to download some of the best GeneXus samples (create local Knowledge Bases from those available on servers).
* **Learn:** Provides links to materials.
* **Marketplace:** Allows you to download User Controls, Extensions, etc. from the [Marketplace](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?26288,,).
* **Update:** Shows downloaded content from the Marketplace that can be updated.

If you close the **Start Page**, you can open it again by selecting **View > Start Page**.

**Note**: Not all the components are displayed when no internet connection is available.
