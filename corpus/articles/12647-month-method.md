# Month method

Returns the numeric month identifier of a given date. A null value (0) is returned if the received parameter is null.

### [Syntax](#Syntax)

*Date* | *DateTime.***Month()**

**Where:**

*Date*|*DateTime*Is an attribute or variable based on the Date/DateTime data type, to which the method will find its numeric month identifier.

**Type returned:**  
Numeric N(2)

### [Scope](#Scope)

**Data Types:** [Date](https://wiki.genexus.com/commwiki/wiki?7373), [DateTime](https://wiki.genexus.com/commwiki/wiki?7370)

### [Samples](#Samples)

```
&MonthNumber= &GivenDate.Month() // if &GivenDate = 07/11/2022, the result of &MonthNumber is: 7
```
