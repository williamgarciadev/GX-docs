# GeneXus objects (GeneXus 18 latest upgrade or prior)

A [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836) is made up of different types of [GeneXus](https://wiki.genexus.com/commwiki/wiki?1756) objects.

Most types of GeneXus objects can be created through the [New Object dialog](https://wiki.genexus.com/commwiki/wiki?9931). In particular, some types of GeneXus objects can be created using contextual options.

**Note**: The concept of GeneXus Object has nothing to do with [OOP](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?1916,,) objects.
