# External utilities used by GeneXus generated applications

Everytime GeneXus builds an application, it uses external utilities in order to include development tools, to improve the application’s visuals and user experience, among others.

To learn about the external utilities used by Web applications check out the [External utilities used by GeneXus generated web applications](https://wiki.genexus.com/commwiki/wiki?15671).

To learn about the external utilities used by Smart Devices applications check out the [External utilities used by GeneXus generated Native Mobile applications](https://wiki.genexus.com/commwiki/wiki?25094).
