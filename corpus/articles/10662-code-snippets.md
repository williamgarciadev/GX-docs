# Code Snippets

Code Snippets are reusable, task-oriented blocks of code which can be used for simple expansions of common programming structures.

### [How to take advantage of Code Snippets?](#How+to+take+advantage+of+Code+Snippets%3F)

When opening the rules or procedural code section of one of the following objects [Procedure\Report](https://wiki.genexus.com/commwiki/wiki?6293), [Transaction](https://wiki.genexus.com/commwiki/wiki?1908), [Web Panel](https://wiki.genexus.com/commwiki/wiki?6916), [Work Panel](https://wiki.genexus.com/commwiki/wiki?7387,,) you will notice the [Toolbox window](https://wiki.genexus.com/commwiki/wiki?10000) details a list of snippets with some generic GeneXus block of code such as:

* [Call](https://wiki.genexus.com/commwiki/wiki?8260)
* [Do Case](https://wiki.genexus.com/commwiki/wiki?8579,,)
* [For Each command](https://wiki.genexus.com/commwiki/wiki?20195,,)
* [For In](https://wiki.genexus.com/commwiki/wiki?8585)
* and so on....

One way to use them is to drag from the [Snippets Toolbox](https://wiki.genexus.com/commwiki/wiki?10000) the one you want and drop it on the source editor. Once dragged you willl notice the code expansion.

If you check the associated snippet shorcut (with a mouse over it) you can also do exactly the same just by typying the [shortcut](https://wiki.genexus.com/commwiki/wiki?20853) in the source editor and pressing the TAB key; again the code expansion will take place !

### [Sample](#Sample)

1. Create a new procedure or open an existing one.
2. In the rules section type
   * def + tab; you will get the [default rule](https://wiki.genexus.com/commwiki/wiki?6850) replacement.
   * asg + tab; you will get the [assignment rule](https://wiki.genexus.com/commwiki/wiki?6847) sample code replacement.
3. In the source section type something like:
   * doc + tab; you will get the [Do Case](https://wiki.genexus.com/commwiki/wiki?8579,,) command replacement.
   * dow+ tab; you will get the [Do While](https://wiki.genexus.com/commwiki/wiki?8582) command replacement.
   * fe + tab; you will get the [assignment rule](https://wiki.genexus.com/commwiki/wiki?6847) replacement.
   * feuwn + tab; you will get the [For Each command](https://wiki.genexus.com/commwiki/wiki?20195,,) using when none.
   * and so on...
