# Supported audio formats for Native Mobile Applications

This document describes the supported formats for [Audio data type](https://wiki.genexus.com/commwiki/wiki?16529) in a Native Mobile Applications.

Remember that some manufacturers or the usage of third-party extension could accept other formats/codecs.

The following table does not pretend to be exhaustive, it only focuses in those formats which are widely used and supported natively on each platform.
