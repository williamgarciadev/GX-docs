# GeneXus For SAP Systems Simple Worklist Floorplan (GeneXus 18 Upgrade 3 or prior)

The Simple Worklist [Floorplan](https://wiki.genexus.com/commwiki/wiki?38629,,) is a set of layouts that allows you to query and view data.

This article describes how to apply it to a [Transaction](https://wiki.genexus.com/commwiki/wiki?1908) or [Web Panel](https://wiki.genexus.com/commwiki/wiki?6916) to obtain a page like the following:

`[imagen omitida: wiki id 53268]`

**Note**: The design guideline of this floorplan is at [SAP's documentation](https://experience.sap.com/fiori-design-web/work-list/#simple-worklist).

## [How to Apply it](#How+to+Apply+it)

Look at the Patterns tab of the Country Transaction. If you have never applied the Fiori for Web pattern in your Knowledge Base before, [read here](https://wiki.genexus.com/commwiki/wiki?38862). Otherwise, by positioning on the Fiori for Web Pattern tab, check the "Apply this pattern on save" checkbox and select the offered link to choose a floorplan:

`[imagen omitida: wiki id 54852]`

You can choose the Simple Worklist floorplan from several offered floorplans:

`[imagen omitida: wiki id 53269]`

This floorplan can be applied to a [Transaction object](https://wiki.genexus.com/commwiki/wiki?1908) or a [Web Panel object](https://wiki.genexus.com/commwiki/wiki?6916).

[Learn how to apply it to a Web Panel](https://wiki.genexus.com/commwiki/wiki?42011).

## [How to customize it](#How+to+customize+it)

The following section explains how to customize your Simple Worklist.

### [Add/Modify/Delete Actions](#Add%2FModify%2FDelete+Actions)

You can add, modify or delete actions by positioning on the Simple Worklist tab.

`[imagen omitida: wiki id 54959]`

**Note**: Consider if you prefer to apply the [List Report Floorplan](https://wiki.genexus.com/commwiki/wiki?38572) which automatically offers to insert, update and delete data.

To add actions, right-click on the GridActions node and then, select Add / UserAction from the contextual menu. The action will be added outside the grid.

To modify these actions, right-click on the action node and select the 'Go to Event' option. Then, you can modify the event code, but remember to do it outside the code generated by GeneXus (to avoid being overwritten by GeneXus).

If you want to add an action inside the grid for every line, right-click on the Grid node and select Add / UserAction in the contextual menu:

`[imagen omitida: wiki id 54960]`

In order to modify these actions, you have to follow the next steps:

1. Right-click on the Simple Worklist tab and select Open YourObjectNameSimpleWorklist.

`[imagen omitida: wiki id 54961]`

2. On the Simple Worklist Web Panel tab, go to the Events Section.

`[imagen omitida: wiki id 38789]`

3. Once there, you only have to create the click events for your customized actions.

`[imagen omitida: wiki id 38790]`

### [Manage Filters](#Manage+Filters)

You can manage the [Filters](https://wiki.genexus.com/commwiki/wiki?38588) by positioning on the Simple Worklist tab.

To add filters, right-click on the GridActions node and then select in the contextual menu Add and select the kind of filter you want:

`[imagen omitida: wiki id 54962]`

For more information, see [GeneXus For SAP Filters](https://wiki.genexus.com/commwiki/wiki?38588)

### [Manage Orders](#Manage+Orders)

You can manage the Orders by positioning on the Simple Worklist tab. Once there, you have to right-click on the GridActions node and then select Add > Orders.

`[imagen omitida: wiki id 54963]`

After having created the Orders node, to add a new Order you have to right-click on Orders and then choose Add > Order.

`[imagen omitida: wiki id 54964]`

For each order you create, you have to complete its Name property:

`[imagen omitida: wiki id 54965]`

and you have to add the attribute(s) by which the list will be sorted:

`[imagen omitida: wiki id 54966]`

For each attribute, you can change the Ascending property to choose whether you want the list to be sorted in ascending or descending order considering that attribute(s) value(s).

`[imagen omitida: wiki id 54967]`

### [Customize the information to be shown on the list](#Customize+the+information+to+be+shown+on+the+list)

You can manage the attributes to show by positioning on the Simple Worklist tab.

To prevent attributes from being shown on the list report, right-click on the attribute and select Delete.

`[imagen omitida: wiki id 54968]`

To add attributes to be shown in the list, right-click on the Grid node, then select Add / GridAttribute:

`[imagen omitida: wiki id 54969]`

Then, GeneXus will display a list of attributes for you to choose which ones you want to add:

`[imagen omitida: wiki id 38760]`
