# Offline Native Mobile Applications Requirements

[Offline Native Mobile applications](https://wiki.genexus.com/commwiki/wiki?22237) can be generated for Android and iOS platforms only.

These applications need to be compiled, they cannot be executed with the [GeneXus Project Navigator](https://wiki.genexus.com/commwiki/wiki?14974) (KBN).
