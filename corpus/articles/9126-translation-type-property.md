# Translation type property

Defines whether to translate the current environment.

### [Values](#Values)

|  |  |
| --- | --- |
| **No translation** | Sets no translation for the current environment. This is the default value. |
| **Run-time** | Allows translation at runtime. |
| **Static** | Sets translation for the current environment. |

### [Scope](#Scope)

**Level:** [Environment](https://wiki.genexus.com/commwiki/wiki?7115)

### [Description](#Description)

To apply the corresponding changes when the property value is configured, execute [Rebuild All](https://wiki.genexus.com/commwiki/wiki?5692) and [Deploy business processes](https://wiki.genexus.com/commwiki/wiki?17111).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
