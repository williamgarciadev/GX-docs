# Business Components as Rest web services in GeneXus

To expose a [Business Component](https://wiki.genexus.com/commwiki/wiki?5846) (henceforth the BC) as a [Rest web service](https://wiki.genexus.com/commwiki/wiki?14573), you only need to configure in the [Transaction object](https://wiki.genexus.com/commwiki/wiki?1908) that is BC the following properties:

* [Expose as Web Service property](https://wiki.genexus.com/commwiki/wiki?36480) = True
* Web Service Protocol property = REST Protocol

After generating the BC, it's exposed as a Rest service and it can be consumed using the HTTP protocol (in particular, the [HttpClient data type](https://wiki.genexus.com/commwiki/wiki?6932)) in GeneXus.

Note that the specification document of this service can be generated automatically. See [Documenting RESTFul services](https://wiki.genexus.com/commwiki/wiki?30776).

The endpoint URI for Business components is

```
 <server uri>/rest/<bc name>
```

E.g: If "Product" is a BC exposed as Rest, the URI of the service would be: 172.19.12.1/MyApp/rest/Product

If the BC belongs to a module, the endpoint URI is

```
<server uri>/rest/<module>/<bc name>
```

To consume a Business Component exposed as Rest, see [Consuming a Business Component exposed as Rest with GeneXus](https://wiki.genexus.com/commwiki/wiki?44414,,).
