# Hardly ever TTL(mins) property

Hardly ever TTL(mins) Property sets the elapsed time, in minutes, that the statement cache keeps information for statements. The property applies to all the tables that have the Change Frequency Property  configured to "Hardly Ever" value.

### [Description](#Description)

Hardly ever TTL(mins) Property is available at generator level, and it's enabled when the value of the [Database access caching property](https://wiki.genexus.com/commwiki/wiki?8968) is set to True.

**Default value** = 600

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply changes made by this property, do a Build with this Only of the object.
