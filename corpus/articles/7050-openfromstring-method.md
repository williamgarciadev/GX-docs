# OpenFromString method

Reads an XML document from an internal buffer instead of a file.

### [Syntax](#Syntax)

**&***VarBasedOnXmlReader*.**OpenFromString(**Parameter**)**

**Where:**  
*Parameter*  
    Character variable or attribute, containing the XML to be read.

### [Scope](#Scope)

**Extended Data Types:** [XmlReader](https://wiki.genexus.com/commwiki/wiki?6928)  
**Generators:**

[.NET](https://wiki.genexus.com/commwiki/wiki?38604), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892),
[Java](https://wiki.genexus.com/commwiki/wiki?12258), Visual Basic (up to GeneXus 9.0), Visual FoxPro (up to GeneXus X Evolution 3)

### [Description](#Description)

Similar to the [Open method](https://wiki.genexus.com/commwiki/wiki?6992), but allows the reading of an XML document from a character variable or attribute instead of a file.
