# KB Explorer

From the KB Explorer, you can create new [GeneXus objects](https://wiki.genexus.com/commwiki/wiki?1866) and view their history, references, etc.  
  
It has several nodes in which Domains, Tables, Documentation, etc., are organized.

To access a certain object, you can double-click on it or type its name in the "Open" box (for example, if there are many objects inside folders and/or modules).

In addition, it is possible to drag/drop and cut/paste objects simply by right-clicking on them. This allows moving several objects at the same time when they are saved in different folders.
