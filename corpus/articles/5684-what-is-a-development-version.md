# What is a Development Version?

In GeneXus, a Development Version is what in [Software Configuration Management](http://en.wikipedia.org/wiki/Software_configuration_management) (SCM) is called a [Branch](http://en.wikipedia.org/wiki/Branching_%28software%29), identifying with this term, the existence of different development lines.

One of the most common situations for using development versions is when there is a need to continue with the application's evolution (usually in the [Trunk](https://wiki.genexus.com/commwiki/wiki?5683)) while making maintenance fixes to an application in production (in a Development Version). What you need is that changes to either of them do not interfere with the other.  
  
To create a new [Development Version](https://wiki.genexus.com/commwiki/wiki?5684), open the [Knowledge Base Versions tool window](https://wiki.genexus.com/commwiki/wiki?5687), right-click on any [Frozen Version](https://wiki.genexus.com/commwiki/wiki?5681) node of the tree which has no child nodes, and select the New Version option. Fill the New Development Version dialog and press Enter. The times it takes to create a branch is proportional to the size of your application. When a Development Vesion is created it is initialized with its parent's content.

`[imagen omitida: wiki id 7505]`  
  
Development Versions can be used:

* [To work on a separate development path](https://wiki.genexus.com/commwiki/wiki?5688)
* As a source or target of a [Revert Operation in GeneXus X](https://wiki.genexus.com/commwiki/wiki?5685,,) from a Backup Frozen Version
