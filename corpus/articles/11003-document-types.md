# Document Types

Allows to set the document type.

### [Values](#Values)

|  |
| --- |
| Microsoft Word, Excel, Power Point |
| PDF |
| Open Office: Text, Spreadsheet, Presentation |
| StarOffice: Starwriter, Starcalc, StarImpress |
| Images: JPG, BMP, GIF |
| XML |
| ZIP |
| XPZ |
| Other. This is the default value. |

### [Note](#Note)

If Other value was selected, any document type could be uploaded.

### [Scope](#Scope)

**Objects:** [Business Process Diagram object](https://wiki.genexus.com/commwiki/wiki?16486)
