# Connection User Password property

Configures the password corresponding to the user name specified in the Connection User Name property.

### [Scope](#Scope)

**Level:** [Environment](https://wiki.genexus.com/commwiki/wiki?7115)

### [Description](#Description)

This property is available when [GAM is activated in your KB](https://wiki.genexus.com/commwiki/wiki?19946).

Its default value is the [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836) name followed by "123" (for example, KBName123).
