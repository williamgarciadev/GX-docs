# Pin Image Field Specifier property

The field containing the image that will be used to display a point on the map in a grid associated with an SDT.

### [Scope](#Scope)

**Objects:** Panel for Smart Devices, Work With for Smart Devices  
**Platforms:** Smart Devices(Android, IOS)  
**Controls:** Grid

### [Description](#Description)

Allows indicating a field of the [Structured Data Type (SDT) object](https://wiki.genexus.com/commwiki/wiki?10021) associated with the Grid containing the image that will be used to display the points on a [Maps Control Type](https://wiki.genexus.com/commwiki/wiki?15309).  
This field must be of [Image data type](https://wiki.genexus.com/commwiki/wiki?15204). Different values can be assigned to each point of the map, by assigning those values to the field in the [Grid control](https://wiki.genexus.com/commwiki/wiki?24817)  [Load event](https://wiki.genexus.com/commwiki/wiki?8188).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#com.gxwiki.wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, execute a [Build with this Only](https://wiki.genexus.com/commwiki/wiki?5693) of the object.
