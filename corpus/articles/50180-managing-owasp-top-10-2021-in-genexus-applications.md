# Managing OWASP Top 10 2021 in GeneXus Applications

This document is a collaborative effort with [GeneXus Consulting](http://gxconsulting.us/security/) and it is intended to be a guideline to help develop more secure applications.

The OWASP Top 10 is a guideline that summarizes the 10 most impactful and exploitable vulnerabilities detected in the last years. The level of security for the application depends on the security policy the enterprise needs.

* [OWASP Documentation](https://owasp.org/Top10/)

For more information, take the [GeneXus web applications security course](https://training.genexus.com/en/learning/courses/security/course-security-in-web-applications) provided by  [GeneXus Consulting](http://gxconsulting.us/security/). It covers all OWASP Top 10 2021 items in depth with demos and practice exercises, and is highly recommended for an effective secure development approach.

Even though CSRF is no longer included in the OWASP Top 10, its updated documentation is available in the article on [Managing Cross-Site Request Forgery (CSRF) with GeneXus](https://wiki.genexus.com/commwiki/wiki?41123,,).
