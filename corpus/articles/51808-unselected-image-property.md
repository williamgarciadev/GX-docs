# Unselected Image property

Shows the image to be used when the item is not selected.

### [Scope](#Scope)

**Objects:** [Menu](https://wiki.genexus.com/commwiki/wiki?16321)  
**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917)

### [Description](#Description)

This property applies to images displayed in the [Menu](https://wiki.genexus.com/commwiki/wiki?16321) tabs when the [Control](https://wiki.genexus.com/commwiki/wiki?16098) property is set to "Tabs." This image will be displayed when the Tab is not selected.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [Samples](#Samples)

In an application that uses a [Menu object](https://wiki.genexus.com/commwiki/wiki?16321), the following properties are set for each item:

Image = Icons\_Home\_IconsHomeSelected

Unselected Image = Icons\_Home\_IconsHomeUnselected
