# Password property

Indicates the password that must be used in order to be authenticated in the server.

### [Syntax](#Syntax)

**control.** Password   

**&***DataType***.Password**

### [Scope](#Scope)

**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [Java](https://wiki.genexus.com/commwiki/wiki?12258)  
**Level:** [Variable](https://wiki.genexus.com/commwiki/wiki?7375)

### [Description](#Description)

This property is offered for variables based on the [LDAPClient](https://wiki.genexus.com/commwiki/wiki?6886), [POP3Session Data Type](https://wiki.genexus.com/commwiki/wiki?6966), [SMTPSession](https://wiki.genexus.com/commwiki/wiki?6937) Extended Data Types.

For SMTPSession this property will be ignored if the [Authentication Property](https://wiki.genexus.com/commwiki/wiki?6982) is set to 0.
