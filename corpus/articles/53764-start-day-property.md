# Start Day property

Indicates which day is the first one when displaying the scheduler in week mode.

### [Values](#Values)

|  |  |
| --- | --- |
| **Sunday** | The week mode will start on Sunday. |
| **Monday** | The week mode will start on Monday. |

### [Scope](#Scope)

**Controls:** [Scheduler](https://wiki.genexus.com/commwiki/wiki?11583)

### [Description](#Description)

The scheduler can be displayed in Day mode, Week mode, or Month mode.

In Week mode, Monday or Sunday can be set as the first day of the week.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, execute a [Build with this Only](https://wiki.genexus.com/commwiki/wiki?5693) of the object.

### [Availability](#Availability)

This property is available since [GeneXus 18 Upgrade 2](https://wiki.genexus.com/commwiki/wiki?53396).
