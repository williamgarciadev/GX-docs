# Abs function

Returns the absolute value of the number provided as a parameter.

### [Syntax](#Syntax)

*abs(Numeric Expression)*

**Where:**

*Numeric Expression*  
      Is a Numeric [Expression](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?51320,,) that you must pass to the function as input to obtain the absolute value of that number.

**Type Returned:**  
*Numeric*

### [Scope](#Scope)

**Generators:** [Java](https://wiki.genexus.com/commwiki/wiki?12258), [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Angular](https://wiki.genexus.com/commwiki/wiki?42550)

### [Description](#Description)

This function returns the absolute value of a number.

For example, Abs(-5) returns 5.

**Note**: This function is supported in all DBMS and can be solved with SQL.

### [Samples](#Samples)

**1)**

```
&NumericExpression1 = -10
&AbsoluteValue = abs(&NumericExpression1) //&AbsoluteValue=10
```

**2)**

```
&NumericExpression2 = 5
&AbsoluteValue = abs(&NumericExpression2) //&AbsoluteValue=5
```
