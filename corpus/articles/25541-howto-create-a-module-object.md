# HowTo: Create a Module Object

This article explains how to create a new [Module object](https://wiki.genexus.com/commwiki/wiki?22411).

### [Creating a Module Object in the Root module.](#Creating+a+Module+Object+in+the+Root+module.)

#### [Steps](#Steps)

1. Right-click on the [Root module](https://wiki.genexus.com/commwiki/wiki?22439) in the [KB Explorer](https://wiki.genexus.com/commwiki/wiki?3210).
2. Select the **New > Module** option.  
     
   `[imagen omitida: wiki id 32312]`
3. Type a name for the newly created Module Object.

### [Creating a Module Object in a module other than the Root module](#Creating+a+Module+Object+in+a+module+other+than+the+Root+module)

#### [Steps](#Steps)

1. In the [KB Explorer](https://wiki.genexus.com/commwiki/wiki?3210), right-click on the Module Object where you want to add a new child Module Object.
2. Select the **New > Module** option.  
     
   `[imagen omitida: wiki id 32314]`
3. Type a name for the newly created Module Object.
