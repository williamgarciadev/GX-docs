# Showed values property

Filter values.

### [Scope](#Scope)

**Objects:** Dashboard

### [Description](#Description)

Selects the attribute values to be displayed when the related Filter property is set to "Show some values."

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
