# Description Class property

Indicates which theme class will be used to customize a Progress Indicator description.

### [Description](#Description)

When a [Progress Indicator User Control](https://wiki.genexus.com/commwiki/wiki?31275) control is used, the description (secondary text) format can be customized setting a Text Block-type theme class name in this property.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply changes made by this property, do a Build All.

### [Availability](#Availability)

This property is available since [GeneXus 15 Upgrade 9](https://wiki.genexus.com/commwiki/wiki?37491,,).

### [Scope](#Scope)

**Objects:** Theme for Smart Devices  
**Platforms:** Smart Devices(Android, IOS)
