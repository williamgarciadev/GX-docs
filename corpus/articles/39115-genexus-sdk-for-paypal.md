# GeneXus SDK for PayPal

GeneXus SDk for Paypal is a GeneXus module that can be imported into your KB.

It has several objects which will allow you to connect with and use Paypal services, such as making payments or creating subscriptions.

### [Scope](#Scope)

**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Java](https://wiki.genexus.com/commwiki/wiki?12258)
