# Control Title property

Indicates the title assigned to the control.

### [Scope](#Scope)

**Controls:** Attribute/Variable (Control Type: Check Box, Radio Button)

### [Description](#Description)

It applies to Attribute/Variable controls included in a [Panel](https://wiki.genexus.com/commwiki/wiki?24829), [Web Panel Web Layout](https://wiki.genexus.com/commwiki/wiki?8132) or [Transaction Web Layout](https://wiki.genexus.com/commwiki/wiki?8057) whose [Control Type property](https://wiki.genexus.com/commwiki/wiki?9550) = Check Box or Radio Button.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
