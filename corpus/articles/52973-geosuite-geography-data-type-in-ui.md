# GeoSuite - Geography Data Type in UI

The [Geography data type](https://wiki.genexus.com/commwiki/wiki?32408) is the basic data type for managing geographic information with GeneXus.

When inserting an attribute or variable based on the [Geography data type](https://wiki.genexus.com/commwiki/wiki?32408) into a [Panel](https://wiki.genexus.com/commwiki/wiki?24829), [Web Panel](https://wiki.genexus.com/commwiki/wiki?6916) or [Transaction](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?1908,,) Layout, it will be displayed by default as a Map (Control Type property = Map). This is valid for all data types associated with the Geography data type (Geography and its derived [GeoPoint](https://wiki.genexus.com/commwiki/wiki?58058), [GeoLine](https://wiki.genexus.com/commwiki/wiki?59358), and [GeoPolygon](https://wiki.genexus.com/commwiki/wiki?59361)).

`[imagen omitida: wiki id 54083]`

The inserted control offers properties to configure its behavior at runtime, such as [Map Zoom property](https://wiki.genexus.com/commwiki/wiki?41339) and [Map Type property](https://wiki.genexus.com/commwiki/wiki?42207). However, its scope is limited to viewing geographic data or editing Geopoints. When creating richer interfaces with greater usability such as data editing or viewing geometries with style, you can use the [Grid with Control Type set to Maps](https://wiki.genexus.com/commwiki/wiki?15309) in Panels or the [Map User Control](https://wiki.genexus.com/commwiki/wiki?5029) in Web Panels.

**Note**: Up to [GeneXus 16](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?35351,,), the Control Type of a Geography attribute/variable in forms used to be named Geolocation. It was renamed to Map in [GeneXus 17](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?46066,,).
