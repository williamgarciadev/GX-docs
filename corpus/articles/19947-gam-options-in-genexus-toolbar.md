# GAM options in GeneXus toolbar

The purpose of these options is to allow to manage the actions which execute on the GAM database, actions that configure the database using the information of the KB.

* [GAM - Create tables option](https://wiki.genexus.com/commwiki/wiki?16588)
* [GAM - Initialize Metadata option](https://wiki.genexus.com/commwiki/wiki?16287)
* [GAM - Applications Registration option](https://wiki.genexus.com/commwiki/wiki?16288)
* [GAM - Reprocess Permissions Option](https://wiki.genexus.com/commwiki/wiki?36013)

The following item is to manage the [GAM - Examples](https://wiki.genexus.com/commwiki/wiki?21993) in the KB.

* Installation Settings. See [GAM - Activation Process](https://wiki.genexus.com/commwiki/wiki?21973) for details.

The following items are available for deployment purposes.

* [GAM - Update Connection File](https://wiki.genexus.com/commwiki/wiki?18690)
* [Create Deploy File](https://wiki.genexus.com/commwiki/wiki?18872)
