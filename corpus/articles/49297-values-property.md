# Values property

Defines the Toggle Button Group control values, each with a description to be shown to the user and an internal value to be assigned to the Attribute/Variable.

### [Scope](#Scope)

**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917)  
**Controls:** Attribute/Variable

### [Description](#Description)

Applies to Attribute/Variable controls defined in [Panel](https://wiki.genexus.com/commwiki/wiki?24829) and [WW](https://wiki.genexus.com/commwiki/wiki?15974) objects whose [Control Type](https://wiki.genexus.com/commwiki/wiki?9550) = Toggle Button Group.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, Build the [Main Object](https://wiki.genexus.com/commwiki/wiki?5770).

### [Availability](#Availability)

This property is available since [GeneXus 17 Upgrade 6](https://wiki.genexus.com/commwiki/wiki?48684,,).
