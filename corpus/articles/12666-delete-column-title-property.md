# Delete column title property

To enter the title to be displayed for the first column in the Transaction grids, which offers to delete a row.

### [Description](#Description)

Each row of a grid in a Transaction has a column with a control that offers to delete the row.

This property allows the developer to enter the title to be displayed for that column.

It is not used for Free-Style grids.
