# Dashboard Main color property

Main color for the filters and objects included in the Dashboard.

### [Scope](#Scope)

**Objects:** Dashboard

### [Description](#Description)

Defines the Main color of the control layout and associated dialogs for [widgets](https://wiki.genexus.com/commwiki/wiki?36779) in a [Dashboard object](https://wiki.genexus.com/commwiki/wiki?36769).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
