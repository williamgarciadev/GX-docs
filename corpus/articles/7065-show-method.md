# Show method

Shows the document on screen.

### [Syntax](#Syntax)

**&***VarBasedOnExtendedDataType***.Show()**  
  
**Type Returned:**   
Numeric

### [Scope](#Scope)

**Extended Data Types:** [ExcelDocument](https://wiki.genexus.com/commwiki/wiki?2476), [WordDocument](https://wiki.genexus.com/commwiki/wiki?2478,,)  
**Generators:**

[.NET](https://wiki.genexus.com/commwiki/wiki?38604), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892),
[Java](https://wiki.genexus.com/commwiki/wiki?12258), Ruby (up to GeneXus X Evolution 3), Visual FoxPro (up to GeneXus X Evolution 3)

**Note**: This method returns an error code, so it is possible to call it as a function (**&**Err **= &**DataType**.Show()**).
