# Work With for Smart Devices Pattern Nodes

When [appliyng the WWSD for a Transaction](https://wiki.genexus.com/commwiki/wiki?15975), the default instance of the Work with for Smart Devices is generated.

The Work With for Smart Devices associated with a transaction includes a tree showing the Level (<transactionName>) node, and within it:

* [Work With List Node](https://wiki.genexus.com/commwiki/wiki?15984)
* [Work With Detail Node](https://wiki.genexus.com/commwiki/wiki?15985)
