# StatusCode Property

Returns the status of the response.

### [Syntax](#Syntax)

***&**varBasedOnHttpClient****.*StatusCode**  
  
**Type Returned:**   
Numeric(X.0) where 4<X<=9

### [Description](#Description)

This property returns a number that indicates the status of the HTTP response.
