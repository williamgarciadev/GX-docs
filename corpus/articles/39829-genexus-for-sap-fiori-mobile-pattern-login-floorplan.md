# GeneXus for SAP Fiori Mobile Pattern - Login Floorplan

The Login [Floorplan](https://wiki.genexus.com/commwiki/wiki?38629,,) is a set of templates that allow you to include authentication on your app.

This article explains how to apply it to a [Panel object](https://wiki.genexus.com/commwiki/wiki?24829).

## [How to apply it](#How+to+apply+it)

If you have never applied the FioriMobile Pattern on your KB before, read [GeneXus for SAP Systems - Fiori Mobile Pattern](https://wiki.genexus.com/commwiki/wiki?39800).

Once you create a Panel, the following window showing a group of categories will be displayed. Each one of them offers different templates.

`[imagen omitida: wiki id 40326]`

If you select the Login category, three templates are shown and you can select one to be applied to the Panel:

**1.Login**

`[imagen omitida: wiki id 39831]`

**2. Login with logo**

`[imagen omitida: wiki id 39832]`

**3. Login with register**

`[imagen omitida: wiki id 39833]`

Another way to apply a category template to a Panel is the following: Open an existing Panel, right-click on its Layout and select **Apply FioriMobile template to control**:

`[imagen omitida: wiki id 39834]`

## [How to customize it](#How+to+customize+it)

In order to customize the action that will be executed when the Login button is pressed, you need to go to the Events section of your login panel and modify the login event.

`[imagen omitida: wiki id 39835]`

To modify the register user action, you need to modify the CreateUser.Tap event

## [How to incorporate it into your App](#How+to+incorporate+it+into+your+App)

To incorporate this into your app read [Genexus for SAP Fiori Mobile Pattern - Menu Floorplan](https://wiki.genexus.com/commwiki/wiki?39836)
