# GeneXus For SAP Systems - Split Screen Master List Floorplan

The Split Screen Master List [Floorplan](https://wiki.genexus.com/commwiki/wiki?38629,,) is a useful page that allows you to query, view, insert, update, and delete data. The data is shown in a Master List on the left side of the page, whose lines offer links to display more details. Those details are shown on the right side of the page.

`[imagen omitida: wiki id 54953]`

**Note**: The design guideline of this floorplan is at [SAP's documentation](https://experience.sap.com/fiori-design-web/master-list/).

## [How to apply it](#How+to+apply+it)

Look at the Patterns tab of the Country Transaction. If you have never applied the Fiori for Web pattern in your Knowledge Base, read this article: [HowTo: Apply the Fiori for Web pattern for the first time](https://wiki.genexus.com/commwiki/wiki?38862). Otherwise, being positioned on the Fiori for Web Pattern tab, check the Apply this pattern on save checkbox and select the offered link to choose a floorplan:

`[imagen omitida: wiki id 54852]`

then select the Split Screen Master List option from the list given by GeneXus:

`[imagen omitida: wiki id 54954]`

This floorplan can be applied to a [Transaction object](https://wiki.genexus.com/commwiki/wiki?1908) or a [Web Panel object](https://wiki.genexus.com/commwiki/wiki?6916).

## [How to customize it](#How+to+customize+it)

The following section explains how to customize your Split Screen Master List.

### [Add/Modify/Delete Actions](#Add%2FModify%2FDelete+Actions)

You can add, modify or delete actions being positioned on the Split Screen Master List tab.

To add actions, you have to right-click the Action Group node and then, select Add > UserAction in the contextual menu. The action will be added outside the grid (in the section where is located the button to insert).

`[imagen omitida: wiki id 54940]`

To modify these actions, you can right-click on the action node and select the 'Go to Event' option. Then, you can modify the event code, but remember to do it outside the code generated by GeneXus (to avoid being overwritten by GeneXus).

If you want to add an action inside the grid for every line, you have to right-click on the Free style grid node and select Add > UserAction in the contextual menu:

`[imagen omitida: wiki id 54941]`

In order to modify these actions, you have to follow the next steps:

1.Right-click on the Split Screen Master List tab and select Open YourObjectNameMasterList.

`[imagen omitida: wiki id 54942]`

**Note**: Temporarily the Web Panel's name is not WebPanelNameMasterList but it is WebPanelNameListReport.

2.Once in the Split Screen Master List Web Panel, go to the Events Section.

`[imagen omitida: wiki id 38901]`

3.While there, you only have to create the [click events](https://wiki.genexus.com/commwiki/wiki?8177) for your customized actions.

`[imagen omitida: wiki id 38902]`

You can also add actions to the Object page by going to the Split Screen Object Page tab.

Once there, you have to right-click the Action Group node, and select Add > UserAction in the contextual menu:

`[imagen omitida: wiki id 54943]`

<To program this action you can do it by right-clicking it and selecting 'Go to Event'.>

### [Manage Filters](#Manage+Filters)

You can manage the [Filters](https://wiki.genexus.com/commwiki/wiki?38588) being positioned on the Split Screen Master List tab.

To add filters, you have to right-click on the Table Main node and then select Add in the contextual menu and choose the kind of filter you want.

`[imagen omitida: wiki id 54944]`

For more information, see [GeneXus For SAP Filters](https://wiki.genexus.com/commwiki/wiki?38588).

### [Manage Orders](#Manage+Orders)

You can manage the Orders by positioning on the Split Screen Master List tab. Once there, you have to right-click on the TableMain node and then select Add > Orders.

`[imagen omitida: wiki id 54945]`

After having created the Orders node, you have to right-click on Orders and then choose Add > Order in order to add a new one.

`[imagen omitida: wiki id 54947]`

For each order you create, you have to complete its Name property:

`[imagen omitida: wiki id 54948]`

and you have to add the attribute(s) by which the list will be sorted:

`[imagen omitida: wiki id 54949]`

For each attribute, you can change the Ascending property to choose whether you want the list to be sorted in ascending or descending order considering that attribute(s) value(s).

`[imagen omitida: wiki id 54950]`

### [Customize the information to be shown in the list](#Customize+the+information+to+be+shown+in+the+list)

You can manage the attributes to show by positioning on the Split Screen Master List tab.

To prevent attributes from being shown on the Split Screen Master List, you have to right-click the attribute and select Delete. Don't worry, it will be deleted from the [Web Panel object](https://wiki.genexus.com/commwiki/wiki?6916), not from the [Transaction object](https://wiki.genexus.com/commwiki/wiki?1908).

`[imagen omitida: wiki id 54951]`

To add attributes to be shown in the list, you have to right-click the Free style grid node, then select Add > Attribute:

`[imagen omitida: wiki id 54952]`

Then, GeneXus will display a list of attributes for you to choose which ones you want to add.

`[imagen omitida: wiki id 38910]`

### [Other Functionalities](#Other+Functionalities)

There are other functionalities generated by GeneXus when you apply the floorplan.

#### [Save as Tile](#Save+as+Tile)

By clicking the Save as Tile button, you create a new tile for the Web Panel generated by GeneXus, with the Split Screen Master List Floorplan. It will always be at the beginning of the Launchpad, so as to have it at hand.
