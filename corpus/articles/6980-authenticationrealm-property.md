# AuthenticationRealm Property

Indicates the server authentication realm, if used.

### [Syntax](#Syntax)

**&***DataType***.AuthenticationRealm**  
  
**Type Returned:**   
Character

### [Description](#Description)

When you make a SOAP call using authentication, this property indicates which realm will be used.  
The default value is “”.

**Extended Data Types:** [Location](https://wiki.genexus.com/commwiki/wiki?6981)  
**Languages:** .NET, Java, Ruby (up to GeneXus X Evolution 3), Visual FoxPro (up to GeneXus X Evolution 3)
