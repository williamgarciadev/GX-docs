# Datastore property

Name of the Data Store associated with the Data View.

### [Description](#Description)

It is associated by selecting the corresponding [Data Stores](https://wiki.genexus.com/commwiki/wiki?7117) name from the combo box.

### [Scope](#Scope)

**Objects:** Data View  
**Platforms:** Web(.Net, Java)
