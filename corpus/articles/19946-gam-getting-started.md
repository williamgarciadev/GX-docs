# GAM - Getting Started

To start using [GeneXus Access Manager (GAM)](https://wiki.genexus.com/commwiki/wiki?24746) in your [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836), you just need to configure the [Enable Integrated Security property](https://wiki.genexus.com/commwiki/wiki?14706) to True at version level and Rebuild All.

A shortcut for enabling integrated security is offered in the main GeneXus menu: **Tools > GeneXus Access Manager > Enable Integrated Security**.

`[imagen omitida: wiki id 35485]`

### [What happens after Enabling Integrated Security?](#What+happens+after+Enabling+Integrated+Security%3F)

#### [**At Knowledge Base Level**](#At+Knowledge+Base+Level)

See [GAM repository creation for the first time from GeneXus](https://wiki.genexus.com/commwiki/wiki?29701).

#### [**At Application Level**](#At+Application+Level)

#### [1. **Automatic Access Control**](#+1.+Automatic+Access+Control)

* Automatic access control in each object where the [Integrated Security Level property](https://wiki.genexus.com/commwiki/wiki?15214) = Authentication or Authorization.

#### [2. **Automatic Application Flow**](#+2.+Automatic+Application+Flow)

* Automatic flow of the application after access control. Before executing any object the generated code validates if the session is valid; if not, the [Login Object for Web](https://wiki.genexus.com/commwiki/wiki?15590) or [Login Object for SD](https://wiki.genexus.com/commwiki/wiki?16589) executes and after validating the session it returns automatically to the object where the invalid session exception had been thrown.

#### [3. **Permission Checks on Startup**](#+3.+Permission+Checks+on+Startup)

* Automatic check of permissions on startup if [Integrated Security Level property](https://wiki.genexus.com/commwiki/wiki?15214) = Authorization.

**Note**: [GAM - Examples](https://wiki.genexus.com/commwiki/wiki?21993) are consolidated in the KB if the user decides to do so, during [GAM - Activation Process](https://wiki.genexus.com/commwiki/wiki?21973).
