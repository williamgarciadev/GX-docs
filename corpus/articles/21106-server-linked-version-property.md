# Server Linked Version property

This property is defined when the [Send Knowledge Base to GeneXus Server](https://wiki.genexus.com/commwiki/wiki?10215) or the [Knowledge Base from GXserver](https://wiki.genexus.com/commwiki/wiki?10625,,) actions are performed. It defines the version to which the local [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836) is connected to in the [GeneXus Server](https://wiki.genexus.com/commwiki/wiki?9911).
