# Show rows per page property

Enables or disables a selector showing the number of rows per page.

### [Values](#Values)

|  |
| --- |
| **False** |
| **True** |

### [Scope](#Scope)

**Objects:** Query

### [Description](#Description)

Enables or disables a selector showing the number of rows per page when using a Table or Pivot Table [QueryViewer control](https://wiki.genexus.com/commwiki/wiki?9075).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
