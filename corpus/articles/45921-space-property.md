# Space property

Space defined for the IBM Cloud organization.

### [Scope](#Scope)

**Level:** Deploy Target Options

### [Description](#Description)

To deploy to IBM cloud, using the [Application Deployment tool](https://wiki.genexus.com/commwiki/wiki?32092), you have to configure the Space property at the deployment target, among other properties such as [User](https://wiki.genexus.com/commwiki/wiki?45930), [Password](https://wiki.genexus.com/commwiki/wiki?45931), [Organization](https://wiki.genexus.com/commwiki/wiki?45920), and [Application](https://wiki.genexus.com/commwiki/wiki?45922).
