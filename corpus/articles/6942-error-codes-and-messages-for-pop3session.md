# Error Codes and Messages for POP3Session

|  |  |
| --- | --- |
| **Code** | **Message** |
| 0 | Ok |
| 1 | Already logged in |
| 2 | Not logged in |
| 3 | Can't connect to host |
| 6 | Invalid sender name |
| 7 | Invalid sender address |
| 8 | Invalid user name |
| 9 | Invalid password |
| 10 | Could not send message |
| 11 | No messages to receive |
| 12 | Could not delete message |
| 13 | No main recipient specified |
| 14 | Invalid recipient |
| 15 | Invalid attachment |
| 16 | Could not save attachment |
| 17 | Invalid Authentication value |
| 18 | Not enough memory |
| 19 | Connection lost |
| 20 | Timeout exceeded |
| 21 | Memory allocation error |
| 23 | The server does not recognize any of the supported authentication methods |
| 24 | Authentication error |
| 25 | User or password refused |
| 26 | No current message |
| 27 | Invalid NewMessages value |
| 29 | POP3 server does not support NewMessages = 1 |
| 30 | POP3 server does not support GetNextUID |
| 50 | Server reply was invalid |
| 51 | Server replied with an error |
