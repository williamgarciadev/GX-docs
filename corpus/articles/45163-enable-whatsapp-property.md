# Enable WhatsApp property

Enables WhatsApp Integration.

### [Scope](#Scope)

**Objects:** [Conversational Flows Instance](https://wiki.genexus.com/commwiki/wiki?37113)

### [Description](#Description)

If this property is set to TRUE, the Chatbot will be integrated into WhatsApp, which means that the necessary objects (Chatbot resources) to implement the integration will be imported into the Knowledge Base.

`[imagen omitida: wiki id 45162]`

You have to configure the [WhatsApp Partner property](https://wiki.genexus.com/commwiki/wiki?45164) to give more information to GeneXus to generate the objects for the integration.

If [WhatsApp Partner property](https://wiki.genexus.com/commwiki/wiki?45164) and the Token (i.e.: [Twilio Token property](https://wiki.genexus.com/commwiki/wiki?45166) or [Botmaker Token property](https://wiki.genexus.com/commwiki/wiki?45993)) are configured, the webhook to Twilio is automatically created. It's generated under the instance's module, and its name is WhatsappWebhook.

### [Availability](#Availability)

This property is available since [GeneXus 16 upgrade 10](https://wiki.genexus.com/commwiki/wiki?45624,,).
