# Maps external object (GeneXus 18 Upgrade 3)

This API enables you to provide several Location Services on Native Mobile applications by interacting with the GPS on the devices where the apps are running.

It contains some Properties, Methods (such as [CalculateDirections method](https://wiki.genexus.com/commwiki/wiki?46643)), Events, and Structured Data Types.

`[imagen omitida: wiki id 44311]`

**Notes:**

* Some of the methods are available for Web [Environments](https://wiki.genexus.com/commwiki/wiki?7115) as well.

* Many of the methods and properties provided by this external object are similar to those provided by the [Geolocation external object](https://wiki.genexus.com/commwiki/wiki?31274). The difference lies in the use of the [Geography data type](https://wiki.genexus.com/commwiki/wiki?32408) (in Maps external object) instead of the [Geolocation domain](https://wiki.genexus.com/commwiki/wiki?14644) (in Geolocation external object) to represent geographic coordinates.
