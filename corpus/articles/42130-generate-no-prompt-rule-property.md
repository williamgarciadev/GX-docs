# Generate No Prompt Rule property

Indicates if NoPrompt rule for primary key will be generated in this transaction.

### [Values](#Values)

|  |  |
| --- | --- |
| **<default>** | The default value (default) is inherited from the property in Pattern settings. |
| **false** |
| **true** |

### [Description](#Description)

It allows, for each transaction in the Pattern instance, to choose whether or not to generate the NoPrompt rule.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply changes made by this property, do a Re-Build All.

### [Scope](#Scope)

**Objects:** Work With for Web  
**Platforms:** Web(.Net, .Net Core, Java)
