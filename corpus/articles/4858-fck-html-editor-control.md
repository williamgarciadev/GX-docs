# FCK HTML Editor Control

Allows you to add an [HTML Editor](https://wiki.genexus.com/commwiki/wiki?4657,,) in your web applications. You need to define a Character/Varchar/Longvarchar Attribute or Variable and change the associated [Control Type property](https://wiki.genexus.com/commwiki/wiki?9550).

|  |  |
| --- | --- |
| **Skins** | Style options at control level:  * Default * Silver * Office 2003 |
| **Toolbar** | Available toolbars at control level:  * Default * Basic * Custom * None |
| [**CustomToolbar**](https://wiki.genexus.com/commwiki/wiki?35457,,) | Add your own toolbars. |
| [**Custom Configuration**](https://wiki.genexus.com/commwiki/wiki?27961,,) | Custom configuration needed for your default toolbars. Check the [can3](https://wiki.genexus.com/commwiki/wiki?3232,,) site for a Custom Toolbar implementation.  The editor configuration parameters can be checked [here](http://docs.cksource.com/ckeditor_api/symbols/CKEDITOR.config.html). |
| **Width** | Control width. |
| **Height** | Control height. |

### [Availability](#Availability)

iPad support has been added as from GeneXus X Evolution 2 Upgrade 3.

### [Scope](#Scope)

**Objects:**[Attribute](https://wiki.genexus.com/commwiki/wiki?6802)s/[Variable](https://wiki.genexus.com/commwiki/wiki?7375)s ([LongVarChar data type](https://wiki.genexus.com/commwiki/wiki?7371) and [VarChar data type](https://wiki.genexus.com/commwiki/wiki?6778))
