# SizeAttribute property

The attribute or variable indicating the size of the square item in an SD Image Map control

### [Description](#Description)

Indicates the size of the square item in an SD Image Map control (blue)

`[imagen omitida: wiki id 42481]`

As of [GeneXus 16 Upgrade 3](https://wiki.genexus.com/commwiki/wiki?42129,,), the property use is replaced for [Height Attribute property](https://wiki.genexus.com/commwiki/wiki?42199) and [Width Attribute property](https://wiki.genexus.com/commwiki/wiki?42197), allowing to specify squares and rectangles as items.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply changes made by this property, do a Build with this Only of the object.

### [Scope](#Scope)

**Objects:** Panel for Smart Devices, Work With for Smart Devices  
**Platforms:** Smart Devices(Android, IOS)  
**Controls:** Grid
