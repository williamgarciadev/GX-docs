# HowTo: Add an object to a Module

This document explains how to add an object to a Module and provides a brief overview about it.

There are many ways of adding [GeneXus objects](https://wiki.genexus.com/commwiki/wiki?1866) to a [Module object](https://wiki.genexus.com/commwiki/wiki?22411). Below is a list of the most common and easiest ways to do so. To see a list of which objects can belong to a [Module object](https://wiki.genexus.com/commwiki/wiki?22411), read the article [Which objects can be defined in a module?](https://wiki.genexus.com/commwiki/wiki?23850).

### [New Object](#New+Object)

A new Object can be added to a Module Object by editing the *Module/Folder* option in the GeneXus Objects dialog. By default, this property will have its value set to the [Root module](https://wiki.genexus.com/commwiki/wiki?22439), but if the dialog is opened and a different Module Object is selected in the [KB Explorer](https://wiki.genexus.com/commwiki/wiki?3210), the property will be automatically set to the selected Module Object.

### [Existing object](#Existing+object)

An existing object can be added/moved to a Module by:

* Selecting the Object and editing the [Module/Folder property](https://wiki.genexus.com/commwiki/wiki?25540) of the Object.
* Using the [KB Explorer](https://wiki.genexus.com/commwiki/wiki?3210), just drag and drop the object in the desired Module.

**Note**: Once an object is moved to or created in a Module, it will be part of its [Interface](https://wiki.genexus.com/commwiki/wiki?23935) if the [Object Visibility property](https://wiki.genexus.com/commwiki/wiki?22473) is set to Public.
