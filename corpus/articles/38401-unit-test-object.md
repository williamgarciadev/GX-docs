# Unit Test object

Defines a Unit or Integration Test on programs with business logic like [Business Components](https://wiki.genexus.com/commwiki/wiki?5846), [Data Providers](https://wiki.genexus.com/commwiki/wiki?5270), and [Procedures](https://wiki.genexus.com/commwiki/wiki?6293).

You can run the defined tests using the GeneXus IDE or automatically on different environments when using CI/CD capabilities.

You have two ways to create a Unit Test object:

1) In the same way that you [create any GeneXus object](https://wiki.genexus.com/commwiki/wiki?9931).

2) In the [KB Explorer](https://wiki.genexus.com/commwiki/wiki?3210) you can right-click on the desired Procedure, Data Provider or Business Component and select in the contextual menu: **Create Unit Test**.

More information at [Unit Testing](https://wiki.genexus.com/commwiki/wiki?38334).
