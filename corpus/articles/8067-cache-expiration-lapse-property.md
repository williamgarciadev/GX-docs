# Cache expiration lapse property

To allow the page to be stored in the client for a specific period of time.

### [Description](#Description)

#### [Values](#Values)

Any natural value, specified in seconds. Zero (0) is the default value.

### [Scope](#Scope)

**Objects:** Web Panel  
**Platforms:** Web(.Net, Java)
