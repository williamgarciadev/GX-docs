# Deploying Java applications with Spring Boot (GeneXus 18 Upgrade 10)

Java applications developed using Spring Boot are deployed using the GeneXus Deploy Engine, just like other applications. Currently, local implementation is supported.

## [Deployment Unit Behavior](#Deployment+Unit+Behavior)

The deployment process for Deployment Units containing web applications or services behaves as follows:

#### [**[Package Type property](https://wiki.genexus.com/commwiki/wiki?53373) = Sources**](#com.gxwiki.wiki%3F53373%2CPackage%2BType%2Bproperty+Package+Type+property+%3D+Sources)

* The Deploy Engine creates a package containing the source code and all necessary files to build the application.
* You need to build the application manually by navigating to the folder created by the Deploy Engine and running the following command:

  ```
  gradlew build -Pdeploy -Dorg.gradle.java.home=<JAVA_HOME>-Dorg.gradle.jvmargs=-Xmx1024m
  ```
* **Important:** Ensure that <JAVA\_HOME> points to a Java version 17 or higher.
* The -Pdeploy option ensures that only the required dependencies are included in the package.
* Dependencies are determined from the gradle.properties file, which is generated by the Deploy Engine based on the model, [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836), and objects included in the [Deployment Unit object](https://wiki.genexus.com/commwiki/wiki?38886).

**Package Type property= Binaries**

* Similar to "Sources" value, a package containing source code and required files is created.
* The Deploy Engine automatically builds the application JAR file.
* The JAR file is placed in a parallel folder to the source code, with the same name but suffixed with "\_".

### [Notes](#Notes)

* In the GeneXus IDE, when selecting the Deploy Target for a Spring Boot application, the Application Server combo box is not available. This is because the package includes an embedded Tomcat server, and specifying the Application Server version is not necessary.
* You cannot directly enter the application's Display Name. You can configure this by following the documentation guidelines, such as the one found here: <https://www.baeldung.com/spring-boot-context-path>
* The Spring Boot framework is not considered in any way for command line applications in GeneXus. So, deployment units containing only command-line [Procedure object](https://wiki.genexus.com/commwiki/wiki?6293) behave in the same way as non-Spring Boot applications. A JAR file is created and executed as usual.

## [Msbuild Tasks](#Msbuild+Tasks)

To deploy using MSBuild tasks, see [Packaging Java sources](https://wiki.genexus.com/commwiki/wiki?54656).

Note that the createdeploy task for Spring Boot applications does not require specifying the Application Server. This information is only relevant for non-Spring Boot applications.

**Note**: It's mandatory to pass DEPLOY\_TYPE property to the createdeploy task. It can be either "Sources" or "Binaries".

### [Automatic JAR  Creation](#Automatic+JAR+Creation)

To automatically create the JAR file, you need to set DEPLOY\_TYPE=Binaries. You must pass the DEPLOY\_TYPE parameter when running the createdeploy task.

#### [Example createdeploy command:](#Example+createdeploy+command%3A)

```
C:\Windows\Microsoft.NET\Framework\v4.0.30319\MSBuild.exe /noconsolelogger /nologo /logger:DeployLogger,"C:\fullgx\gx\GeneXus.Deploy.MSBuild.Tasks.dll" /verbosity:quiet /ToolsVersion:4.0 "C:\fullgx\gx\deploy.msbuild" /p:KBPath="c:\fullgx\kb" 
/p:KBEnvironment="Java Environment" 
/p:KBVersion="kb" 
/p:DeploymentUnit="DeploymentUnit1" 
/p:ProjectName="DeploymentUnit1_20240509193009" 
/p:TargetId="LOCAL" 
/p:ObjectNames="WebPanel:WebPanel1" 
/p:EXTRA_MSBUILD="C:\fullgx\gx\ApplicationServers\Templates\JavaWeb\msbuild\TomcatContextSettings.msbuild" /p:DeployFullPath="c:\fullgx\kb\JavaModel\Deploy\LOCAL\DeploymentUnit1\20240509193009" 
/p:WebSourcePath="c:\fullgx\kb\JavaModel\web" 
/p:GX_PROGRAM_DIR="C:\fullgx\gx" 
/p:USE_APPSERVER_DATASOURCE="False" 
/p:GENERATE_OPEN_API_INTERFACE="False" 
/p:DEPLOY_TYPE="BINARIES" 
/p:APPLICATION_KEY="MY_KEY" 
/p:INCLUDE_GAM="False" 
/p:INCLUDE_GXFLOW_BACKOFFICE="True" 
/p:APP_UPDATE="NONE" 
/p:ENABLE_KBN="False" 
/p:TARGET_JRE="9" 
/p:PACKAGE_FORMAT="Automatic" 
/p:TimeStamp="20240509193009" 
/p:AppName="GenexusWebApp" /t:CreateDeploy
```

### [Availability](#Availability)

This feature is available since [GeneXus 18 Upgrade 10](https://wiki.genexus.com/commwiki/wiki?54244).
