# Filter data type property

Filter's data type.

### [Description](#Description)

[Dashboard](https://wiki.genexus.com/commwiki/wiki?36769) filter possible data types are:

* Numeric (without decimals)
* Numeric (with decimals)
* Character
* Boolean
* Date
* DateTime

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
