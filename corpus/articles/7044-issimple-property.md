# IsSimple Property

Indicates whether the current node obtained through the Read or ReadType method is simple.

### [Syntax](#Syntax)

**&***DataType***.IsSimple**  
  
**Type Returned:**   
Boolean

### [Description](#Description)

Indicates whether the current node, obtained through the Read or ReadType method, corresponds to an Element Value /Element type structure.

### [Scope](#Scope)

**Extended Data Types:** [XmlReader](https://wiki.genexus.com/commwiki/wiki?6928)  
**Languages:** .NET, Java, Visual FoxPro (up to GeneXus X Evolution 3), Ruby(up to GeneXus X Evolution 3)
