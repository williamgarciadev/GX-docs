# Filter picture property

Filter's picture.

### [Scope](#Scope)

**Objects:** Dashboard

### [Description](#Description)

Sets the desired format to accept and display a [Dashboard](https://wiki.genexus.com/commwiki/wiki?36769) filter's value.

### [Runtime/Design time](#Runtime%2FDesign+time)
