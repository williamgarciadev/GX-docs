# Preview Object property

Indicates an application that shows the user basic data about a Task before the user takes it.

### [Scope](#Scope)

**Controls:** [Task](https://wiki.genexus.com/commwiki/wiki?17495)

### [Description](#Description)

It applies only when using the GXflow Client for Native Mobile applications.

When this property is used, the user views information about the Task but doesn't take it. This information will help users to decide whether they can perform the Task.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [Availability](#Availability)

This property is available since [GeneXus 17 upgrade 7](https://wiki.genexus.com/commwiki/wiki?49301,,).
