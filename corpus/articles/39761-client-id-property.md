# Client Id property

Specify the Client Id for Google Cloud Services (Dialogflow service).

### [Scope](#Scope)

**Objects:** Conversational Flows

### [Description](#Description)

After doing the necessary [DialogFlow setup](https://wiki.genexus.com/commwiki/wiki?39749) to use it as a provider for your chatbot, you'll have a pair of Client Id and [Client Secret](https://wiki.genexus.com/commwiki/wiki?39762) values. Enter your Client Id in this property.

### [Availability](#Availability)

This property is available since [GeneXus 15 upgrade 12](https://wiki.genexus.com/commwiki/wiki?39737,,).
