# Application Id property (WeChat Pay)

Application ID obtained when registering your application in WeChat Open Platform, to be used for WeChat Pay integration.

### [Scope](#Scope)

**Objects:** [Menu](https://wiki.genexus.com/commwiki/wiki?16321), [Panel](https://wiki.genexus.com/commwiki/wiki?24829), [Work With](https://wiki.genexus.com/commwiki/wiki?15974) (Only [Main Objects](https://wiki.genexus.com/commwiki/wiki?5770))  
**Generators:** [Apple](https://wiki.genexus.com/commwiki/wiki?14917)

### [Description](#Description)

When WeChat Pay integration is required, a [registration process](https://wiki.genexus.com/commwiki/wiki?37323,,) need to be followed for the application.

In this process, an identifier is created for the application, which value has to be set in this property.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
