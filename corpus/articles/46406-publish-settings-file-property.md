# Publish Settings File property

Publishes the Settings File given by Azure Portal.

### [Scope](#Scope)

**Level:** Deploy Target Options

### [Description](#Description)

In the Publish Settings File property, you should enter the file with .PublishSettings extension given by Azure after configuring a web app.
