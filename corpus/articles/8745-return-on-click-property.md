# Return On Click property

Indicates the control that will cause a Return within a prompt and will assign the selected value to the foreign key.

### [Values](#Values)

|  |
| --- |
| **False** |
| **True** |

### [Scope](#Scope)

**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [Java](https://wiki.genexus.com/commwiki/wiki?12258)  
**Controls:** Attribute/Variable, [Image](https://wiki.genexus.com/commwiki/wiki?5939), [Text Block](https://wiki.genexus.com/commwiki/wiki?5948)

### [Description](#Description)

This property is only available for [Transaction Web Layout](https://wiki.genexus.com/commwiki/wiki?8057) or [Web Panel Web Layout](https://wiki.genexus.com/commwiki/wiki?8132) Attribute/Variable, [Text Block](https://wiki.genexus.com/commwiki/wiki?5948), and [Image](https://wiki.genexus.com/commwiki/wiki?5939) controls.

To enable the Return on click property, the Attribute/Variable must be set as Read Only.

When the property is set to True, the control triggers the return, and the value is assigned to the parameters returned by the prompt.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
