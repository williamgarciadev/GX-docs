# Filter control values property

List of possible values for the filter's control.

### [Scope](#Scope)

**Objects:** Dashboard

### [Description](#Description)

Sets a list of possible values for a non-dynamic filter's control. It applies to a:

* Value type filter displayed as a Radio button or Checkbox.
* Collection type filter displayed as a Checkbox or Drop-down list.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
