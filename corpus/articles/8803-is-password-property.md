# Is Password property

Displays asterisks (\*) or black circles, depending on the browser or platform, instead of what the user typed.
This property is not available when the attribute is a formula and applies only at execution time.

### [Syntax](#Syntax)

**control.** IsPassword   

Type returned: Boolean

### [Values](#Values)

|  |
| --- |
| **False** |
| **True** |

### [Scope](#Scope)

**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917), [Java](https://wiki.genexus.com/commwiki/wiki?12258)  
**Controls:** Attribute/Variable (Control Type: Edit)

### [Description](#Description)

Applies to Attribute/Variable controls defined in a [Panel object](https://wiki.genexus.com/commwiki/wiki?24829), [Transaction object](https://wiki.genexus.com/commwiki/wiki?1908), [Web Panel object](https://wiki.genexus.com/commwiki/wiki?6916), [Menu object](https://wiki.genexus.com/commwiki/wiki?16321) or [WW](https://wiki.genexus.com/commwiki/wiki?15974) whose [Control Type](https://wiki.genexus.com/commwiki/wiki?9550) = Edit.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at runtime.
