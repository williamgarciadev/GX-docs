# Form Template property

Specifies the template used to generate the default form for Web Panels generated by the pattern.

### [Values](#Values)

|  |  |
| --- | --- |
| **<default>** | Takes the value defined in the Form Layout property of the Transaction. |
| **Carmine Template** | Selects the default template associated with the Carmine style. |
| **Fiori Template** | Selects the default template associated with the Fiori style. |
| **Flat Template** | Selects the default template associated with the Flat style. |
| **Unanimo Template** | Selects the default template associated with the Unanimo style. |

### [Scope](#Scope)

**Objects:** [Work With for Web](https://wiki.genexus.com/commwiki/wiki?25475)

### [Description](#Description)

This property is available at [KB Explorer](https://wiki.genexus.com/commwiki/wiki?3210) > Preferences > Patterns > Work With for Web > Template node:

`[imagen omitida: wiki id 52380]`

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, execute a [Rebuild All](https://wiki.genexus.com/commwiki/wiki?5691).
