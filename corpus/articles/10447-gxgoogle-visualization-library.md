# GXGoogle Visualization Library

GXGoogle Visualization Library, based on [Google Visualization API](https://developers.google.com/chart/interactive/docs/reference), expands the capabilities of data visualization using the GeneXus way.

Now you can choose between several ways of showing your data including standard pie, intensity maps and motion charts.

This is the list of available controls that you can use just dragging them in your form:

* [Motion Chart](https://wiki.genexus.com/commwiki/wiki?10651)
* [Intensity Map](https://wiki.genexus.com/commwiki/wiki?10648)
* [Gauge](https://wiki.genexus.com/commwiki/wiki?9896)
* [Table](https://wiki.genexus.com/commwiki/wiki?10448,,)
* [Map](https://wiki.genexus.com/commwiki/wiki?5029)
* [Organizational Chart](https://wiki.genexus.com/commwiki/wiki?10621)
* [Annotated Time Line](https://wiki.genexus.com/commwiki/wiki?10617)
* [Gadget](https://wiki.genexus.com/commwiki/wiki?7834)
* [Charts](https://wiki.genexus.com/commwiki/wiki?10449)
  + [Bar](https://wiki.genexus.com/commwiki/wiki?10454)
  + [Line](https://wiki.genexus.com/commwiki/wiki?10455,,)
  + [Pie](https://wiki.genexus.com/commwiki/wiki?10456)
  + [Column](https://wiki.genexus.com/commwiki/wiki?10450)
  + [Scatter](https://wiki.genexus.com/commwiki/wiki?10457)
* [Feed Viewer](https://wiki.genexus.com/commwiki/wiki?10614,,)
* [Analytics](https://wiki.genexus.com/commwiki/wiki?11847)

### [IMPORTANT NOTE:](#IMPORTANT+NOTE%3A)

As of GeneXus X Evolution 1 Beta 2 Build# 21802, the folder structure of GXGoogleVisualizationLibrary was changed. Now you will have a single folder named GXGoogleVisualizationLibrary under %GXEv1InstallationFolder%\UserControls containing all the controls inside. If you already have this library installed, please be sure to delete the single folder of each control under %GXEv1InstallationFolder%\UserControls before building your application in order to avoid duplicated controls.
