# SD Label Horizontal Alignment property

Determine the horizontal Alignment of the Label.

### [Values](#Values)

|  |  |
| --- | --- |
| **Center** | Center the text. |
| **Default** | For both platforms, the value is Left. |
| **Justify** | Justify text. |
| **Left** | Align text to the left. |
| **Right** | Align text to the right. |

### [Description](#Description)

Text alignment determines the appearance of the text in a paragraph. If the paragraph is left-aligned, the text will be aligned to the left margin. If the paragraph is justified, the text will be aligned to both margins.

**Note:**

Justify is available as of [GeneXus 16 upgrade 8](https://wiki.genexus.com/commwiki/wiki?44913,,).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply changes made by this property, do a Build All.

### [Availability](#Availability)

This property is available since [GeneXus 15](https://wiki.genexus.com/commwiki/wiki?27605,,).
