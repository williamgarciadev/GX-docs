# Object Editors

[GeneXus objects](https://wiki.genexus.com/commwiki/wiki?1866) are composed of parts. Each part is edited through a specific selector, using a specific editor.

When an object is opened or created, the section on the far left (according to the order the selectors are shown) is opened.

For example, when a Transaction is opened, the Structure part is first edited:  
  
`[imagen omitida: wiki id 51309]`  
  
There are several kinds of editors to be used in different parts. Some of them are:

* The [Structure Editor](https://wiki.genexus.com/commwiki/wiki?3913)
* The [Variables Editor](https://wiki.genexus.com/commwiki/wiki?3173)
* The [Properties Editor](https://wiki.genexus.com/commwiki/wiki?3160)
* The [Source Code Editor](https://wiki.genexus.com/commwiki/wiki?3914)

You can navigate through the different parts using the keyboard shortcuts CTRL+PgUp/PgDn:
