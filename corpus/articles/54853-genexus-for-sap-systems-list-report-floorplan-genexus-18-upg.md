# GeneXus For SAP Systems List Report Floorplan (GeneXus 18 Upgrade 3 or prior)

The List Report [Floorplan](https://wiki.genexus.com/commwiki/wiki?38629,,) is a set of layouts that allows you to query, view, insert, update, and delete data.

This article describes how to apply it to a [Transaction object](https://wiki.genexus.com/commwiki/wiki?1908) or [Web Panel object](https://wiki.genexus.com/commwiki/wiki?6916) and how to customize it to obtain a page like the following:

`[imagen omitida: wiki id 53250]`

**Note**: The design guideline of this floorplan is at [SAP's documentation](https://experience.sap.com/fiori-design-web/list-report-floorplan-sap-fiori-element/).

### [How to apply it](#How+to+apply+it)

Look at the Patterns tab of the Country Transaction. If you have never applied the Fiori for Web pattern in your Knowledge Base before. For more information, read this article: [HowTo: Apply the Fiori for Web pattern for the first time](https://wiki.genexus.com/commwiki/wiki?38862). Otherwise, by positioning on the Fiori for Web Pattern tab, check the Apply this pattern on save checkbox and select the offered link to choose a floorplan:

`[imagen omitida: wiki id 54852]`

You can choose the List Report floorplan from several offered floorplans:

`[imagen omitida: wiki id 53251]`

When it is applied to a Transaction, everything is analogous to when it is applied to the traditional Work With GeneXus (but with more power), automatically creating all the necessary objects and functionalities.

[Learn how to apply it to a Web Panel](https://wiki.genexus.com/commwiki/wiki?42011).

### [How to customize it](#How+to+customize+it)

The following section explains how to customize your List Report.

### [Add/Modify/Delete Actions](#Add%2FModify%2FDelete+Actions)

You can add, modify or delete actions by positioning on the List Report tab.

`[imagen omitida: wiki id 53252]`

To add actions, right-click on the GridActions node and then select Add > UserAction from the contextual menu. The action will be added outside the grid (in the section where is located the button to insert).

To modify these actions, right-click on the action node and select the 'Go to Event' option. Then, you can modify the event code, but remember to do it outside the code generated by GeneXus (to avoid being overwritten by GeneXus).

If you want to add an action inside the grid for every line, right-click on the Grid node and select Add > UserAction from the contextual menu:

`[imagen omitida: wiki id 53253]`

To show this action as an image in the grid, set the Control type = image and also set the Name and Icon Unicode properties:

`[imagen omitida: wiki id 53254]`

In order to modify these actions, you have to follow the next steps:

1. Right-click on the List Report tab and select Open YourObjectNameListReport. `[imagen omitida: wiki id 53255]`

2. Being in the List Report Web Panel, go to the Events Section.

3. Once there, you only have to create the [click events](https://wiki.genexus.com/commwiki/wiki?8177) for your customized actions.

`[imagen omitida: wiki id 38655]`

### [Manage Filters](#Manage+Filters)

You can manage the [Filters](https://wiki.genexus.com/commwiki/wiki?38588) by positioning on the List Report tab.

To add filters, right-click on the Header Content node. In the contextual menu, select: Add, and then select the kind of filter you want.

`[imagen omitida: wiki id 53259]`

For more information, see [GeneXus For SAP Filters](https://wiki.genexus.com/commwiki/wiki?38588).

### [Manage Orders](#Manage+Orders)

You can manage the Orders by positioning on the List Report tab. Once there, right-click on the Header Content node and then select Add > Orders.

`[imagen omitida: wiki id 53260]`

After having created the Orders node, right-click on Orders and then choose Add > Order in order to add a new one.

`[imagen omitida: wiki id 53261]`

For each order you create, you have to complete its Name property, and you have to add the attribute(s) by which the list will be sorted:

`[imagen omitida: wiki id 53262]`

For each attribute, you can change the Ascending property to choose whether you want the list to be sorted in ascending or descending order considering that attribute(s) value(s).

`[imagen omitida: wiki id 53263]`

### [Customize the information to be shown in the list](#Customize+the+information+to+be+shown+in+the+list)

You can manage which attributes to show by positioning on the List Report tab.

To prevent attributes from being shown on the list report, right-click on the attribute and select Delete. Don't worry, it will be deleted from the Web Panel, not from the Transaction.

`[imagen omitida: wiki id 53264]`

To add attributes to be shown in the list, right-click on the Grid node, then select Add > GridAttribute:

`[imagen omitida: wiki id 53265]`

Then, GeneXus will display a list of attributes for you to choose which ones you want to add.

`[imagen omitida: wiki id 53266]`

### [Other Functionalities](#Other+Functionalities)

There are other functionalities generated by GeneXus when you apply the floorplan.

* Pin the Header
  + By clicking on the pin button, you prevent the header from collapsing when you scroll.
* Save as Tile
  + By clicking on the Save as Tile button, you create a new tile for the Web Panel generated by GeneXus with the List Report Floorplan. It will always be at the beginning of the Launchpad, so as to have it at hand.
