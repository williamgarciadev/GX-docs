# Public Key property (Mercado Pago)

Public key given by Mercado Pago to collect the credit/debit card info and tokenize it from your mobile application.

### [Description](#Description)

Note: By default the [Menu object](https://wiki.genexus.com/commwiki/wiki?16321) has its [Main program property](https://wiki.genexus.com/commwiki/wiki?7407) set to True, so in this object, you will see the **Public Key property** directly. But for a [Panel object](https://wiki.genexus.com/commwiki/wiki?24829) or a [Work With pattern and Work With object](https://wiki.genexus.com/commwiki/wiki?15974) first, you must set their [Main program property](https://wiki.genexus.com/commwiki/wiki?7407) to True and after that, you will see the **Public Key property**.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Availability](#Availability)

This property is available since [GeneXus 16 upgrade 7](https://wiki.genexus.com/commwiki/wiki?44454,,).

### [Scope](#Scope)

**Objects:** [Menu for Smart Devices](https://wiki.genexus.com/commwiki/wiki?16321), [Panel for Smart Devices](https://wiki.genexus.com/commwiki/wiki?24829), [Work With for Smart Devices](https://wiki.genexus.com/commwiki/wiki?15974)  
**Platforms:** Smart Devices(Android, IOS)
