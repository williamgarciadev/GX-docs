# Preview Application property

Indicates the application that shows the user the basic data to decide if he must take a task.

### [Scope](#Scope)

**Objects:** [Business Process Diagram](https://wiki.genexus.com/commwiki/wiki?16486)  
**Controls:** [Task](https://wiki.genexus.com/commwiki/wiki?17495)

### [Description](#Description)

This property allows you to define the behavior of a[Tasks](https://wiki.genexus.com/commwiki/wiki?17495) in a [Business Process Diagram](https://wiki.genexus.com/commwiki/wiki?16486).

The user visualizes the task but does not take it.

It is for Web objects.
