# Indentchar Property

This property defines the character that is used to indent the code generated.

### [Syntax](#Syntax)

**&***DataType***.Indentchar**

### [Description](#Description)

Defines the character used for indenting the code generated.  
The default value is a blank space.

### [Scope](#Scope)

**Extended Data Types:** [XmlWriter](https://wiki.genexus.com/commwiki/wiki?6938)  
**Languages:** .NET, Java, Ruby (up to GeneXus X Evolution 3), Visual FoxPro (up to GeneXus X Evolution 3)
