# Input Not Understood Messages property

Messages to send if the chatbot does not understand the user’s input. You can type multiple messages using the ‘;’ delimiter, and reference any context parameter using the '&' character.

### [Scope](#Scope)

**Objects:** Conversational Flows

### [Description](#Description)

When the the user input isn't recognized by the [AI](https://en.wikipedia.org/wiki/Artificial_intelligence), display this message to the end user.

`[imagen omitida: wiki id 39223]`

The message can include context parameters.  
  
See [HowTo: Reference context parameters in a conversation](https://wiki.genexus.com/commwiki/wiki?38942) for more information.

### [Availability](#Availability)

This property is available since [GeneXus 15 upgrade 12](https://wiki.genexus.com/commwiki/wiki?39737,,).
