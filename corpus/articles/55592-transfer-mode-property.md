# Transfer Mode property

Indicates the way used to transfer the generated program to the iSeries for its compilation.

### [Values](#Values)

|  |  |
| --- | --- |
| **FTP over TCP/IP** | Uses FTP over TCP/IP protocol. This is the default value. |
| **Client/Access Native** | Uses a Client/Access Native way. |
| **Secure FTP** | Uses a Secure FTP protocol. |

### [Scope](#Scope)

Available at the Data Store.  
**Data Store:** iSeries  
**Generators:** Cobol, RPG  
**Level:** Generator

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
