# Enable Telegram property

Enables integration with Telegram.

### [Scope](#Scope)

**Objects:** [Conversational Flows Instance](https://wiki.genexus.com/commwiki/wiki?37113)

### [Description](#Description)

When this property is set to True, the chatbot is integrated with Telegram, and the [Telegram Bot Token property](https://wiki.genexus.com/commwiki/wiki?48120) is offered. The objects necessary (Chatbot resources) will be imported into the [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836) for the implementation.

`[imagen omitida: wiki id 48192]`

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [Availability](#Availability)

This property is available since [GeneXus 17 upgrade 4](https://wiki.genexus.com/commwiki/wiki?47936,,).
