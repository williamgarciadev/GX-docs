# WriteRawText method

Generates any text without replacing special characters with character sequences.

### [Syntax](#Syntax)

**&***VarBasedOnXmlWriter***.WriteRawText(***Value***)**  
  
**Where:**  
*Value*  
   String to be written.

### [Scope](#Scope)

**Extended Data Types:** [XmlWriter](https://wiki.genexus.com/commwiki/wiki?6938)  
**Generators:**

[.NET](https://wiki.genexus.com/commwiki/wiki?38604), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892),
[Java](https://wiki.genexus.com/commwiki/wiki?12258), Ruby (up to GeneXus X Evolution 3), Visual FoxPro (up to GeneXus X Evolution 3)

### [Description](#Description)

Generates any text without replacing special characters with character sequences. This method is used to write pure XML in a document.

### [Security tips](#Security+tips)

This method does not sanitize inputs. Proper sanitization is advised.
