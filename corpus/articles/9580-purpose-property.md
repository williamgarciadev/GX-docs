# Purpose property

General text detailing the objects being distributed purpose.

### [Description](#Description)

This property must be filled at distribution time, in case any selected object has enabled the **Private Object** property.

### [Scope](#Scope)

**Objects:** Procedure, Transaction, Web Panel
