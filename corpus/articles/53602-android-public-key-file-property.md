# Android Public Key File property

Specifies the file containing the public key used to validate Mini Apps' metadata in the Android Super App.

### [Scope](#Scope)

**Objects:** [Super App](https://wiki.genexus.com/commwiki/wiki?53457)  
**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917)

### [Description](#Description)

This is a .crt file containing the public key used to validate Mini Apps' metadata in the Android Super App.

It needs to be downloaded from the [Mini App Center](https://wiki.genexus.com/commwiki/wiki?57522), below the Super App version declaration for the [Android platform](https://wiki.genexus.com/commwiki/wiki?14453).

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, Build the [Main Object](https://wiki.genexus.com/commwiki/wiki?5770).
