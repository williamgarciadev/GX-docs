# Indentation Property

This property is ussed to define how many characters are used to indent the code generated.

### [Syntax](#Syntax)

**&***DataType***.Indentation**

### [Description](#Description)

It defines how many characters are used to indent the code generated.  
The default value is 2.

### [Scope](#Scope)

**Extended Data Types:** [XmlWriter](https://wiki.genexus.com/commwiki/wiki?6938)  
**Languages:** .NET, Java, Ruby (up to GeneXus X Evolution 3), Visual FoxPro (up to GeneXus X Evolution 3)
