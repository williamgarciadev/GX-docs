# Generate Dynamic Provider property

Enables the generation of a dynamic scripted chatbot.

### [Scope](#Scope)

**Objects:** [Conversational Flows Instance](https://wiki.genexus.com/commwiki/wiki?37113)  
**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Java](https://wiki.genexus.com/commwiki/wiki?12258)

### [Description](#Description)

The **Generate Dynamic Provider** property is shown only if the [NLP Provider property](https://wiki.genexus.com/commwiki/wiki?38931) is set to “None”.

When the **Generate Dynamic Provider** property is set to True, it is possible to add/edit Flows, Trigger Messages, User inputs, etc. dynamically. To do so, certain [Transaction object](https://wiki.genexus.com/commwiki/wiki?1908)s, [Data Provider object](https://wiki.genexus.com/commwiki/wiki?5270)s, and [Web Panel object](https://wiki.genexus.com/commwiki/wiki?6916)s are automatically generated in the CommonChatbots module to store the definition of the Chatbot in the database. This makes it possible to modify the chatbot behavior at runtime.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
