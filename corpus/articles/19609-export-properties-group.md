# Export Properties group

This group of Properties is made up by the export formats.

The export formats supported are XML, HTML, XLS, XLSX,and PDF. The developer can select those that will be available for use by the end user and those that will not.

`[imagen omitida: wiki id 52511]`

Clicking in the menu icon on the Pivot Table or Table area displays a context menu with all the export options which are set to True.
