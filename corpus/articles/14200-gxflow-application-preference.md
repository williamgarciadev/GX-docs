# GXflow Application Preference

This menu allows you to set a group of preferences that are applied at runtime.

### [Preferences](#Preferences)

`[imagen omitida: wiki id 52393]`

**Show Applications in a new window**: It allows you to set whether the tasks are displayed in a new window or not.

**Autoresize application windows**: It allows establishing whether web forms will be automatically resized according to the contents of its attributes and variables.

**Encrypt URL parameters property**: To either allow or deny the encryption of the parameters sent to an URL, and to establish levels of security when the encryption of the parameters is used between Web Objects.

**Enable Dynamic Forms**: It allows the use of Dynamic Forms.

**Dynamic Forms Provider**: It allows to set the the provider of the Dynamic Forms.
