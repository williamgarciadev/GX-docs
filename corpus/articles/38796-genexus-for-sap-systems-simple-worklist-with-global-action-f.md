# GeneXus For SAP Systems - Simple Worklist with global action Floorplan

The Simple Worklist with global action [Floorplan](https://wiki.genexus.com/commwiki/wiki?38629,,) is a set of layouts that allows you to query and view data and offers the possibility of applying a certain action to a group of items (to select the items, a checkbox is offered for each line).

This article describes you how to apply it to a [Transaction object](https://wiki.genexus.com/commwiki/wiki?1908) or [Web Panel object](https://wiki.genexus.com/commwiki/wiki?6916) to obtain a page like the following:  
`[imagen omitida: wiki id 55018]`

**Note**: The design guideline of this floorplan is at [SAP's documentation](https://experience.sap.com/fiori-design-web/work-list/#1-global-actions).

## [How to create it](#How+to+create+it)

Look at the Patterns tab of a Transaction in your [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836). If you have never applied the Fiori for Web pattern in your KB before, read this article: [HowTo: Apply the Fiori for Web pattern for the first time](https://wiki.genexus.com/commwiki/wiki?38862). Otherwise, by positioning on the Fiori for Web Pattern tab, check the "Apply this pattern on save" checkbox and select the offered link to choose a floorplan:

`[imagen omitida: wiki id 54852]`

You can choose the Simple Worklist with global action floorplan from several offered floorplans:

`[imagen omitida: wiki id 55019]`

[Learn how to apply a Floorplan to a Web Panel](https://wiki.genexus.com/commwiki/wiki?42011).

## [How to program it](#How+to+program+it)

By default, the global action comes unset. To set it, you have to right-click the ProcessItems User action on the Simple Worklist with global action tab, and select the 'Go to Event' option:

`[imagen omitida: wiki id 55020]`

This will open the Simple Worklist with global action Web Panel on its Events section and automatically created the [Click event](https://wiki.genexus.com/commwiki/wiki?8177) of the ProcessItems action:

`[imagen omitida: wiki id 38872]`

## [How to customize it](#How+to+customize+it)

The following section explains how to customize your Simple Worklist with global action.

### [Add/Modify/Delete actions](#Add%2FModify%2FDelete+actions)

You can add, modify or delete actions by positioning on the Simple Worklist with global action tab, but if you want to do this, you may prefer the [GeneXus For SAP Systems - List Report Floorplan](https://wiki.genexus.com/commwiki/wiki?38572)

To add actions, you have to right-click the GridActions node and then, select Add > UserAction in the contextual menu. The action will be added outside the grid (in the section where the button to insert is located).

`[imagen omitida: wiki id 54995]`

To modify these actions, you can right-click on the action node and select the 'Go to Event' option. Then, you can modify the event code, but remember to do it outside the code generated by GeneXus (to avoid being overwritten by GeneXus).

If you want to add an action inside the grid for every line, you have to right-click on the Grid node and select Add > UserAction in the contextual menu:

`[imagen omitida: wiki id 55021]`

To modify these actions, you have to follow the next steps:

1. Right-click on the Simple Worklist with global action tab and select Open YourObjectNameSimpleWorklistwithglobalaction.

`[imagen omitida: wiki id 54997]`

**Note**: Temporarily, the Web Panel's name is not WebPanelNameSimpleWorklistwithglobalaction, but it is WebPanelNameListReport.

2. Once in the Simple Worklist with global action Web Panel, go to the Events Section.

`[imagen omitida: wiki id 38855]`

3. While there, you only have to create the [Click event](https://wiki.genexus.com/commwiki/wiki?8177) for your customized actions.

`[imagen omitida: wiki id 38856]`

### [Manage Filters](#Manage+Filters)

You can manage the [filters](https://wiki.genexus.com/commwiki/wiki?38588) by positioning on the Simple Worklist with global action tab.

To add filters, you have to right-click on the GridsActions node and then select Add in the contextual menu and then choose the kind of filter you want.

`[imagen omitida: wiki id 54998]`

For more information, see [GeneXus For SAP Filters](https://wiki.genexus.com/commwiki/wiki?38588).

### [Manage Orders](#Manage+Orders)

You can manage the Orders by positioning on the Simple Worklist with global action tab. Once there, you have to right-click on the GridActions node and then select Add > Orders.

`[imagen omitida: wiki id 54999]`

After having created the Orders node, you have to right-click on Orders and then choose Add > Order to add a new one.

`[imagen omitida: wiki id 55000]`

For each order you create, you have to complete its Name property:

`[imagen omitida: wiki id 55023]`

and you have to add the attribute(s) by which the list will be sorted:

`[imagen omitida: wiki id 55024]`

For each attribute, you can change the Ascending property, to choose whether you want the list to be sorted in ascending or descending order considering that attribute(s) value(s).

`[imagen omitida: wiki id 55025]`

### [Customize the information to be shown on the list](#Customize+the+information+to+be+shown+on+the+list)

You can manage the attributes to show by positioning on the Simple Worklist with global action tab.

To prevent attributes from being shown on the Simple Worklist with global action, you have to right-click the attribute and select Delete. Don't worry, it will be deleted from the Web Panel, not from the Transaction.

`[imagen omitida: wiki id 55005]`

To add attributes to be shown in the list, you have to right-click the Grid node, then select Add > GridAttribute:

`[imagen omitida: wiki id 55026]`

Then, GeneXus will display a list of attributes for you to choose which ones you want to add.

`[imagen omitida: wiki id 38861]`
