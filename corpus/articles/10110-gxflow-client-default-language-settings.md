# GXFlow Client Default Language Settings

This menu allows you to change the default language of the GXflow client. To do this, you must have previously added and configured the languages ​​in the [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836). See more in [HowTo: Customize GXflow labels](https://wiki.genexus.com/commwiki/wiki?50114).

`[imagen omitida: wiki id 52395]`

**Default Language:** It allows setting the GXflow client default language. Users will be able to change it by logging into the system.

Once the language has been changed, it is necessary to login again to see the changes.

A user can also change the language in his session from the [login](https://wiki.genexus.com/commwiki/wiki?17835).
