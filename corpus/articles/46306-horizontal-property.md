# Horizontal Property

Indicates the value of the Horizontal alignment in the [ExcelAlignment data type](https://wiki.genexus.com/commwiki/wiki?46082).

### [Syntax](#Syntax)

&ExcelAlignment.**Horizontal**

### [Type returned](#Type+returned)

CellHorizontalAlignment type (Numeric Enumerated)

### [Scope](#Scope)

[ExcelCellRange data type](https://wiki.genexus.com/commwiki/wiki?46081)

### [Availability](#Availability)

This property is available since [GeneXus 16 Upgrade 11](https://wiki.genexus.com/commwiki/wiki?45901,,)
