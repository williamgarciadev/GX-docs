# Layout Metadata Directory property

This property is used to configure the path where the dynamic report schema files will be located once generated (this metadata is used to obtain in run-time, the properties of the controls).

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply changes made by this property, Build a main object.

**Objects:** Procedure  
**Platforms:** Web(.Net, Java)
