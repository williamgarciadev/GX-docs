# Insert - Object

By selecting **Insert** and then, **Object...** from the [GeneXus Main Menu](https://wiki.genexus.com/commwiki/wiki?7212), the [Select Objects dialog](https://wiki.genexus.com/commwiki/wiki?9889) opens, allowing you to insert the name of an object into the section of the [GeneXus objects](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?1866,,) where you are currently working.

You can filter by different criteria to reduce the number of objects displayed and easily find the object you want to insert.

### [Shortcut](#Shortcut)

The keyboard shortcut **Ctrl+Shift+J** opens the Insert Object dialog.
