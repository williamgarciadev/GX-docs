# GxFtpError function

**Alert**: FTP does not encrypt the channel. It is recommended to use a protocol that encrypts the channel such as SFTP or FTPS.

Determines if any error occurred in the last command.

### [Syntax](#Syntax)

**Call**(**'GxFtpError'**, &*ST*)

**Where:**  
*ST*  
    Numeric. Is the error’s indicator. It is 1 if there was an error, and 0 otherwise.
