# Minimum Text property

Text to be displayed after the interval in seconds set in the Minimum Seconds property has elapsed.

### [Scope](#Scope)

**Generators:** [Apple](https://wiki.genexus.com/commwiki/wiki?14917)  
**Controls:** Attribute/Variable (Control Type: [Relative Timer](https://wiki.genexus.com/commwiki/wiki?42490))

### [Description](#Description)

This property is only visible for [Panel](https://wiki.genexus.com/commwiki/wiki?24829) Attributes or Variables whose data type is [DateTime](https://wiki.genexus.com/commwiki/wiki?7370).

The Minimum Text property allows you to set the message or content that will be displayed once a minimum time interval, controlled by the [Minimum Seconds property](https://wiki.genexus.com/commwiki/wiki?42258), has passed.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)
