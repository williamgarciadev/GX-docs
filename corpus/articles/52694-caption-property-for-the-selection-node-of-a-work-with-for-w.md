# Caption property for the Selection Node of a Work With for Web Pattern instance

Sets the text to be displayed in a button or "in-grid" actions that do not have an associated image.

### [Scope](#Scope)

**Level:** [Work With for Web Pattern Instance](https://wiki.genexus.com/commwiki/wiki?25475)

### [Description](#Description)

You can complete this property for the [Selection Node](https://wiki.genexus.com/commwiki/wiki?5640) of a [Work With for Web pattern](https://wiki.genexus.com/commwiki/wiki?25475) instance.

If the property is empty, the [Description property](https://wiki.genexus.com/commwiki/wiki?52696) value is used.

Attributes, Variables, and Functions are not supported.

This property is also used to reference the object in the [Recent links](https://wiki.genexus.com/commwiki/wiki?1863,,) section.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
