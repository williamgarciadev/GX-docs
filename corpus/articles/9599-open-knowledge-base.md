# Open - Knowledge Base

You can select **File > Open > Knowledge Base** to open an existing [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836).

A dialog to select a Knowledge Base will be displayed.

### [Shortcuts](#Shortcuts)

* Ctrl+Shift+O
* File > Recent KBs
* The Start Page shows a table with links to the recent KBs
