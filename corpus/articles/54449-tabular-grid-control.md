# Tabular Grid control

Displays data associated with several records in such a way that each data item to be displayed is included as a column.

**Note**: This control is in beta stage.

### [Scope](#Scope)

**Objects:** [Panel object](https://wiki.genexus.com/commwiki/wiki?24829)  
**Generators:** [Angular](https://wiki.genexus.com/commwiki/wiki?42550)

The Tabular Grid control allows you to display records in such a way that each data item to be displayed is included as a column. The control allows you to drag and drop columns to reorder them.

Attributes are always read-only and variables may be edited.

To add a Tabular Grid to a Panel, drag the Tabular Grid Control Icon from the Toolbox to the Layout.

`[imagen omitida: wiki id 54451]`

The Selector window will open to choose which attributes/variables you want to include in it:

`[imagen omitida: wiki id 54452]`

The Tabular Grids allow end users to move the columns inside it.
