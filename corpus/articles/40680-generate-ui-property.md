# Generate UI property

Enables user interface generation (Panels) for this instance.

### [Scope](#Scope)

**Objects:** [Conversational Flows Instance](https://wiki.genexus.com/commwiki/wiki?37113)

### [Description](#Description)

If set to FALSE, [Panel object](https://wiki.genexus.com/commwiki/wiki?24829)s related to the [Conversational Flows object](https://wiki.genexus.com/commwiki/wiki?37113) are not generated.

For example, the main object <InstanceName>UI (main Panel which calls the "PanelChat" [resource](https://wiki.genexus.com/commwiki/wiki?37102) object) is not generated. The objects specified in the [Generated Component property](https://wiki.genexus.com/commwiki/wiki?39880) of the [Flows](https://wiki.genexus.com/commwiki/wiki?38531) are not generated either.

### [Availability](#Availability)

This property is available since [GeneXus 17 upgrade 1](https://wiki.genexus.com/commwiki/wiki?46852,,).
