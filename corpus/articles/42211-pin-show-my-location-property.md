# Pin Show My Location property

Image used to display the current location of the device on the map.

### [Description](#Description)

Allows specifying an [Image object](https://wiki.genexus.com/commwiki/wiki?23387) to be used to display the current location of the device on an [SD Maps control](https://wiki.genexus.com/commwiki/wiki?15309).  
The property value will be used only when [Show My Location property](https://wiki.genexus.com/commwiki/wiki?42206) is set to True.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply changes made by this property, do a Build with this Only of the object.

### [Scope](#Scope)

**Objects:** Panel for Smart Devices, Work With for Smart Devices  
**Platforms:** Smart Devices(Android, IOS)  
**Controls:** Grid
