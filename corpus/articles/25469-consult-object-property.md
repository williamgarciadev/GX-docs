# Consult Object property

Indicates the application that will be displayed when the task is queried in the history.

### [Scope](#Scope)

**Objects:** [Business Process Diagram](https://wiki.genexus.com/commwiki/wiki?16486)  
**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917)  
**Controls:** [Task](https://wiki.genexus.com/commwiki/wiki?17495)

### [Description](#Description)

It applies only when using the GXflow Client for Native Mobile Applications and when the task has already been executed.

The application associated with the Query Application Property will be opened when the task is opened from the history.

### [Availability](#Availability)

This property is available since [GeneXus 17 upgrade 7](https://wiki.genexus.com/commwiki/wiki?49301,,).
