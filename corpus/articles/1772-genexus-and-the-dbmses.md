# GeneXus and the DBMSes

GeneXus maintains several DBMSes, it generates code for the programs that access the databases and also generates the database reorganization programs.

The following is a list of relational database management systems that supports GeneXus. More specifically, it is a list of the available data store property values in the preferences of an Environment

* [DB2 Universal Database](https://wiki.genexus.com/commwiki/wiki?1961)
* [DB2 for iSeries](https://wiki.genexus.com/commwiki/wiki?1962,,)
* [Informix](https://wiki.genexus.com/commwiki/wiki?1963,,)
* [MySQL](https://wiki.genexus.com/commwiki/wiki?1964)
* [Oracle](https://wiki.genexus.com/commwiki/wiki?1965)
* [PostgreSQL](https://wiki.genexus.com/commwiki/wiki?1966)
* [SQL Server](https://wiki.genexus.com/commwiki/wiki?1967)
* [SQLite](https://wiki.genexus.com/commwiki/wiki?22810,,)
* [SAP HANA Database](https://wiki.genexus.com/commwiki/wiki?31713)
* [Dameng](https://wiki.genexus.com/commwiki/wiki?50988)(1)

(1) - Since [GeneXus 17 Upgrade 11](https://wiki.genexus.com/commwiki/wiki?49972,,)

Nevertheless, that was not a complete list of all the supported DBMSes; reasons that make the list wider are: a) Some have been branched or forked (open source, commercial reasons) (i.e. ClearDB MySQL, MariaDB), b) some are provided as a [Cloud Database](https://wiki.genexus.com/commwiki/wiki?31685) and under that concept changed it's name (i.e. ElephantSQL is a PostgreSQL)

The following is a list of those others:

* [MariaDB](https://wiki.genexus.com/commwiki/wiki?31692)
* Please refer to [Cloud Database](https://wiki.genexus.com/commwiki/wiki?31685)

NOTE: this is a generic document about GeneXus and the DBMSes. To know about the supported GeneXus version for each DBMS and version needed, check the specific documentation of the requirements of the GeneXus version or directly in the DBMS documentation.
