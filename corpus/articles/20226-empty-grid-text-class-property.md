# Empty Grid Text Class property

Indicates the Theme Class to be used when showing the Empty Grid Text in the Grid of a Front end layout.

### [Scope](#Scope)

**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Angular](https://wiki.genexus.com/commwiki/wiki?42550), [Apple](https://wiki.genexus.com/commwiki/wiki?14917)  
**Controls:** [Grid](https://wiki.genexus.com/commwiki/wiki?24817)

### [Samples](#Samples)

In the following example the "TextBlock" is selected to show the background text ("No data Found") of the Grid.

`[imagen omitida: wiki id 50480]`
