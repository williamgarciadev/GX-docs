# Background opacity property

Sets the transparency of the chart's tooltip background. Valid values are between 0 and 1.

### [Description](#Description)

Defines the transparency of the [QueryViewer chart](https://wiki.genexus.com/commwiki/wiki?9075) tooltip.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Scope](#Scope)

**Objects:** Query
