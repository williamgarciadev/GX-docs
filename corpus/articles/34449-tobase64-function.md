# ToBase64 function

Converts a string into a base64 encoded string.

### [Syntax](#Syntax)

**ToBase64**( s1 )

**Where:**  
*s1*  
    Is a string

**Type returned:**  
Character

### [Scope](#Scope)

**Objects:**[Procedure](https://wiki.genexus.com/commwiki/wiki?6293), [Transaction](https://wiki.genexus.com/commwiki/wiki?1908), [Web Panel](https://wiki.genexus.com/commwiki/wiki?6916), [Objects for Native Mobile applications](https://wiki.genexus.com/commwiki/wiki?20087)

### [Sample](#Sample)

```
&MyBase64EncodedString = ToBase64(&MyString)
```

### [Availability](#Availability)

It is available since [GeneXus 15 Upgrade 4](https://wiki.genexus.com/commwiki/wiki?33798,,).
