# CurrentPage property

CurrentPage allows to get the current page of the grid (-1 if the grid doesn't support server side paging)

### [Description](#Description)

Applies to any grid which supports paging:

1. Rows property value different than 0. Nextpage and PreviousPage methods of the grid are used in some control event.

2. Rows property value different than 0. Nextpage and PreviousPage methods of the grid are not used in any control event, so automatic paging is done.

### [Scope](#Scope)

**Objects:** Web Panel  
**Platforms:** Web(.Net, Java)  
**Controls:** FreeStyle Grid, Grid
