# Setting a Development Version as Active

At any given time, a developer is working, for example, either on fixes to an already released application or on new features for the next application's release.

Both application states (released and to be released) are represented by [Development Versions](https://wiki.genexus.com/commwiki/wiki?5684) (or the [Trunk](https://wiki.genexus.com/commwiki/wiki?5683)) in GeneXus.  
  
To set a development version as active, open the [Knowledge Base Versions tool window](https://wiki.genexus.com/commwiki/wiki?5687), right-click on the desired development version and select "Set as active".

`[imagen omitida: wiki id 7549]`  
  
To identify what is the **active development version** at any given time see [here](https://wiki.genexus.com/commwiki/wiki?5689).
