# GeneXus .NET Framework Generator

Csharp (C#) is a language developed by Microsoft for running applications in .NET platforms (.NET Framework and .NET).

The .NET Framework generator (formally so-called since [GeneXus 17 Upgrade 8](https://wiki.genexus.com/commwiki/wiki?49616,,)) enables the generation of Web applications in C# for the .NET Framework (4.x). The programs generated are C# code sources (.cs) and compiled into assemblies (.dll or .exe) in a common intermediate language (IL), which, in runtime, are interpreted by the .NET virtual machine.

The applications communicate with the database through ADO.NET, and possible DBMS to be used are all those supported by [GeneXus](https://wiki.genexus.com/commwiki/wiki?1756): DB2 UDB for iSeries, DB2 Universal Database, Informix, MySQL, Oracle, PostgreSQL, and SQL Server.

### [.NET Framework Generator Requirements for generation and execution](#.NET+Framework+Generator+Requirements+for+generation+and+execution)

Check the corresponding requirements listed in the following article [GeneXus 18 hardware and software requirements](https://wiki.genexus.com/commwiki/wiki?30900).

### [State of .NET Framework Generator](#State+of+.NET+Framework+Generator)

This generator has been declared Legacy (ref.: [.NET 8 and the future of .NET in GeneXus](https://www.genexus.com/en/news/read-news/-net-8-and-the-future-of-net-in-genexus))

New features and improvements will be available only in the [GeneXus .NET Generator](https://wiki.genexus.com/commwiki/wiki?38604). The .NET Framework generator will keep receiving security updates only.

So, you should use the [GeneXus .NET Generator](https://wiki.genexus.com/commwiki/wiki?38604) instead.  
For further information read the following article: [Comparing the .NET generator with the .NET Framework generator](https://wiki.genexus.com/commwiki/wiki?45778).
