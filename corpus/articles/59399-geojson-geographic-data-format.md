# GeoJSON Geographic data format

It is a standard for representing vector data in JSON format (plain text).

The [Geography data type](https://wiki.genexus.com/commwiki/wiki?32408) and its specific data types ([GeoPoint](https://wiki.genexus.com/commwiki/wiki?58058), [GeoLine](https://wiki.genexus.com/commwiki/wiki?59358), and [GeoPolygon](https://wiki.genexus.com/commwiki/wiki?59361)) can use the [FromGeoJSON method](https://wiki.genexus.com/commwiki/wiki?59777) to load the vector data from its representation in GeoJSON format.

Similarly, the [ToGeoJSON method](https://wiki.genexus.com/commwiki/wiki?59810) allows you to obtain the vector data's representation in GeoJSON format.
