# Dashboard Gauge Maximum value property

Element's maximum value for a Gauge chart.

### [Description](#Description)

Set the desired Maximum Value when using a [Gauge Chart](https://wiki.genexus.com/commwiki/wiki?40424).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Availability](#Availability)

This property is available since [GeneXus 16](https://wiki.genexus.com/commwiki/wiki?35351,,).

### [Scope](#Scope)

**Objects:** Dashboard
