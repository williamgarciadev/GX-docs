# Name (upper value) property

Filter name for the upper value.

### [Scope](#Scope)

**Objects:** Dashboard

### [Description](#Description)

Name associated with the upper value in a Range filter. The link between the upper value and other Dashboard elements is accomplished through this name.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
