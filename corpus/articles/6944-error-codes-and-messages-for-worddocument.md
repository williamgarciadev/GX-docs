# Error Codes and Messages for WordDocument

|  |  |  |
| --- | --- | --- |
| **Code** | Message | **Comments** |
| 0 | Ok |  |
| 2 | Document no longer valid | This happens when a document has been opened from a program and is manually closed by the user |
| 3 | Application no longer valid | This happens when Word is manually closed by the user |
| 4 | Invalid template |  |
| 5 | Invalid file name | (\*) |
| 6 | Could not open file |  |
| 7 | Could not save file |  |
| 8 | Invalid value |  |
| 9 | Error running macro |  |
| 10 | Could not complete operation |  |
