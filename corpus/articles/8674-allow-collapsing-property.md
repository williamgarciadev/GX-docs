# Allow Collapsing property

Allows defining whether the Grid will collapse or not.

### [Syntax](#Syntax)

**control.** AllowCollapsing   

Type returned: Boolean

*Control*  
    Is the name of a grid control inserted in the form.

### [Values](#Values)

|  |
| --- |
| **False** |
| **True** |

### [Scope](#Scope)

**Controls:** [Grid](https://wiki.genexus.com/commwiki/wiki?24817)

### [Description](#Description)

To define a [Grid](https://wiki.genexus.com/commwiki/wiki?24817) in a [Web Panel Web Layout](https://wiki.genexus.com/commwiki/wiki?8132) or [Transaction Web Layout](https://wiki.genexus.com/commwiki/wiki?8057) as collapsible, you must set the Allow Collapsing property = True.  
During runtime, an icon will appear on the Grid's upper corner. Clicking on it will cause the grid to collapse or expand (depending on the previous status), without the need to refresh the page.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies both at runtime and at design time.
