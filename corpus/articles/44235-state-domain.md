# State domain

Enumerated domain representing the training state in the context of [GeneXus Cognitive API](https://wiki.genexus.com/commwiki/wiki?40167) for custom models.

## [Values](#Values)

|  |  |
| --- | --- |
| **Aborted** | The model aborted, raising an error. |
| **Deployed** | The model is currently deployed. |
| **Ready** | The model is ready to be used. |
| **Training** | The model is currently training. |
| **Unknown** | The model is in an unknown state (e.g. when the model does not exist). |
