# HowTo: Set up Botmaker for Chatbots using WhatsApp

Here you will find instructions to set up [Botmaker](https://go.botmaker.com/get/?lang=en) to use WhatsApp as a messaging platform for the [Chatbot generator](https://wiki.genexus.com/commwiki/wiki?37102).

### [Step 1 - Creating an account](#Step+1+-+Creating+an+account)

First, create the account.

`[imagen omitida: wiki id 45902]`

You will be asked to choose a channel to connect your Chatbot (you can change this later).

`[imagen omitida: wiki id 45903]`

When selecting WhatsApp, you are asked to provide a phone number and the Facebook Business Manager ID. If you don't have it, Botmaker can help you get it.

`[imagen omitida: wiki id 45904]`

Next, select the plan.

`[imagen omitida: wiki id 45907]`

Select to configure it on your own or to receive help from experts.

`[imagen omitida: wiki id 45908]`

Finally, complete the form to finish the process.

`[imagen omitida: wiki id 45909]`

### [Step 2 - Configuring inbound message webhooks](#Step+2+-+Configuring+inbound+message+webhooks)

On the [platform page](https://go.botmaker.com/#/platforms), configure the URL that Botmaker sends a webhook to for inbound messages.

The Webhook is automatically generated by configuring in the KB the following properties:

* [Enable WhatsApp property](https://wiki.genexus.com/commwiki/wiki?45163)
* [WhatsApp Partner property](https://wiki.genexus.com/commwiki/wiki?45164)
* [Botmaker Token property](https://wiki.genexus.com/commwiki/wiki?45993)

It's generated under the [instance's](https://wiki.genexus.com/commwiki/wiki?37113) module, and its name is WhatsappWebhook.

After building it, configure the URL as follows:

**http://<server>/<baseURL>/<InstanceModule>.WhatsappWebhook.aspx (.NET) or http://<server>/<baseURL>/<InstanceModule>.WhatsappWebhook (Java)**

Note that the computer where the webhook is hosted has to be visible online:

`[imagen omitida: wiki id 45938]`

### [Step 3 - Configuration settings](#Step+3+-+Configuration+settings)

On the [platform page](https://go.botmaker.com/#/platforms), create the credentials:

`[imagen omitida: wiki id 45939]`Once it is created, the access token will be shown there. This access token is JWT.
