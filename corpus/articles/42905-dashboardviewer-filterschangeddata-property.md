# DashboardViewer FiltersChangedData property

Name of the variable containing information about the DashboardViewer FiltersChanged event when it's raised.

### [Description](#Description)

Upon changing the value of any filter in the DashboardViewer control you may want to trigger a particular action. This property contains the name of the variable based on the DashboardViewerFiltersChangedData SDT that can be used in the FiltersChanged event.
