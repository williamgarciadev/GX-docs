# Second method

Returns a numeric value representing the seconds of a datetime argument.

### [Syntax](#Syntax)

*Datetime***.Second(****)**  
  
**Type Returned:**  
Numeric(2)

### [Scope](#Scope)

**Objects:** [Procedure](https://wiki.genexus.com/commwiki/wiki?6293), [Transaction](https://wiki.genexus.com/commwiki/wiki?1908), [Web Panel](https://wiki.genexus.com/commwiki/wiki?6916)  
**Generators:**

[.NET](https://wiki.genexus.com/commwiki/wiki?38604), Ruby (up to GeneXus X Evolution 3),
[Java](https://wiki.genexus.com/commwiki/wiki?12258), RPG, Visual FoxPro (up to GeneXus X Evolution 3), Cobol

### [Samples](#Samples)

```
If &DateTime.Second() > 0
   &TxtMinute = "Past o'clock..."
EndIf
```
