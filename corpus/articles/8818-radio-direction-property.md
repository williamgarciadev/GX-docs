# Radio Direction property

Allows setting whether the radio options will be displayed vertically or horizontally.

### [Values](#Values)

|  |  |
| --- | --- |
| **Horizontal** | Radio options will be displayed horizontally. |
| **Vertical** | Radio options will be displayed vertically. This is the default value. |

### [Scope](#Scope)

**Controls:** Attribute/Variable (Control Type: Radio Button)

### [Description](#Description)

It controls the orientation of radio options in a user interface. It allows you to specify whether the radio options of a Radio Button included in a [Panel](https://wiki.genexus.com/commwiki/wiki?24829), [Transaction Web Layout](https://wiki.genexus.com/commwiki/wiki?8057) or [Web Panel Web Layout](https://wiki.genexus.com/commwiki/wiki?8132) should be displayed vertically or horizontally.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
