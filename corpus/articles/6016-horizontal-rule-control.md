# Horizontal Rule Control

The Horizontal Rule control has only cosmetic implications for webforms. It is merely used frequently to separate other controls.

`[imagen omitida: wiki id 6017]` To add a horizontal rule to the selected location, drag the corresponding icon from the toolbox and into the webform.
