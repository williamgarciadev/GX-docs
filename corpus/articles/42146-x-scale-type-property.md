# X-Scale Type property

Selects the type of scale to be adopted by the X-axis: continuous or discrete.

### [Values](#Values)

|  |  |
| --- | --- |
| **Continuous** | Allows a value to be selected within a given interval. Example: Natural numbers between 0 and 100. |
| **Discrete** | Allows you to select values which must exist within a set. Example: Monday, Tuesday, Wednesday, Thursday, Friday. |

### [Scope](#Scope)

**Generators:** [Apple](https://wiki.genexus.com/commwiki/wiki?14917)  
**Controls:** [Grid](https://wiki.genexus.com/commwiki/wiki?24817) (Control Type: [Matrix Grid](https://wiki.genexus.com/commwiki/wiki?25139))

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)
