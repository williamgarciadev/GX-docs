# Merge Triggers property

Merges trigger messages before synchronize.

### [Scope](#Scope)

**Objects:** [Conversational Flows Instance](https://wiki.genexus.com/commwiki/wiki?37113)

### [Description](#Description)

The Merge Triggers property allows you to determine if the training messages of the flows at the NLP Providers will be merged with the corresponding [Trigger Messages](https://wiki.genexus.com/commwiki/wiki?39067) of the [Conversational Flows object](https://wiki.genexus.com/commwiki/wiki?37113) when the instance is synchronized.

### [Availability](#Availability)

This property is available since [GeneXus 17](https://wiki.genexus.com/commwiki/wiki?46066,,).
