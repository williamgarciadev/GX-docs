# Text property

Description of the selected item of the control.

### [Syntax](#Syntax)

**control.** Text

### [Samples](#Samples)

```
&CountryName = CountryList.Text
```

The CountryList attribute is defined as a Dynamic List Box and contains a list of countries loaded from a table.

### [Scope](#Scope)

**Objects:** [Transaction](https://wiki.genexus.com/commwiki/wiki?1908), [Web Panel](https://wiki.genexus.com/commwiki/wiki?6916)  
**Controls:** Attribute/Variable (Control Type DynamicComboBox)
