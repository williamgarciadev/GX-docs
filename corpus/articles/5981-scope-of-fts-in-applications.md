# Scope of FTS in Applications

Full Text Search in Applications allows end users to define their own searches.

The search will examine:

* The database, but **only** in relation to the structure of Transactions defined as Business Components (the text that is built and indexed has the following format: Attribute<1> Title + " " + Attribute<1> Value + .... + Attribute<n> Value);
* All files in the hard disk.

See [Full Text Search](https://wiki.genexus.com/commwiki/wiki?5277) for further information.
