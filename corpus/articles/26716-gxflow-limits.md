# GXflow limits

The purpose of this article is to present the limits in the usage and definition of objects —or relations between objects, in GXflow.

| Object/Data Type | Limit | Version |
| --- | --- | --- |
| [WorkflowUser Data Type](https://wiki.genexus.com/commwiki/wiki?17273) | An user cannot be assigned to more than 1000 roles. | All versions |
| GXFlow users | unlimited GXflow users | All versions |
| GXFlow Organization Definitions | unlimited Organization Definitions | All versions |
| GXFlow users within a Organization Unit | unlimited GXflow users in a Organization unit | All versions |
| GXFlow users belonging to a Organization Unit | unlimited GXflow users belonging to a Organization unit | All versions |
| GXFlow Organizational Units in a GXflow process instance | unlimited GXFlow Organizational Units in a GXflow process instance | All versions |
