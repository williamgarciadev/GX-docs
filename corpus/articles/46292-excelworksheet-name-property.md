# ExcelWorksheet Name Property

Returns the name of the [ExcelWorksheet data type](https://wiki.genexus.com/commwiki/wiki?46080).

### [Syntax](#Syntax)

&ExcelworkSheet.**Name**

### [Type returned](#Type+returned)

Character

### [Description](#Description)

This property is read only, it cannot be assigned.

### [Scope](#Scope)

[ExcelWorksheet data type](https://wiki.genexus.com/commwiki/wiki?46080)

### [Availability](#Availability)

This property is available since [GeneXus 16 Upgrade 11](https://wiki.genexus.com/commwiki/wiki?45901,,)
