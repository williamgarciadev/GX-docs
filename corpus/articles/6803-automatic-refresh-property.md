# Automatic refresh property

Refreshes the Grid / Free Style Grid / Tabular Grid automatically without the end user having to click on a "Refresh" button.

### [Values](#Values)

|  |  |
| --- | --- |
| **No** | The Web Panel or Panel does not refresh automatically. |
| **Yes** | A refresh is performed automatically after every change in any variable included in the screen and used in the Load event or Conditions (for both Web Panels and Panels). In the case of Web Panels, if the variable is used in the Refresh event as well. This is the default value. |

### [Scope](#Scope)

**Objects:** [Web Panel](https://wiki.genexus.com/commwiki/wiki?6916), [Panel](https://wiki.genexus.com/commwiki/wiki?24829)  
**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [Java](https://wiki.genexus.com/commwiki/wiki?12258), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Angular](https://wiki.genexus.com/commwiki/wiki?42550)

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
