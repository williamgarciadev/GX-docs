# Animation Key Field Specifier property

If the "Animation Key Attribute" property is set with an SDT variable, this property is offered to enter the SDT member which is the identifier (key) of the entity to animate.

### [Description](#Description)

It applies only to Grids whose:

* [Control Type property = SD Maps](https://wiki.genexus.com/commwiki/wiki?15309)
* [Animations Layer property](https://wiki.genexus.com/commwiki/wiki?43487) = True
* [Animation Key Attribute property](https://wiki.genexus.com/commwiki/wiki?43488) is set with an SDT variable

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply changes made by this property, do a Build with this Only of the object.

### [Availability](#Availability)

This property is available since [GeneXus 15 Upgrade 5](https://wiki.genexus.com/commwiki/wiki?34646,,).

### [Scope](#Scope)

**Platforms:** Smart Devices(IOS)  
**Controls:** Grid (Control Type: [SD Maps](https://wiki.genexus.com/commwiki/wiki?15309))
