# Animation Duration property (for Animation Theme class)

Duration of the animation (in milliseconds). Empty uses the platform default.

### [Description](#Description)

This property is available in [Theme object](https://wiki.genexus.com/commwiki/wiki?16595) classes only when [Animated property](https://wiki.genexus.com/commwiki/wiki?34111) is enabled. Its aim is to improve the UI/UX of a smart device application when it includes [transformations](https://wiki.genexus.com/commwiki/wiki?23694).

#### [Values](#Values)

It accepts positive integer values indicating the time in milliseconds (ms) that the animation will last.

#### [Notes](#Notes)

* As of [GeneXus 15 Upgrade 4](https://wiki.genexus.com/commwiki/wiki?33798,,), altought the developer can enable the Animation property in order to include a smooth transition when a cell is [collapsed](https://wiki.genexus.com/commwiki/wiki?22743), the Animation Duration proprety is not taken into account for this scenario. It only applies for [transformations](https://wiki.genexus.com/commwiki/wiki?23694).
