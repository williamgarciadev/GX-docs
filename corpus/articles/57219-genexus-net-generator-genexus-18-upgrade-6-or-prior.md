# GeneXus .NET Generator (GeneXus 18 Upgrade 6 or prior)

The GeneXus .NET generator (formally so called since [GeneXus 17 Upgrade 8](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?49616,,) because [Microsoft renamed the .NET Core platform to .NET](https://docs.microsoft.com/en-us/dotnet/core/whats-new/dotnet-5)) enables the generation of Web applications in C# for .NET 6 and is therefore the evolution of the [.NET Framework generator](https://wiki.genexus.com/commwiki/wiki?2892).

The programs generated are C# code sources (.cs) and compiled into assemblies (.dll or .exe) in a common intermediate language (IL), which, in runtime, are interpreted by the .NET virtual machine. Services and web pages are handled by the model of [convention-based middleware](https://wiki.genexus.com/commwiki/wiki?51326).
