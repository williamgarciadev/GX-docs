# Pin Image Attribute property

Attribute or variable that contains the image that will be used to display a point on the map.

### [Description](#Description)

Allows indicating an [Attribute/Variable](https://wiki.genexus.com/commwiki/wiki?6911) containing the image that will be used to display the points on an [SD Maps control](https://wiki.genexus.com/commwiki/wiki?15309).  
This [Attribute/Variable](https://wiki.genexus.com/commwiki/wiki?6911) must be of [Image data type](https://wiki.genexus.com/commwiki/wiki?15204). Also, different values can be assigned to each point of the map, by assigning those values to the [Attribute/Variable](https://wiki.genexus.com/commwiki/wiki?6911) in the [Grid control](https://wiki.genexus.com/commwiki/wiki?24817) [Load event](https://wiki.genexus.com/commwiki/wiki?8188).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply changes made by this property, do a Build with this Only of the object.

### [Scope](#Scope)

**Objects:** Panel for Smart Devices, Work With for Smart Devices  
**Platforms:** Smart Devices(Android, IOS)  
**Controls:** Grid
