# Rest Test object

Defines a Rest test, for an object which has been exposed as a Rest Web Service like [Business Components](https://wiki.genexus.com/commwiki/wiki?5846), [Data Providers](https://wiki.genexus.com/commwiki/wiki?5270), and [Procedures](https://wiki.genexus.com/commwiki/wiki?6293).

You can run the defined tests using the GeneXus IDE or automatically on different [Environments](https://wiki.genexus.com/commwiki/wiki?7115) when using CI/CD capabilities.

You have two ways to create a Rest Test object:

1) In the same way that you create any [GeneXus object](https://wiki.genexus.com/commwiki/wiki?9931).

2) In the [KB Explorer](https://wiki.genexus.com/commwiki/wiki?3210) you can right-click on the desired Procedure, Data Provider or Business Component and select in the contextual menu: **Create Rest Test**.

More information at [Create tests for Rest objects](https://wiki.genexus.com/commwiki/wiki?50074).
