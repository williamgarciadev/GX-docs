# Enable Zoom property

Allows zooming in/out on an image.

### [Values](#Values)

|  |
| --- |
| **True** |
| **False** |

### [Scope](#Scope)

**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917)  
**Controls:** Attribute/Variable (Control Type: Image, [Advanced Image](https://wiki.genexus.com/commwiki/wiki?20497))

### [Description](#Description)

When the Attribute/ Variable has its **Control Type = Advanced Image**, these related properties are available:

* [Max Zoom property](https://wiki.genexus.com/commwiki/wiki?46472)
* [Max Zoom Relative To property](https://wiki.genexus.com/commwiki/wiki?46574)
* [Zoom Outside Control property](https://wiki.genexus.com/commwiki/wiki?43486)
* [Enable Copy To Clipboard property](https://wiki.genexus.com/commwiki/wiki?46557)

When the Attribute/Variable has its **Control Type = Image** and the[Enable Zoom property](https://wiki.genexus.com/commwiki/wiki?46466) = True, the properties mentioned above are available.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
