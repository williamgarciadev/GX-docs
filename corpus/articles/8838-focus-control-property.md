# Focus control property

Determines if Web objects –when showing a page– try to put the focus in the first input control on a plain level Form (non-read-only controls) or leave the position of the focus up to the Browser.

### [Values](#Values)

|  |  |
| --- | --- |
| **Browser dependent** |  |
| **Use Environment property value** |
| **First input att/var on the page** |  |
| **First input att/var on the page only if not embedded** |

### [Scope](#Scope)

**Objects:** [Web Component](https://wiki.genexus.com/commwiki/wiki?1864), [Web Panel](https://wiki.genexus.com/commwiki/wiki?6916)  
**Level:** Generator

### [Description](#Description)

You can find this property at the Back end Generator level and also at the [Web Panel object](https://wiki.genexus.com/commwiki/wiki?6916)s and [Web Component object](https://wiki.genexus.com/commwiki/wiki?1864)s level.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, execute a Rebuild All.
