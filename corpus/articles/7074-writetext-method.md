# WriteText method

#### [Generates character data with the indicated value string.](#Generates+character+data+with+the+indicated+value+string.)

### [Syntax](#Syntax)

**&***VarBasedOn*XmlWriter**.WriteText(***Value***)**

**Where:**  
  
*Value*   
   String to write.

### [Scope](#Scope)

**Extended Data Types:** [XmlWriter](https://wiki.genexus.com/commwiki/wiki?6938)  
**Generators:**

[.NET](https://wiki.genexus.com/commwiki/wiki?38604),
[.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Java](https://wiki.genexus.com/commwiki/wiki?12258),
Ruby (up to GeneXus X Evolution 3),
Visual Basic (up to GeneXus X Evolution 3),
Visual FoxPro (up to GeneXus X Evolution 3)

### [Description](#Description)

Special characters are replaced with character sequences ('<' is replaced with '&lt;', '>' with '&gt;', and so on).
