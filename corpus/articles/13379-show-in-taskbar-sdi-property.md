# Show in taskBar (SDI) property

Allows indicating if the object will appear in the Windows taskbar or not.

### [Values](#Values)

|  |  |
| --- | --- |
| **No** | The object will not appear in the Windows taskbar. |
| **Yes** | The object will appear in the Windows taskbar. Default value. |

### [Description](#Description)

#### [Note](#Note)

An SDI (Single Document Interface) application will be generated. Every transaction or work panel will be an independent window (i.e.: this is the interface used by Microsoft Exchange).

### [Scope](#Scope)

**Objects:** Transaction  
**Platforms:** Web(.Net, Java)
