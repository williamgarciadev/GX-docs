# Object Help Tab

Edits the Help content available for the current object. You can enter a detailed description, which the end user can then access as online help at runtime.

### [Description](#Description)

Most [GeneXus objects](https://wiki.genexus.com/commwiki/wiki?1866) include a Help tab that contains two selectors:

* Browse / Preview (the selector title changes depending on whether you are editing or not)
* Edit

`[imagen omitida: wiki id 58597]`

When entering content in the Edit selector, the first selector's title changes from 'Browse' to 'Preview' and shows how your content will be displayed:

`[imagen omitida: wiki id 58609]`

Each selector contains two tabs: Design and HTML to use a visual editor or directly edit the HTML code.
