# Flexible client update policy property (GeneXus 18 Upgrade 13 or prior)

Determines the update policy of the flexible client referenced by the generated application.

### [Values](#Values)

|  |  |
| --- | --- |
| **Defined by Generator** | The generated application uses the flexible client version released with the installed generator. |
| **Custom** | Enables you to set a specific flexible client version in the 'Flexible client version' property. |

### [Scope](#Scope)

**Generators:** [Apple](https://wiki.genexus.com/commwiki/wiki?14917)  
**Level:** Generator

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#com.gxwiki.wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, execute a [Rebuild All](https://wiki.genexus.com/commwiki/wiki?5691).

### [Availability](#Availability)

This property is available since [GeneXus 18 Upgrade 8](https://wiki.genexus.com/commwiki/wiki?54242).
