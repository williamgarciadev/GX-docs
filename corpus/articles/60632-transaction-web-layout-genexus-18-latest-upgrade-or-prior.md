# Transaction Web Layout (GeneXus 18 latest upgrade or prior)

When defining a [Transaction object](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?1908,,), a default Layout is automatically created by [GeneXus](https://wiki.genexus.com/commwiki/wiki?1756) to specify the way the user will access data in web applications. This Layout may be modified.

The edited screen that is finally saved will be the screen that will always appear. Note that all attributes present in the Layout must be previously declared in the [Transaction Structure](https://wiki.genexus.com/commwiki/wiki?7661).
