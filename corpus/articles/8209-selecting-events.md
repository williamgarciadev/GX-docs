# Selecting Events

The purpose is to show the available events to be used in the object.

The following image shows the Events Editor of a [Transaction object](https://wiki.genexus.com/commwiki/wiki?1908) (Analyst). A combo box allows selection of one of the system events, to enable programming of the behaviour when the event occurs. Following the selection, the minimum event structure is included in the editor.
