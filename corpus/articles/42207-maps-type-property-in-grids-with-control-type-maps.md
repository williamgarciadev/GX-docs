# Maps Type property in Grids with Control Type = Maps

Sets the type of map to display.

### [Values](#Values)

|  |  |
| --- | --- |
| **Hybrid** | Displays a mixture of normal and satellite views. |
| **Satellite** | Displays satellite images. |
| **Standard** | Displays the default road map view. |

### [Scope](#Scope)

**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917)  
**Controls:** [Grid](https://wiki.genexus.com/commwiki/wiki?24817) (Control Type: [Maps](https://wiki.genexus.com/commwiki/wiki?15309))

### [Description](#Description)

This property is visible only for Grids whose [Control Type property = Maps](https://wiki.genexus.com/commwiki/wiki?15309).

It allows selecting one type of map to be displayed.

It is an interface that defines the display and usage of map tiles.

The different Values are given by the Maps Platform provided.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies both at run-time and at design-time.
