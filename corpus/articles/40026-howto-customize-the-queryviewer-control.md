# HowTo: Customize the QueryViewer control

The purpose of this article is to explain the necessary steps to customize the QueryViewer control.

### [Step 1](#Step+1)

To customize the [QueryViewer control](https://wiki.genexus.com/commwiki/wiki?9075), you need to associate a class to it (Appearence section).

`[imagen omitida: wiki id 40027]`

### [Step 2](#Step+2)

Open the associated [Web Theme object](https://wiki.genexus.com/commwiki/wiki?6420) and locate the QueryViewer node matching the class you selected:

`[imagen omitida: wiki id 40028]`

Depending on the control output Type (Table, Pivot Table, Chart or Card) property, you will find a section to set the desired UI properties:

`[imagen omitida: wiki id 40029]`

### [Availability](#Availability)

This customization is available since [GeneXus 15 upgrade 12](https://wiki.genexus.com/commwiki/wiki?39737,,).
