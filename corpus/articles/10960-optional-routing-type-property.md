# Optional routing type property

Indicates the optional route once the activity is over.

### [Values](#Values)

|  |  |
| --- | --- |
| **Branch** | Once the activity is over the flow will continue for one of the subsequent ones. This is the Default value. |
| **Split** | Once the activity is over the flow will continue for all the subsequent ones. |

### [Scope](#Scope)

**Controls:** [Task](https://wiki.genexus.com/commwiki/wiki?17495)

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
