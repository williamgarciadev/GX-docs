# Module Version property

Holds the version of the packaged module.

### [Scope](#Scope)

**Objects:** [Module](https://wiki.genexus.com/commwiki/wiki?22411)

### [Description](#Description)

The version of the packaged module should typically be a sequence of numbers separated by a period.

### [Samples](#Samples)

* 1.0
* 1.0.1
* 3.1
* 4.3.12344

You may also go to the [Manage Module References](https://wiki.genexus.com/commwiki/wiki?40172) tool window and look at how other modules have been versioned.
