# Custom Center Attribute property

Attribute used to indicate the location (coordinates) used to center the map.

### [Description](#Description)

Allows indicating an [Attribute/Variable](https://wiki.genexus.com/commwiki/wiki?6911) to store the value of the location used to center the map. This [Attribute/Variable](https://wiki.genexus.com/commwiki/wiki?6911) has to be of [Geolocation domain](https://wiki.genexus.com/commwiki/wiki?14644) or [Geography data type](https://wiki.genexus.com/commwiki/wiki?32408).

The property is used only when [Center property](https://wiki.genexus.com/commwiki/wiki?42220) is set to Custom.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply changes made by this property, do a Build with this Only of the object.

### [Scope](#Scope)

**Objects:** Panel for Smart Devices, Work With for Smart Devices  
**Platforms:** Smart Devices(Android, IOS)  
**Controls:** Grid (Control Type: [SD Maps](https://wiki.genexus.com/commwiki/wiki?15309))
