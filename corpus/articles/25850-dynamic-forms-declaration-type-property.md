# Dynamic forms declaration type property

Sets if the dynamic form definition to be used in the user Task is statically defined —fixed— or defined by using Relevant Data.

### [Values](#Values)

|  |  |
| --- | --- |
| **Fixed** | If this value is used, a Form Definition has to be used in the Application form property , Preview form property and Consult form property . This is the default value. |
| **Relevant data** | If this value is used, a Relevant Data has to be used in the Application form property , Preview form property and Consult form property . |

### [Scope](#Scope)

**Controls:** [Task](https://wiki.genexus.com/commwiki/wiki?17495)

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [Samples](#Samples)

This property is used to set whether the Form Definition for the user Task is fixed or taken from the value of a [Relevant Data](https://wiki.genexus.com/commwiki/wiki?11759).
