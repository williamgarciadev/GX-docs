# Cell method

Returns an ExcelCellRange data type, which contains the indicated cell.

### [Syntax](#Syntax)

**&***ExcelSpreadSheet***.Cell*(****Row, Column***)**  
  
**Where:**  
  
*Row*  
     Is the row where the cell is.  
  
*Column*  
     Is the column where the cell is.

**Type Returned:**   
Numeric

### [Scope](#Scope)

**Data Types:** [ExcelSpreadSheet](https://wiki.genexus.com/commwiki/wiki?46040)

### [Description](#Description)

It returns an [ExcelCellRange data type](https://wiki.genexus.com/commwiki/wiki?46081) with the cell located in the Row (row specified) and Column (column specified).
