# Filter Changed Data property

Upon changing the filters of a [Query Element](https://wiki.genexus.com/commwiki/wiki?19788), we may want to trigger a particular action (such as recalculating a value, changing the color of a text, interacting with another control, etc.). This property contains the name of the variable based on the QueryViewerFilterChangedData SDT that can be used in the [FilterChanged Event](https://wiki.genexus.com/commwiki/wiki?19646).

### [Values](#Values)

|  |  |
| --- | --- |
| **&FilterChangedData** | Name of the variable that will implement the event’s inherent properties. This is the default value. |
