# Reorganization Generator property

Selects the Reorganization Generator for the active Environment.

### [Scope](#Scope)

**Level:** [Environment](https://wiki.genexus.com/commwiki/wiki?7115)

### [Description](#Description)

This property is available for each Environment of a [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836) and lets you select the [GeneXus Generator](https://wiki.genexus.com/commwiki/wiki?7116) to generate the programs to create/modify the database structure (in other words, the [Reorganization](https://wiki.genexus.com/commwiki/wiki?5288) programs).  
  
`[imagen omitida: wiki id 55854]`

By default, it is set to **Back end** (**Default**) Generator. If more Generators are defined for the Environment, you can select one of them.

Read more details in [GeneXus Generators](https://wiki.genexus.com/commwiki/wiki?7116).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
