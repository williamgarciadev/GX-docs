# Estimated process duration property

It allows estimating the process duration (in minutes).

### [Description](#Description)

We will be able to see the difference between estimated duration and real duration with the [GXflow Process Analysis](https://wiki.genexus.com/commwiki/wiki?18410).

The default value is zero, but it can be changed to any other value.
