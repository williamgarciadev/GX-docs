# GXflow client for Native Mobile

GXflow client for Native Mobile is an example of a Native Mobile application aimed to provide some functionalities of the [GXflow Client](https://wiki.genexus.com/commwiki/wiki?17835) to the end users.

The operations a typical end user can execute in the GXflow client for Native Mobile are: starting new processes, visualizing and executing his pending tasks and downloading and uploading files.
