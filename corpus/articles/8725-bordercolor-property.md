# BorderColor property

Allows selecting a color for the control's lines.

### [Syntax](#Syntax)

**control.** BorderColor = Expression   

Where:

Control  
Is the name of a control inserted in the form.

Expression  
Is a numeric representing an RGB color.

### [Scope](#Scope)

**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [Java](https://wiki.genexus.com/commwiki/wiki?12258)  
**Controls:** [Table](https://wiki.genexus.com/commwiki/wiki?6001)

### [Description](#Description)

Applies to [Table control](https://wiki.genexus.com/commwiki/wiki?6001)s included in [Web Panel Web Layout](https://wiki.genexus.com/commwiki/wiki?8132)s and [Transaction Web Layout](https://wiki.genexus.com/commwiki/wiki?8057)s.
