# APIs to integrate with payment methods

This article lists the different APIs available in GeneXus to integrate your applications with different payment services providers.

* [GeneXus SDK for Mercado Pago](https://wiki.genexus.com/commwiki/wiki?36547,,)
* [GeneXus SDK for PayPal](https://wiki.genexus.com/commwiki/wiki?39115)
* [GeneXus SDK for Stripe](https://wiki.genexus.com/commwiki/wiki?37967)
* [WeChat Pay API](https://wiki.genexus.com/commwiki/wiki?37322)
* [Alipay API](https://wiki.genexus.com/commwiki/wiki?37152)

**Note**: These APIs are typically developed with GeneXus, using integration and extensibility capabilities to.
