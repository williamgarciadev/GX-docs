# AlignItems property

Defines the default behavior for how flex items are laid out along the cross axis on the current line. Think of it as the justify-content version for the cross-axis (perpendicular to the main-axis).

### [Values](#Values)

|  |  |
| --- | --- |
|  | No value is specified. The browser's default value is used. |
| **Baseline** | items are aligned such as their baselines align |
| **Center** | items are centered in the cross-axis |
| **Flex End** | cross-end margin edge of the items is placed on the cross-end line |
| **Flex Start** | cross-start margin edge of the items is placed on the cross-start line |
| **Stretch** | stretch to fill the container (still respect min-width/max-width) |

### [Scope](#Scope)

**Platforms:** Web(.Net, .Net Core, Java)  
**Controls:** [Flex](https://wiki.genexus.com/commwiki/wiki?40521), [Grid](https://wiki.genexus.com/commwiki/wiki?24817) (Control Type: Flex)
