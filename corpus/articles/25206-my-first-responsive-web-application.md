# My first Responsive Web Application

This is a getting started guide for developing a [Responsive Web Applications](https://wiki.genexus.com/commwiki/wiki?25159) with GeneXus. In this example, the application is based mainly on Web Transactions and Work With [Pattern](https://wiki.genexus.com/commwiki/wiki?2814) forms.

All that’s needed is to:

* Set [Web Form Defaults property](https://wiki.genexus.com/commwiki/wiki?25135) to Responsive Web Design value.
* Check that [Default Theme property](https://wiki.genexus.com/commwiki/wiki?8145) is set to Carmine. The Carmine Theme is the one with the settings and classes adequate for a [Responsive Web Design (RWD)](https://wiki.genexus.com/commwiki/wiki?25161).
* Check that [Default Master Page property](https://wiki.genexus.com/commwiki/wiki?11597) is set to RwdMasterPage.

Note: Those are the default values for new KBs.  
        `[imagen omitida: wiki id 31203]`

Note: Make sure that [HTML Document Type property](https://wiki.genexus.com/commwiki/wiki?13517) is set to HTML 5.

* Create a Transaction, and apply the Work With Pattern to it : Apply Pattern -> Work With for Web.

As a result of these configuration settings, web transaction default forms, Work With Pattern instances, and prompts, will use the [Abstract Layout](https://wiki.genexus.com/commwiki/wiki?25209).
