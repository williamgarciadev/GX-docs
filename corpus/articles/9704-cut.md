# Cut

Removes the selected data from the object and puts it on the clipboard. The command is unavailable if there is no data currently selected. Cutting data to the clipboard replaces the contents previously stored.

### Shortcuts

`[imagen omitida: wiki id 9706]` and Ctrl+X
