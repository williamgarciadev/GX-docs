# Workflow Tools

The workflow Tools that are shown in GeneXus IDE are:

`[imagen omitida: wiki id 43815]`

* #### [****Deploy workflow runtime****](#Deploy+workflow+runtime)

The deploy of the workflow application is automatic too. But this option allows you to do it manually.

* #### [**Deploy business processes**](#Deploy+business+processes)

**​**It allows forcing the deploy of the business process diagrams into the database.

* #### [**Create business process deploy file**](#Create+business+process+deploy+file)

**​****​**Through this option, a .bpd file is created. It contains the definition of the business process diagrams to impact in the production database. [More Information](https://wiki.genexus.com/commwiki/wiki?18244)

* #### [**Create workflow tables**](#Create+workflow+tables)

**​**The workflow tables creation is integrated with Genexus Build. It executes automatically the first time you make a build or run a diagram. Then the creation can be executed manually.

* #### [**Import from XPDL**](#Import+from+XPDL)

           Through this option, you can import [XPDL](http://www.wfmc.org/standards/xpdl) diagrams to the Knowledge Base.

* #### [**Export to XPDL**](#Export+to+XPDL)

           Through this option, you can export Diagrams to [XPDL](http://www.wfmc.org/xpdl.html) format.

* #### [**Import GXPM Project**](#Import+GXPM+Project)

Through this option, you will be able to import GXPM projects to the Knowledge Base.
