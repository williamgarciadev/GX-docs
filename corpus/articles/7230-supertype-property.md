# Supertype property

Indicates the attribute’s supertype name, if applicable.

### [Scope](#Scope)

**Level:** [Attribute](https://wiki.genexus.com/commwiki/wiki?7240)

### [Description](#Description)

When defining an attribute as a subtype, you must indicate its supertype name in this property.

The [Data Type property](https://wiki.genexus.com/commwiki/wiki?7232), Domain, [Autonumber property](https://wiki.genexus.com/commwiki/wiki?6798), [Value range property](https://wiki.genexus.com/commwiki/wiki?6797), and [Picture Properties Group](https://wiki.genexus.com/commwiki/wiki?6800) of properties are disabled since they are inferred from the attribute indicated in this property.

This property is only valid for attributes and is read-only.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
