# Dashboard Layout property

Layout used to arrange the widgets in the main area of the dashboard.

### [Description](#Description)

Layout used to arrange the [Dashboard widgets](https://wiki.genexus.com/commwiki/wiki?36779). Non filter widgets are placed in the main area of the dashboard. They may be laid out using a series of predefined layout templates:

* Free
* Two columns
* Header + two columns
* Header + two columns + footer
* Three columns
* Header + three columns
* Header + three columns + footer

`[imagen omitida: wiki id 40468]`

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Availability](#Availability)

This property is available since [GeneXus 15 upgrade 12](https://wiki.genexus.com/commwiki/wiki?39737,,).

### [Scope](#Scope)

**Objects:** Dashboard
