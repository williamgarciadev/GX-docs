# GeneXus for SAP Systems - Installation

To add all the features related to GeneXus for SAP System in a GeneXus standard version, you can download and install the GeneXus for SAP System Pack from [GeneXus For SAP Download](http://genexus.com/GeneXus-For-SAP-Download).

Then, execute the setup and select the path of your GeneXus installation main directory.

Press install and you are done!
