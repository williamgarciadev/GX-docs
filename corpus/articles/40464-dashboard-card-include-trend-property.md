# Dashboard Card Include trend property

Specifies whether to include a trend mark for the values or not.

### [Description](#Description)

This property is available when the [Type property](https://wiki.genexus.com/commwiki/wiki?40424) has the [Card](https://wiki.genexus.com/commwiki/wiki?31810) value assigned and it allows setting the trending of the returned data.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Availability](#Availability)

This property is available since [GeneXus 15 upgrade 12](https://wiki.genexus.com/commwiki/wiki?39737,,).

### [Scope](#Scope)

**Objects:** Dashboard
