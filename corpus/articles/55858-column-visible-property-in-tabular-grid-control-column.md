# Column Visible property in Tabular Grid control Column

Indicates whether the column is visible or not.

### [Scope](#Scope)

**Generators:** [Angular](https://wiki.genexus.com/commwiki/wiki?42550)  
**Controls:** [Tabular Grid](https://wiki.genexus.com/commwiki/wiki?54449)

### [Description](#Description)

This property is available when you are positioned in a column of a [Tabular Grid control](https://wiki.genexus.com/commwiki/wiki?54449) included in a [Panel object](https://wiki.genexus.com/commwiki/wiki?24829).

The possible values for this property are:

* **True**: The column is visible to the end user in the Tabular Grid. This is the default value.
* **False**: The column is not visible to the end user in the Tabular Grid.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [Availability](#Availability)

This property is available since [GeneXus 18 Upgrade 6](https://wiki.genexus.com/commwiki/wiki?54240).
