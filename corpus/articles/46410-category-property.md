# Category property

Sets the flow category in order to add it to a group.

### [Scope](#Scope)

**Objects:** [Conversational Flows Instance](https://wiki.genexus.com/commwiki/wiki?37113)

### [Description](#Description)

This property is available for the [Flows](https://wiki.genexus.com/commwiki/wiki?38531) of [Conversational Flows objects](https://wiki.genexus.com/commwiki/wiki?37113) when using the [Conversational Flows Editor](https://wiki.genexus.com/commwiki/wiki?45141).

It allows grouping the flows according to some criteria, defined by the GeneXus user, in relation to the model.

`[imagen omitida: wiki id 46602]`

### [Availability](#Availability)

This property is available since [GeneXus 17](https://wiki.genexus.com/commwiki/wiki?46066,,).
