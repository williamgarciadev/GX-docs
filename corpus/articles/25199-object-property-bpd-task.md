# Object property (BPD Task)

Indicates the Panel object that will be invoked when executing the task from a mobile device.

### [Scope](#Scope)

**Objects:** [Business Process Diagram](https://wiki.genexus.com/commwiki/wiki?16486)  
**Controls:** [Task](https://wiki.genexus.com/commwiki/wiki?17495)

### [Description](#Description)

This property indicates the GeneXus Object for a Native Mobile application to be called when using the GXflow Client and ignored when executing the GXflow Client.

### [Availability](#Availability)

This property is available since [GeneXus 17 upgrade 7](https://wiki.genexus.com/commwiki/wiki?49301,,).
