# Master Page property

Assigns one of the Master Pages defined in the Knowledge Base to a Transaction or Web Panel.

### [Scope](#Scope)

**Objects:** Transaction, Web Panel  
**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [Java](https://wiki.genexus.com/commwiki/wiki?12258)

### [Description](#Description)

All [Transaction object](https://wiki.genexus.com/commwiki/wiki?1908)s and [Web Panel object](https://wiki.genexus.com/commwiki/wiki?6916)s have this property so that you can assign a [Master Page](https://wiki.genexus.com/commwiki/wiki?10348) to them.

If you don't assign an explicit Master Page in this property, it inherits the Master Page set in the [Default Master Page property](https://wiki.genexus.com/commwiki/wiki?11597) (offered at [version level](https://wiki.genexus.com/commwiki/wiki?7860)).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
