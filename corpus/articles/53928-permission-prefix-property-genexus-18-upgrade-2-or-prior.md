# Permission Prefix property (GeneXus 18 Upgrade 2 or prior)

Generates permissions automatically for the Application where the object belongs.

### [Scope](#Scope)

**Objects:** [Transaction](https://wiki.genexus.com/commwiki/wiki?1908), [Business Component](https://wiki.genexus.com/commwiki/wiki?5846), [Procedure](https://wiki.genexus.com/commwiki/wiki?6293), [Data Provider](https://wiki.genexus.com/commwiki/wiki?5270), [Web Panel](https://wiki.genexus.com/commwiki/wiki?6916), [Web Component](https://wiki.genexus.com/commwiki/wiki?1864), [Work With](https://wiki.genexus.com/commwiki/wiki?15974)  
**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917), [Java](https://wiki.genexus.com/commwiki/wiki?12258)

### [Description](#Description)

This property is valid in the context of applications where Authorization is going to be checked automatically using [GAM](https://wiki.genexus.com/commwiki/wiki?14960). That is to say, that [Enable Integrated Security property](https://wiki.genexus.com/commwiki/wiki?14706) is set to Yes and [Integrated Security Level property](https://wiki.genexus.com/commwiki/wiki?15214) is set to "Authorization" value.

In run time, this permission will be checked automatically when the object is being executed.

As it is a prefix, it also allows grouping different objects in the [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836), so as all these objects check the same set of permissions (the objects which have the same prefix).

This property accepts any string which follows the syntax for GeneXus objects names. The default value is the name of the object.

It is available at object level. It applies to the following types of objects:

Objects for WEB applications:

* Web objects with URL access ([Web Panel](https://wiki.genexus.com/commwiki/wiki?6916), [Transactions](https://wiki.genexus.com/commwiki/wiki?1908), [Web Components](https://wiki.genexus.com/commwiki/wiki?1864) with [URL access property](https://wiki.genexus.com/commwiki/wiki?7868) set to Yes).
* [REST Web Services](https://wiki.genexus.com/commwiki/wiki?14573) ([Procedures](https://wiki.genexus.com/commwiki/wiki?6293), [Business Component](https://wiki.genexus.com/commwiki/wiki?5846), [Data Providers](https://wiki.genexus.com/commwiki/wiki?5270) exposed as REST web services).
* Procedures HTTP (main Procedures with [Call protocol property](https://wiki.genexus.com/commwiki/wiki?7947) = HTTP).

Objects for Native Mobile applications:

* [Work With](https://wiki.genexus.com/commwiki/wiki?15974) objects
* [Panel object](https://wiki.genexus.com/commwiki/wiki?24829)

When you specify a permission prefix in any Transaction, a set of permissions are created in [GAM Repository](https://wiki.genexus.com/commwiki/wiki?17568), named:

<prefix>\_FullControl

* <prefix>\_Execute
* <prefix>\_Insert
* <prefix>\_Update
* <prefix>\_Delete

In case of Business Components exposed as a service, the following permissions are created in GAM Repository:

<prefix>\_Services.FullControl

* <prefix>\_Services\_Execute
* <prefix>\_Services\_Insert
* <prefix>\_Services\_Update
* <prefix>\_Services\_Delete

In case of Web Panels, after specifying a permission prefix the following permission is created in GAM Repository:

* <prefix>\_Execute

All those permissions are automatically assigned to all the applications of the [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836).
