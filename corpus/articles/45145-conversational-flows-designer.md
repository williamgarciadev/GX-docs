# Conversational Flows Designer

The Designer mode of the [Conversational Flows Editor](https://wiki.genexus.com/commwiki/wiki?45141) provides an intuitive way to add and edit all the parts of a [Conversational Flows](https://wiki.genexus.com/commwiki/wiki?45141) object in order to create a [Chatbot](https://wiki.genexus.com/commwiki/wiki?38520). It is available by clicking on the Designer tab at the bottom of the Editor.  
  
The Designer editor provides direct access to the actions most commonly executed (such as adding [Flows](https://wiki.genexus.com/commwiki/wiki?28686,,), selecting a [Conversational Object](https://wiki.genexus.com/commwiki/wiki?38189) for the Flow, or adding [User Inputs](https://wiki.genexus.com/commwiki/wiki?38959)).

At the left of the pane, you have all the [Flows](https://wiki.genexus.com/commwiki/wiki?28686,,) of the Conversation Flows object, which can be easily added through the "Add another flow" option.  
Also, for each Flow, the [Conversational Object](https://wiki.genexus.com/commwiki/wiki?38189) (if it exists) is shown clearly in the edit box of the corresponding Flow:

`[imagen omitida: wiki id 45147]`

Selecting a Flow shows its configuration on the right. There, you can view and edit the [Trigger Messages](https://wiki.genexus.com/commwiki/wiki?39067) of the Flow, as well as add, delete or edit the [User Inputs](https://wiki.genexus.com/commwiki/wiki?38959) and the [Responses](https://wiki.genexus.com/commwiki/wiki?39781) of the Flow.

As the following figure shows, each can be expanded to see their details. For example, for the User Input of the Flow, you can edit the [Ask Messages](https://wiki.genexus.com/commwiki/wiki?40217) and see more details using the Advanced mode.

`[imagen omitida: wiki id 45148]`

Take a look at the Advanced mode, where you can edit the [Required Conditions](https://wiki.genexus.com/commwiki/wiki?43693) of the User Input, the [Validation Procedure](https://wiki.genexus.com/commwiki/wiki?10483) and other information related to the User Input configuration.

`[imagen omitida: wiki id 45149]`
