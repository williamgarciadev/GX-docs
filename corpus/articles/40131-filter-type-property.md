# Filter type property

It allows you to configure the filter's type.

### [Values](#Values)

|  |  |
| --- | --- |
| **Collection** | Defines a multi valued filter |
| **Range** | Defines a double value filter |
| **Value** | Defines a single value filter (Default) |

### [Description](#Description)

By default a filter consists of a single value, but you can set a more complex filter using this property:

* **Value**: the filter consists of a single value (see [Value](https://wiki.genexus.com/commwiki/wiki?40495) property).
* **Range**: the filter consists of a lower and upper values (see [Upper value](https://wiki.genexus.com/commwiki/wiki?40135) and [Lower value](https://wiki.genexus.com/commwiki/wiki?40134) properties).
* **Collection**: the filter consists of a collection of values (see [Values](https://wiki.genexus.com/commwiki/wiki?40515) property).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Availability](#Availability)

This property is available since [GeneXus 15 upgrade 12](https://wiki.genexus.com/commwiki/wiki?39737,,).

### [Scope](#Scope)

**Objects:** Dashboard
