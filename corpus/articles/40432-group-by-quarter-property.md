# Group by quarter property

Group date or date-time values by quarter.

### [Description](#Description)

Creates another element in the query by grouping same quarter values together. This property applies only to date or date-time attributes.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Availability](#Availability)

This property is available since [GeneXus 15 upgrade 12](https://wiki.genexus.com/commwiki/wiki?39737,,).

### [Scope](#Scope)

**Objects:** Dashboard
