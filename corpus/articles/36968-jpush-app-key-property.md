# JPush - App Key property

Application Key obtained when registering the application in the JPush developer site.

### [Scope](#Scope)

**Objects:** [Menu](https://wiki.genexus.com/commwiki/wiki?16321), [Panel](https://wiki.genexus.com/commwiki/wiki?24829), [Work With](https://wiki.genexus.com/commwiki/wiki?15974) (Only [Main Objects](https://wiki.genexus.com/commwiki/wiki?5770))  
**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917)

### [Description](#Description)

An application must be registered in the [Jiguang Developer Site](https://www.jiguang.cn/accounts/login/form) to use JPush services. An App Key and a Master Secret are obtained. The App Key value has to be set in this property.

Please check [HowTo: Register an application to use JPush services](https://wiki.genexus.com/commwiki/wiki?37021)

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
