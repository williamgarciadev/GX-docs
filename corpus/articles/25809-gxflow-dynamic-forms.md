# GXflow Dynamic Forms

The Dynamic Forms menu consists of a group of applications whose purpose is to allow the user to create new dynamic form definitions as well as the elements and domains used in them. It also allows making changes to the existing ones.

Dynamic Forms are forms that can be changed in runtime. The purpose of Dynamic forms is to allow completing the [Model Automation](https://wiki.genexus.com/commwiki/wiki?25115) stage without the need for adding a single line of code; in other words, it gives the user the possibility to add a [user task](https://wiki.genexus.com/commwiki/wiki?17499) without programming a new [Web Panel object](https://wiki.genexus.com/commwiki/wiki?6916) or adding a [Transaction object](https://wiki.genexus.com/commwiki/wiki?1908). With Dynamic Forms the user will be able to create or edit forms at runtime, associate them to [Business Process Diagram object](https://wiki.genexus.com/commwiki/wiki?16486)s and execute them. All information associated to them will be saved and mantained in the Workflow tables.  
Dynamic Forms are specially useful in cases when the data from a workflow does not need to be saved in a [Transaction object](https://wiki.genexus.com/commwiki/wiki?1908), because they are only relevant to that instance.

By default, only users with the GXflow Form Designer rol will have access to this menu. Read [GXflow Backend](https://wiki.genexus.com/commwiki/wiki?25704) for details on how to allow other roles to access the Dynamic Forms menu.

`[imagen omitida: wiki id 52070]`

The Dynamic Forms menu has the following components:

* [GXflow Form Definitions](https://wiki.genexus.com/commwiki/wiki?25811)
* [GXflow Elements](https://wiki.genexus.com/commwiki/wiki?25812)
* [GXflow Domains for Dynamic Forms](https://wiki.genexus.com/commwiki/wiki?25813)

For an overview of the GXflow Standard client please refer to the following section: [GXflow Client General Structure](https://wiki.genexus.com/commwiki/wiki?17836).
