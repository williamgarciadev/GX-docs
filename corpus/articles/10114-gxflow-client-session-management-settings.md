# GXflow Client Session Management Settings

This menu allows you to set the session management options.

`[imagen omitida: wiki id 52401]`

**Session Timeout**: It allows specifying the duration of the session of a currently logged user. It may be  1, 2, 8 or 24 hours.

**Reconnect automatically when expiring**: It allows specifying whether when the currently logged user session expires he must be automatically reconnected, thus avoiding the need for a new authentication.
