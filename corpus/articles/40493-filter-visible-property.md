# Filter visible property

When set to False, it hides the filter in the dashboard so its value cannot be modified.

### [Scope](#Scope)

**Objects:** Dashboard

### [Description](#Description)

Sets the desired visibility of the [Dashboard Filter](https://wiki.genexus.com/commwiki/wiki?36779). The default value is True.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Availability](#Availability)

This property is available since [GeneXus 15 upgrade 12](https://wiki.genexus.com/commwiki/wiki?39737,,).
