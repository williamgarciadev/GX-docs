# Row Span property

Allows the cell to expand to occupy more than one row.

### [Scope](#Scope)

**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [Java](https://wiki.genexus.com/commwiki/wiki?12258)  
**Controls:** Attribute/Variable, [Button](https://wiki.genexus.com/commwiki/wiki?6011), [Image](https://wiki.genexus.com/commwiki/wiki?5939), [Text Block](https://wiki.genexus.com/commwiki/wiki?5948), [Canvas](https://wiki.genexus.com/commwiki/wiki?22452), [Flex](https://wiki.genexus.com/commwiki/wiki?40521), [Grid](https://wiki.genexus.com/commwiki/wiki?24817), [Group](https://wiki.genexus.com/commwiki/wiki?6570), [Tab](https://wiki.genexus.com/commwiki/wiki?25623), [Table](https://wiki.genexus.com/commwiki/wiki?6001), [Tabular Grid](https://wiki.genexus.com/commwiki/wiki?54449)

### [Description](#Description)

Enables vertical expansion for any control inside the [Panel](https://wiki.genexus.com/commwiki/wiki?24829)'s layout, allowing it to span across multiple rows as needed.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
