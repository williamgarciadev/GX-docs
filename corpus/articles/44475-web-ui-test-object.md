# Web UI Test object

Defines a sequence of Web User Interface interactions and validations.

Represents a GeneXus [Procedure object](https://wiki.genexus.com/commwiki/wiki?6293) with the ability to control the browser using different [commands](https://wiki.genexus.com/commwiki/wiki?40281), such as opening the browser, clicking or typing over different controls, checking text on panels and values over controls (variables/ attributes), etc.

You can create a Web UI Test object through the [New Object dialog](https://wiki.genexus.com/commwiki/wiki?9931). There, you have to select the Test category, and you are offered to create a Web UI Test object.
