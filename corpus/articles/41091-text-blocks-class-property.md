# Text blocks class property

Class used to style the dashboard text blocks.

### [Scope](#Scope)

**Objects:** Dashboard

### [Description](#Description)

Defines the Theme class to be used to style the dashboard text blocks.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
