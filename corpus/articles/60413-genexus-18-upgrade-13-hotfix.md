# GeneXus 18 Upgrade 13 Hotfix

This hotfix includes important fixes for [GeneXus 18 Upgrade 13](https://wiki.genexus.com/commwiki/wiki?59630) and updates Android libraries required for publishing apps on Google Play.

## [Download](#Download)

<https://www.genexus.com/en/developers/downloadcenter?data=6315;;>

## [Fixes](#Fixes)

The following SACs fixes are included in this hotfix:

* [SAC #60846](https://www.genexus.com/es/developers/websac?data=60846;) – GlobalEvents do not execute if they contain assignments to variables or attributes of type Date or DateTime
* [SAC #60879](https://www.genexus.com/es/developers/websac?data=60879;) – Compilation error in SDT REST interface with two numeric collections
* [SAC #60877](https://www.genexus.com/es/developers/websac?data=60877;) – Android compilation fails when the SciJava repository is down
* [SAC #60857](https://www.genexus.com/es/developers/websac?data=60857;) – JSON with null substructure is not correctly received through API Object
* [SAC #60869](https://www.genexus.com/es/developers/websac?data=60869;) – Duplicated method in .java file generated from SDT
* [SAC #60442](https://www.genexus.com/es/developers/websac?data=60442;) – Issue when sending the Content-Range or Content-Disposition HTTP headers using the httpclient data type
* [SAC #60822](https://www.genexus.com/es/developers/websac?data=60822;) – Android: Records not written to the Offline DB when multiple Procedures are executed concurrently via Submit
* [SAC #60840](https://www.genexus.com/es/developers/websac?data=60840;) – Error “Didn’t find class 'com.genexus.reports.GXReport'” when generating PDFs in Android Offline mode
* [SAC #60898](https://www.genexus.com/es/developers/websac?data=60898;) – Problem with SetEmpty in numeric fields with decimals and picture
* [SAC #60903](https://www.genexus.com/es/developers/websac?data=60903;) – GXflow: Reorgs Folder for Java Oracle Platform is missing
* [SAC #60902](https://www.genexus.com/es/developers/websac?data=60902;) – The barcode scanner library was updated to version 17.3.0 for support of 16 KB pages on Android
* [SAC #60905](https://www.genexus.com/es/developers/websac?data=60905;) – Migrated to Google Play Billing version 7.2.2.11 on Android
* [SAC #61043](https://www.genexus.com/es/developers/websac?data=61043;) – The selected value in the Dynamic Combo Box is lost when exiting and returning to the panel where it is located
