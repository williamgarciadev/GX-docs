# Web Frontend Display Mode property

Defines the developers' preferred display mode for the website.

### [Values](#Values)

|  |  |
| --- | --- |
| **Browser** | Opens the application in a new browser tab or a new window, depending on the browser and platform. |
| **Fullscreen** | Opens the web application without showing any of the browser's user interface controls and takes up the entire available viewing area. |
| **Minimal** | Opens the web application like a standalone app, but it will have minimal interface elements to control navigation. These elements may vary depending on the browser. |
| **Standalone** | Opens the web application like a standalone app. The app runs in its own window, separate from the browser, and hides standard browser UI elements such as the URL bar. |

### [Scope](#Scope)

**Objects:** [Menu](https://wiki.genexus.com/commwiki/wiki?16321), [Panel](https://wiki.genexus.com/commwiki/wiki?24829), [Work With](https://wiki.genexus.com/commwiki/wiki?15974) (Only [Main Objects](https://wiki.genexus.com/commwiki/wiki?5770))  
**Generators:** [Angular](https://wiki.genexus.com/commwiki/wiki?42550)

### [Description](#Description)

This property is available when the [Web Frontend Application property](https://wiki.genexus.com/commwiki/wiki?54265) is set to Progressive.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [Availability](#Availability)

This property is available since [GeneXus 18 Upgrade 3](https://wiki.genexus.com/commwiki/wiki?53853).
