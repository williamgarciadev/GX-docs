# Botmaker Security Token property

Botmaker Security Token used in the webhook.

### [Scope](#Scope)

**Objects:** [Conversational Flows Instance](https://wiki.genexus.com/commwiki/wiki?37113)

### [Description](#Description)

Botmaker allows you to create a security token, which is sent as a header in each request to the configured webhook.

This property is visible in the WhatsApp section if the chosen partner is Botmaker. This token is found in the configuration section of the webhook in Botmaker and must be the same as in the property to be configured in GeneXus. That is, both can also be empty if desired.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Availability](#Availability)

This property is available since [GeneXus 17 Upgrade 10](https://wiki.genexus.com/commwiki/wiki?49971,,).
