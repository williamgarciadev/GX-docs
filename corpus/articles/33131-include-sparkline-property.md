# Include Sparkline Property

Include Sparkline Property it's a [QueryViewer control](https://wiki.genexus.com/commwiki/wiki?9075) and a [Query object](https://wiki.genexus.com/commwiki/wiki?9026) property. It's only available when the [Type property in QueryViewer control](https://wiki.genexus.com/commwiki/wiki?19612) has the [Card](https://wiki.genexus.com/commwiki/wiki?31810) value assigned and allows displaying (under the Card indicator) a Sparkline chart showing the indicator's evolution.

### [Values](#Values)

|  |  |
| --- | --- |
| **False** | The Sparkline chart it's not displayed. This is the default value. |
| **True** | A Sparkline chart it's displayed under the Card's indicator. |

### [Description](#Description)

If the Query object includes a Date or DateTime attribute, a Sparkline chart can be calculated and shown by setting the Include Sparkline Property in True:

`[imagen omitida: wiki id 33133]`

The period displayed in the chart it's determined by the query's structure (this means that all the returned data define it).

`[imagen omitida: wiki id 33134]`
