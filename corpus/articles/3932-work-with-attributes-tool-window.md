# Work With Attributes Tool window

By selecting **View > Work With Attributes** from the GeneXus main menu, you can manage all the attributes defined in your [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836), as well as filter and work with them.

`[imagen omitida: wiki id 58641]`

Once in the Work With Attributes Tool window, if you click the More button, an additional filter by object appears as shown below:

`[imagen omitida: wiki id 58642]`

The attributes shown as a result of your search can be selected (with both single and multiple selections) and dragged to an open object.

Right-clicking on a specific attribute or a multiple selection opens a contextual menu with various actions available. This menu provides additional options for working with the selected attributes:
