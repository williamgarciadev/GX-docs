# Type property in Query Element

Defines the Output type used.

### [Values](#Values)

|  |  |
| --- | --- |
| **Axis** | To slice and dice the data. |
| **Datum** | It contains the relevant information provided by the query. |

### [Scope](#Scope)

**Objects:** [Query](https://wiki.genexus.com/commwiki/wiki?9026)  
**Generators:** [Java](https://wiki.genexus.com/commwiki/wiki?12258), .NET, [.NET Core](https://wiki.genexus.com/commwiki/wiki?38604)

### [Description](#Description)

Defines how a [query element](https://wiki.genexus.com/commwiki/wiki?19788) will be displayed; it can be set as an [Axis](https://wiki.genexus.com/commwiki/wiki?47159) or directly as a Datum value.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies both at run-time and at design-time.
