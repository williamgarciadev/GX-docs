# AddMinutes method

Adds minutes to a DateTime attribute or variable.

### [Syntax](#Syntax)

*Date* | *DateTime***.AddMinutes(***Numeric-expression***)**

**Where:**

*Date* | *DateTime*Is an attribute or variable based on the Date/DateTime data type, to which the method will add a certain number of minutes.

*Numeric-expression*  
   Is a Numeric [expression](https://wiki.genexus.com/commwiki/wiki?51320,,) that indicates the number of minutes to be added to the *Date | DateTime.*

**Type Returned**:  
DateTime

### [Scope](#Scope)

**Data Types:**

[DateTime](https://wiki.genexus.com/commwiki/wiki?7370)

### [Samples](#Samples)

```
&AppointmentDateTime.AddMinutes(10)  // Adds 10 minutes to &AppointmentDateTime variable
```
