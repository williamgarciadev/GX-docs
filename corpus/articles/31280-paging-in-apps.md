# Paging in apps

When the amount of data to be displayed by a grid (or free style grid) is not manageable, the user needs to view a subset of sorted data in the screen, and have some paging controls to go to the next and previous pages.

In GeneXus Web Applications, paging can be automatically generated. See [Automatic paging in Grid control](https://wiki.genexus.com/commwiki/wiki?6086).

Otherwise, if you want to program the paging controls, it can be done using the [NextPage](https://wiki.genexus.com/commwiki/wiki?8769), [PreviousPage](https://wiki.genexus.com/commwiki/wiki?8770), [LastPage](https://wiki.genexus.com/commwiki/wiki?8771) and [FirstPage method](https://wiki.genexus.com/commwiki/wiki?8768) methods. Follow the [Grid paging on the Web](https://wiki.genexus.com/commwiki/wiki?6064) guide for more information on this topic.

In GeneXus Web and SD apps, paging can follow the [Infinite scrolling](https://wiki.genexus.com/commwiki/wiki?31231) pattern.
