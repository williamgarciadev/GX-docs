# Label caption property

The Label caption property is available for all the attributes and variables in the [Abstract Layout](https://wiki.genexus.com/commwiki/wiki?25209) whose Label position property = Left.

It allows establishing the label contents of the variable or attribute. It's a design and runtime property.

### [Syntax](#Syntax)

Control.Caption = Exp

### [Where:](#Where%3A+)

Control  
    Is the name of the control inserted on the [Abstract Layout](https://wiki.genexus.com/commwiki/wiki?25209) form.

Exp   
    Is the text that will be displayed.

### [Examples](#Examples)

```
ArticleName.Caption = &value
```
