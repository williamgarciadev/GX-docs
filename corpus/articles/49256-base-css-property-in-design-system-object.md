# Base CSS property in Design System Object

Specifies the CSS library to include as the base style.

### [Values](#Values)

|  |
| --- |
| **None** |
| **Bootstrap v3** |
| **Bootstrap v3 RTL** |
| **Bootstrap v5** |

### [Scope](#Scope)

**Objects:** [Design System](https://wiki.genexus.com/commwiki/wiki?47375)  
**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Java](https://wiki.genexus.com/commwiki/wiki?12258)

### [Description](#Description)

This property allows you to select which CSS library you want to base your Design System on.

The values you can select are pre-defined by GeneXus. If you want to base your Design System on another library, then use the [Import style rule](https://wiki.genexus.com/commwiki/wiki?49346).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#com.gxwiki.wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, Build any object.
