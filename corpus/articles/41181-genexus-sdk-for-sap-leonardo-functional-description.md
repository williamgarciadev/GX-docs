# GeneXus SDK for SAP Leonardo: Functional Description

GeneXus SDK for SAP Leonardo Machine Learning Foundation includes the next services(API) :

1. [Optical Character Recognition (OCR)](https://wiki.genexus.com/commwiki/wiki?41767)
2. [Scene Text Recognition](https://wiki.genexus.com/commwiki/wiki?41774)
3. [Image Classification](https://wiki.genexus.com/commwiki/wiki?41782)
4. [Image Feature Extraction](https://wiki.genexus.com/commwiki/wiki?41789)
5. [Similarity Scoring](https://wiki.genexus.com/commwiki/wiki?41791)
6. [Product Text Classification](https://wiki.genexus.com/commwiki/wiki?41792)
7. [Face Detection](https://wiki.genexus.com/commwiki/wiki?41794)
8. [Language Detection](https://wiki.genexus.com/commwiki/wiki?41808)
9. [Translation](https://wiki.genexus.com/commwiki/wiki?41810)

To use services that are not included on this SDK, follow the instructions on [GeneXus SDK for SAP Leonardo: Importing a ML service](https://wiki.genexus.com/commwiki/wiki?41823).
