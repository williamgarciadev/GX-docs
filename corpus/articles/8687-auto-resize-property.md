# Auto Resize property

Indicates whether the control will keep the default size.

### [Values](#Values)

|  |
| --- |
| **False** |
| **True** |

### [Scope](#Scope)

**Controls:** [Grid](https://wiki.genexus.com/commwiki/wiki?24817)

### [Description](#Description)

Default value: True.

This property applies to [Transaction Web Layout](https://wiki.genexus.com/commwiki/wiki?8057) or [Web Panel Web Layout](https://wiki.genexus.com/commwiki/wiki?8132) [Grid](https://wiki.genexus.com/commwiki/wiki?24817)s.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
