# CC Property

This property indicates a message's list of secondary recipients (Carbon Copy).

### [Syntax](#Syntax)

**&***DataType***.CC**  
  
**Type Returned:**   
MailRecipientCollection

### [Description](#Description)

This property is read only, so it cannot be assigned.

### [Scope](#Scope)

**Extended Data Types:** [MailMessage](https://wiki.genexus.com/commwiki/wiki?6925)  
**Languages:** .NET, Java, Ruby (up to GeneXus X Evolution 3), Visual FoxPro (up to GeneXus X Evolution 3)
