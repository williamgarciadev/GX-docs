# Significant object name length property

Sets the number of significant characters to ensure the uniqueness of the GeneXus Object names.

### [Scope](#Scope)

**Generators:** Cobol, RPG

### [Description](#Description)

This property is available in the Properties window of the Knowledge Base [Versions](https://wiki.genexus.com/commwiki/wiki?5680,,).

### [[Values](https://wiki.genexus.com/commwiki/wiki?7250)](#https%3A%2F%2Fwiki.genexus.com%2Fcommwiki%2Fservlet%2Fwiki%3F7250%2CSignificant%2BObject%2BName%2BLength%2BProperty%23Values+Values)

Number of characters in Object names:  
  
**Default Value =** 128 (the minimum value is 6 characters and the maximum value is 128 characters).

**Note:**

When using [Cobol](https://wiki.genexus.com/commwiki/wiki?13999), [Visual FoxPro](https://wiki.genexus.com/commwiki/wiki?10302,,) (dbfs) or [RPG](https://wiki.genexus.com/commwiki/wiki?14000,,) Generator, the maximum value is 7.

Remember that there can't be two Objects with the same name, which is why it is recommended that the assigned value is really significant.
