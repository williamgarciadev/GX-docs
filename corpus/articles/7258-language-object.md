# Language object

Translates the texts of your application into a certain language.

### [Description](#Description)

Every [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836) automatically contains predefined **Language objects** that can be used for translation.

You can view the predefined **Language objects** in the [KB Explorer](https://wiki.genexus.com/commwiki/wiki?3210) below the Localization node, which in turn is below the Customization node:

`[imagen omitida: wiki id 54439]`

If the language you want your application to be translated into is not predefined, you can create a new **Language object** through the [New object dialog](https://wiki.genexus.com/commwiki/wiki?9931).

A Language object contains a list of texts and messages (some of them predefined by GeneXus and others defined by you in single or double quotes in [Msg](https://wiki.genexus.com/commwiki/wiki?6854) and [Error](https://wiki.genexus.com/commwiki/wiki?6852) rules, Sources, Events, Controls, etc.). In other words, all translatable texts appear in the list so that you can complete their translations for the respective language.

In addition, this object has some Properties that you may set (like the [Date format property](https://wiki.genexus.com/commwiki/wiki?8904) for the language).

Also, it has a Documentation section so that you can describe information about the Language you are creating.

For information on how to translate your application and use the Language object, see [GeneXus Application Localization](https://wiki.genexus.com/commwiki/wiki?6330).
