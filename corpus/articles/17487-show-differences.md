# Show Differences

When a working copy Knowledge Base is connected to a GeneXus Server repository, the *Show differences* Team Development contextual menu is enabled to show the difference between the object latest revision against the revision corresponding to the last [update operation](https://wiki.genexus.com/commwiki/wiki?10627) performed from this client that includes the object.
