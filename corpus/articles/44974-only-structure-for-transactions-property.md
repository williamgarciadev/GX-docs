# Only Structure For Transactions property

When exporting Transactions, if this property is set to True, only their structures are included in the XPZ file (forms, variables, etc. are not included).

### [Values](#Values)

|  |
| --- |
| **False** |
| **True** |

### [Scope](#Scope)

**Level:** [Knowledge Manager -> Export](https://wiki.genexus.com/commwiki/wiki?3942)

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Availability](#Availability)

This property is available since [GeneXus 16 upgrade 7](https://wiki.genexus.com/commwiki/wiki?44454,,).
