# Table Main color property

Sets the Main color for the control layout and dialogs.

### [Description](#Description)

Defines the Main color for the control layout and associated Table dialogs.

You can find this definition in the Design System QueryViewer (which is located in [GeneXusReporting module](https://wiki.genexus.com/commwiki/wiki?51178)) with the token name gxqv-color-main. The default is the primary color of the [Unanimo Design System](https://wiki.genexus.com/commwiki/wiki?52175).

`[imagen omitida: wiki id 54144]`

You can change the main color. To do so, you only need to overwrite this token in its Design System Object that is associated with the KB—by default, the associated color is the primary color of Unanimo.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
