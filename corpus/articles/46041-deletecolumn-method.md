# DeleteColumn method

Deletes the column indicated.

### [Syntax](#Syntax)

&ExcelSpreadSheet**.DeleteColumn(**Column**)**

**Where:**  
*Column*  
     Is the column number that will be deleted.

**Type Returned:**  
Boolean

### [Scope](#Scope)

**Extended Data Types:** [ExcelSpreadSheet data type](https://wiki.genexus.com/commwiki/wiki?46040)  
**Generators:**

[Java](https://wiki.genexus.com/commwiki/wiki?12258)

### [Description](#Description)

It deletes the column indicated from the Excel sheet. It returns True if the column is deleted successfully.
