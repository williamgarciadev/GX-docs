# Order None clause

Allows to specify no [navigation order](https://wiki.genexus.com/commwiki/wiki?6075) for the [For Each command](https://wiki.genexus.com/commwiki/wiki?24744) or [Data provider group](https://wiki.genexus.com/commwiki/wiki?25082).

This clause prevents GeneXus from choosing the order of the attributes of the base table’s primary key by default, and makes it use an undefined navigation order.

### [Syntax](#Syntax)

**Order none**

### [Scope](#Scope)

Commands: [For Each command](https://wiki.genexus.com/commwiki/wiki?24744), [Data Provider Group statement](https://wiki.genexus.com/commwiki/wiki?25082)
