# HowTo: Compile Android's FlexibleClient

This document explains how to compile Android's FlexibleClient and provides a brief overview about it, in case you need to add to your app developed with GeneXus for Android some extra functionality that is not provided by GeneXus or cannot be extended using [Extension Libraries](https://wiki.genexus.com/commwiki/wiki?33546).

**Note**: It is essential to notice that the first approach to extend the out-of-the-box functionality should be adding an extension library.

### [Steps to change and compile the Flexible client](#Steps+to+change+and+compile+the+Flexible+client)

1. Go to the [Download Center](HTTP://genexus.com/download) and search for 'Flexible Client Sources'
2. Download the Flexible Client Sources corresponding to your GeneXus version
3. Unzip the downloaded file and follow the instructions in the README.MD

If you get into trouble, refer to [Building Android FlexibleClient Troubleshooting](https://wiki.genexus.com/commwiki/wiki?43511,,).
