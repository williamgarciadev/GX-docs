# Copy method

Creates a Copy of the current Excel worksheet.

### [Syntax](#Syntax)

**&***VarBasedOnExcelWorksheet***.Copy*****(**newName***)**  
  
**Where:**  
  
*newName*  
    New value to name the copy of the Excel worksheet.

**Type Returned:**   
Boolean

### [Scope](#Scope)

**Extended Data Types:** [ExcelWorksheet](https://wiki.genexus.com/commwiki/wiki?46080)  
**Generators:** 
[Java](https://wiki.genexus.com/commwiki/wiki?12258)

### [Description](#Description)

This method creates a copy of the current Excel worksheet with the name defined in newName.
