# Rotation Field Specifier property

Indicates the SDT field used to determine the item's rotation in an Image Map control.

### [Scope](#Scope)

**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917)  
**Controls:** [Grid](https://wiki.genexus.com/commwiki/wiki?24817) (Control Type: [Image Map](https://wiki.genexus.com/commwiki/wiki?17823))

### [Description](#Description)

This property is only available when the [Rotation Attribute property](https://wiki.genexus.com/commwiki/wiki?42201) is set to an attribute or variable based on a [Structured Data Type (SDT) object](https://wiki.genexus.com/commwiki/wiki?10021).

The value of the Rotation Field Specifier indicates which field of the SDT contains the rotation angle (in degrees, counter-clockwise) to be applied to the Image Map control in the Grid.

`[imagen omitida: wiki id 42480]`

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#com.gxwiki.wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)
