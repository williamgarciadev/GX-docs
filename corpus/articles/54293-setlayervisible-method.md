# SetLayerVisible method

Shows or hides a given layer using its identifier (of character type) in a [Panel](https://wiki.genexus.com/commwiki/wiki?24829) Grid whose [Control Type property](https://wiki.genexus.com/commwiki/wiki?9550) is set to Maps.

### [Syntax](#Syntax)

GridControlName**.SetLayerVisible**(LayerId, Visible)  
  
**Where:**

*GridControlName*  
   Grid control name whose Control Type property is set to Maps.

*LayerId*  
    Layer Identifier based on the character data type.

*Visible*  
    Boolean value. When True, the Layer is shown. Otherwise, it is hidden.
