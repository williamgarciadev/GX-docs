# Work With List Node

The objective of the List Node is to show a list of the data related to the Transaction to which the pattern has been applied.

From the Work With List Node, a [Panel object](https://wiki.genexus.com/commwiki/wiki?24829) will be generated containing the following:

* A Grid with the Transaction attributes
* Orders and filters.
