# Flow of a Conversational instance

The Flow node is the main element of [Conversational Flows object](https://wiki.genexus.com/commwiki/wiki?37113). It's associated to an [intent](https://wiki.genexus.com/commwiki/wiki?38949) of the conversation.

Greetings and Hello World are Flows generated automatically when you define a new Conversational Flows instance.

`[imagen omitida: wiki id 38934]`

The Flow node has two main children:

* [Chatbot User Input](https://wiki.genexus.com/commwiki/wiki?38959)
* [Chatbot Response](https://wiki.genexus.com/commwiki/wiki?39781)  
    
  `[imagen omitida: wiki id 39780]`

You can add multiple Flow nodes. This node is mapped to the [Artificial Intelligence](https://en.wikipedia.org/wiki/Artificial_intelligence) provider as the representation of an intent.

In Watson, you can see the Dialog defined in the Watson workspace. Each Flow of the Conversational Flows instance is represented by a node in the Dialog.
