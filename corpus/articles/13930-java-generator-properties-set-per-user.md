# Java Generator Properties set per User

There is a group of properties (not logically grouped) that allows establishing a custom configuration per user for a given KB.

The following is a list of properties that are set per Knowledgebase User.

The values set in these properties may change per User and that is to cover the following Scenario: A [KB shared over the network](https://wiki.genexus.com/commwiki/wiki?8277,,) by different users that want to prototype on different web servers (each one in it's own machine).
