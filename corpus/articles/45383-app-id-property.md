# App Id property

Application ID provided by WeChat to use with WeChat Pay and WeChat Login.

### [Scope](#Scope)

**Objects:** [Menu](https://wiki.genexus.com/commwiki/wiki?16321)  
**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917)

### [Description](#Description)

Associated to the AppID property provided by [WeChat](https://open.weixin.qq.com/) to use with:

* [WeChat Pay API](https://wiki.genexus.com/commwiki/wiki?37322)
* [GAM - WeChat Authentication type](https://wiki.genexus.com/commwiki/wiki?45037)

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, Build any object.
