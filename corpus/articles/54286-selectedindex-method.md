# SelectedIndex method

Returns the currently selected index.

## [Syntax](#Syntax)

GridControlName.**SelectedIndex(****)**

**Where:**

*GridControlName*  
     Is the name of the grid control.

**Type Returned:** Numeric

### [Description](#Description)

The indexes correspond to the order in which the pins were loaded. The first pin loaded corresponds to index 1, the second pin entered corresponds to index 2, and so on.
