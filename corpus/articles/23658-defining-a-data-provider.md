# Defining a Data Provider

The main way to define a [Data Provider object](https://wiki.genexus.com/commwiki/wiki?5270) is to define the SDT ([Structured Data Type](https://wiki.genexus.com/commwiki/wiki?10021)) needed, and then define the Data Provider's structure with it (by dragging and dropping the SDT, or by using it as a template). The example below shows how to do it:

[Example: 'CustomersProvider' Data Provider](https://wiki.genexus.com/commwiki/wiki?6310)

Also, as of [GeneXus Tilo Beta 2](https://wiki.genexus.com/commwiki/wiki?23074,,) it is possible to define the Data Provider structure first, and then let GeneXus infer and create the SDT with the structure necessary. See how it is done in this example:

[HowTo: Use the Infer Structure property of a Data Provider](https://wiki.genexus.com/commwiki/wiki?23651)
