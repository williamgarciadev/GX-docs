# GAM - Create tables option

This is a menu option: Tools -> GAM -> Create tables.

Forces the creation of [GAM](https://wiki.genexus.com/commwiki/wiki?14960) tables, initializes metadata in those tables, and registers the applications of the knowledge base in GAM database.
