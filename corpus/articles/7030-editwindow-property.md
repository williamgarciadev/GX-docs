# EditWindow Property

This property is used to indicate whether or not the message edit window will be shown before sending the message.

#### [Syntax](#Syntax)

**&***DataType***.EditWindow**  
  
**Type Returned:**   
Numeric

### [Values](#Values)

|  |  |
| --- | --- |
| **0** | The message will be sent without user interaction. This is the default value. |
| **1** | The edit window of the message to be sent will be shown every time the *Send* property is invoked. |

### [Scope](#Scope)

**Extended Data Types:** [MAPISession](https://wiki.genexus.com/commwiki/wiki?6935), [OutlookSession](https://wiki.genexus.com/commwiki/wiki?6936)
