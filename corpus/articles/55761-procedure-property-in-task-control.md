# Procedure property in Task Control

Indicates the GeneXus Procedure associated with a Task.

### [Scope](#Scope)

**Controls:** [Task](https://wiki.genexus.com/commwiki/wiki?17495)

### [Description](#Description)

This property allows setting the GeneXus Procedure object that will be invoked upon executing the [Task](https://wiki.genexus.com/commwiki/wiki?17495) whose [Type property](https://wiki.genexus.com/commwiki/wiki?11464) = Script.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
