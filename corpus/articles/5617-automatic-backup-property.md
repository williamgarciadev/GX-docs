# Automatic Backup property

Controls whether a backup is made before importing.

### [Values](#Values)

|  |
| --- |
| **False** |
| **True** |

### [Description](#Description)

Default value: True.

Backups are always a good way of recovering from errors. Experience tells us that importing is a common source of errors (inconsistent Export files, missing objects, etc.).

The backup process consist in creating a [Frozen Version](https://wiki.genexus.com/commwiki/wiki?5681) with the status of the current [Development Version](https://wiki.genexus.com/commwiki/wiki?5684), which will be visible and available to make a [Revert operation](https://wiki.genexus.com/commwiki/wiki?5685,,) in the [Knowledge Base Versions Tool Window](https://wiki.genexus.com/commwiki/wiki?5687).

#### [Scope](#Scope)

**Action:** [Import option](https://wiki.genexus.com/commwiki/wiki?3179)
