# Business Process Documents property

It allows determining which documents will be associated with the process through a dialog that shows all the documents defined on the Knowledge Base.

### [Description](#Description)

By clicking this `[imagen omitida: wiki id 10942]` button this dialog appears:

`[imagen omitida: wiki id 10943]`

Then clicking the same button over the lines the dialog that shows the knoweledge base documents definition will be shown:

`[imagen omitida: wiki id 10944]`

Then the process can be propagable or not (using "share" option), this means that the documents definitions will applied for the subprocess or not.
