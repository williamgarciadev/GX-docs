# Custom Chatbot Definition property

Selects a custom Data Provider for the Chatbot Definition.

### [Scope](#Scope)

**Objects:** [Conversational Flows Instance](https://wiki.genexus.com/commwiki/wiki?37113)

### [Description](#Description)

The Custom Chatbot Definition property is available for [Scripted Chatbots](https://wiki.genexus.com/commwiki/wiki?45151); that is, when the [NLP Provider property](https://wiki.genexus.com/commwiki/wiki?38931) is set to None.

It allows selecting a Data Provider (its [Output property](https://wiki.genexus.com/commwiki/wiki?41037) must be ChatbotStruct). The purpose of this property is to allow changing at runtime the [Conversational Flows object](https://wiki.genexus.com/commwiki/wiki?37113) to be used (mostly for multi-company applications).

For more information, see [Multi-Tenant Scripted Chatbots](https://wiki.genexus.com/commwiki/wiki?45526,,).

### [Availability](#Availability)

This property is available since [GeneXus 16 upgrade 10](https://wiki.genexus.com/commwiki/wiki?45624,,).
