# Disambiguation Cancellation Message property

Specifies the cancellation message for disambiguation.

### [Scope](#Scope)

**Objects:** [Conversational Flows Instance](https://wiki.genexus.com/commwiki/wiki?37113)

### [Description](#Description)

Allows defining the message that will be displayed to the user in the event that the options presented are not satisfactory. It represents the "None of the above" option when a disambiguation event occurs.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Availability](#Availability)

This property is available since [GeneXus 17 upgrade 3](https://wiki.genexus.com/commwiki/wiki?47659,,).
