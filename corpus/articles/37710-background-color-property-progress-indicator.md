# Background Color property (Progress Indicator)

Indicates the background color that will be used for a Progress Indicator control

### [Description](#Description)

The background color of a [Progress Indicator User Control](https://wiki.genexus.com/commwiki/wiki?31275) control can be set using this property.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply changes made by this property, do a Build All.

### [Availability](#Availability)

This property is available since [Genexus 15 Upgrade 10](https://wiki.genexus.com/commwiki/wiki?38023,,).

### [Scope](#Scope)

**Objects:** Theme for Smart Devices  
**Platforms:** Smart Devices(Android, IOS)
