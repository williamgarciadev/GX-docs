# Change Password Object for SD property

Specifies which will be the object which will be automatically executed when the user password expires.

### [Scope](#Scope)

**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917)  
**Level:** [Version](https://wiki.genexus.com/commwiki/wiki?7860)

### [Description](#Description)

The user password expires depending on the value of the property "Period change password (days)" of the [GAM Security Policies](https://wiki.genexus.com/commwiki/wiki?18521) assigned to the user.

The values for this property are any object for Native Mobile applications. The default value is "(none)".

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
