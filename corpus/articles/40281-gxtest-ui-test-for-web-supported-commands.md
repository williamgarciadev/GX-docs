# GXtest UI Test for Web - Supported Commands

This list of GXtest commands is designed to control test execution over the browser (on the desktop and mobile OS). This is achieved using an adaptation layer (External Object) that wraps the WebDriver protocol.

This actions to handle test automation over browsers can be grouped into 5 categories:

## [Driver and Browser Automation](#Driver+and+Browser+Automation)

[WebDriver](https://wiki.genexus.com/commwiki/wiki?41690): Start and end test sessions (locally or remote) using Web Driver protocol.

[Browser](https://wiki.genexus.com/commwiki/wiki?41616): Handle window size, take screenshots, navigations (back, refresh, forward), etc.

[Waits](https://wiki.genexus.com/commwiki/wiki?41633): To wait for specific elements to be present (or visible) on the webpage.

[Timeouts](https://wiki.genexus.com/commwiki/wiki?41632): To set timeout values (explicit, implicit, and page load).

## [Mouse and Keyboard actions](#Mouse+and+Keyboard+actions)

[Click](https://wiki.genexus.com/commwiki/wiki?41647): Send click and double click events for controls.

[Type](https://wiki.genexus.com/commwiki/wiki?41649): For text typing into different controls (after clearing the current text)

[Select](https://wiki.genexus.com/commwiki/wiki?41650): For choosing options on combo boxes

[Keystroke](https://wiki.genexus.com/commwiki/wiki?41651): For sending keys to different controls.

[Mouse Move](https://wiki.genexus.com/commwiki/wiki?41653): To move the mouse pointer to a specific position.

[Edit Content](https://wiki.genexus.com/commwiki/wiki?41652): To edit content of special HTML5 controls.

[File Upload](https://wiki.genexus.com/commwiki/wiki?45868): To upload files.

## [Validations](#Validations)

[Control Presence](https://wiki.genexus.com/commwiki/wiki?45802): To check the presence of a control.

[Control Enabling](https://wiki.genexus.com/commwiki/wiki?45803): To check if a control is enabled.

[Control Visibility](https://wiki.genexus.com/commwiki/wiki?45804): To check if a control is visible.

[Control Focus](https://wiki.genexus.com/commwiki/wiki?45805): To check if a control has the focus.

[Appear Text](https://wiki.genexus.com/commwiki/wiki?45238): To check if a text appears on the web page.

## [Text, Values and Assertions](#Text%2C+Values+and+Assertions)

[Get Text](https://wiki.genexus.com/commwiki/wiki?41680): To get text from controls

[Get Value](https://wiki.genexus.com/commwiki/wiki?41681): To get values from controls

[Assertions](https://wiki.genexus.com/commwiki/wiki?41682): Combined commands to make validations over different text, values, browser title, or any data.

[Verify](https://wiki.genexus.com/commwiki/wiki?45806): Works like an assertion of a boolean value, but can make a web test stop its execution (default behavior), and take screenshots.

## [Forms, Frames, Alerts, and Windows](#Forms%2C+Frames%2C+Alerts%2C+and+Windows)

[Windows / Tabs](https://wiki.genexus.com/commwiki/wiki?41683): To manage current windows / tabs working on.

[Form Submit](https://wiki.genexus.com/commwiki/wiki?41684): To submit forms

[Frames](https://wiki.genexus.com/commwiki/wiki?41685): To choose frames to work with.

[Alerts](https://wiki.genexus.com/commwiki/wiki?41686): To handle Javascript Alerts / Messages / Prompts
