# WorkflowError Data Type

The error Data Type allows managing the errors occurring on interacting with the other object types, and it is provided by the [Workflow API](https://wiki.genexus.com/commwiki/wiki?51350).

### [Properties](#Properties)

|  |  |  |  |
| --- | --- | --- | --- |
| **Property** | **Type** | **Access** | **Description** |
| Code | Numeric | Read | Returns zero if the operation was succesfull or other value if not. |
| Message | Character | Read | Error Message |
