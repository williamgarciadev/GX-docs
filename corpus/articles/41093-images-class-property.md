# Images class property

Class used to style the dashboard images.

### [Scope](#Scope)

**Objects:** Dashboard

### [Description](#Description)

Defines the Theme class to be used to style the dashboard images.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
