# Exposed name property

It is the name with which the data type is published in the WSDL for Web Services.

### [Description](#Description)

The default value is the same as the [Structured Data Type (SDT) object](https://wiki.genexus.com/commwiki/wiki?10021) name.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Scope](#Scope)

**Objects:** Structured Data Type  
**Platforms:** Web(.Net, Java)
