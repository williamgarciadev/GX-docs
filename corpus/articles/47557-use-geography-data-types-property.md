# Use Geography Data Types property

Indicates whether Geography Data Types are used in your mobile application (to include the necessary library).

### [Values](#Values)

|  |
| --- |
| **False** |
| **True** |

### [Scope](#Scope)

**Objects:** [Panel](https://wiki.genexus.com/commwiki/wiki?24829), [Menu](https://wiki.genexus.com/commwiki/wiki?16321)  
**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453)

### [Description](#Description)

This property is available only for [Panel object](https://wiki.genexus.com/commwiki/wiki?24829)s and [Menu object](https://wiki.genexus.com/commwiki/wiki?16321)s set as [Main](https://wiki.genexus.com/commwiki/wiki?5770).

By setting it to True, the additional libraries to draw geographies will be included.

The size of the Android Package (apk) will be increased.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

|  |
| --- |
| To apply the corresponding changes when the property value is configured, Build a main object. |

### [Availability](#Availability)
