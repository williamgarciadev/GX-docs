# How does GeneXus Super App work?

For a Super App to work, it needs a component for enabling other applications to load dynamically within the host application.

GeneXus has an essential technology to allow any Native Mobile application the possibility of dynamically loading Mini Apps. This component is called Super App Render (a.k.a. GeneXus Flexible Client).

What the Super App Render does is to render pure Native Mobile applications ―similar to the OS― that are not applications running inside a browser, although it also supports loading web-type Mini Apps.

Moreover, if you already have an application, **not developed with GeneXus**, that you wish to transform into a Super App, you may incorporate the Super App Render technology in your current application. Thus, you can also **turn any Native Mobile application into a Super App** and benefit from all its advantages: dynamic application loading, integration with partners, incremental development, and more. See <https://github.com/genexus-books/gx-super-app> for more details and samples.

For more information, contact us [here](https://www.genexus.com/en/products/super-apps).
