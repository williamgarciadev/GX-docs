# Dashboard Widget Show data labels in property

Specifies whether the data elements in a pivot table are shown in the Columns or Rows area. Only meaningful for two or more data elements.

### [Values](#Values)

|  |  |
| --- | --- |
| **Columns area** | Show the Data elements as columns. |
| **Rows area** | Show the Data elements as rows. |

### [Description](#Description)

When using two or more data elements in a query (using a PivotTable), you can specify whether they are presented in the Columns or Rows area.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
