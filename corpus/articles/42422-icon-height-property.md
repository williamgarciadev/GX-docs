# Icon Height property

Determines the default icon height for markers on Map control.

### [Scope](#Scope)

**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Java](https://wiki.genexus.com/commwiki/wiki?12258)  
**Controls:** [Map](https://wiki.genexus.com/commwiki/wiki?5029)

### [Description](#Description)

Each marker has an associated icon. This property determines the default icon height for markers in the Map control.
