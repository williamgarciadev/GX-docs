# ErrDisplay Property

It indicates whether error messages will be displayed or not.

### [Syntax](#Syntax)

**&***DataType***.ErrDisplay**  
  
**Type Returned:**   
Numeric  
  
**Where:**  
*DataType*  
Is the variable name of the ExcelDocument, MAPISession, OutlookSession, POP3Session, SMTPSession or WordDocument type.

### [Values](#Values)

**1:** Specifies that the message displayed to warn the user of an error occurrence will include the error’s text.  
**0:** Otherwise.  
  
**Default Value** = 0

### [Scope](#Scope)

**Extended Data Types:** [ExcelDocument](https://wiki.genexus.com/commwiki/wiki?2476), [MAPISession](https://wiki.genexus.com/commwiki/wiki?6935), [OutlookSession](https://wiki.genexus.com/commwiki/wiki?6936), [POP3Session](https://wiki.genexus.com/commwiki/wiki?6966), [SMTPSession](https://wiki.genexus.com/commwiki/wiki?6937), [WordDocument](https://wiki.genexus.com/commwiki/wiki?2478,,)  
**Languages:** .NET, Java, Ruby (up to GeneXus X Evolution 3), Visual FoxPro (up to GeneXus X Evolution 3)
