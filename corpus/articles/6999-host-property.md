# Host Property

This property is used to indicate the server address.

### [Syntax](#Syntax)

**&***DataType***.Host**  
  
**Type Returned:**   
Character

### [Description](#Description)

Both the name of the server and its IP address can be specified.  
**Location:** The default value is “localhost”.

### [Scope](#Scope)

**Extended Data Types:** [HttpClient](https://wiki.genexus.com/commwiki/wiki?6932), [Location](https://wiki.genexus.com/commwiki/wiki?6981), [LDAPClient](https://wiki.genexus.com/commwiki/wiki?6886), [POP3Session](https://wiki.genexus.com/commwiki/wiki?6966), [SMTPSession](https://wiki.genexus.com/commwiki/wiki?6937)  
**Languages:** .NET, Java, Ruby (up to GeneXus X Evolution 3), Visual FoxPro (up to GeneXus X Evolution 3)
