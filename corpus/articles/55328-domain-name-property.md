# Domain Name property

Sets the domain of a URL that was visited by users on your website.

### [Scope](#Scope)

**Controls:** [Google Analytics Control](https://wiki.genexus.com/commwiki/wiki?11847)

### [Description](#Description)

This property is useful whenever you need to jointly measure the activity of several domains; for example, that of a customer's website domain and that of the shopping cart domain. More information on [domain measurement](https://support.google.com/analytics/answer/10071811).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
