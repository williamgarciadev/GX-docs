# Chatbots Collection property

Indicates whether the user's input has multiple entity values.

### [Scope](#Scope)

**Objects:** [Conversational Flows Instance](https://wiki.genexus.com/commwiki/wiki?37113)

### [Description](#Description)

The Collection property is available for [Chatbot User Inputs](https://wiki.genexus.com/commwiki/wiki?38959) when [Match With Entity property](https://wiki.genexus.com/commwiki/wiki?39295) is set to TRUE and an entity is specified in the [Entity property](https://wiki.genexus.com/commwiki/wiki?39300).

In that case, if Collection is set to TRUE, it means that more than one entity value can be recognized from the user's input.

#### [Temporary Limitation](#Temporary+Limitation)

For Web UI components ([Web Component property](https://wiki.genexus.com/commwiki/wiki?39885) or [Conversational Object](https://wiki.genexus.com/commwiki/wiki?38189) which are Web components), it's only supported in NET applications.

### [Compatibility](#Compatibility)

Since GeneXus 16 upgrade 10, this property does not exist in the User Input and is part of the variable definition.

### [Availability](#Availability)

This property is available since [GeneXus 16 upgrade 3](https://wiki.genexus.com/commwiki/wiki?42129,,).
