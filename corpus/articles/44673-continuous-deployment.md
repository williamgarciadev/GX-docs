# Continuous Deployment

You achieve Continuous Deployment when your [Continuous Integration](https://wiki.genexus.com/commwiki/wiki?38331) and [Continuous Delivery](https://wiki.genexus.com/commwiki/wiki?44672) process is so smooth/automatic that you can deploy automatically and continually.

GeneXus offers the option to deploy to [Docker Container](https://wiki.genexus.com/commwiki/wiki?36951) to be able to make more continuous delivery of your application. This allows creating a binary containing the entire application inside to deploy. The good thing about this is that it is programmable and automatable, so it is easy to include it in your [DevOps](https://wiki.genexus.com/commwiki/wiki?38363) process.
