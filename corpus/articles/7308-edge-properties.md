# Edge Properties

They help define the Edge's behavior.

Type: It allows the following values:

* Fixed: allows establishing the connection between other diagram symbols.
* Optional: path where the user selects, in runtime, whether he wants to follow it or not.
* Deadline: indicates the path to be executed when the selected time expires.
