# Number of days to keep property

Specifies the number of days a Mini app is kept in the Super App cache since its last use.

### [Scope](#Scope)

**Objects:** [Super App](https://wiki.genexus.com/commwiki/wiki?53457,,)  
**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917)

### [Description](#Description)

Specifies the number of days a Mini app is kept since its last use; after that, the Mini app is deleted from the cache.

A value of 0 means that Mini apps aren't removed based on their usage.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, execute a [Build with this Only](https://wiki.genexus.com/commwiki/wiki?5693) of the object.
