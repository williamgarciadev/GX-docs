# On Click Event property

Sets the event name that will be executed when clicking on the control.

### [Scope](#Scope)

**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917), [Java](https://wiki.genexus.com/commwiki/wiki?12258)  
**Controls:** [Button](https://wiki.genexus.com/commwiki/wiki?6011), [Image](https://wiki.genexus.com/commwiki/wiki?5939), Attribute/Variable, [Text Block](https://wiki.genexus.com/commwiki/wiki?5948)

### [Description](#Description)

Applies to [Button](https://wiki.genexus.com/commwiki/wiki?6011), [Image](https://wiki.genexus.com/commwiki/wiki?5939), Attribute/Variable and [Text Block](https://wiki.genexus.com/commwiki/wiki?5948) controls included in [Transaction Web Layout](https://wiki.genexus.com/commwiki/wiki?8057), [Web Panel Web Layout](https://wiki.genexus.com/commwiki/wiki?8132) and [Panel](https://wiki.genexus.com/commwiki/wiki?24829)s.

It enables the definition of an event (which can be customized) to be executed when the associated control is clicked on at runtime.

The possible values the property can take are: <new>, Cancel, Enter, Help, and Refresh.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
