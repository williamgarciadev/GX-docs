# Generate Update Flow property

If it is true, GeneXus will generate the Update Flow.

### [Scope](#Scope)

**Objects:** Conversational Flows Pattern

### [Description](#Description)

The Generate Update [Flow](https://wiki.genexus.com/commwiki/wiki?38531) property is available for the Transaction node under the Conversational Configuration (Pattern Settings).

`[imagen omitida: wiki id 40380]`

### [Availability](#Availability)

This property is available since [GeneXus 15 upgrade 12](https://wiki.genexus.com/commwiki/wiki?39737,,).
