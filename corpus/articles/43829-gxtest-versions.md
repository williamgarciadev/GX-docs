# GXtest versions

On this page, you will find all information about the different GXtest versions.

GXtest is published continuously over Beta and Preview GeneXus channels.

## [Beta Channel](#Beta+Channel)

GXtest Beta version is daily integrated into the GeneXus Beta channel, and the main purpose is to release new features to gather feedback within the community. This means that if you are using the latest GeneXus Beta version you are already up to date. If not, you can always download the latest GXtest Beta version from the links below:

`[imagen omitida: wiki id 40856]` [GXtest for GeneXus Beta](https://gxtest-downloads.s3.amazonaws.com/develop/GXtest_Beta.zip)

`[imagen omitida: wiki id 40856]` [GXtest Extension for GXServer Beta](https://gxtest-downloads.s3.amazonaws.com/develop/GXtest_Beta_GXServer.zip)

## [Preview Channel](#Preview+Channel)

GXtest Preview channel is also daily integrated into GeneXus Preview Channel and will become the official Upgrade on each GeneXus release. This means that if you already have the latest upgrade of GeneXus, your GXtest version is also up to date.In any case, you can always install manually the latest version of GXtest by downloading the GXtest Preview version from the links below:

`[imagen omitida: wiki id 40856]` [GXtest for GeneXus Preview](https://gxtest-downloads.s3.amazonaws.com/staging/GXtest_Stable.zip)

`[imagen omitida: wiki id 40856]` [GXtest Extension for GXServer Preview](https://gxtest-downloads.s3.amazonaws.com/staging/GXtest_Stable_GXServer.zip)

## [Older GXtest Versions](#Older+GXtest+Versions)

Besides, GXtest is released for the different versions of GeneXus (since GeneXus 15 U7) and it is necessary to install a compatible version. There are GXtest versions for older GeneXus versions, you can [download and install them manually](https://wiki.genexus.com/commwiki/wiki?42858).
