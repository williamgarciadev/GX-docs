# Module/Folder property

Sets the Module or Folder to which the Genexus object will belong.

### [Scope](#Scope)

**Objects:** [Data Provider](https://wiki.genexus.com/commwiki/wiki?5270), [File](https://wiki.genexus.com/commwiki/wiki?5852), [Procedure](https://wiki.genexus.com/commwiki/wiki?6293), [Transaction](https://wiki.genexus.com/commwiki/wiki?1908), [Web Panel](https://wiki.genexus.com/commwiki/wiki?6916), [Data View](https://wiki.genexus.com/commwiki/wiki?1914), [Stencil](https://wiki.genexus.com/commwiki/wiki?38418), [External Object](https://wiki.genexus.com/commwiki/wiki?5669)

### [Description](#Description)

This property allows you to indicate the Module or Folder to which the GeneXus object will belong.

Folders establish hierarchies where each folder can contain GeneXusobjects as well as other folders — but no Module Objects.

Modules also establish hierarchies where each Module can contain GeneXusobjects as well as other folders. Please read [Modules](https://wiki.genexus.com/commwiki/wiki?22414) for further details.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
