# Column Title Visible property in Tabular Grid Control Column

Indicates whether the text in the column header is visible or not.

### [Scope](#Scope)

**Generators:** [Angular](https://wiki.genexus.com/commwiki/wiki?42550)  
**Controls:** [Tabular Grid](https://wiki.genexus.com/commwiki/wiki?54449)

### [Description](#Description)

The available values for this property are:

* **True**: The title of the column is displayed in the column header. This is the default value.
* **False**: The title of the column is not displayed in the column header. In general, this option is used in combination with the [Column Image property](https://wiki.genexus.com/commwiki/wiki?55829) and [Column Tooltip property](https://wiki.genexus.com/commwiki/wiki?55830).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [Availability](#Availability)

This property is available since [GeneXus 18 Upgrade 6](https://wiki.genexus.com/commwiki/wiki?54240).
