# Model Automation

This stage in the [BPM Cycle](https://wiki.genexus.com/commwiki/wiki?44029), is where the model becomes a functional application.

To make the diagram executable, we should associate GeneXus objects to the diagram symbols. For example, an interactive [task](https://wiki.genexus.com/commwiki/wiki?17495) may be associated to a [Transaction object](https://wiki.genexus.com/commwiki/wiki?1908), while a script task may be integrated with a [Procedure object](https://wiki.genexus.com/commwiki/wiki?6293).

GeneXus procedures also could be associated with [Gateways](https://wiki.genexus.com/commwiki/wiki?24918) to evaluate a complex decision, to a [Connector](https://wiki.genexus.com/commwiki/wiki?24921), for specific conditional flow behaviour, or to a [Conditional Event](https://wiki.genexus.com/commwiki/wiki?24917), which trigger with a conditional expression that must be met for the process.

To associate a GeneXus object to a task, we have to use the task [Application Property](https://wiki.genexus.com/commwiki/wiki?11884) allows indicating the GeneXus object that will be invoked upon executing the task.

To know the details on using this property, and see a practical example on model automation, please have a look to [My first BPM Application](https://wiki.genexus.com/commwiki/wiki?11218)
