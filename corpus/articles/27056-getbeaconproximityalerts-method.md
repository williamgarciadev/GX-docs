# GetBeaconProximityAlerts method

Retrieve a collection for the beacon regions that are currently being monitored.

### [Return Value](#Return+Value)

* ProximityAlerts
  + Type: [BeaconProximityAlert SDT Collection](https://wiki.genexus.com/commwiki/wiki?27040)
  + Returns the beacon regions that are currently being monitored.
