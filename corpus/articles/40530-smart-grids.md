# Smart Grids

The Smart Grid control is an evolution of the classic [Grid control](https://wiki.genexus.com/commwiki/wiki?24817) that is used in mobile application development with GeneXus. As from [GeneXus 16 Upgrade 11](https://wiki.genexus.com/commwiki/wiki?45901,,), when creating a new Grid control, the default value of the [Control Type property](https://wiki.genexus.com/commwiki/wiki?9550) is Smart Grid.

In addition to the classic functionality of displaying a group of related data, it now provides a set of properties that allow managing how that information will be displayed in the Grid. For instance, it is possible to indicate the scroll direction or the number of items per row that will be displayed.


* [Auto Grow property](https://wiki.genexus.com/commwiki/wiki?20204)
* [Scroll Direction property](https://wiki.genexus.com/commwiki/wiki?37547)
* Snap To Grid property
* Items in Rows and Columns
  + [Items Layout Mode property](https://wiki.genexus.com/commwiki/wiki?40556)
  + [Items Per Column property](https://wiki.genexus.com/commwiki/wiki?37550)
  + [Items Per Row property](https://wiki.genexus.com/commwiki/wiki?37549)
* Size
  + [Maximum Width property](https://wiki.genexus.com/commwiki/wiki?37552)
  + [Minimum Width property](https://wiki.genexus.com/commwiki/wiki?37551)
  + [Maximum Height property](https://wiki.genexus.com/commwiki/wiki?37554)
  + [Minimum Height property](https://wiki.genexus.com/commwiki/wiki?37553)
