# GAM - Update Connection File

The GeneXus Menu option GAM - Update Connection File calls the [GAMDeployTool](https://wiki.genexus.com/commwiki/wiki?18608) with the option of "Update Connection File" in order to create or update the [connection.gam](http://www2.gxtechnical.com/portal/hgxpp001.aspx?15,4,61,O,E,0,,30451) file.

See [GAMDeployTool:Creating connection.gam file](https://wiki.genexus.com/commwiki/wiki?18610) for additional information.
