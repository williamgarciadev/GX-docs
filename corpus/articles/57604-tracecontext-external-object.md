# TraceContext External Object

TraceContext helps represent [context propagation](https://opentelemetry.io/docs/concepts/context-propagation/).

A context propagation mechanism carries scoped values across API boundaries and between threads.

`[imagen omitida: wiki id 58686]`

You can find the TraceContext [External Object](https://wiki.genexus.com/commwiki/wiki?5669) in the [KB Explorer](https://wiki.genexus.com/commwiki/wiki?3210) within the [GeneXusObservability module](https://wiki.genexus.com/commwiki/wiki?58681), which in turn is located within the GeneXus module.

It has no properties or methods, as it's an object to be passed between invocations.

See [HowTo: Create new Spans manually](https://wiki.genexus.com/commwiki/wiki?57598) for a clear example of its use.
