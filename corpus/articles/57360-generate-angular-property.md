# Generate Angular property

Enables the generation of code for the Angular platform.

### [Values](#Values)

|  |
| --- |
| False |
| True |

### [Scope](#Scope)

**Generators:** [Angular](https://wiki.genexus.com/commwiki/wiki?42550)  
**Level:** Generator

### [Description](#Description)

The default value for this property is False.

When set to True, the Angular Specific group will be available for you to set the necessary properties to generate applications in this platform.
