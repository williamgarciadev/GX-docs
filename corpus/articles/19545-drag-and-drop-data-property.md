# Drag And Drop Data property

This property contains the name of the variable based on the QueryViewerDragAndDropData SDT that can be used in the [DragAndDrop Event](https://wiki.genexus.com/commwiki/wiki?19546,,).

### Values

|  |  |
| --- | --- |
| **&DragAndDropData** | Name of the variable that will implement the event’s inherent properties. This is the default value. |

### Syntax

**&DragAndDropData.**{ *Axis* | *Name* }

Where:

*Axis*  
      Axis in which it was dropped (row or column).

*Name*  
Name of the element that was dragged and dropped.

### Scope

|  |  |
| --- | --- |
| **Output type** | PivotTable |
