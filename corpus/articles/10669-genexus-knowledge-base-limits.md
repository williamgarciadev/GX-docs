# GeneXus Knowledge Base Limits

The following table specify the maximun numbers of various object within the Knowlege Base.

|  |  |
| --- | --- |
| **Object** | **Max. number** |
| Environments and Versions per KB | 999 |
| Objects per KB (includes Table, Indexes and Subtype Groups) | 2^31 |
| Attributes per KB (includes Subtypes) | 2^31 |
| Domains per KB | 2^31 |
| Attributes per Transaction | 999 |
| Levels per Transaction | 99 parallels |
| Key Attributes per Table | 32 |
| Secondary Attributes per Table | 999 |
| Indexes per Table | 200 |
| Candidate Key Attributes per Table | 99 |
| Where conditional filters in a For each(1) | 500 |

1 - Depending on the For each filtering conditions, this number may vary, 500 is set as a reasonable threshold.
