# Custom ad-hoc application property

Personalizes the task selection dialog. You must specify the name of the main web panel.

### [Scope](#Scope)

**Generators:** [Java](https://wiki.genexus.com/commwiki/wiki?12258), .NET, [.NET Core](https://wiki.genexus.com/commwiki/wiki?38604)  
**Controls:** [Task](https://wiki.genexus.com/commwiki/wiki?17495)

### [Description](#Description)

This property is only available when the [Is ad-hoc property](https://wiki.genexus.com/commwiki/wiki?11875) is set to True.
