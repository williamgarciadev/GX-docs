# My first Angular application

This guide describes how to build and run a basic Angular app.

### [1. Requirements](#1.+Requirements)

Check [Angular Generator requirements](https://wiki.genexus.com/commwiki/wiki?42541).

### [2. Create the app](#2.+Create+the+app)

You can generate your native mobile apps as web apps using Angular. If you don't have one already, you can start with the [TravelAgencyAngular KB available in GeneXus Server](http://open.genexusserver.com/v17/kbdashboard.aspx?TravelAgencyAngular,) and generate that KB with the Angular Generator.

Once you have opened the [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836) you want to generate with the Angular generator, go to the [Preferences window](https://wiki.genexus.com/commwiki/wiki?7109). Select the Front end subnode below the desired [Environment](https://wiki.genexus.com/commwiki/wiki?7115).

Set the [Generate Angular property](https://wiki.genexus.com/commwiki/wiki?57360) to True.

`[imagen omitida: wiki id 57318]`

### [3. Execute the app](#3.+Execute+the+app)

Read [How to execute an app using Angular Generator](https://wiki.genexus.com/commwiki/wiki?42544).

### [4. That's it!](#4.+That%27s+it%21)

Your app will run on a random available port and the browser will automatically open to display the running application.
