# HANA Instance name property

Sets the HANA DB Instance name for SAP Cloud Platform Cloud Foundry Environment.

### [Scope](#Scope)

**Level:** Deploy Target Options

### [Description](#Description)

You must specify the HANA DB instance name that you create in your SAP Cloud Platform account. You can get this information in the Cockpit (control panel) of SAP Cloud Platform Cloud Foundry Environment, in the "Services \ Services Instances" section after you access your Space.

### [Availability](#Availability)

This property is available since [GeneXus 16 upgrade 10](https://wiki.genexus.com/commwiki/wiki?45624,,).
