# Data Source From property (GeneXus 18 Upgrade 4 or prior)

Indicates where is the data loaded from with which the control will be filled.

### [Values](#Values)

|  |  |
| --- | --- |
| **Attributes** | Fill the ItemValues and ItemDescriptions properties to specify from what attributes the control will be filled. |
| **Data Provider** | Select the Data Provider object that the control will use in order to be filled. |
| **Values** | Select a set of values that the control will use in order to be filled. (\*) Only visible for Wheel Control for Native Mobile apps. |

### [Scope](#Scope)

**Controls:** Attribute/Variable (Control Type: [Dynamic Combo Box](https://wiki.genexus.com/commwiki/wiki?7598), [Dynamic List Box](https://wiki.genexus.com/commwiki/wiki?7599), [Wheel](https://wiki.genexus.com/commwiki/wiki?16239))

### [Description](#Description)

When the [Control Type property](https://wiki.genexus.com/commwiki/wiki?9550)= [Wheel Control for Native Mobile apps](https://wiki.genexus.com/commwiki/wiki?20180), the "Range" value is also offered. This value selects a range of numbers (Only for Numeric variables / attributes).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
