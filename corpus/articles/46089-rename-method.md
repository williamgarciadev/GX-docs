# Rename method

Renames a worksheet.

### [Syntax](#Syntax)

**&***VarBasedOnExcelWorksheet***.Rename*****(**Character***)**

**Where:**  
*Character*  
    New value to rename the worksheet

**Type Returned:**   
Boolean

### [Scope](#Scope)

**Extended Data Types:** [ExcelWorksheet data type](https://wiki.genexus.com/commwiki/wiki?46080)  
**Generators:** 
[Java](https://wiki.genexus.com/commwiki/wiki?12258)

### [Description](#Description)

It renames the active worksheet to the value defined in Character
