# Lines Back Color property

Changes the back color of the even lines of a Grid or Freestyle Grid, with the value ‘Header’ or ‘Report’.

### [Scope](#Scope)

**Objects:** [Web Theme](https://wiki.genexus.com/commwiki/wiki?6420)  
**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [Java](https://wiki.genexus.com/commwiki/wiki?12258)

### [Description](#Description)

It allows choosing a particular design with which to show the Grid lines.

**Important:**Since GeneXus 15, the Lines Back Color property is available in the [Web Theme object](https://wiki.genexus.com/commwiki/wiki?6420).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
