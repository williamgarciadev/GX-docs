# Size property

Sets the GeneXus connection pool size.

### [Scope](#Scope)

Available at the Data Store.  
**Data Store:** Iseries, DB2 UDB, INFORMIX, MYSQL, ORACLE, POSTGRESQL, SQLSERVER

### [Description](#Description)

The size of the pool is the maximum number of available connections to the database. This property becomes available only when the [Unlimited size property](https://wiki.genexus.com/commwiki/wiki?9386) is set to "False;" otherwise, it doesn't apply.

The default value is 10.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, Build any object.
