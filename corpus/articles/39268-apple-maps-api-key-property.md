# Apple Maps API Key property

API Key for Apple Maps. Depending on the selected API, it may have to be generated from the application's Bundle Identifier.

### [Scope](#Scope)

**Objects:** [Menu](https://wiki.genexus.com/commwiki/wiki?16321), [Panel](https://wiki.genexus.com/commwiki/wiki?24829), [Work With](https://wiki.genexus.com/commwiki/wiki?15974) (Only [Main Objects](https://wiki.genexus.com/commwiki/wiki?5770))  
**Generators:** [Apple](https://wiki.genexus.com/commwiki/wiki?14917)

### [Description](#Description)

This property will be displayed when [Apple Maps API property](https://wiki.genexus.com/commwiki/wiki?39267) has a different value from its default (Apple Maps) in order to set the access key for displaying maps.

* If [Apple Maps API property](https://wiki.genexus.com/commwiki/wiki?39267) has 'Google Maps' value, refer to [HowTo: Get a Google Maps API Key for Apple](https://wiki.genexus.com/commwiki/wiki?39319) to get its respective key.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
