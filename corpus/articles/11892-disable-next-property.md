# Disable Next Property

It indicates that the movement to the subsequent task is not automatically executed and the user application will perform it.

### [Values](#Values)

**False  
True**

**Default:** False

### [Scope](#Scope)

**Objects**: Business Process Diagram ([User Task](https://wiki.genexus.com/commwiki/wiki?17499))
