# Form theme-class for Smart Devices

Allows the developer to set some properties to Form of a Panel or Work With Devices object (also known as Layout).

### [Properties](#Properties)

* [Name property](https://wiki.genexus.com/commwiki/wiki?6985)
* [Description property](https://wiki.genexus.com/commwiki/wiki?7446)
* [Enter effect property](https://wiki.genexus.com/commwiki/wiki?20961)
* [Exit effect property](https://wiki.genexus.com/commwiki/wiki?20961)
* [Call Type property](https://wiki.genexus.com/commwiki/wiki?25322)
* [Target Name](https://wiki.genexus.com/commwiki/wiki?25323)
* [gx-content-size-change property](https://wiki.genexus.com/commwiki/wiki?33517)
* [Input View Appearance property](https://wiki.genexus.com/commwiki/wiki?37783)
* [Loading Animation Class](https://wiki.genexus.com/commwiki/wiki?37189) (1)

### [Notes](#Notes)

* (1) Available as of [GeneXus 15 Upgrade 8](https://wiki.genexus.com/commwiki/wiki?36778,,)
