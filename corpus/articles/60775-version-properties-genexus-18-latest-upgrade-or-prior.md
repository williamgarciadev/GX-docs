# Version properties (GeneXus 18 latest upgrade or prior)

Each [Knowledge Base Version](https://wiki.genexus.com/commwiki/wiki?5680) includes a set of configurable properties.

To view or modify them, open the [Preferences](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?7109,,) window and select the corresponding Version node. The [Properties window](https://wiki.genexus.com/commwiki/wiki?3160) will then refresh to display all the properties available for that specific version.
