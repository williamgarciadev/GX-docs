# ResultingString Property

Allows you to inquire the value of the XML document that is in the internal buffer when the document was created with the OpenToString() method.

### [Syntax](#Syntax)

**&***DataType***.ResultingString**  
  
**Type Returned:**   
String

### [Description](#Description)

Allows you to inquire the value of the XML document that is in the internal buffer when the document was created with the OpenToString() method. The returned document may be incomplete if the property is invoked before the close() method is executed.

### [Scope](#Scope)

**Extended Data Types:** [XmlWriter](https://wiki.genexus.com/commwiki/wiki?6938)  
**Languages:** .NET, Java, Ruby (up to GeneXus X Evolution 3), Visual FoxPro (up to GeneXus X Evolution 3)
