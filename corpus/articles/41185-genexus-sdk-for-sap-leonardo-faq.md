# GeneXus SDK for SAP Leonardo - FAQ

In this article, you can find the most frequently asked questions about GeneXus SDK for SAP Leonardo.

#### [**1. Can SAP Leonardo ML Foundation services(API) that are not included on GeneXus SDK for SAP Leonardo be used?**](#1.+Can+SAP+Leonardo+ML+Foundation+services%28API%29+that+are+not+included+on+GeneXus+SDK+for+SAP+Leonardo+be+used%3F)

It is possible to use services that are not included on GeneXus SDK for SAP Leonardo, to do so follow the steps detailed on the [GeneXus SDK for SAP Leonardo: Importing a ML service](https://wiki.genexus.com/commwiki/wiki?41823) article.

#### [**2. Can retrained models in my Knowledge Base** **on GeneXus be used? What about training one's own model?**](#2.+Can+retrained+models+in+my+Knowledge+Base+on+GeneXus+be+used%3F+What+about+training+one%27s+own+model%3F)

You can achieve both using GeneXus.

* The process to use retrained models is completely analog to using pre-trained models. The only differences are that the URL service would be different and that the authentication method would be OAuth 2.0 instead of the APIKey.
* You can your train models from GeneXus. To do this, SAP Leonardo provides an API that allows this task.

For more information about this, read [GeneXus SDK for SAP Leonardo: Retraining a model to use in a ML service](https://wiki.genexus.com/commwiki/wiki?41860)
