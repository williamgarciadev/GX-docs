# View Last Navigation object option

This allows you to obtain the last specification report of a certain object, at any time, through this contextual option on the selected object.

This option avoids having to specify the object again.

### [Availability](#Availability)

Available since [GeneXus X Evolution 3 Upgrade 3](https://wiki.genexus.com/commwiki/wiki?27678,,)
