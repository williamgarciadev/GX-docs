# REST Protocol property in API Object

Enables or disables the REST Protocol in the API. The API becomes available through the REST protocol when this property is set to True.

### [Values](#Values)

|  |
| --- |
| **False** |
| **True** |

### [Scope](#Scope)

**Objects:** [API](https://wiki.genexus.com/commwiki/wiki?46151)  
**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Java](https://wiki.genexus.com/commwiki/wiki?12258)

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
