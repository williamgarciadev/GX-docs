# SOAP Protocol property

Indicates whether the object exposed as a service accepts the SOAP protocol.

### [Values](#Values)

|  |
| --- |
| **False** |
| **True** |

### [Scope](#Scope)

**Objects:** [Business Component](https://wiki.genexus.com/commwiki/wiki?5846), [Procedure](https://wiki.genexus.com/commwiki/wiki?6293)  
**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Java](https://wiki.genexus.com/commwiki/wiki?12258)

### [Description](#Description)

To expose a GeneXus object as a SOAP Web Service, set the following object properties:

* [Expose as Web Service property](https://wiki.genexus.com/commwiki/wiki?36480) = True (after setting this property to True, the SOAP Protocol property will be shown)
* SOAP Protocol = True

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
