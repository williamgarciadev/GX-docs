# Select Objects dialog

The **Select Objects** dialog allows selecting object(s) for different actions (open, build, insert, export, etc.).

`[imagen omitida: wiki id 58665]`

For each object displayed, its Name, Type, Description, and Modified Date are shown in addition to other relevant details.

You can modify the window size. Once resized, the window dimensions are kept until you modify it again.

### [Filters section](#Filters+section)

The Filters section allows you to refine your search for specific objects:

|  |  |
| --- | --- |
| **Pattern** | Used to indicate the Search Pattern. |
| **Type** | Used to display all objects (Transactions, Procedures, Reports, Work Panels, etc.) that match the type you selected from the combo box. |
| **Category** | Displays all objects subordinate to a category as listed in the combo box, or all. |
| **Module** | Allows you to select the objects in the Module you selected from the Combo Box. |
| **Modified** | Allows you to select the objects that were modified After the Last Build, After Consolidation, or After a Determined Date/time. |

When multiple criteria (Pattern, Type, and Module) are specified simultaneously, the dialog will display all objects that meet the combined conditions.

This section lists the objects that match the Filters criteria. Once the matching objects are listed, you can select the ones you wish to work with. To select all objects, click on the Select All button.

If the object you're looking for is not listed, you can create it by clicking on the New... button, which opens the object creation window.
