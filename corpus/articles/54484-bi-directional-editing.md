# Bi-Directional editing

The IDE Rules and Events editor is not ready for Bi-Directional editing yet. For those cases where RTL text must be set, use the RTL Language object to localize the associated texts and [GeneXus Application Localization](https://wiki.genexus.com/commwiki/wiki?6330) to set the correct language in runtime.
