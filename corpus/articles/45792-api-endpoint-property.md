# API Endpoint property

Sets the SAP Cloud Platform Cloud Foundry API Endpoint. (i.e.: https://api.cf.eu10.hana.ondemand.com)

### [Scope](#Scope)

**Level:** Deploy Target Options

### [Description](#Description)

You must specify the URL address for the API Endpoint for your account in SAP Cloud Platform Cloud Foundry environment. You can get this information in the SAP Cloud Platform Cockpit (control panel), in the Overview section of your Cloud Foundry environment.

### [Availability](#Availability)

This property is available since [GeneXus 16 upgrade 10](https://wiki.genexus.com/commwiki/wiki?45624,,).
