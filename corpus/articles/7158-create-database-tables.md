# Create Database Tables

Provides an Impact Analysis Report. If the user confirms the reorganization, it generates the creation programs for the database and automatically executes them, thus creating the empty structure of the database, based on the [Environment](https://wiki.genexus.com/commwiki/wiki?7115) properties set in the [Preferences](https://wiki.genexus.com/commwiki/wiki?7109) panel from the [Knowledge Base Navigator](https://wiki.genexus.com/commwiki/wiki?5634,,).
