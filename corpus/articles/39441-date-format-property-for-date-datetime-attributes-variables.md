# Date format property (for Date/DateTime attributes/variables)

Sets whether to accept and display two or four digits for the year.

### [Values](#Values)

|  |  |
| --- | --- |
| **Year with four digits (99/99/9999)** | Accepts and displays four digits for the year. |
| **None** | Accepts and displays only the time part (no date). |
| **Year with two digits (99/99/99)** | Accepts and displays two digits for the year. |

### [Scope](#Scope)

**Level:** [Attribute](https://wiki.genexus.com/commwiki/wiki?7240), [Domain](https://wiki.genexus.com/commwiki/wiki?7221), [Variable](https://wiki.genexus.com/commwiki/wiki?7375)

### [Description](#Description)

This property is offered for attributes, variables, or domains based on Date / DateTime data type.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, execute a [Build All](https://wiki.genexus.com/commwiki/wiki?5691).
