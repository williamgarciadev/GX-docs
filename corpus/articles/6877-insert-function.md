# Insert - Function

By selecting **Insert** and then, **Function...** from the [GeneXus Main Menu](https://wiki.genexus.com/commwiki/wiki?7212) the following dialog will be opened, showing the available functions to use in the [GeneXus object](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?1866,,) section where you are working.

`[imagen omitida: wiki id 58612]`

Therefore, different functions will be displayed depending on whether you are working in a [Procedure Source](https://wiki.genexus.com/commwiki/wiki?6664), in the [Events section of a Transaction](https://wiki.genexus.com/commwiki/wiki?8042), or in the [Events section of a Web Panel](https://wiki.genexus.com/commwiki/wiki?8566), for example.

Every function returns a value. The returned value can be assigned to a Variable (based on the same data type returned by the function). In addition, the returned value can be assigned to an Attribute (based on the same data type returned by the function) in [Procedure Source](https://wiki.genexus.com/commwiki/wiki?6664)s and/or in the Rules section of [Transaction object](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?1908,,)s. Also, the returned value can be the entry of another function or expression.

### [Shortcut](#Shortcut)

The keyboard shortcut **Ctrl + Shift + F** opens the insert function dialog.
