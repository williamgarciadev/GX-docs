# Generate On Save property

Determines if, when saving changes, the objects of the instance are generated or not if there are changes to be applied with respect to the previous generation.

### [Scope](#Scope)

**Objects:** [Conversational Flows Instance](https://wiki.genexus.com/commwiki/wiki?37113)

### [Description](#Description)

This property is available for the [Flow](https://wiki.genexus.com/commwiki/wiki?38531) of the [Conversational Flows object](https://wiki.genexus.com/commwiki/wiki?37113). If set to TRUE, when saving changes, the objects of the instance will be generated if necessary (there are changes to be applied with respect to the previous generation).

`[imagen omitida: wiki id 46980]`

Note: This option does not synchronize the instance.

More information about instance generation: [Chatbot generator](https://wiki.genexus.com/commwiki/wiki?37102)
