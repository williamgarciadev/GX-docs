# HowTo: Consume a Rest Data Provider

This document explains how to call a [Data Provider](https://wiki.genexus.com/commwiki/wiki?4417) (DP) exposed as [Rest web services in GeneXus](https://wiki.genexus.com/commwiki/wiki?28213).

First, let's see the basic guidelines:

#### [**1. How are the Rest services called in GeneXus?**](#1.+How+are+the+Rest+services+called+in+GeneXus%3F)

Use the [HttpClient data type](https://wiki.genexus.com/commwiki/wiki?6932).

#### [**2. Which HTTP method is used to call the Rest Data Provider?**](#2.+Which+HTTP+method+is+used+to+call+the+Rest+Data+Provider%3F)

The HTTP method used for calling the Data Provider is the HTTP GET verb.

#### [**3. Which is the URL format to execute the GET verb?**](#3.+Which+is+the+URL+format+to+execute+the+GET+verb%3F)

*<ServerUrl>/<module>/<DP name>?<param1>=<value1>&<param2>=<value2>,..,<paramN>=<valueN>*

**Where:**

*<param1>,<param2>,..,<paramN>*  
      Are the parameters of the DP. The parameters should be separated by &.

### [Samples](#Samples)

Consider the Invoice Business Component transaction, which looks as follows:

`[imagen omitida: wiki id 30738]`

A DP (called "DPCaso20") has been created, whose [Data Provider Output](https://wiki.genexus.com/commwiki/wiki?41037) is the Invoice BC. Also, it's exposed as a Rest service as shown below:

`[imagen omitida: wiki id 30739]`

The DP has the following rule:

```
parm(in:&invoicedate,in:&CustomerId, in:&Customername);
```

The following code is used to call that Rest DP:

```
//http://server:8080/BaseUrl/rest/DPCaso20?Invoicedate=2013-11-14&Customerid=1&Customername=Francisco
&httpclient.Host= "server"
&httpclient.Port = 8080
&httpclient.BaseUrl = "BaseUrl"
&httpclient.secure = 0
&httpclient.Execute('GET','DPCaso20?Invoicedate=2013-11-14&Customerid=1&Customername=Francisco')

if &httpclient.StatusCode = 200
    &result = &httpclient.ToString()
else
   msg("Error: " + &httpclient.StatusCode.ToString())
endif
```

Download the sample from [Sample consuming a Rest DP](https://wiki.genexus.com/commwiki/wiki?30740,,)

#### [**Notes:**](#Notes%3A)

* If the service URI is *http://localhost/TestRESTFullGX.NetEnvironment/rest/Invoice*, the BASE URL is: */TestRESTFullGX.NetEnvironment/rest/*
* In
  [Java](https://wiki.genexus.com/commwiki/wiki?12258), the parameter name must be normalized (First Character must be uppercase, and all the others must be lowercase) , in this example: Invoicedate, Customerid and Customername.
* Error handling is managed by querying the HTTP Status Code after the invocation.
