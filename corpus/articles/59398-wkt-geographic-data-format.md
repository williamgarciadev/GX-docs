# WKT Geographic data format

WKT (Well-Known Text) is a plain text format used to represent vector data.

The [Geography data type](https://wiki.genexus.com/commwiki/wiki?32408) and its specific data types ([GeoPoint](https://wiki.genexus.com/commwiki/wiki?58058), [GeoLine](https://wiki.genexus.com/commwiki/wiki?59358), and [GeoPolygon](https://wiki.genexus.com/commwiki/wiki?59361)) can use the [FromWkt method](https://wiki.genexus.com/commwiki/wiki?18900) to load the vector data from a WKT representation.

Similarly, the ToWkt method allows you to obtain the vector data's representation in WKT format.

**Note**: The FromString and ToString methods are enabled for Geography data types only for compatibility reasons. Use [FromWkt](https://wiki.genexus.com/commwiki/wiki?18900) and [ToWkt](https://wiki.genexus.com/commwiki/wiki?59814) methods instead.
