# Read Replica property

Indicates whether a Data Store is the Read Replica of the primary Data Store of the Knowledge Base.

### [Values](#Values)

|  |  |
| --- | --- |
| **Default Data Store** | Replicates this Data Store from the default Data Store of the Knowledge Base. |
| **No** | Default value. |

### [Scope](#Scope)

**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [Java](https://wiki.genexus.com/commwiki/wiki?12258), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892)  
**Level:** [Data Store](https://wiki.genexus.com/commwiki/wiki?7117)

### [Description](#Description)

A Read Replica is a copy of a primary database. Read more about this topic in [Using Read Replicas in GeneXus](https://wiki.genexus.com/commwiki/wiki?54289).

This property allows indicating that a certain [Data Store](https://wiki.genexus.com/commwiki/wiki?7117) is a Read Replica. Therefore, it will be a replica of the default Data Store of the [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836).

By default, this property is set to No.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, execute a [Build All](https://wiki.genexus.com/commwiki/wiki?5691).

### [Availability](#Availability)

This property is available since [GeneXus 18 Upgrade 3](https://wiki.genexus.com/commwiki/wiki?53853).
