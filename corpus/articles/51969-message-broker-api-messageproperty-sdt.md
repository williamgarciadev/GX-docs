# Message Broker API: MessageProperty SDT

The *MessageProperty* [Structured Data Type](https://wiki.genexus.com/commwiki/wiki?10021) is defined under the *GeneXusMessagingMessageBroker* module and represents the attributes of a message (Key and Value pairs) that are returned when a message is sent to the Message Broker.

`[imagen omitida: wiki id 51970]`

The attributes depend on the provider that can return different metadata information after sending a message to the Broker.

### [Availability](#Availability)

This feature is available since [GeneXus 18 upgrade 1](https://wiki.genexus.com/commwiki/wiki?51081).
