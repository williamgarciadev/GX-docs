# ReasonLine Property

Returns the HTTP reason text.

### [Syntax](#Syntax)

***&**varBasedOnHttpClient***.ReasonLine**  
  
**Type Returned:**   
String

### [Description](#Description)

This property returns a string that describes the reason of the HTTP response.
