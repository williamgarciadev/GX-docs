# Data Type property

Indicates the data type of an attribute, variable, relevant data, or domain.

### [Description](#Description)

Possible values include:

* [Numeric](https://wiki.genexus.com/commwiki/wiki?6793) (default value)
* [Character](https://wiki.genexus.com/commwiki/wiki?6777)
* [VarChar](https://wiki.genexus.com/commwiki/wiki?6778)
* [Long Varchar](https://wiki.genexus.com/commwiki/wiki?7371)
* [Date](https://wiki.genexus.com/commwiki/wiki?7373)
* [DateTime](https://wiki.genexus.com/commwiki/wiki?7370)
* [Blob](https://wiki.genexus.com/commwiki/wiki?6704)
* [Image](https://wiki.genexus.com/commwiki/wiki?15204)
* [Boolean](https://wiki.genexus.com/commwiki/wiki?4374)
* [GUID](https://wiki.genexus.com/commwiki/wiki?31772)
* [Audio](https://wiki.genexus.com/commwiki/wiki?16529)
* [Video](https://wiki.genexus.com/commwiki/wiki?16608)

**Notes**

* Data Types can be categorized into **Basic**, **Extended**, **Domain**, **Structured** Data Types, etc.
* Attributes only support **Basic** and **Domain** data types.
* Relevant data only supports Character, Date, DateTime, and Numeric Data Types.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
