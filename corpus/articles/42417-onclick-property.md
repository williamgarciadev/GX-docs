# Onclick property

Determines the on-click behavior on the map.

### [Values](#Values)

|  |  |
| --- | --- |
| **Add Marker** | Adds a marker when clicking on the map. |
| **Get Value** | Returns the coordinates of the clicked point. |
| **none** | There is no action when clicking on the map. |

### [Scope](#Scope)

**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Java](https://wiki.genexus.com/commwiki/wiki?12258)  
**Controls:** [Map](https://wiki.genexus.com/commwiki/wiki?5029)
