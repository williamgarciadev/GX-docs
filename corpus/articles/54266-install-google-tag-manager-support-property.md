# Install Google Tag Manager Support property

Indicates whether to install Google Tag Manager Support.

### [Values](#Values)

|  |
| --- |
| **False** |
| **True** |

### [Scope](#Scope)

**Objects:** [Menu](https://wiki.genexus.com/commwiki/wiki?16321), [Panel](https://wiki.genexus.com/commwiki/wiki?24829), [Work With](https://wiki.genexus.com/commwiki/wiki?15974) (Only [Main Objects](https://wiki.genexus.com/commwiki/wiki?5770))  
**Generators:** [Angular](https://wiki.genexus.com/commwiki/wiki?42550)

### [Description](#Description)

Google Tag Manager (GTM) is the mediator between your website and the tracking tool, acting as a tag manager.

The tags enable an analysis of application visits and can be configured through the manager, which eliminates the need to program events to register in the applications. This allows you to track information in Google Analytics or other tools that support GTM.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [Availability](#Availability)

This property is available since [GeneXus 18 Upgrade 3](https://wiki.genexus.com/commwiki/wiki?53853).
