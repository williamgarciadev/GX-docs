# RemoveDuplicates property

Allows to remove the duplicate records in the query.

### [Values](#Values)

|  |
| --- |
| **False** |
| **True** |

### [Description](#Description)

Default value: False

The SQL sentence will be generated with a DISTINCT clause.

### [Scope](#Scope)

**Objects:** Query
