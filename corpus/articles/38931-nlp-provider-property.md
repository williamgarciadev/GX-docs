# NLP Provider property

Selects the Natural Language Processing provider.

### [Values](#Values)

|  |  |
| --- | --- |
| **Dialogflow** | Uses Dialog Flow provider. |
| **None** |
| **Watson** | Uses IBM Watson provider. |

### [Scope](#Scope)

**Objects:** [Conversational Flows Instance](https://wiki.genexus.com/commwiki/wiki?37113)  
**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Java](https://wiki.genexus.com/commwiki/wiki?12258)

### [Description](#Description)

The value "None" indicates that a [scripted chatbot](https://wiki.genexus.com/commwiki/wiki?45151) will be generated.

When you save the instance, the synchronization with the new provider is triggered. So, you don't need to take any other action.

For more information about the configuration to be done, see [Configuring GeneXus for using the Chatbot Generator](https://wiki.genexus.com/commwiki/wiki?37096).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

No action is required to apply the corresponding changes when the property value is configured.
