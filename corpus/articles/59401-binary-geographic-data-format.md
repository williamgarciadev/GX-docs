# Binary Geographic data format

Every Database Management System (DBMS) provides support for the storage and functions of geographic data types.

The format of this data varies with each DBMS, but in all cases it is a binary stored in the database. Therefore, this is not a standard format per se, unlike the ones previously mentioned ([WKT](https://wiki.genexus.com/commwiki/wiki?59398), [GeoJSON](https://wiki.genexus.com/commwiki/wiki?59399), and [KML](https://wiki.genexus.com/commwiki/wiki?59400)).

For more information read: [Geo Data Source](https://wiki.genexus.com/commwiki/com.gxwiki.wiki?54036,,)
