# Impact Database Tables

Performs an [Impact Analysis](https://wiki.genexus.com/commwiki/wiki?31023) of the current [environment](https://wiki.genexus.com/commwiki/wiki?7115). An Impact Analysis Report will be displayed. This option is available under **Build>Impact Database Tables**.
