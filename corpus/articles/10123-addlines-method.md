# AddLines method

Adds lines to a grid.

### [Syntax](#Syntax)

control.**AddLines(**N**)**

**Where:**  
*control*  
    Is the grid/free style grid ControlName

*N*   
    Is the number of lines to be added.

### [Scope](#Scope)

**Controls:** [Grid](https://wiki.genexus.com/commwiki/wiki?24817), [Free Style Grid](https://wiki.genexus.com/commwiki/wiki?6058)

**Note**: This method doesn't validate; it only adds blank lines.
