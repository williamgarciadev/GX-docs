# Synchronize On Save property

Determines whether the saving of changes to the instance will be synchronized with the NLP provider.

### [Scope](#Scope)

**Objects:** [Conversational Flows Instance](https://wiki.genexus.com/commwiki/wiki?37113)

### [Description](#Description)

This property is available for the [Flow](https://wiki.genexus.com/commwiki/wiki?38531) of the [Conversational Flows object](https://wiki.genexus.com/commwiki/wiki?37113). When saving changes to the instance, it will be synchronized with the NLP provider if the property Synchronize On Save is set to true.

`[imagen omitida: wiki id 46979]`

### [Availability](#Availability)

This property is available since [GeneXus 17](https://wiki.genexus.com/commwiki/wiki?46066,,).
