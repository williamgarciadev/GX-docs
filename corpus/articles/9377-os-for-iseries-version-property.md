# OS for iSeries version property

Sets the Operating System version of the DB2 Server for which the code is generated.

### [Values](#Values)

|  |  |
| --- | --- |
| **V5R1** | . |
| **V5R2** | . |
| **V5R3** | . |
| **V5R4** | V5R4 or higher (lower than V6R1) |
| **V6R1 to V7R1** | V6R1 to V7R1 version |
| **V7R1(SF99701-38) or higher** | V7R1(SF99701-38) or higher version |

### [Scope](#Scope)

Available at the Data Store.  
**Data Store:** Iseries

### [Description](#Description)

It is highly recommended to use version 6.1 or higher. Further information: [SAC 40453](https://www.genexus.com/developers/websac?,,,40453)

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, execute a [Rebuild All](https://wiki.genexus.com/commwiki/wiki?5691).
