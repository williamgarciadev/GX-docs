# Dashboard Chart X axis intersection at zero property

Specifies whether the X axis intersects the Y axis at zero or the intersection point is automatically calculated.

### [Description](#Description)

It defines whether the intersection between X and Y axis is made static (at the Zero value) or is calculated dynamically (depending the nature of Data values).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
