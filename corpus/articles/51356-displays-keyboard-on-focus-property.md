# Displays Keyboard On Focus property

Displays or hides the virtual keyboard when the field is focused.

### [Values](#Values)

|  |
| --- |
| **False** |
| **True** |

### [Scope](#Scope)

**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453), [Apple](https://wiki.genexus.com/commwiki/wiki?14917)  
**Controls:** Attribute/Variable (Data Type: [Character](https://wiki.genexus.com/commwiki/wiki?6777), [LongVarChar](https://wiki.genexus.com/commwiki/wiki?7371), [Numeric](https://wiki.genexus.com/commwiki/wiki?6793), [Varchar](https://wiki.genexus.com/commwiki/wiki?6778))

### [Description](#Description)

It allows configuring whether a keyboard should be displayed when tapping on an [Attribute/Variable](https://wiki.genexus.com/commwiki/wiki?6911) on the screen.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
