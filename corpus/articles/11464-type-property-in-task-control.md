# Type property in Task control

Defines the Task type.

### [Values](#Values)

|  |  |
| --- | --- |
| **None** | Represents a generic task. This type of activity does not have an associated application; it is automatically executed by the engine and affects neither the relevant workflow data nor the application data. |
| **Script** | Represents a task that do not require interaction by the user and will be executed by the Workflow engine. |
| **User** | Represents a task executed by an user. |

### [Scope](#Scope)

**Controls:** [Task](https://wiki.genexus.com/commwiki/wiki?17495)

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
