# Startup Object property

Specifies which object will start running when F5 is pressed.

### [Scope](#Scope)

**Level:** [Environment](https://wiki.genexus.com/commwiki/wiki?7115)

### [Description](#Description)

By default, the Startup Object property is set to "(none)". In this case, when pressing F5 the [Launchpad Tool Window](https://wiki.genexus.com/commwiki/wiki?52315) is opened.

When you set a specific object for this property, it will be the one that starts when pressing F5.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
