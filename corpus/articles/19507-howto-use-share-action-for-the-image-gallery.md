# HowTo: Use Share Action for the Image Gallery

One of the properties of the Image Gallery control is to enable Share Action.

`[imagen omitida: wiki id 19508]`

This will add a button that allows the user to share one or a selection of images of the Image Gallery: `[imagen omitida: wiki id 19509]`  
Some info from the developers blog: <http://genexus-sd.blogspot.com/2012/01/share-button-in-image-gallery.html>

When viewing an image, you can tap on the share button:

`[imagen omitida: wiki id 19511]`     `[imagen omitida: wiki id 20081]`

The following dialogue will appear:

`[imagen omitida: wiki id 19512]`     `[imagen omitida: wiki id 20082]`

Email example:

`[imagen omitida: wiki id 19513]`     `[imagen omitida: wiki id 20083]`

Twitter example:

`[imagen omitida: wiki id 19514]`     `[imagen omitida: wiki id 20084]`

To share with Facebook, first follow this link: [HowTo: Register a Facebook App](https://wiki.genexus.com/commwiki/wiki?19399). After having everything configured on the KB to interact with Facebook the app should be able to post an image on the user's Facebook wall.

Take into consideration that the images that can be posted to Facebook have to be accesible in a public URL.

`[imagen omitida: wiki id 19515]`     `[imagen omitida: wiki id 20085]`

### [Considerations](#Considerations)

When using iOS, the Share option is enabled if any of the following is set on the device:

* Mail
* SMS
* Twitter
* Facebook
