# Responsive Web Design (RWD)

A [RWD](https://wiki.genexus.com/commwiki/wiki?25157,,) allows creating a [Responsive Web Applications](https://wiki.genexus.com/commwiki/wiki?25159): basically, the challenge is to be able to arrange the layout in a way that all the information is presented in a readable way, obtaining an optimal viewing experience across different devices, and screen sizes.

In order to achieve this, a RWD generally works with various techniques such as Fluid grids, [media queries](http://en.wikipedia.org/wiki/Media_queries), and flexible images.

GeneXus includes editing features in order to allow doing a RWD. See [GeneXus Responsive Web Applications based on Bootstrap](https://wiki.genexus.com/commwiki/wiki?29146,,)
