# Prototyping an API with Swagger

**Deprecated**: Since [GeneXus 18](https://wiki.genexus.com/commwiki/wiki?51066). Replaced by  [Launchpad Tool Window](https://wiki.genexus.com/commwiki/wiki?52315).

When you [run](https://wiki.genexus.com/commwiki/wiki?5692) an [API object](https://wiki.genexus.com/commwiki/wiki?46151) using the [GeneXus .NET Generator](https://wiki.genexus.com/commwiki/wiki?38604), the browser opens a [Swagger](https://wiki.genexus.com/commwiki/wiki?50321,,) UI and helps you in viewing and interacting with the API generated.

To execute an [API object](https://wiki.genexus.com/commwiki/wiki?46151) with Swagger, you must set its [Generate OpenAPI interface property](https://wiki.genexus.com/commwiki/wiki?31859) to Yes.

After that, you only have to right click on the API Object and select Run.

The browser will open up with a Swagger user interface that will let you view and interact with the API generated:
