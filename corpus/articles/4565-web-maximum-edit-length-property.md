# Web Maximum Edit Length Property

Sets the maximum length in characters for controls of Edit type. If it is exceeded, the control will show a horizontal scroll.

### [Scope](#Scope)

**Level:** [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836)

### [Description](#Description)

Defines the maximum length, in characters, that an attribute can have to be defined as a "simple" edit control.

If the length of an attribute exceeds this value but is lower than the [Web maximum single line edit length property](https://wiki.genexus.com/commwiki/wiki?4566) value, the associated control will be defined as having a horizontal scroll bar.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, execute a Rebuild All.
