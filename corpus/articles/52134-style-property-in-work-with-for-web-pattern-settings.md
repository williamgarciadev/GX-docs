# Style property in Work With for Web Pattern Settings

Sets the object (Design System or Web Theme) that will be assigned by default for each Work With for Web pattern instance. If not specified, the object set for the Default Style property will be used.

### [Scope](#Scope)

**Generators:** [.NET](https://wiki.genexus.com/commwiki/wiki?38604), [.NET Framework](https://wiki.genexus.com/commwiki/wiki?2892), [Java](https://wiki.genexus.com/commwiki/wiki?12258)

### [Description](#Description)

You can find this property in the [Work With for Web Pattern Settings](https://wiki.genexus.com/commwiki/wiki?5642):

`[imagen omitida: wiki id 53344]`

You may complete it with a [Web Theme object](https://wiki.genexus.com/commwiki/wiki?6420) or [Design System object](https://wiki.genexus.com/commwiki/wiki?47375) that you want to be assigned by default for each [Work With for Web pattern](https://wiki.genexus.com/commwiki/wiki?25475) pattern instance.

If not specified, the object set for the [Default Style property](https://wiki.genexus.com/commwiki/wiki?8145) will be used.

Note that since [GeneXus 18 upgrade 1](https://wiki.genexus.com/commwiki/wiki?51081) classes whose default value depends on the template used to generate the form are shown with the value <template-dependent>.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.
