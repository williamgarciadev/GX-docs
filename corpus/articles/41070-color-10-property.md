# Color 10 property

Tenth color.

### [Description](#Description)

Defines the tenth color to be assigned when using a chart [QueryViewer control](https://wiki.genexus.com/commwiki/wiki?9075).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.
