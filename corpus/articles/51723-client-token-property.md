# Client Token property

Sets the value of the unique Client Token of a Facebook application.

### [Scope](#Scope)

**Objects:** [Menu](https://wiki.genexus.com/commwiki/wiki?16321), [Panel](https://wiki.genexus.com/commwiki/wiki?24829) (Only [Main Objects](https://wiki.genexus.com/commwiki/wiki?5770))  
**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453)

### [Description](#Description)

Client tokens make requests to the Graph API on behalf of apps.

As from SDK v13.0 for Apple and Android, a [Client Token](https://developers.facebook.com/docs/facebook-login/access-tokens/#clienttokens) will be required for all calls to the Graph API.

To get the Client Token for an app, follow the steps below:

1. Sign in to your [developer account](https://developers.facebook.com/?locale=en_US).
2. In the [app page](https://developers.facebook.com/apps), select an app to open the corresponding panel.
3. In the **panel**, go to **Settings > Advanced > Security > Client Token**.

For more information, we recommend reading this documentation: [Facebook Access Token](https://developers.facebook.com/docs/facebook-login/guides/access-tokens?locale=en_US).
