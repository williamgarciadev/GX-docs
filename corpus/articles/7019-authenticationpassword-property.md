# AuthenticationPassword Property

This property indicates the server authentication password, if used

### [Syntax](#Syntax)

**&***DataType***.AuthenticationPassword**  
  
**Type Returned:**   
Character

### [Description](#Description)

When you make a SOAP call using authentication, this property indicates which password will be used.  
The default value is “”.
