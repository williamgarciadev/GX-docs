# Continent property in Query

Specifies the continent map that will be displayed.

### [Values](#Values)

|  |
| --- |
| **Africa** |
| **Antarctica** |
| **Asia** |
| **Europe** |
| **North America** |
| **Oceania** |
| **South America** |

### [Scope](#Scope)

**Objects:** [Query](https://wiki.genexus.com/commwiki/wiki?9026)  
**Generators:** [Java](https://wiki.genexus.com/commwiki/wiki?12258), .NET, [.NET Core](https://wiki.genexus.com/commwiki/wiki?38604)

### [Description](#Description)

Continent map that will be displayed in the QueryViewer when choosing to display a continent through the Region property.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

| --- |
| To apply the corresponding changes when the property value is configured, execute a [Build with this Only](https://wiki.genexus.com/commwiki/wiki?5693) of the object. |

### [Availability](#Availability)

This property is available since [GeneXus 17 upgrade 4](https://wiki.genexus.com/commwiki/wiki?47936,,).
