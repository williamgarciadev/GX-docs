# Image Height property

Image height in pixels

### [Scope](#Scope)

**Objects:** [Image](https://wiki.genexus.com/commwiki/wiki?23387)  
**Platforms:** Smart Devices(IOS)

### [Description](#Description)

Read-only property. Returns the image height in pixels.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at run-time.

### [Samples](#Samples)

&height = &image.ImageHeight

### [Availability](#Availability)

This property is available since [GeneXus 16 upgrade 2](https://wiki.genexus.com/commwiki/wiki?41525,,).
