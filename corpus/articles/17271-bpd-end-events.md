# BPD End Events

#### [Purpose](#Purpose)

An End Event marks where a process ends. There are different types of these events to indicate the varying circumstances that can end processes.

#### [Description](#Description)

An End Event is represented by a single red circle with its corresponding icon inside.

The End Events available are as follows:
