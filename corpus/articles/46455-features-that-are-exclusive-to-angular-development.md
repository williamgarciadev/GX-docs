# Features that are exclusive to Angular development

The following is a list of features that are exclusive to [Angular Application Development](https://wiki.genexus.com/commwiki/wiki?42539); that is, they may not be available for developing [Native mobile](https://wiki.genexus.com/commwiki/wiki?24799) or Web applications using the traditional approach.

## [User Controls](#User+Controls)

A [User Control object](https://wiki.genexus.com/commwiki/wiki?39356) is supported as a UI control in [Panel object](https://wiki.genexus.com/commwiki/wiki?24829)s and [Work With object](https://wiki.genexus.com/commwiki/wiki?15974)s, but it is only supported in Angular (not in Apple or Android generators).  
To use this feature, you need to create a layout that is specific to Angular.

More information at [Multiple Layouts in Panels](https://wiki.genexus.com/commwiki/wiki?23489) and [KB Platforms](https://wiki.genexus.com/commwiki/wiki?24284).

## [Tabular Grid Control](#Tabular+Grid+Control)

The [Tabular Grid control](https://wiki.genexus.com/commwiki/wiki?54449) is available since [GeneXus 18 Upgrade 3](https://wiki.genexus.com/commwiki/wiki?53853) to be included in [Panels](https://wiki.genexus.com/commwiki/wiki?24829) generated with Angular.

## [Master Panels](#Master+Panels)

The [Master Panel object](https://wiki.genexus.com/commwiki/wiki?46247) is only supported in [Panel objects](https://wiki.genexus.com/commwiki/wiki?24829) generated in Angular (not in Apple or Android generators).

## [Web Platforms](#Web+Platforms)

Web Platforms have been added to the [KB Platforms](https://wiki.genexus.com/commwiki/wiki?24284), so you can design layouts that are specific for Angular apps running in browsers or for Desktop screens.

## [Call Options (Target: Top)](#Call+Options+%28Target%3A+Top%29)

Angular supports the target Top as a [CallOptions Target](https://wiki.genexus.com/commwiki/wiki?25323).
