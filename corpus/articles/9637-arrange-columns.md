# Arrange Columns

#### [Purpose](#Purpose)

Shows information about the selected Grid and its columns.

`[imagen omitida: wiki id 9638]`

##### [Name](#Name)

Control name.

##### [Columns](#Columns)

Grid’s columns. You can select a column by clicking on it.

**Column:** Column name.

**Title:** Column title.

##### [Properties](#Properties)

Edit selected column properties. The Column Properties dialog will be displayed.

##### [Add](#Add)

Add a column. The Attribute/Variable Selector dialog will be displayed.

##### [Delete](#Delete)

Delete a column.

##### [Move Up](#Move+Up)

Move the selected column up one position.

##### [Move Down](#Move+Down)

Move the selected column down one position.
