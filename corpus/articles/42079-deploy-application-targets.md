# Deploy Application Targets

The following document lists the available targets to deploy when using the [Application Deployment tool](https://wiki.genexus.com/commwiki/wiki?32092).

The default target for every platform is "Local," which would just create the packaged app and tell the user where the package has been created.

## [Common targets](#Common+targets)

There are some common targets for every platform, as follows:

**Docker**: Creates an image with the selected web app based on the selected properties. For more information, read [HowTo: Deploy an Application to Docker](https://wiki.genexus.com/commwiki/wiki?36951)

**AWSEB**: Amazon Web Services Elastic Beanstalk. For more information, read [HowTo: Deploy an Application to AWS Elastic Beanstalk](https://wiki.genexus.com/commwiki/wiki?32104)

**AZURE**: Microsoft Azure. Deploys the web app as an Azure WebSite. For more information, read [HowTo: Deploy as an Azure Web App](https://wiki.genexus.com/commwiki/wiki?31457)

## [Java](#Java)

**AWSLAMBDA**: Only deploys [Procedures](https://wiki.genexus.com/commwiki/wiki?6293) set as [main](https://wiki.genexus.com/commwiki/wiki?7407) as Lambda functions. For more information, read [HowTo: Deploy mobile services to AWS Serverless using AWS Lambda and AWS API Gateway](https://wiki.genexus.com/commwiki/wiki?35355)

**IBM Cloud**: Deploys to IBM Cloud. For more information, read [HowTo: Deploy an application to IBM Cloud](https://wiki.genexus.com/commwiki/wiki?32150)

**GAE**: Deploys to Google App Engine. For more information, read [HowTo: Deploy an application to Google App Engine](https://wiki.genexus.com/commwiki/wiki?32211)

**HCP**: Deploys to SAP Cloud Platform. For more information, read [HowTo: Deploy an application to SAP Cloud Platform](https://wiki.genexus.com/commwiki/wiki?32059)
