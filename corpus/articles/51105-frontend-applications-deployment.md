# Frontend applications deployment

Frontend applications, such as [Angular](https://wiki.genexus.com/commwiki/wiki?42550) applications, can be deployed to any Cloud Provider Object Storage or to docker.

The [Application Deployment tool](https://wiki.genexus.com/commwiki/wiki?32092) supports the deployment to [AWS S3](https://aws.amazon.com/es/s3/) and [Azure Blob Storage](https://azure.microsoft.com/en-us/services/storage/blobs/) and to docker containers.

You can use the Application Deployment tool from inside the GeneXus IDE, or MSBuild commands.

Note: You have to build the application using the following settings:

* [Build Mode](https://wiki.genexus.com/commwiki/wiki?49860)= Distribution
* [Run Target](https://wiki.genexus.com/commwiki/wiki?49730)= Default

### [Availability](#Availability)

The deploy to docker support is added since [GeneXus 17 Upgrade 11](https://wiki.genexus.com/commwiki/wiki?49972,,)
