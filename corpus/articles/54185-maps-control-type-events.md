# Maps Control Type Events

These are some events that you can use when having a Grid with its [Control Type property set to Maps](https://wiki.genexus.com/commwiki/wiki?15309) in a [Panel object](https://wiki.genexus.com/commwiki/wiki?24829).

#### [**[GeographySaved Event](https://wiki.genexus.com/commwiki/wiki?46858)**](#wiki%3F46858%2CGeographySaved%2BEvent+GeographySaved+Event)

It is launched when you finish editing a geometry.

#### [**[MarkerDragStarted Event](https://wiki.genexus.com/commwiki/wiki?46859)**](#wiki%3F46859%2CMarkerDragStarted%2BEvent+MarkerDragStarted+Event)

It is launched when you start dragging a geoPoint.

#### [**[MarkerDragEnd Event](https://wiki.genexus.com/commwiki/wiki?46860)**](#wiki%3F46860%2CMarkerDragEnd%25C2%25A0Event+MarkerDragEnd+Event)

It is launched when you finish dragging a geoPoint.

#### [**[SelectionChanged Event](https://wiki.genexus.com/commwiki/wiki?36236)**](#wiki%3F36236%2CSelectionChanged%2BEvent+SelectionChanged+Event)

It is triggered every time an index is selected or deselected on the map, both by code and manually by the application user.
