# GXflow Organizational Units Definitions

The *Organizational Units Definitions* application can be accessed from the [GXflow Management Console](https://wiki.genexus.com/commwiki/wiki?9340).

The organizational units definitions allows to define the organizational units structure. Please read [HowTo: Work With Organizational Units](https://wiki.genexus.com/commwiki/wiki?13650) to see an example on how organizational units are used.

`[imagen omitida: wiki id 52090]`

The following sections describe the different components making up this application.

### [Actions](#Actions)

* **New**: It allows to add new organizational units definitions.
* **Edit**: It allows to edit organizational units definitions.
* **Remove**: It allows to remove organizational units definitions.
* **Display**: It allows to display organizational units definitions.

### [Organizational Units Grid](#Organizational+Units+Grid)

This grid has the following options:

* `[imagen omitida: wiki id 52013]` It allows refreshing the grid.
* `[imagen omitida: wiki id 52012]` It allows selecting the columns wanted to be visible.
* It is possible to sort some columns by clicking on their title.

This grid consists of the following columns:

* Name: organizational unit definition name.
* Description: organizational unit definition description.
