# GeneXus for SAP Systems - Initialize Fiori

After creating a [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836) as shown in [GeneXus for SAP Systems - First Application](https://wiki.genexus.com/commwiki/wiki?34041), you have to choose the Fiori Design System version according to your needs and initialize/import the corresponding resources to generate the User Interfaces.

To do so, select one of the following options:

* Tools > Fiori > Initialize Fiori Horizon
* Tools > Fiori > Initialize Fiori 3.0
* Tools > Fiori > Initialize Fiori 2.0
