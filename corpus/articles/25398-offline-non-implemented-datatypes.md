# Offline non-implemented DataTypes

This document lists the non-implemented DataTypes for [offline applications](https://wiki.genexus.com/commwiki/wiki?22228) for each Smart Devices platform.

The specification error "[spc0106](https://wiki.genexus.com/commwiki/wiki?6433)" occurs for offline objects that use some of the following non-available DataTypes:

| Data Type | iOS | Android |
| --- | --- | --- |
| ContentInfo | Not Available | Not Available |
| Cookie | Not Available | Not Available |
| Crypto | Not Available | **Available** |
| DBConnection | Not Available | **Available** |
| ExcelDocument | Not Available | Not Available |
| Expression | Not Available | **Available** |
| Geography | Not Available | Not Available |
| HttpResponse | Not Available | Not Available |
| LDAPClient | Not Available | Not Available |
| Location | **Available (1)** | **Available** |
| MailMessage | Not Available | Not Available |
| MailRecipient | Not Available | Not Available |
| MAPISession | Not Available | Not Available |
| OutlookSession | Not Available | Not Available |
| POP3Session | Not Available | Not Available |
| Queue | Not Available | Not Available |
| QueueMessage | Not Available | Not Available |
| SearchResult | Not Available | Not Available |
| SearchResultItem | Not Available | Not Available |
| SMTPSession | Not Available | Not Available |
| WApi | Not Available | Not Available |
| WebWrapper | Not Available | Not Available |
| Window | Not Available | Not Available |
| WordDocument | Not Available | Not Available |

**(1)** from GeneXus 15 Upgrade 1
