# iOS Deployment Target property

The minimum iOS deployment target to use when generating the Xcode project.

### [Scope](#Scope)

**Objects:** [Menu](https://wiki.genexus.com/commwiki/wiki?16321), [Panel](https://wiki.genexus.com/commwiki/wiki?24829), [Work With](https://wiki.genexus.com/commwiki/wiki?15974) (Only [Main Objects](https://wiki.genexus.com/commwiki/wiki?5770))  
**Level:** Front end

### [Description](#Description)

This property is available at front end level and it is also available for [Panel object](https://wiki.genexus.com/commwiki/wiki?24829)s, [Work With objects](https://wiki.genexus.com/commwiki/wiki?15974), and [Menu object](https://wiki.genexus.com/commwiki/wiki?16321)s configured as [Main Object](https://wiki.genexus.com/commwiki/wiki?5770).

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, Build the [Main Object](https://wiki.genexus.com/commwiki/wiki?5770).
