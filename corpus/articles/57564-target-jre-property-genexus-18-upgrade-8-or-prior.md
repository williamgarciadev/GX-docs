# Target JRE property (GeneXus 18 Upgrade 8 or prior)

Defines the Java Runtime Environment version where the deployed application will run

### [Values](#Values)

|  |
| --- |
| **JRE 6** |
| **JRE 7/8** |
| **JRE 9 (or higher)** |

### [Scope](#Scope)

**Generators:** [Java](https://wiki.genexus.com/commwiki/wiki?12258)  
**Level:** Deploy Target Options

### [Description](#Description)

The Target JRE property is used in the deploy engine to determine which jars to deploy when the libraries have different jars depending on the version of JRE that is used at runtime.

### [Availability](#Availability)

This property is available since [GeneXus 15 upgrade 12](https://wiki.genexus.com/commwiki/wiki?39737,,).
