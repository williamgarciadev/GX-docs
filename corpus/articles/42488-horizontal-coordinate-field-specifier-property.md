# Horizontal Coordinate Field Specifier property

SDT field indicating the horizontal coordinate where the item will be placed in an SD Image Map control.

### [Scope](#Scope)

**Objects:** Panel for Smart Devices, Work With for Smart Devices  
**Platforms:** Smart Devices(Android, IOS)  
**Controls:** Grid

### [Description](#Description)

The property is enabled when a [Structured Data Type (SDT) object](https://wiki.genexus.com/commwiki/wiki?10021) variable is used in the [Horizontal Coordinate Attribute property](https://wiki.genexus.com/commwiki/wiki?42487).

A numeric value that represents the X coordinate of the left upper corner of the element in the SD Image Map (red).

`[imagen omitida: wiki id 42484]`

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [[How to apply changes](https://wiki.genexus.com/commwiki/wiki?17719)](#com.gxwiki.wiki%3F17719%2CApplying%2Bproperty%2Bchanges+How+to+apply+changes)

To apply the corresponding changes when the property value is configured, execute a [Build with this Only](https://wiki.genexus.com/commwiki/wiki?5693) of the object.
