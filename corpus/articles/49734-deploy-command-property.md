# Deploy Command property

Sets the command used to deploy the Angular application.

### [Scope](#Scope)

**Generators:** [Angular](https://wiki.genexus.com/commwiki/wiki?42550)  
**Level:** Generator

### [Description](#Description)

The default value for this property is "npm run deploy." It is a command that executes the generated script to run the deployment process. That script depends on the "Run Target property" value.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design-time.

### [Availability](#Availability)

This property is available since [GeneXus 17 Upgrade 5](https://wiki.genexus.com/commwiki/wiki?48247,,).
