# Database Reverse Engineering

Would you like your GeneXus application to access [Data Stores](https://wiki.genexus.com/commwiki/wiki?7117) defined in other databases? Furthermore: do you have an existing database over which you want to run a full GeneXus application?

The Database Reverse Engineering allows you to do so by applying ***Reverse Engineering*** to existing databases. This means that it reads all schema information from a database's table structure and their relationships, and creates all necessary GeneXus objects (Tables, [Transactions](https://wiki.genexus.com/commwiki/wiki?1908), [Data View](https://wiki.genexus.com/commwiki/wiki?1914), [Subtypes](https://wiki.genexus.com/commwiki/wiki?20206)) to represent that schema.

*Reverse Engineering* is a broad term, but in this scenario, it means reading a database's table structure and their relationships and defining the necessary [GeneXus](https://wiki.genexus.com/commwiki/wiki?1756) Objects (data model) to represent the schema.
