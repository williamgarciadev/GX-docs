# GetProximityAlerts method

Returns the collection of [ProximityAlerts](https://wiki.genexus.com/commwiki/wiki?25185) which have been [set](https://wiki.genexus.com/commwiki/wiki?25166) in the device and are still active.

**Type Returned:**[GeolocationProximityAlerts SDT](https://wiki.genexus.com/commwiki/wiki?25185) (A list of the set alerts).

**Note**: This method cannot be used on the server side. If used, the [spc0200](https://wiki.genexus.com/commwiki/wiki?6774) message will be displayed.
