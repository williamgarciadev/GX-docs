# Mapbox API Private Key property

Sets the Mapbox API Private Key.

### [Scope](#Scope)

**Objects:** [Panel](https://wiki.genexus.com/commwiki/wiki?24829)  
**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453)

### [Description](#Description)

This property is available when the [Android Maps API property](https://wiki.genexus.com/commwiki/wiki?22729) is set to "Mapbox API." It is necessary to use the Mapbox Maps provider. To get a valid API key value, refer to [Mapbox Access Token](https://account.mapbox.com/access-tokens/).

### [Availability](#Availability)

This property is available since [GeneXus 17 upgrade 4](https://wiki.genexus.com/commwiki/wiki?47936,,).
