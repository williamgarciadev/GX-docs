# Type Property

Returns the Qualified Name of the object.

### [Syntax](#Syntax)

*object***.Type**

**Where:**  
  
*object*  
    Is the name of a [GeneXus object](https://wiki.genexus.com/commwiki/wiki?1866) defined in the [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836).

**Type returned**  
Character

### [Description](#Description)

This property returns the [Qualified Name](https://wiki.genexus.com/commwiki/wiki?22477) of the object.

### [Run-time/Design-time](#Run-time%2FDesign-time)

This property applies only at run-time.
