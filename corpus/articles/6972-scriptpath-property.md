# ScriptPath Property

Returns the URL portion corresponding to the virtual directory name.

### [Syntax](#Syntax)

**&***DataType***.ScriptPath**  
  
**Type Returned:**   
String

### [Scope](#Scope)

**Extended Data Types:** [HttpRequest](https://wiki.genexus.com/commwiki/wiki?6933)  
**Languages:** .NET, Java, Ruby (up to GeneXus X Evolution 3)
