# Google Analytics Control

The Google Analytics control allows you to integrate all the features provided by [Google Analytics](http://www.google.com/analytics/) in your websites.

To use this control, follow the steps below:

1. Define the object of your application that will contain the control (in general a master page is a good option); to do so, define a [Web Panel object](https://wiki.genexus.com/commwiki/wiki?6916).
2. Drag the control from the [Toolbox](https://wiki.genexus.com/commwiki/wiki?10000) to your Web form:  
   `[imagen omitida: wiki id 55325]`
3. Configure the following properties at the control level:  
   `[imagen omitida: wiki id 55326]`
   * [Domain Name](https://wiki.genexus.com/commwiki/wiki?55328)
   * [Code](https://wiki.genexus.com/commwiki/wiki?55327)
   * [Dimensions](https://wiki.genexus.com/commwiki/wiki?48674)
