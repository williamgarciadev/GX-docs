# Java Method Throws Exceptions property

It indicates whether the method in the external class sends an exception.

### [Values](#Values)

|  |  |
| --- | --- |
| **No** | The Java method won't throw the exceptions. This is the default value. |
| **Yes** | The Java method will throw the exceptions. |
