# HowTo: Change Your Inbox Theme

This article shows you the steps to follow to change your Inbox Theme to grey:

**1.** Download and unzip the file from [here](https://www.genexus.com/en/developers/downloadcenter?data=3147;GXflow%20Themes;).

**2.** If you are working with [.NET](https://wiki.genexus.com/commwiki/wiki?38604) environment must copy to the web directory of the model. (C:\Models\<KB>\<directorio del modelo>\Web).

**3.** If you are working with
[Java](https://wiki.genexus.com/commwiki/wiki?12258) environment must copy to the static directory of the web application. (C:\Program Files\Apache Software Foundation\Tomcat 5.5\webapps\<web application>\static).

**Note**: You must backup the folder with the blue theme.
