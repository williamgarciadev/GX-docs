# Calendar external object

With the Calendar external object, you can allow the end user to select a date to input into the application using a calendar.

|  |  |
| --- | --- |
|  |  |

### [Properties](#Properties)

It does not have any.

### [Methods](#Methods)

### [Schedule method](#Schedule+method)

Allows you to schedule a task on the end user's calendar. All parameters are optional except Title and StartDate.

|  |  |
| --- | --- |
| **Return value** | None |
| **Parameters** | Title:Character(30), StartDate:[Date](https://wiki.genexus.com/commwiki/wiki?7373), EndDate:[Date](https://wiki.genexus.com/commwiki/wiki?7373), StartTime:[Time](https://wiki.genexus.com/commwiki/wiki?15050), EndTime:[Time](https://wiki.genexus.com/commwiki/wiki?15050), Place:Character(30) |
