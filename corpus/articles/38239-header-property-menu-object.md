# Header property (Menu object)

Specifies an image header.

### [Scope](#Scope)

**Objects:** [Menu](https://wiki.genexus.com/commwiki/wiki?16321)  
**Generators:** [Android](https://wiki.genexus.com/commwiki/wiki?14453)

### [Description](#Description)

The property applies to the root item of the [Menu object](https://wiki.genexus.com/commwiki/wiki?16321) and allows you to display a header image on the application (through an [Image object](https://wiki.genexus.com/commwiki/wiki?23387) stored in the [Knowledge Base](https://wiki.genexus.com/commwiki/wiki?1836)).

### [Notes](#Notes)

* In Android, this property is ignored when the Menu object has the [Control property](https://wiki.genexus.com/commwiki/wiki?16098) set to "Tabs".

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at run-time.
