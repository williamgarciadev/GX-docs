# Telegram Bot Token property

Defines a Telegram authorization Token.

### [Scope](#Scope)

**Objects:** [Conversational Flows Instance](https://wiki.genexus.com/commwiki/wiki?37113)

### [Description](#Description)

To enable integration with Telegram, the [Enable Telegram property](https://wiki.genexus.com/commwiki/wiki?48119) must be set to True. After activating the property, it will be necessary to set up the token assigned by Telegram that will identify the bot.

### [Runtime/Design time](#Runtime%2FDesign+time)

This property applies only at design time.

### [Availability](#Availability)

This property is available since [GeneXus 17 upgrade 4](https://wiki.genexus.com/commwiki/wiki?47936,,).
