# AttributeCount Property

It returns the number of attributes in the current node, obtained through the Read or ReadType methods.

### [Syntax](#Syntax)

**&***DataType***.AttributeCount**  
  
**Type Returned:**   
Integer

### [Description](#Description)

This property is used to return the number of attributes in the current node, which is obtained with the Read or ReadType methods.  
  
**Note:**  
It is valid for Element type nodes only.

### [Scope](#Scope)

**Extended Data Types:** [XmlReader](https://wiki.genexus.com/commwiki/wiki?6928)  
**Languages:** .NET, Java, Ruby (up to GeneXus X Evolution 3), Visual FoxPro (up to GeneXus X Evolution 3)
