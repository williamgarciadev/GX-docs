# Chatbot Message

The Message node (child of the [Chatbot Response](https://wiki.genexus.com/commwiki/wiki?39781)) includes the [Condition](https://wiki.genexus.com/commwiki/wiki?39491), and the [Style](https://wiki.genexus.com/commwiki/wiki?39492) to show the message.

You can define as many Messages as necessary (they will be shown depending on the Condition).

Depending on the [Style](https://wiki.genexus.com/commwiki/wiki?39492) selected, you will have additional properties to configure. In particular, when the Style = "Component view", you need to configure the [Show Response As property](https://wiki.genexus.com/commwiki/wiki?39494) and decide whether you will use an auto-generated component ([Generated Component property](https://wiki.genexus.com/commwiki/wiki?39880) or [Generated Web Component property](https://wiki.genexus.com/commwiki/wiki?39884)) or a custom component ([SD Component property](https://wiki.genexus.com/commwiki/wiki?39878,,) or [Web Component property](https://wiki.genexus.com/commwiki/wiki?39885)).

`[imagen omitida: wiki id 39877]`

Response Parameters are used to automatically generate the response views when you use auto-generated components.

If you remove any of the Response parameters, they won't be included in the auto-generated view.
